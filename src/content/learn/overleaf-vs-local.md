# Browser project vs folder on disk

## The trade

| | Cloud (e.g. Overleaf) | Local (Oleafly / TeX Live) |
| --- | --- | --- |
| Setup | Instant | One install |
| Offline | Limited | Full |
| Privacy | Provider can see projects | Files stay on disk |
| Git | Via link / sync | Native |
| Collaboration | Real-time cursors | Git, patches, shared folders |
| Cost | Free tier + paid | Free |

## When cloud still wins

Live pair-writing under a deadline with coauthors who will not install anything.

## When local wins

Sensitive drafts, air-gapped machines, large figure assets, and anyone who wants real Git history on every compile.

Oleafly is built for the local side: bundled engine, a library of projects, and optional AI with your own key. Longer take on the [blog](/blog/local-first-vs-cloud-latex-editors/).
