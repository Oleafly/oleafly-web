# 不適合的方程

推導遲早會產生一個比文字區塊更寬的方程，而 LaTeX 會讓它進入邊緣，而不是猜測在哪裡打破它。兩個“amsmath”環境允許您自己放置中斷：“multline”用於單一長表達式，“split”用於應保持對齊的中斷。

## 多行

```latex
\begin{multline}
 a + b + c + d + e + f \\
 + g + h + i + j
\end{multline}
```

“multiline”適合沒有自然對齊點的長公式。您可以使用「\\」選擇分隔符，環境會處理佈局：第一行設定為左對齊，最後一行設定為右對齊，所有中間行都居中。整個表達式得到一個方程式編號，放在最後一行。約定是在二元運算子之前中斷，因此「+」開啟續行，讀者一眼就能看出表達式繼續進行。

＃＃ 分裂

```latex
\begin{equation}
\begin{split}
 a &= b + c \\
 &\quad + d + e
\end{split}
\end{equation}
```

`split` 也會產生一個數字，但以 `align` 的方式對齊其行，並用 `&` 標記對齊點。它不是一個獨立的環境；它位於「equation」或另一個提供數字的顯示環境中。這裡，「&」位於第一行等號之前，延續以「&\quad」開始，這是一個空對齊點，後面跟著一個四邊形的空格，因此第二行縮排正好經過等號。這個縮排告訴讀者這仍然是右邊，而不是一個新的方程式。

## 在它們之間做選擇

當方程式是一個長和且沒有值得對齊的結構時，請使用“multiline”。當有等號應掛在其下時，請使用“split”。如果你有幾個真正獨立的方程，那麼沒有一個是正確的。這是「align」的工作，包含在[排列的多行方程式](/learn/align-equations/) 中。

在嘗試其中任何一個之前，請考慮重寫數學。在前面的句子中命名子表達式、因式分解或分解為兩個方程式通常可以控制寬度並且讀起來也更好。喜歡這樣做而不是縮小類型。擠壓的顯示器幾乎總是比完全斷裂的顯示器讀起來更糟。

需要了解的一個錯誤：單獨使用 `split`，如果沒有封閉的 `equation`，會因「Package amsmath Error」而停止。先封裝，再編譯。這兩種環境都可以在[現場遊樂場](/live/) 中快速進行實驗。
