## 你在云中放弃了什么

您的手稿位于其他人的数据库中。导出通常有效，直到
计划发生变化、公司被收购或某个功能消失，而您的
截止日期保持不变。

静态加密可将外人拒之门外。服务本身还是可以看到的
通过其基础设施的草案、赠款和未发表的结果。

延迟是另一个安静的成本。您的机器上处理的击键几乎是
总是更加敏捷。编译队列和免费层超时仅在以下情况下显示
构建不是你的。

线下是另一个差距。在飞机上、医院地下室或安全的地方
在没有开放网络的实验室中，浏览器编辑器只是一个空白选项卡。

一些托管编辑器还提供完整的历史记录、跟踪更改或 Git/GitHub 同步
落后于付费等级。 Local Git 并不关心你购买了哪个计划。

## 网络仍然发生（故意）

本地工具仍然可以获取首次使用包、模板包、引用
元数据、托管人工智能（如果您打开它）、Git 远程和更新。重点是
默认值：起草和缓存编译保留在磁盘上。

项目、元数据、构建和 Git 历史记录都在本地保存。网络运行时
你采取了需要它的行动。编辑和缓存编译应该可以工作
离线。粘贴 DOI 或启用云模型，这些请求就会发送到您的位置
瞄准了他们。在任何隐私文章中清楚地说出这一点，而不是假装
网络永远不会发生。

## 纸堆周围

研究周几乎从来都不是“只是编辑”。它通常是以下内容的组合：

- 具有真实项目智能的写作环境
- TeX 分发和包维护
- 带 SyncTeX 的 PDF 查看器
- Git客户端和远程主机
- 引文查找和参考书目卫生
- 语法和拼写工具
- 图表或图形管道
- 截止日期和其他辅助工具

当这些部分位于同一位置时，本地研究工作空间会很有用
普通文件夹项目：项目感知编辑器（参考文献、引用、宏、结构、
数学预览、离线校对）、监督编译、PDF 工作区
耐过时的 SyncTeX、自动 Git 检查点、导入和导出、预检
在提交之前，可选代理必须显示差异。

## Oleafly 适合的地方

[Oleafly](https://github.com/Oleafly/Oleafly) 是为该类别构建的：免费，
LaTeX、Typst 和 Markdown 的开源桌面工作区。捆绑式
编译器。具有叉子和搜索功能的项目库。项目范围的编辑器
情报（定义、参考文献、重命名、实时引用/引用检查、结构
视图、带有参数形状的宏、TexLab/Tinymist（如果可用）。直播
数学预习。仅离线哈珀和亨斯佩尔散文。集成 PDF 与
双向 SyncTeX 在重建挂起时仍然可以映射。真正的 Git
自动检查点和可选的 GitHub。引文搜索和粘贴。图解
可编辑 TikZ 的作曲家。飞行前。可选的批准门控人工智能与您的密钥
或当地的奥拉马。

[隐私页面](/privacy/) 故意保持简短：没有 Oleafly 帐户，没有
产品遥测。草稿存在于您的机器上。托管人工智能、引文查找和
GitHub 根据其政策与这些服务进行对话，使用您的密钥和您的
行动。

如果您想小尝鲜而不安装，[免费浏览器
工具](/tools/) 运行客户端。桌面应用程序是智能的所在，
编译、历史和项目树实际上满足。

## 当云仍然获胜时

当实时共同创作是产品时，当
合作者不会安装任何东西，或者当您的机构已经
对提交的托管编辑器进行标准化。

将工具与您实际拥有的星期相匹配。如果您需要实时多用户
键入内容，留在浏览器中（或者当合著者可以异步工作时使用 Git）。如果你
更关心所有权、线下深度和完整的本地研究编辑，
将手稿作为文件保存在磁盘上，在您的计算机上构建 PDF，然后保留
任何 Git 工具都可以打开的存储库中的历史记录。
