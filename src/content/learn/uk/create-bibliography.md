# Створіть довговічний .bib

Файл `.bib` — це невелика база даних у вигляді звичайного тексту з усім, що ви можете цитувати. Кожен запис має тип, ключ і набір полів, і той самий файл може служити для кожної статті, яку ви пишете роками. Трохи дисципліни зараз у тому, як ви вибираєте типи, заповнюєте поля та ключі імен, позбавляє від справжнього болю пізніше, коли стиль журналу раптом захоче поле, яке ви ніколи не записували.

## Анатомія запису

```bibtex
@article{knuth84,
  author  = {Knuth, Donald E.},
  title   = {Literate Programming},
  journal = {The Computer Journal},
  year    = {1984},
  volume  = {27},
  number  = {2},
  pages   = {97--111}
}
```

Слово після `@` є типом запису, який повідомляє стилю, що це за робота і, отже, які поля очікувати. `knuth84` — це ключ цитування, дескриптор, який ви вводите всередині `\cite{...}`. Все інше – поле. У полі «автор» використовується форма «Прізвище, ім’я», щоб стиль міг надійно скорочувати та сортувати імена, а в полі «сторінки» використовується подвійний дефіс, який LaTeX набирає як тире діапазону сторінок.

## Типи записів, які вам дійсно потрібні

Шість типів охоплюють майже всі академічні письма. Використовуйте `@article` для журнальних статей, `@inproceedings` для конференцій і семінарів, `@book` для книг, `@phdthesis` для дисертацій, `@techreport` для інституційних звітів і багатьох препринтів і `@misc` для всього іншого, включаючи програмне забезпечення та веб-сайти. Вибір правильного типу має значення, оскільки стилі форматують кожен із них по-різному: для запису `@inproceedings` потрібен `booktitle` (назва конференції), а для `@article` — `journal`.

## Обов'язкові поля та чому валідатори скаржаться

Кожен тип має обов’язкові поля, і відсутність одного є найпоширенішою причиною того, що запис бібліографії виявляється спотвореним або викликає попередження серверної частини. Для `@article` основними є `автор`, `назва`, `журнал` і `рік`; для `@inproceedings`, `author`, `title`, `booktitle` і `year`. Відсутність `year` або `author` є класичною помилкою, оскільки стилі авторського року буквально не можуть створити мітку цитування без них. Додаткові поля, такі як `volume`, `pages`, `doi` і `publisher`, роблять записи більш корисними, тому записуйте їх, поки джерело буде перед вами. Ви можете перевірити весь файл одразу за допомогою [валідатора BibTeX](/tools/bibtex-validator/).

## Ключі, які виживають десятиліття

Ключі цитування назавжди. Кожен `\cite{knuth84}` у кожній чернетці, нотатці та слайді стосується саме цього рядка, тому перейменування ключа означає відстеження кожного використання. Виберіть угоду, наприклад `authorYEAR` або `authorYEARkeyword`, застосовуйте її з першого дня та ніколи не "очищайте" ключі у встановленій базі даних. Якщо ви керуєте посиланнями в Zotero, плагін Better BibTeX може генерувати та закріплювати стабільні ключі для вас; див. [Zotero у файл .bib](/learn/zotero-latex/). Щоб підключити файл до документа, почніть із [From .bib key to in-text cite](/learn/add-citations/).
