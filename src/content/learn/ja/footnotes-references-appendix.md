# 脚注、参考文献、付録: 誰が何をするのか

論文には、メインフローに属さない内容を配置する場所が 3 か所あり、それぞれに異なる役割があります。適切なコンテンツを適切な場所に配置すれば、読者は集中力を維持できます。これらを混ぜ合わせると、紙はジャンクの引き出しのようになります。

## 脚注: 丁寧な話はさておき

脚注は、URL、説明、注意事項、「この指摘について査読者に感謝します」など、言う価値はあるが文を中断するほどではない内容に使用されます。

```latex
We use the standard split.\footnote{Available at
\url{https://example.org/data}.}
```

慎重に使用してください。段落ごとに脚注がある論文は、それ自体を議論している論文です。コンテンツが重要な場合は、テキストに昇格します。先行研究が引用可能な場合は、代わりに参考文献に属します。また、適切な引用を優先して URL の脚注を禁止している会場もあるので、テンプレートを確認してください。

## 参考文献: 証拠の痕跡

著作物を引用するときは、主張の背後にある証拠を指していることになります。つまり、この事実はそこで確立され、この方法は彼らによって導入され、このデータセットはここから来たものです。参考文献リストは、誰に基づいて構築されているかを示す完全な地図であり、査読者は、エントリの欠落や、実際には裏付けられていない引用に固定された主張がないかを注意深くチェックします。

LaTeX では、仕組みは自動的です。テキスト内の `\cite{key}`、`.bib` ファイル内のエントリ、そしてリストが自動的にレンダリングされます。

```latex
Transformers \cite{vaswani2017attention} replaced recurrence
with attention.
```

完全なワークフローは、[引用文献の追加](/learn/add-citations/) と [文献目録の作成](/learn/create-bibliography/) にあります。 Oleafly は、DOI ルックアップから `.bib` エントリを埋めることができ、著者リストを手入力するよりも優れています。

## 付録: オーバーフロー ルーム

付録には、完全なプルーフ、追加の結果テーブル、ハイパーパラメータ グリッド、プロンプト テンプレート、データセットのドキュメントなど、論文をサポートするもののフローを壊す可能性のある資料が含まれています。本紙は単独で存在しなければならないというのがルールだ。付録を開いたことがない読者でも、納得できるはずです。実際にそれを開いた読者は、約束されたすべての詳細を見つけることができるはずです。

```latex
\appendix
\section{Full proofs}
```

`\appendix` の後に、セクション自体に A、B、C という文字が自動的に付けられます。

## 補足資料: PDF の外

補足資料は、コード、データ、ビデオ、インタラクティブなデモなど、PDF にまったく含めることができないすべてのものです。多くの会場では、独自のサイズ制限のある個別のアップロードとしてデータを収集します。これを再現性ストーリーの一部として扱い、メソッドのセクションから明示的に参照して、読者がその存在を認識できるようにします。

## 実際に誰が何を読むのか

|パート |査読者の行動 |
|---|---|
|脚注 |ついでに読んでもすぐ忘れる |
|参考文献 |不足している作業、特に自分自身の作業をスキャンします。
|付録 |論文内の主張を確認する必要がある場合に開かれます |
|補足 |コードを実行する 1 人のレビュー担当者によって開かれます |

これが実際に意味することは、脚注や付録で重要なことは決して隠さないことです。査読者は本文を判断するものであり、「答えは付録 F にありました」と言って査読が和らぐことは一度もありません。スキムが見つけやすい場所に最高の資料を置き、バックマターに最も得意なこと、つまり領収書を静かに保持することを任せます。
