如果您是在桌面 LaTeX 环境下长大的，打开 [TeXstudio](https://www.texstudio.org/)，该工具就会立即发挥作用。结构视图。自动完成。一千个符号。表格和公式向导。 PDF 并排。 SyncTeX。将运行您配置的任何链的构建系统。在很长一段学术历史中，这就是桌面 LaTeX。

论文具有多文件和多工具。人们开始期待项目架、自动历史记录、引文搜索、理解源代码的离线语法、用于快速笔记的 Typst、可以编译和显示差异的可选人工智能。 UI 模式发生了变化。 TeXstudio 仍然是 TeX 的工作室（围绕您安装的发行版的可定制 IDE），而不仅仅是围绕手稿的所有内容的研究工作区。

接下来是批判性的审视。优点、缺点、比较表，然后如何在不扔掉 TeXstudio 的情况下尝试现有的树。

## 留下来的理由

**增强力量。** 自由形式的多工具链、latexmk 风格的配方、shell 转义工作流程、“我的大学课程只有在运行 X 然后运行 ​​Y 时才有效”的长尾。如果这是您的日常工作，TeXstudio 的可配置性仍然是打开它的一个理由。

**成熟度。** 经典桌面 LaTeX 上多年的边缘情况。肌肉记忆。闭着眼睛也能找到的菜单。跨平台且免费（GPL 系列桌面传统）。

**经典 IDE 功能仍然有效。** 结构、完成、集成 PDF、SyncTeX、参考检查、折叠、拼写。对于您已经喜欢的带有 TeX Live 安装的单引擎 LaTeX 生活，核心循环已经过验证。

如果您唯一的抱怨是图标看起来过时并且构建系统已经运行您的论文，那么您不需要迁移故事。关闭此选项卡。

## 批评的理由

### 这是一个工作室，而不是人工智能时代的工作空间

TeXstudio 可以帮助您排版。它不会将项目视为现代研究台：可以编辑、编译、读取日志并显示批准差异的可选代理；用于外部工具的 MCP；带接受/拒绝的内联重写；文献检索连接到同一表面。你可以将 Copilot 连接到其他东西上，或者在没有人工智能的情况下生活。美好的。将其称为 2026 年完整的研究工作区，过分夸大了该产品的内涵。

Oleafly 的 AI 是可选且可检查的（您的密钥或 Ollama；红/绿差异；首先是 Git 检查点）。工作空间是围绕该循环形成的。 TeXstudio 围绕菜单、构建配置文件和 TeX 树构建。

### UI 感觉还是 2010 年的桌面

对话框。偏好森林。通过添加另一种形式来解决问题的辅助面板。高级用户适应。新同学蹦蹦跳跳。 “直觉”是主观的； “密集且过时”与过去几年设计的工具相比是公平的。其中一些密度是暴露每个构建旋钮的成本。其中一些只是年龄。

现代研究 UI 仍然可以是键盘优先（命令面板、多功能栏、Vim），无需通过嵌套选项进行寻宝游戏来开始论文。

### 带上你自己的多千兆字节 TeX

TeXstudio 假设 TeX Live / MiKTeX（或类似的）已经存在并保持健康。这就是力量和负担。路径问题、破坏类文件的包更新、“在我的实验室机器上运行”在合著者之间的混乱。

Oleafly 在应用程序中提供了 Tectonic 和 Typst；首次使用时包缓存；需要时通过托管 Pandoc 进行 Markdown。你放弃了自由形式的多工具配方，转而使用一个不属于你周末的受监督引擎。大量的出版商类别仍然可能会绊倒 Tectonic（大声说出来），而大多数 ACM/IEEE/Elsevier 风格的工作都很好。

### 项目寿命很短

打开一个文件。编译。关闭。活跃论文的架子在哪里？分叉一个具有完整历史记录的简历变体？将鼠标悬停在封面上并查看 PDF 的最后一页？在每个项目中搜索一个短语？为论文添加书签？

TeXstudio 是面向文件和会话的。 Oleafly 的图书馆是面向组合的：书籍、封面、引擎徽章、前叉谱系、书签、“/docs”搜索、导出历史记录。不同的工作。

###历史和Git是别人的问题

您可以在 TeXstudio 旁边使用 Git。您将自行设置。编译和闲置编辑后的自动检查点、PDF 旁边的暂存 UI、一键恢复、AI 会话检查点 - 这是在研究工作区中产品化的，而不是在经典 IDE 中假设的。

### 多引擎和研究工具

Typst 是一流的项目。降价到 PDF。跨 arXiv / Semantic Sc​​holar / Crossref / PubMed / OpenAlex 的引文搜索。 DOI 粘贴到 `.bib` + `\cite` 中。图表画布到可编辑的 TikZ。 ATS 的预检和面向辅助功能的检查。上下文感知导出（DOCX、HTML、Beamer 的 PPTX、EPUB）。这些不是“TeXstudio 失败”；他们处于其时代和职责之外。

### TeXstudio 还做得更好的地方

可配置的多步骤构建。成熟期长。熟悉度。如果 Oleafly 的 beta 标签或 Tectonic 边缘情况让您在严格的截止日期前感到害怕，那么 TeXstudio 是保守的开放。

## 现代在相同的纯文件上看起来是什么样子

在 Oleafly 中打开相同的 `.tex` 树，区别在于集成，而不是新的文件格式：

- 项目范围的智能：定义、引用、重命名、实时引用/引用检查、结构视图、带有参数形状的宏、TexLab/Tinymist（如果可用）
- 实时 KaTeX 预览； Harper + Hunspell 仅限散文
- PDF 工作区，具有耐过时的 SyncTeX、跨页、分离窗口
- 从第一天开始就真正的 Git；免费 GitHub 同步
- 具有完整历史记录的库叉
- LaTeX + Typst + Markdown
- 可选的AI / MCP由您控制
- 模板（23 个捆绑包 + 99 个包）、预检、多格式导出
- 永久免费（AGPL），无需帐户

**缺点。**公开测试版。监督编译模型（配方保留在 TeXstudio 中）。实时多用户编辑仍在路线图上（今天是 Git）。目前以英语为主的校对。在严格的截止日期之前尝试一篇低风险的论文。

## 每个工具的一天

**TeXstudio 日。** 打开昨天的文件。希望 TeX 安装仍然匹配。调整构建配置文件，因为日志类需要一个奇怪的链。 PDF 更新。如果您已经熟悉了迷宫，那么您的工作效率就会很高。

**油叶日。** 打开架子。选择论文或分叉的简历。类型;自动编译； SyncTeX 即使 PDF 正在迎头赶上。损坏的“\cite”在日志小说之前亮起。当你煮咖啡时检查点发生了。可选：要求代理尝试修复，批准差异，如果有误则恢复。

有一天是经典的工作室工艺。另一个是围绕相同来源的研究台自动化。根据您面前的文件进行选择，而不是根据身份。

## 无需硬切换即可移动

1. 保持TeXstudio安装。
2. 从以下位置下载 Oleafly
   [发布页面](https://github.com/Oleafly/Oleafly/releases/latest)。
3.导入同一棵树；编译；看看编辑器和库是否可以节省您的时间。
4. 在TeXstudio上留下噩梦般的菜谱文档。移动那些只需要可靠的发动机和现代化的办公桌的人。

## 结束

TeXstudio 最初是一个 TeX 工作室。它仍然在构建和成熟度方面赢得了尊重。它从未成为人工智能时代的研究工作区，它的用户界面也从未假装如此。

如果您想要经典 IDE 并且您已经拥有 TeX Live，请留下来。如果你想要一个免费的现代办公桌——深度编辑器、真正的 Git、多引擎、引文、可选的人工智能、作品集库——在相同的普通文件上，打开一篇论文，一天后做出决定。消息来源并不关心关注哪个应用程序。
