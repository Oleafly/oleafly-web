# 一列或两列

打开十张纸，你会看到两个部落：密集的两栏页面，看起来像新闻纸，以及通风的单栏页面，看起来像一本书。两者都不是更好。每一种进化都有其原因，而选择几乎永远不是你能做出的。

## 为什么场地不同

两栏布局是会议传统，诞生于会议记录印刷和页面预算紧张的情况下。窄栏每页包含更多字数，短行更容易浏览。大多数 CS 会议（ACM、IEEE 等）仍在使用它们。

一栏布局在期刊、预印本和论文中占主导地位。它们给方程、数字和表格提供了喘息的空间，而且更适合长篇阅读。正是由于这个原因，预印本服务器和许多机器学习场所已经转向单列。

|布局|典型家居|个性|
|---|---|---|
|两栏|会议记录|密集、可扫描、页数有限 |
|一栏|期刊、预印本、论文 |宽敞、可读、易于方程式 |

## 两列对你的数据有何影响

在两列文档中，普通的“图形”浮动在一列中，这对于详细绘图来说通常太窄。带星号的变体跨越两列：

```latex
\begin{figure*}
  \centering
  \includegraphics[width=\textwidth]{wide-results.pdf}
  \caption{A figure that needs the full page width.}
\end{figure*}
```

对于带有“table*”的宽表，同样的技巧。一个问题：加星号的浮动通常会出现在页面的顶部，不能使用底部或此处的位置，因此请尽早规划您的宽图。尺寸调整基础知识位于[插入图像](/learn/insert-images/)。

## 方程变得狭窄

大约 3.3 英寸宽的柱子不适合长方程。在两栏论文中，您将更频繁地打破方程，更积极地缩写，并依赖于多行环境。如果您的论文包含大量方程式并且您可以选择地点，那么单栏将节省您真正的格式化时间。有关工具，请参阅[数学模式](/learn/math-mode/)。

## 屏幕和屏幕阅读器更喜欢一栏

对于任何非正式论文提交的内容（报告、文档、简历、人们将在笔记本电脑和手机上阅读的预印本），单栏获胜。 PDF 不会重排，因此两列页面迫使屏幕阅读器和文本提取器猜测阅读顺序，并迫使人们在每个页面内上下滚动。简历解析系统因扰乱多列布局而臭名昭著。为有需要的场地预留两根柱子。

## 文档类别由你决定

这是令人放松的部分：您几乎从不手动配置它。场地为您提供了一个类或模板，并且布局也随之而来。

```latex
\documentclass{article}              % one column
\documentclass[twocolumn]{article}   % two columns
\documentclass[sigconf]{acmart}      % venue class, layout included
```

内容编写一次，切换模板即可重排所有内容。这就是 LaTeX 的用途：相同的源代码编译为两列会议版本和一列预印本（仅更改一行）。将图形保持为矢量格式，将方程保持在标准环境中，并且布局交换几乎是轻松的。
