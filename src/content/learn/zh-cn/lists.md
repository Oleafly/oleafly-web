# 项目符号、编号和定义列表

LaTeX 中的列表是环境：用 `\begin{...}` 打开一个列表，用 `\end{...}` 关闭它，并用 `\item` 标记每个条目。然后，LaTeX 会为您处理编号、项目符号、缩进和间距。最后一部分是重点。您永远不会手动重新编号任何内容，如果您删除编号列表的第三个条目，则条目四到十会默默地变成三到九。

## 三个列表环境

```latex
\begin{itemize}
 \item Bullet
\end{itemize}

\begin{enumerate}
 \item Numbered
\end{enumerate}

\begin{description}
 \item[Term] Definition style
\end{description}
```

“itemize”会生成无序的项目符号列表，当条目没有顺序（例如假设列表）时，它是正确的选择。 “enumerate”会自动对每个条目进行编号，这正是您想要按顺序发生的步骤或计划返回引用的项目的情况。您甚至可以在枚举中的“\item”后面放置“\label”，并稍后使用“\ref”引用其编号，就像使用节一样。

“描述”是三者中最不为人所知的，但非常有用。每个“\item”都采用方括号中的可选参数，并且该参数以粗体形式打印为标签，其后带有定义文本。它是词汇表、符号列表或任何“术语：解释”结构的自然环境。

## 嵌套

多级列表的嵌套环境。将完整的 `\begin{itemize} ... \end{itemize}` 块放入外部列表的 `\item` 中，LaTeX 会缩进它并自动切换项目符号。这同样适用于“enumerate”，其中嵌套会更改每个级别的编号样式：首先是阿拉伯数字，然后是字母，然后是罗马数字。 LaTeX 支持四级嵌套，这超出了任何可读文档的需要。如果你发现自己有三层深度，那么材料可能需要散文或表格。

## 自定义标签

任何单个项目都可以使用可选参数覆盖其自己的标记：`\item[(a)]` 打印“(a)”而不是项目符号或数字。这对于一次性情况很方便，但如果您想要重新设计整个列表，则手动更改每个项目会破坏自动化。为此，加载 `enumitem` 包，它允许您编写诸如 `\begin{enumerate}[label=(\alph*)]` 之类的内容，以在一处重新标记整个列表，并且还为您提供收紧垂直间距的选项。

初学者常见的一个错误是在“\item”条目之间留一个空行，希望将它们隔开。列表中的空行是无害的，但它在视觉上没有任何作用。间距由列表环境本身或“enumitem”选项控制。另一种情况是：每个列表环境在任何文本之前都必须至少包含一个“\item”，否则您会收到令人困惑的错误“有些问题——也许缺少\item”。您可以在[live Playground](/live/) 中尝试所有三个环境。
