[TeXstudio](https://www.texstudio.org/) を開くと、デスクトップ LaTeX で育ってきた人であれば、このツールがすぐに理解できます。構造ビュー。オートコンプリート。千のシンボル。テーブルと数式のウィザード。 PDF を並べて表示します。シンクテックス。構成したチェーンを実行するビルド システム。長い学問の歴史において、それはデスクトップ LaTeX でした。

論文はマルチファイルとマルチツールになりました。人々は、プロジェクトシェルフ、自動履歴、引用検索、ソースを理解するオフライン文法、高速メモ用の Typst、コンパイルして差分を表示できるオプションの AI を期待し始めました。 UIパターンを移動しました。 TeXstudio は依然として TeX のスタジオであり、インストールするディストリビューションに合わせてカスタマイズ可能な IDE であり、原稿に関するすべての研究ワークスペース以上のものです。

以下は批判的な見方です。長所、短所、比較表、そして TeXstudio を捨てずに既存のツリーを試す方法。

## 滞在する場合

**ビルドパワー。** 自由形式のマルチツールチェーン、latexmk スタイルのレシピ、シェルエスケープワークフロー、「大学のクラスは X を実行してから Y を実行した場合にのみ動作します」のロングテール。それが日常の仕事である場合でも、TeXstudio の設定可能性は、TeXstudio を開く理由になります。

**成熟度** クラシック デスクトップ LaTeX における長年にわたるエッジ ケース。筋肉の記憶。目を閉じても見つかるメニュー。クロスプラットフォームかつ無料 (GPL ファミリのデスクトップの伝統)。

**今も機能するクラシックな IDE 機能。** 構造、補完、統合 PDF、SyncTeX、参照チェック、折りたたみ、スペルチェック。すでに愛用している TeX Live インストールを使用したシングルエンジンの LaTeX ライフについては、コア ループが証明されています。

唯一の不満が、アイコンが古く見え、ビルド システムが既に論文を実行していることである場合は、移行の話は必要ありません。このタブを閉じます。

## 批判の余地がある

### これはスタジオであり、AI 時代のワークスペースではありません

TeXstudio はタイプセットに役立ちます。プロジェクトを最新のリサーチ デスクとして扱いません。ログを編集、コンパイル、読み取り、承認の差分を表示できるオプションのエージェントです。外部ツール用の MCP。受け入れ/拒否によるインライン書き換え。同じ表面に配線された文献検索。 Copilot を他のものにボルトで固定することも、AI なしで生活することもできます。大丈夫。これを 2026 年の完全な研究ワークスペースと呼ぶのは、製品の内容を誇張しすぎています。

Oleafly の AI はオプションであり、検査可能です (キーまたは Ollama、赤/緑の差分、Git チェックポイントが最初)。ワークスペースはそのループを中心に形成されます。 TeXstudio は、メニュー、ビルド プロファイル、TeX ツリーを中心に構成されています。

### UI はまだ 2010 年のデスクトップのような感じ

ダイアログ。森林を好みます。別のフォームを追加することで問題を解決するアシスタント パネル。パワーユーザーは適応します。新入生が弾む。 「直感的」とは主観的なものです。 「緻密で時代遅れ」は、ここ数年に設計されたツールに比べればかなりのものです。その密度の一部は、すべてのビルド ノブを公開するコストです。中には単なる年齢のせいもあります。

最新の研究 UI は、論文を開始するためにネストされたオプションを探し回らなくても、キーボード ファースト (コマンド パレット、オムニバー、Vim) のままにすることができます。

### 独自の数ギガバイトの TeX を持ち込む

TeXstudio は、TeX Live / MiKTeX (または同様のもの) がすでに存在し、健全なままであることを前提としています。それは力であり、負担です。 PATH の問題、クラス ファイルを壊すパッケージの更新、「私のラボ マシンでは動作する」という共同作成者間での混乱。

Oleafly はアプリ内に Tectonic と Typst を同梱しています。パッケージは最初の使用時にキャッシュされます。必要に応じてマネージド Pandoc 経由でマークダウン。週末を所有しない教師ありエンジンのための自由形式のマルチツール レシピを放棄することになります。ほとんどの ACM/IEEE/エルゼビア スタイルの作品は問題ありませんが、大量のパブリッシャー クラスは依然として Tectonic につまずく可能性があります (大声で言います)。

### プロジェクトの寿命は短い

ファイルを開きます。コンパイル。近い。アクティブな論文の棚はどこですか?完全な履歴を含む履歴書のバリアントをフォークしますか?表紙にカーソルを置くと、PDF の最後のページが表示されますか?すべてのプロジェクトでフレーズを検索しますか?論文をブックマークしますか?

TeXstudio はファイルとセッション指向です。 Oleafly のライブラリはポートフォリオ指向です: 書籍、カバー、エンジン バッジ、フォーク系統、ブックマーク、「/docs」検索、エクスポート履歴。違う仕事。

### 歴史と Git は他人事

TeXstudio の隣で Git を使用できます。自分で設定します。コンパイルおよびアイドル編集後の自動チェックポイント、PDF の横にあるステージング UI、ワンクリック復元、AI セッション チェックポイントなど、従来の IDE では想定されていないリサーチ ワークスペースで製品化されています。

### マルチエンジンと研究ツール

第一級プロジェクトとしての Typst。 PDF へのマークダウン。 arXiv / Semantic Sc​​holar / Crossref / PubMed / OpenAlex にわたる引用検索。 DOI を `.bib` + `\cite` に貼り付けます。ダイアグラムキャンバスを編集可能なTikZに。 ATS およびアクセシビリティ指向のチェックのためのプリフライト。コンテキスト認識エクスポート (DOCX、HTML、Beamer 用の PPTX、EPUB)。これらは「TeXstudio が失敗しました」ではありません。彼らはその時代と義務の外に座っています。

### TeXstudio がさらに優れている点

構成可能なマルチステップ ビルド。長期熟成。親しみやすさ。 Oleafly のベータ ラベルや Tectonic のエッジ ケースが厳しい締め切りに怯えるのであれば、TeXstudio は保守的なオープンな選択肢です。

## 同じプレーン ファイルでのモダンな外観

Oleafly で同じ `.tex` ツリーを開くと、違いは統合であり、新しいファイル形式ではありません。

- プロジェクト全体のインテリジェンス: 定義、参照、名前変更、ライブ参照/引用チェック、構造ビュー、引数形状を含むマクロ、TexLab/Tinymist (利用可能な場合)
- ライブ KaTeX プレビュー;ハーパー + フンスペルは散文のみ
- 古いものを許容する SyncTeX、スプレッド、ウィンドウの切り離しを備えた PDF ワークスペース
- 初日から本物の Git;無料の GitHub 同期
- 完全な履歴を含むライブラリフォーク
- LaTeX + タイプスト + マークダウン
- オプションの AI / MCP を制御可能
- テンプレート (23 バンドル + 99 パック)、プリフライト、マルチフォーマットエクスポート
- 永久無料 (AGPL)、アカウントなし

**名前の欠点** パブリックベータ版。教師付きコンパイル モデル (レシピは TeXstudio に残ります)。ライブ マルチユーザー編集はまだロードマップ中です (Git は現在)。とりあえず英語中心の校正。厳しい締め切りの前に、リスクの低い論文に挑戦してください。

## 各ツールの 1 日

**TeXstudio の日。** 昨日のファイルを開きます。 TeX のインストールがまだ一致していることを願っています。ジャーナル クラスが奇妙なチェーンを必要とするため、ビルド プロファイルを微調整します。 PDF の更新。迷路をすでに知っていれば生産的です。

**モクセイの日** 棚を開けてください。紙または二股に分かれた履歴書を選択します。タイプ;自動コンパイル。 PDF が追いついている間でも SyncTeX を実行します。ログ小説の前に壊れた`\cite`が点灯します。コーヒーを淹れているときにチェックポイントが発生しました。オプション: エージェントに、修正を試み、差分を承認し、嘘がある場合は復元するように依頼します。

ある日はクラシックなスタジオクラフト。もう 1 つは、同じソースを中心としたリサーチデスクの自動化です。アイデンティティではなく、目の前の紙に基づいて選択してください。

## ハードな切り替えを行わずに移行する

1. TeXstudio をインストールしたままにします。
2. 以下から Oleafly をダウンロードします。
   [リリース ページ](https://github.com/Oleafly/Oleafly/releases/latest)。
3. 同じツリーをインポートします。コンパイル;エディターとライブラリーが時間を節約するかどうかを確認してください。
4. 悪夢のレシピ文書を TeXstudio に残します。信頼性の高いエンジンと最新のデスクのみを必要とするものを移動します。

## 終わりに

TeXstudio は TeX スタジオとして古いものです。ビルドと成熟度に関しては今でも尊敬を集めています。 AI 時代の研究ワークスペースになることはありませんでしたし、その UI がそのふりをすることもありませんでした。

クラシックな IDE が必要で、すでに TeX Live を所有している場合は、そのままにしておいてください。同じプレーン ファイル上に、ディープ エディター、本物の Git、マルチエンジン、引用、オプションの AI、ポートフォリオ ライブラリなどの無料の最新デスクが必要な場合は、1 つの論文を開いて 1 日後に決定してください。ソースはどのアプリがフォーカスされているかを気にしません。
