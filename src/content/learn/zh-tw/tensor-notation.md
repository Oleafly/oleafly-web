# 堆疊索引

相對論和微分幾何中的張量表示法區分了上索引和下索引，索引的水平順序也有意義：一旦用度量升高和降低索引，首先具有較高索引的對象與首先具有較低索引的對象並不相同。 LaTeX 的預設腳本放置忽略了這種區別，因此張量較多的文件依賴空組的小技巧。

```latex
T^{i}{}_{j}{}^{k}
R^{\mu}{}_{\nu\rho\sigma}
g_{\mu\nu}
```

## 空組技巧

寫「T^i_j」會將上標和下標放在同一個水平槽中，一個疊放在另一個上面。要交錯排列它們，請插入一個空組“{}”：“T^{i}{}_{j}”將“i”作為上標附加到 T，然後將“j”作為下標附加到後面的空組，因此下標位於上標之後而不是其下方。每個「{}」都會開啟一個新的腳本槽，您可以根據張量需要連結任意數量的腳本槽，如「T^{i}{}_{j}{}^{k}」所示。

第二行顯示了真實物體的回報。在 `R^{\mu}{}_{\nu\rho\sigma}` 中，mu 佔據第一個索引位置，三個較低的索引緊接著。這是黎曼張量的標準佈局。折疊交錯，索引順序變得不明確。當每個索引都位於一個層級時，如度量“g_{\mu\nu}”中所示，不需要任何技巧，單一下標組可以容納所有索引。

同樣的「{}」也解決了一個簡單的錯誤。 `T^i^k` 使用「雙上標」停止編譯，因為一個原子不能有兩個上標。 `T^{i}{}^{k}` 為第二個上標提供了自己的槽並乾淨地編譯。

## 約定與一致性

索引是交錯的還是堆疊的是字段約定。廣義相對論幾乎普遍地令人震驚。當沒有指標移動索引時，其他區域可以使用堆疊索引。匹配您所在領域的習慣，如果您在某個地方提交，請先匹配期刊的模板，然後再匹配您自己的口味。 「tensor」套件可以使用「\tensor」指令自動放置，但手動空組是可移植的，不需要包，並且可以在任何提交系統中保持不變。

一致性比選擇本身更重要。決定一次每個張量的索引如何排列。對於您經常鍵入的內容，請在它們周圍放置一個序言宏，這樣後期對約定的變更就是一次編輯，而不是搜尋整個文件。在[現場遊樂場](/live/) 中並排比較交錯和堆疊的表格。
