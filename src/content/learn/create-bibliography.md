# Build a .bib that lasts

Entry types you need: `article`, `book`, `inproceedings`, `misc`, `phdthesis`, `techreport`.

Required fields vary by type. Missing `year` or `author` is the usual validator failure. Keep **stable citation keys** so renames do not break the manuscript.
