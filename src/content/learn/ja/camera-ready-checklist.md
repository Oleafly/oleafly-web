# 慌てることなくカメラの準備完了

受け入れられました！祝賀会の後には、カメラの準備を整えるという最後の期限が来ます。この名前は、出版社が印刷用にページを撮影したときの名残です。今日、それは、まさに読者が永遠に目にすることになる、議事録に入る最終版を意味します。これ以降、タイプミスを修正してくれるエディタはありません。その部分はあなたにあります。

## 送信とカメラ準備の間での変更点

提出されたバージョンはレビュー担当者向けに調整されました。カメラの準備が整った状態は永久記録用であり、いくつかのことが反転します。

|アイテム |提出されたバージョン |カメラ対応 |
|---|---|---|
|著者名 |隠し (二重盲検) |本名、所属、メールアドレス |
|謝辞 |省略 |資金提供、補助金、感謝 |
|ページ制限 |レビュー制限 |多くの場合 +1 ページですが、正確です |
|著作権ブロック |プレースホルダーまたはなし |出版社のブロック、DOI、ISBN |
|自己引用 |三人称 (「スミスら」) | 「私たちの以前の作品」と言える |
|反論の約束 |約束 |実際に納品されました |

匿名化の解除は、単に名前を追加し直すだけではありません。自分のアイデンティティについて書いたすべての場所をソースで検索します。通常の隠れ場所については [二重盲検レビューのための匿名化](/learn/anonymization-double-blind/) を参照してから、すべてを反転してください。

## 正確なページ制限を再度示します

カメラ対応制限は議長だけでなく出版社によって強制され、余分なコンテンツ (著者ブロック、謝辞) がスペースを食います。突然 6 行オーバーになった場合は、正直に実行してください。スペース コマンドを乱用するのではなく、文章や図を引き締めてください。 [犯罪のないページ制限](/learn/page-limits-without-crimes/) の手法は、出版社が書式をチェックするため、ここでも二重に適用されます。

## フォントを埋め込む必要があります

これは人を噛むやつです。出版社は自動チェックを実行しますが、拒否の最大の理由は非埋め込みフォントであり、通常はプロット ツールからエクスポートされた図 PDF によって密かに持ち込まれます。 `pdffonts yourpaper.pdf` を確認してください。すべてのフォントに「emb: yes」と表示されるはずです。そうでない場合、犯人はほとんどの場合、人物です。フォントを埋め込んだ状態で、または適切に生成された PDF として再エクスポートします。

## 最終校正: 参照を最初に行う

参照はエントロピーが集中する場所です。アップロードする前に:

- [ ] いいえ "？？"ログ内の引用または未定義の参照
- [ ] すべての参考文献エントリには、開催地、年、および正しく大文字と小文字が区別されたタイトルが含まれています
- [ ] 著者名は正しく綴られています (人々は自分の名前に気づきます)
- [ ] arXiv のみの引用が存在する公開バージョンに更新されました
- 参照内の [ ] URL は引き続き解決されます

次に、論文全体を一度声に出して読みます。遅くても動作します。

## ソースアップロードの癖

ほとんどの出版社は PDF だけでなく LaTeX ソースを求めており、そのビルド システムにはこだわりがあります。`.bbl` を含める、非標準パッケージを避ける、ファイル レイアウトに従うなどです。クリーンなソース ZIP をエクスポートし (Oleafly はこれを 1 ステップで実行します)、アップロードする前に空のフォルダーで最初からテストコンパイルします。マシン上の迷走ファイルが原因でビルドされただけの場合は、発行者のシステムがそれを検出します。

## 一人で座るチェックリスト

- [ ] 名前、所属、メールアドレスが復元され、修正されました
- [ ] 謝辞と資金提供番号を追加しました
- [ ] 著作権ブロック / DOI 情報が発行者の電子メールから貼り付けられました
- [ ] ページ制限を正確に満たしました
- [ ] `pdffonts` は埋め込まれているすべてのフォントを表示します
- [ ] 参考文献の校正
- [ ] クリーンなソース ZIP を最初からコンパイルします
- [ ] 1 日余裕を持ってアップロードされました

その後、それは永久に完了します。 [プレゼンテーション](/learn/present-your-paper/) について考える時間です。
