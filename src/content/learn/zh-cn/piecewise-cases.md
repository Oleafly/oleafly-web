# 分段定义

分段函数在其域的不同部分给出不同的公式：绝对值、ReLU 激活、税级表。排版约定是一个高左大括号，每个案例一行，每行显示公式及其应用条件。 “amsmath”包提供了“cases”环境，它可以准确地生成此布局，而无需任何手动调整括号大小。

## 案例环境

```latex
\[
f(x) =
\begin{cases}
 x^2 & x \ge 0 \\
 -x & x < 0
\end{cases}
\]
```

逐行阅读此内容：整个内容位于 `\[ ... \]` 内，因此它在自己的行上显示数学。 `f(x) =` 是普通数学，然后 `\begin{cases}` 打开分段块。在里面，每行有两列，用“&”分隔：左边是公式，右边是条件。行以“\\”结尾，但最后一行不需要。编译时，LaTeX 会绘制一个足够高的左大括号以跨越两行，并对齐一列中的公式和另一列中的条件。

“&”在这里发挥着真正的作用。如果没有它，每一行都将是一个斑点，并且条件不会垂直排列。有了它，“x^2”和“-x”共享左边缘，“x \ge 0”和“x < 0”共享它们自己的左边缘，这使得定义可扫描。

必须具备两件事才能编译。首先，序言中的 `\usepackage{amsmath}`，因为 `cases` 不是核心 LaTeX 的一部分。其次，环境必须处于数学模式内。 `cases` 构建数学内容，但本身不会打开数学模式。如果缺少其中一个，您将收到“环境案例未定义”或“缺少 $ 插入”错误。后者在[插入缺失的美元](/learn/missing-dollar/) 中进行了解释。

## 添加单词

大多数已发表的分段定义都包含“如果”一词，并且通常包含最后的“否则”。由于条件列是数学模式，因此普通单词需要“\text{...}”以适当的间距以文档字体显示：

```latex
\[
f(x) =
\begin{cases}
 x^2 & \text{if } x \ge 0 \\
 -x & \text{otherwise}
\end{cases}
\]
```

注意“\text{if }”内部的空格。数学模式会忽略您键入的空格，但在 `\text` 内部空格是真实的，因此在右大括号之前放置一个空格会将“if”与后面的条件分开。

## 变体和常见错误

如果公式是高分数并且看起来很拥挤，“mathtools”包提供了“dcases”，这是一个直接替代品，可以设置每个公式的显示样式。还有一种用于镜像情况的“情况”，其中支架属于右侧。

最常见的错误是忘记行之间的“\\”，这会默默地将两个案例合并为一长行。如果编译的输出显示公式中存在条件，请首先计算行中断数。您可以在[游乐场](/live/) 中尝试现场环境。
