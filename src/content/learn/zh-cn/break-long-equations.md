# 不适合的方程

推导迟早会产生一个比文本块更宽的方程，而 LaTeX 会让它进入边缘，而不是猜测在哪里打破它。两个“amsmath”环境允许您自己放置中断：“multline”用于单个长表达式，“split”用于应保持对齐的中断。

## 多行

```latex
\begin{multline}
 a + b + c + d + e + f \\
 + g + h + i + j
\end{multline}
```

“multiline”适合没有自然对齐点的长公式。您可以使用“\\”选择分隔符，环境会处理布局：第一行设置为左对齐，最后一行设置为右对齐，所有中间行都居中。整个表达式得到一个方程编号，放在最后一行。约定是在二元运算符之前中断，因此“+”打开续行，读者一眼就能看出表达式继续进行。

＃＃ 分裂

```latex
\begin{equation}
\begin{split}
 a &= b + c \\
 &\quad + d + e
\end{split}
\end{equation}
```

`split` 也生成一个数字，但以 `align` 的方式对齐其行，并用 `&` 标记对齐点。它不是一个独立的环境；它位于“equation”或另一个提供数字的显示环境中。这里，“&”位于第一行等号之前，延续以“&\quad”开始，这是一个空对齐点，后跟一个四边形的空格，因此第二行缩进正好经过等号。这个缩进告诉读者这仍然是右边，而不是一个新的方程。

## 在它们之间进行选择

当方程是一个长和且没有值得对齐的结构时，请使用“multiline”。当有等号应挂在其下时，请使用“split”。如果你有几个真正独立的方程，那么没有一个是正确的。这是“align”的工作，包含在[排列的多行方程](/learn/align-equations/) 中。

在尝试其中任何一个之前，请考虑重写数学。在前面的句子中命名子表达式、因式分解或分解为两个方程通常可以控制宽度并且读起来也更好。更喜欢这样做而不是缩小类型。挤压的显示屏几乎总是比完全断裂的显示屏读起来更糟糕。

需要了解的一个错误：单独使用 `split`，如果没有封闭的 `equation`，会因“Package amsmath Error”而停止。先封装，再编译。这两种环境都可以在[现场游乐场](/live/) 中快速进行实验。
