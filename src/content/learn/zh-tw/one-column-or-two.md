# 一列或兩列

打開十張紙，你會看到兩個部落：密集的兩欄頁面，看起來像新聞紙，以及通風的單欄頁面，看起來像一本書。兩者都不是更好。每一種進化都有其原因，而選擇幾乎永遠不是你能做出的。

## 為什麼場地不同

兩欄佈局是會議傳統，誕生於會議記錄印刷和頁面預算緊張的情況下。窄欄每頁包含更多字數，短行更容易瀏覽。大多數 CS 會議（ACM、IEEE 等）仍在使用它們。

一欄佈局在期刊、預印本和論文中占主導地位。它們為方程式、數字和表格提供了喘息的空間，而且更適合長篇閱讀。正是由於這個原因，預印本伺服器和許多機器學習場所已經轉向單列。

|佈局|典型家居|個性|
|---|---|---|
|兩欄|會議記錄|密集、可掃描、頁數有限 |
|一欄|期刊、預印本、論文 |寬敞、可讀、易於方程式 |

## 兩列對你的資料有何影響

在兩列文件中，普通的「圖形」浮動在一列中，這對於詳細繪圖來說通常太窄。帶星號的變體跨越兩列：

```latex
\begin{figure*}
  \centering
  \includegraphics[width=\textwidth]{wide-results.pdf}
  \caption{A figure that needs the full page width.}
\end{figure*}
```

對於有「table*」的寬表，同樣的技巧。一個問題：加星號的浮動通常會出現在頁面的頂部，不能使用底部或此處的位置，因此請儘早規劃您的寬圖。尺寸調整基礎知識位於[插入影像](/learn/insert-images/)。

## 方程式變得狹窄

大約 3.3 英吋寬的柱子不適合長方程式。在兩欄論文中，您將更頻繁地打破方程，更積極地縮寫，並依賴多行環境。如果您的論文包含大量方程式並且您可以選擇地點，那麼單欄將節省您真正的格式化時間。有關工具，請參閱[數學模式](/learn/math-mode/)。

## 螢幕和螢幕閱讀器更喜歡一欄

對於任何非正式論文提交的內容（報告、文件、簡歷、人們將在筆記型電腦和手機上閱讀的預印本），單欄獲勝。 PDF 不會重排，因此兩列頁面迫使螢幕閱讀器和文字擷取器猜測閱讀順序，並迫使人們在每個頁面內上下滾動。簡歷解析系統因擾亂多列佈局而臭名昭著。為有需要的場地預留兩根柱子。

## 文檔類別由你決定

這是令人放鬆的部分：您幾乎從不手動配置它。場地為您提供了一個類別或模板，佈局也隨之而來。

```latex
\documentclass{article}              % one column
\documentclass[twocolumn]{article}   % two columns
\documentclass[sigconf]{acmart}      % venue class, layout included
```

內容編寫一次，切換模板即可重排所有內容。這就是 LaTeX 的用途：相同的原始碼編譯為兩列會議版本和一列預印本（僅更改一行）。將圖形保持為向量格式，將方程式保持在標準環境中，並且佈局交換幾乎是輕鬆的。
