# そのパッケージはインストールされていません

遅かれ早かれコンパイルは `! のような行で停止します。 LaTeX エラー: ファイル 'siunitx.sty' が見つかりません`。このメッセージの意味はまさにその通りです。ドキュメントは `\usepackage{siunitx}` 経由でパッケージを要求しましたが、コンパイラはマシン上でパッケージの `.sty` ファイルを見つけることができませんでした。あなたの文書には何も問題はありません。 LaTeX ディストリビューションにはデフォルトですべてのパッケージが同梱されているわけではなく、修正は実行するディストリビューションによって異なります。

## TeX ライブ

Linux および macOS (MacTeX として) の標準ディストリビューションである TeX Live には、「tlmgr」と呼ばれるパッケージ マネージャーが含まれています。不足しているパッケージをターミナルからインストールします。

```
tlmgr install siunitx
```

何ギガバイトもの完全な TeX Live がインストールされている場合は、すべてがすでに存在しているため、このエラーは発生しません。通常、これは小規模な「基本」または「小規模」インストール スキームで表示されます。 `tlmgr` への引数はファイル名ではなくパッケージ名であるため、`.sty` 拡張子はつかないことに注意してください。

## MiKTeX

Windows で一般的な MiKTeX には 2 つのメカニズムがあります。そのオンザフライ インストール機能は、コンパイル中に不足しているファイルを検出し、それを取得するよう提案し、プロンプトを表示するか、設定に応じて自動的に続行します。あるいは、MiKTeX コンソールを開き、「パッケージ」タブに移動してパッケージを検索し、そこにインストールします。オンザフライ インストールでコンパイルがハングしているように見える場合は、通常、別のウィンドウの後ろに隠れた確認ダイアログが表示されるのを待っています。

## 地殻変動

Oleafly にバンドルされている Tectonic エンジンは、手動の手順をスキップします。パッケージはコンパイル中にオンデマンドでダウンロードされ、エンジンのローカル キャッシュに配置されます。 `siunitx` を使用する最初のコンパイルはそれをフェッチします。後でコンパイルするとキャッシュが再利用されます。最初の実行では、依存関係のダウンロードに時間がかかる可能性があり、ネットワーク接続が必要です。

## インストールしても直らない場合

パッケージ マネージャーがそのようなパッケージが存在しないと報告した場合は、ctan.org にある中央の LaTeX パッケージ アーカイブである CTAN のパッケージのページと照合してスペルを確認してください。頑固なケースのほとんどは 2 つの不一致によって説明されます。まず、配布パッケージには複数の `.sty` ファイルが含まれる場合があるため、ファイルとパッケージには異なる名前を付けることができます。 CTAN でエラー メッセージから正確な `.sty` ファイル名を検索すると、この問題が解決されます。第 2 に、このエラーでは、テンプレートに含めるのを忘れたクラス ファイルなど、独自のプロジェクトのファイルに名前が付けられる場合があり、パッケージ マネージャーはそれを提供できません。ファイルは、テンプレートが作成した場所から取得する必要があります。

古いアドバイスに関する最後の注意: LaTeX は最初に現在のディレクトリを検索するため、インターネットから単独の `.sty` ファイルをプロジェクト フォルダーにダウンロードすることは機能しますが、そのパッケージはランダムなバージョンでフリーズされ、更新から隠蔽されます。パッケージマネージャーを使用し、締め切り間近の緊急事態に備えて手動コピーを使用してください。
