# 研究寫作工具箱的過去與現在

每一代研究人員都認為其工具是永久性的。他們從來都不是。快速瀏覽論文是如何撰寫的，以及工具箱現在的樣子，以便您可以謹慎地選擇您的工具。

## 之前的時間

進入 20 世紀 80 年代，論文**在打字機上**，用手寫下方程式，然後郵寄給期刊。然後出現了文字處理器：數十年的 **Word 模板**，編號脆弱，方程式粘貼為圖像，圖形佈局在段落移動時會爆炸。協作意味著**來回透過電子郵件發送文件**：`paper_final_v3_REALLY_FINAL_jw_edits.docx` 不是一個笑話，它是歷史。 LaTeX 在這一切中一直存在（請參閱 [TeX 45 年](/learn/history-of-tex-latex/)），但您在終端中編譯了它並透過電子郵件共享了它。

## 今天的工具箱

|工具|分類 |擅長什麼 |
| --- | --- | --- |
|背頁|雲端 LaTeX 編輯器 |瀏覽器即時協同編輯，零設定|
| TeXstudio/TeXmaker |本地 LaTeX IDE |經典桌面編輯，免費 |
| VS Code + LaTeX 研討會 |本地IDE |如果您已經使用 VS Code，那麼功能強大 |
|油葉 |本地優先工作區 |捆綁編譯器的 LaTeX、Typst 和 Markdown |
|佐特羅 |參考經理 |收集、組織與匯出引文 |
|Google學術|發現 |搜尋論文並追蹤引用|
| arXiv |發現+預印本|免費閱讀最新作品，請參閱[預印本世界](/learn/what-is-arxiv/) |
|打字員 |全新排版系統|當沒有場地需要 .tex 時，快速、現代的文檔 |

**發現**工具查找論文，**參考管理器**組織您找到的內容，**編輯器**將其全部轉換為 PDF。您最終會得到其中一個。

## 老實說，雲端與本地

**Overleaf** 透過完全刪除安裝使 LaTeX 成為主流，其實時協作編輯確實是其殺手級功能。如果您的合著者想要同時輸入同一個文檔，那麼像 Overleaf 這樣的雲端工具現在更適合。

**本地優先**工具扭轉了這一局面：您的文件以普通文件的形式存在於您的電腦上，您可以在火車上或在醫院防火牆後面工作，一切都不依賴於訂閱或伺服器的存活，並且版本歷史記錄是真實的 [Git](/learn/oleafly-workflow/)，而不是專有的時間軸。本地 LaTeX 的典型難題是安裝一個多 GB 的 TeX 發行版。這是已經改變的部分。

## Oleafly 適合的地方

Oleafly 是一個免費、開源、本地優先的桌面工作區。 LaTeX 和 Typst 的編譯器是捆綁在一起的，因此無需安裝發行版。可以透過 [DOI 或 arXiv ID](/learn/open-access-doi-explained/) 取得引文，項目是具有誠實歷史的 Git 儲存庫，內建場地模板，並且可選的 AI 助理可以在您需要時提供協助。目標是使本地路徑與雲路徑一樣低摩擦。公平地說：對於即時同步共同編輯，Overleaf 仍然是更強的選擇。對於文件的所有權和離線工作，本地優先勝出。許多人都使用兩者，在本地起草並透過 Git 同步。

## 毫不痛苦地選擇

從這個月為你消除最多摩擦的事情開始。 .tex 檔案可以跨桌面上的每個工具移植。這種可移植性是純文字寫作的真正優勢，[LaTeX vs Word](/learn/latex-vs-word/) 對此進行了介紹。然後編寫您的[第一個文件](/learn/first-document/)，並讓工具箱隨著工作而成長。
