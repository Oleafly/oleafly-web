# 强制或拒绝分页

LaTeX 决定页面结束位置。大多数情况下，它的决定很好，但有时您需要推翻它：章节标题会在页面底部搁浅，表格太晚一行，或者您希望报告的每一章都重新开始。 LaTeX 为此提供了一小部分命令，范围从严格的命令到礼貌的建议。

```latex
\newpage % end page
\clearpage % end page + flush floats
\cleardoublepage
\pagebreak[3] % soft request
\nopagebreak
```

## 艰难的突破

`\newpage` 立即结束当前页面并开始新页面。它是最钝的工具，也是您在绘图时最常用的工具。

`\clearpage` 做同样的事情，但首先刷新所有挂起的浮动。 LaTeX 中的图形和表格是浮动的：它们会漂移到算法找到空间的任何地方，有时会漂移到您编写它们的位置之后的页面。 `\clearpage` 会在继续之前强制将到目前为止已排队的每个浮动到页面上，因此在章节末尾或您不希望出现任何掉队的部分之前，这是正确的命令。如果文档末尾的数字似乎堆积如山，那么放置在适当位置的“\clearpage”通常可以解决问题；请参阅[为什么人物移动](/learn/figure-wrong-position/) 了解完整故事。

`\cleardoublepage` 在双面文档中更进一步：刷新浮动后，它确保下一页是右侧（奇数）页面，如果需要，则插入空白的左侧页面。书籍章节传统上在右侧打开，并且“book”类在每个“\chapter”处为您调用它。

## 软请求

`\pagebreak[n]` 没有命令。它问。 0 到 4 之间的可选数字表示强度：`\pagebreak[1]` 表示“这里休息一下就好”，`\pagebreak[4]` 表示“这里休息，句号”。中间的值让 LaTeX 权衡你的愿望和它自己的间距判断，这通常会产生比硬的“\newpage”更好看的页面，因为“\pagebreak”拉伸内容以填充页面而不是留下间隙。

`\nopagebreak` 是相反的请求：它不鼓励在此时中断。它在标题之后或您想要与其简介一起保留的简短列表之前非常有用。与 `\pagebreak` 一样，它接受 0 到 4 之间的可选强度。

## 什么时候该接触这些

常见的错误是在草稿中散布“\newpage”来修复布局，然后随着文本的增长，每次修复都会出错。分页符取决于它们之前的所有内容，因此今天看起来完美的手动分页符可能会在下一次修订后留下半空的页面。合理的工作流程是首先编写整个文档，然后只在最后一遍添加中断，在确切位置可以协商的情况下，优先使用软“\pagebreak[3]”而不是硬命令。
