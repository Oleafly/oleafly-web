# Отримайте робочий TeX на будь-якій ОС

Для локального написання LaTeX потрібна система TeX: механізм, який компілює ваш вихідний код, а також тисячі пакетів, від яких залежать документи. Є два розумних способи отримати один. Одна з них — це програма з вбудованим двигуном, яка дозволяє компілювати за лічені хвилини. Інший — це повний дистрибутив TeX, який встановлює повний інструментарій командного рядка, який може використовувати будь-який редактор. Обидва шляхи закінчуються в одному місці: файл `.tex` перетворюється на PDF на вашій машині.

## Шлях A: програма з включеним механізмом

Завантажте [Oleafly](https://github.com/Oleafly/Oleafly/releases/latest) для Mac, Windows або Linux. Він об’єднує движок Tectonic, тому немає окремого встановлення TeX для керування: ви відкриваєте програму, створюєте проект і компілюєте. Коли документ використовує пакет, якого немає, Tectonic отримує його на вимогу, для чого потрібне підключення до мережі під час першого використання даного пакета та нічого після цього. Цей шлях підходить усім, хто хоче писати статті, а не адмініструвати встановлення TeX, і він залишає звичайні файли `.tex` і `.bib` на диску, які може читати будь-який інший інструмент.

## Шлях B: повний дистрибутив TeX

Встановлюючи дистрибутив, ви отримаєте `pdflatex`, `xelatex`, `lualatex` і менеджер пакетів як системні команди. На Mac інсталюйте MacTeX, який є пакетом TeX Live для macOS; якщо багатогігабайтне завантаження небажане, BasicTeX — це невелике ядро, яке ви розширюєте за допомогою TeX Live Utility за потреби. У Windows MiKTeX є звичайним вибором і може встановлювати відсутні пакунки на льоту під час компіляції, тоді як TeX Live працює однаково добре. У Linux інсталюйте `texlive-full` зі свого менеджера пакунків для всього одночасно або меншу схему, таку як `texlive-latex-extra` плюс інструмент `tlmgr` для додавання пакунків пізніше. Очікуйте, що повна інсталяція займе деякий час і кілька гігабайт диска.

## Перевірте встановлення

Відкрийте термінал і запитайте у двигуна його версію:

```bash
pdflatex --version
# or
xelatex --version
```

Банер версії означає, що ланцюжок інструментів на вашому шляху та готовий. Помилка про те, що команда не знайдена, зазвичай означає, що зміни, внесені інсталятором у ваш ШЛЯХ, ще не набули чинності; перезапуск терміналу або вихід із системи та повторний вхід у Windows вирішує її.

## Який шлях вибрати

Виберіть програму, якщо ви починаєте чи просто хочете найкоротший шлях до скомпільованого PDF-файлу. Виберіть повний дистрибутив, якщо вам потрібні певні двигуни, збірки командного рядка або інтеграція з існуючим редактором. Обидва співіснують без конфлікту, тому початок зі Шляху A та додавання Шляху B пізніше нічого не коштує. У будь-якому випадку наступний крок той самий: скомпілюйте [ваш перший документ](/learn/first-document/).
