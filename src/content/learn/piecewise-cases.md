# Piecewise definitions

```latex
\[
f(x) =
\begin{cases}
 x^2 & x \ge 0 \\
 -x & x < 0
\end{cases}
\]
```

Right-aligned conditions; `&` separates formula and condition. Requires `amsmath`.
