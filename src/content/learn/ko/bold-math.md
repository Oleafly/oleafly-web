# 벡터와 굵은 기호

많은 필드에서 벡터와 행렬을 굵은 글씨로 설정합니다. 벡터는 **x**, 행렬은 **A**, 계수 벡터는 굵은 베타로 설정됩니다. LaTeX에는 수학을 위한 두 가지 다른 굵은 글씨 명령이 있으며 서로 바꿔서 사용할 수 없습니다. 어느 것에 접근해야 하는지 알고 선택을 매크로로 래핑하면 전체 논문에서 표기법의 일관성을 유지할 수 있습니다.

## 두 가지 명령

```latex
\mathbf{x} % upright bold (often matrices)
\boldsymbol{\beta} % bold italic Greek (amsmath)
```

`\mathbf`는 인수를 똑바로 굵은 로마체 글꼴로 전환합니다. 라틴 문자에 잘 작동하므로 ``\mathbf{A}'는 많은 텍스트에서 행렬에 사용하는 단단한 직립형 굵은 A를 제공합니다. 제한 사항은 문자와 숫자만 포함한다는 것입니다. `\mathbf{\beta}`는 아무 쓸모가 없습니다. 굵은 로마자 글꼴에는 그리스어 문자가 없고 베타는 변경되지 않고 인쇄되기 때문입니다.

`amsmath`(기술적으로 `amsmath`가 로드하는 `amsbsy`의 `bm`과 같은 기계에 의해 제공됨)에서 제공되는 `\boldsymbol`은 모양을 유지하면서 건네주는 모든 기호를 대담하게 만듭니다. `\boldsymbol{\beta}`는 굵은 이탤릭체 베타를 생성하고 `\boldsymbol{x}`는 굵은 이탤릭체 x를 생성하여 일반 수학 변수의 기울어진 스타일과 일치합니다. 벡터가 굵은 이탤릭체로 표시되는 경우 이는 원하는 명령입니다.

따라서 실제적인 분할은 다음과 같습니다: 똑바로 굵은 라틴 문자, `\mathbf` 사용; 이탤릭체로 유지되어야 하는 그리스어 또는 굵은 글씨체는 `\boldsymbol`을 사용하세요.

## 매크로를 한 번만 정의하세요.

문서 전체에 걸쳐 이러한 명령을 입력하는 대신 서문에서 의미 매크로를 정의하십시오.

```latex
\newcommand{\vect}[1]{\boldsymbol{#1}}
\newcommand{\mat}[1]{\mathbf{#1}}
```

이제 벡터에는 `\vect{x}`를 쓰고 행렬에는 `\mat{A}`를 씁니다. `[1]`은 각 매크로가 하나의 인수를 취하고 `#1`이 해당 인수가 있는 위치임을 나타냅니다. 결과는 나중에 나옵니다. 저널에서 벡터를 굵은 이탤릭체 대신 똑바로 굵은체로 표시하도록 요구하는 경우 `\vect`가 `\mathbf`를 감싸도록 한 줄을 편집하면 논문의 모든 벡터가 다음 컴파일 시 업데이트됩니다. 이는 200개의 방정식에서 검색 및 바꾸기를 수행하는 것보다 뛰어납니다.

매크로는 또한 소스에서 의도를 읽을 수 있게 만듭니다. 지금으로부터 6개월 후 `\vect{w}`는 w가 벡터임을 알려줍니다. ``\boldsymbol{w}'만 표시하면 굵게 표시됩니다.

## 흔히 저지르는 실수

수학 내에서 `\textbf`를 사용하여 굵은 그리스어를 가짜로 만들지 말고 `\mathbf`를 사용하지 말고 작동했다고 가정하십시오. 컴파일하고 자세히 살펴보십시오. 굵은 글씨 옆에 굵은 글씨가 없는 베타는 화면에서는 놓치기 쉽고 인쇄물에서는 분명합니다. 후보자를 빠르게 확인하고 싶다면 `\boldsymbol{\beta} \mathbf{\beta} \beta`와 같은 줄을 [라이브 놀이터](/live/)에 붙여넣고 세 개를 나란히 비교하세요. `\sum`과 같은 기호를 포함하여 전체 방정식을 굵게 표시하려면 `\boldsymbol`보다 더 많은 기호 클래스를 처리하는 `bm` 패키지의 `\bm` 명령을 살펴보세요.

실행 중인 텍스트에서 굵은 글씨는 다른 명령을 사용하는 다른 주제입니다. [텍스트 강조](/learn/bold-italic/)를 참조하세요.
