# 조각별 정의

조각별 함수는 도메인의 여러 부분(절대값, ReLU 활성화, 세금 등급 일정)에 대해 서로 다른 공식을 제공합니다. 조판 규칙은 케이스당 하나의 행이 있는 하나의 긴 왼쪽 중괄호이며, 각 행은 공식과 그것이 적용되는 조건을 표시합니다. `amsmath` 패키지는 수동으로 버팀대 크기를 조정하지 않고도 이 레이아웃을 정확하게 생성하는 `cases` 환경을 제공합니다.

## 케이스 환경

```latex
\[
f(x) =
\begin{cases}
 x^2 & x \ge 0 \\
 -x & x < 0
\end{cases}
\]
```

이 줄을 한 줄씩 읽으면 모든 내용이 `\[ ... \]` 안에 있으므로 자체 줄에 수학이 표시됩니다. `f(x) =`는 일반적인 수학이고 `\begin{cases}`는 조각별 블록을 엽니다. 내부에는 각 행에 '&'로 구분된 두 개의 열이 있습니다. 왼쪽에는 수식, 오른쪽에는 조건이 있습니다. 행은 `\\`로 끝납니다. 단, 마지막 행에는 필요하지 않습니다. 컴파일할 때 LaTeX는 두 행에 걸쳐 있을 만큼 큰 왼쪽 중괄호 하나를 그리고 한 열의 수식과 다른 열의 조건을 정렬합니다.

`&`는 여기서 실제 작업을 수행합니다. 이것이 없으면 각 행은 단일 얼룩이 되고 조건은 수직으로 정렬되지 않습니다. 이를 통해 `x^2`와 `-x`는 왼쪽 가장자리를 공유하고 `x \ge 0`과 `x < 0`은 자체 왼쪽 가장자리를 공유하므로 정의를 스캔할 수 있게 됩니다.

이를 컴파일하려면 두 가지가 준비되어 있어야 합니다. 먼저, `cases`는 핵심 LaTeX의 일부가 아니기 때문에 서문의 `\usepackage{amsmath}`입니다. 둘째, 환경은 수학 모드 내에 있어야 합니다. 'cases'는 수학 콘텐츠를 구축하지만 자체적으로 수학 모드를 열지는 않습니다. 둘 중 하나라도 누락된 경우 "정의되지 않은 환경 사례" 또는 "$ 삽입 누락" 오류가 발생합니다. 후자는 [누락된 달러 삽입](/learn/missing-dollar/)에 설명되어 있습니다.

## 단어 추가

대부분의 출판된 조각별 정의에는 "if"라는 단어가 포함되며, 종종 최종 "그렇지 않은 경우"가 포함됩니다. 조건 열이 수학 모드이므로 일반 단어가 적절한 간격으로 문서 글꼴로 나오려면 `\text{...}`가 필요합니다.

```latex
\[
f(x) =
\begin{cases}
 x^2 & \text{if } x \ge 0 \\
 -x & \text{otherwise}
\end{cases}
\]
```

`\text{if }` 내부의 공백을 확인하세요. 수학 모드는 사용자가 입력한 공백을 무시하지만 `\text` 내부의 공백은 실제이므로 닫는 중괄호 앞에 공백을 넣으면 "if"가 뒤따르는 조건과 구분됩니다.

## 변형 및 일반적인 실수

공식이 큰 분수이고 비좁아 보이는 경우 `mathtools` 패키지는 표시 스타일에서 각 공식을 설정하는 드롭인 대체 기능인 `dcases`를 제공합니다. 버팀대가 오른쪽에 속하는 거울상 상황에 대한 'rcases'도 있습니다.

가장 흔히 저지르는 실수는 행 사이에 '\\'를 잊어버리는 것인데, 이는 두 개의 사례를 하나의 긴 줄로 조용히 병합하는 것입니다. 컴파일된 출력에 수식이 실행되는 조건이 표시되면 먼저 행 나누기를 계산하세요. [놀이터](/live/)에서 실시간으로 환경을 실험해 볼 수 있습니다.
