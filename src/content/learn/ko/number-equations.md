# 방정식의 숫자와 포인터

방정식에 번호를 매기는 것은 나중에 참조할 것이라는 약속입니다. LaTeX는 그 약속의 두 부분을 모두 처리합니다. `equation` 환경은 숫자를 할당하고 레이블 시스템은 숫자를 직접 입력하지 않고도 문서의 어느 곳에서나 이를 가리킬 수 있게 해줍니다.

```latex
\begin{equation}
 \label{eq:bayes}
 p(\theta \mid y) \propto p(y \mid \theta)\, p(\theta)
\end{equation}
As shown in \eqref{eq:bayes}, ...
```

## 라벨 및 참조

`\begin{equation}`은 표시된 줄에 번호를 매깁니다. `\label{eq:bayes}`는 해당 번호에 `eq:bayes`라는 이름을 붙입니다. 이름은 원하는 대로 선택할 수 있으며 `eq:` 접두사는 방정식 레이블을 그림 및 표와 구별되도록 유지합니다. 이를 인용하기 위해 `\ref{eq:bayes}`는 숫자만 인쇄하고 `amsmath`의 `\eqref{eq:bayes}`는 방정식 옆에 숫자가 나타나는 방식과 일치하도록 이를 괄호로 묶습니다. 두 스타일이 일치하도록 방정식에는 `\eqref`를 선호합니다.

숫자는 한 번에 기록되고 다음 번에 읽혀지기 때문에 새로운 컴파일은 다음 실행까지 '??'를 표시합니다. [숫자 대신 물음표](/learn/equations-show-qq/)가 해당 주기를 다룹니다.

표시된 방정식이 참조되지 않으면 번호를 매기지 마십시오. 대신 `\[ ... \]` 또는 별표 표시된 `등식*`을 사용하십시오. 따라서 숫자는 독자가 다시 찾아야 할 줄만 표시합니다.

## 정렬 시 일부 줄에 번호 매기기

`align`의 여러 줄 파생은 기본적으로 모든 줄에 번호를 매기는데 이는 거의 원하는 것이 아닙니다. 두 명령이 한 줄씩 조정됩니다.

```latex
\begin{align}
 a &= b \label{eq:a} \\
 c &= d \notag \\
 e &= f \label{eq:e}
\end{align}
```

`\notag`는 해당 줄의 숫자를 억제하므로 여기서 중간 단계는 번호가 없는 상태로 유지되고 첫 번째와 마지막 줄은 번호와 레이블을 유지합니다. 각 `\label`을 이름이 지정된 줄의 `\\` 앞에 놓아 올바른 번호에 바인딩합니다. 전부 아니면 전무의 지름길은 `align*`으로, 숫자에 아무 것도 붙지 않습니다. 여러 줄 환경의 전체 제품군은 [일렬로 정렬된 여러 줄 방정식](/learn/align-equations/)에서 다룹니다.

일반적인 실수는 "수식 3 참조"와 같이 리터럴 숫자를 쓰는 것입니다. 이는 위에 수식을 삽입하는 순간 중단됩니다. 항상 레이블을 살펴보고 컴파일할 때마다 LaTeX에서 번호를 다시 매기도록 하세요. [플레이그라운드](/live/)에서 `\notag`를 추가하고 제거하면서 번호 매기기 업데이트를 실시간으로 볼 수 있습니다.
