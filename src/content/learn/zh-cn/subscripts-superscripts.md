# 不会爆炸的指数

下标和上标是每个人在 LaTeX 中学习的第一个数学语法，也是每个人产生的第一个令人困惑的输出的来源。下划线“_”降低后面的字符，插入符号“^”升高它，并且两者都适用于一个字符，除非您另有说明。这一单字符规则几乎存在于您所见过的每一个损坏的索引背后。

## 基本形式

```latex
x_i x^2
x_{ij} x^{2n}
x_i^2 x_{i_j}^{2n}
```

`x_i` 在下标位置放置一个 `i`，而 `x^2` 则产生一个 `2`。因为 `_` 和 `^` 只抓取下一个标记，所以任何超过一个字符的字符都必须用大括号括起来：`x_{ij}` 为两个字母添加下标，而 `x^{2n}` 则引发整个 `2n`。您可以将下标和上标以任意顺序附加到同一个符号，LaTeX 会正确地堆叠它们：`x_i^2`。脚本也嵌套。在“x_{i_j}”中，“j”是“i”的下标，而“i”本身也是“x”的下标，并且每个级别设置得逐渐变小。

多字符脚本**必须**使用大括号：“x_ij”是“x_i”，然后是“j”。 LaTeX 不会将此报告为错误，因为“x_i”后跟变量“j”是完全合法的数学。这个公式编译起来，乍一看几乎是正确的，但含义却有所不同。尽早养成戴牙套的习惯。如有疑问，请支撑脚本。

同样的陷阱也出现在界限和界限中。 `\sum_i=1^n` 并不像看起来那样。正确的形式是“\sum_{i=1}^{n}”，其中整个“i=1”是一个大括号下标。如果您完全在数学模式之外使用“_”或“^”，则会出现[插入缺失美元](/learn/missing-dollar/)中涵盖的经典错误。

## 素数和点

```latex
f' f'' \dot{x} \ddot{x}
```

对于导数，你很少需要文字上标。撇号键生成一个素数：“f”渲染为带有一个素数的 f，带有两个素数的 f''`，LaTeX 会自行处理升高和间距，因此不需要“f^{\prime}”。对于物理风格中的时间导数，“\dot{x}”在 x 上放置一个点，“\ddot{x}”在 x 上放置两个点。这些是重音，所以他们将他们的论点放在大括号中。

还有一个微妙之处：如果您需要在素数后添加上标，只需将它们链接起来即可，如“f”^2”。 LaTeX 将它们组合成一个上标簇。

## 检查你的输出

内化大括号规则的最快方法是在 [live Playground](/live/) 中并排键入 `x_ij` 和 `x_{ij}` 并观察差异渲染。每当编译文档中的索引看起来有细微错误时，首先要检查的是缺少一对大括号。
