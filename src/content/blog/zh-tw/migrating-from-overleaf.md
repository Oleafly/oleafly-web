多年來，[Overleaf](https://www.overleaf.com/) 一直是「我該如何啟動 LaTeX？」的預設答案。分享一個連結。觀察合著者的遊標。在雲端編譯。那個入口匝道是真的。對於多人紙質衝刺來說，情況仍然如此。

一旦你住在那裡是為了寫論文、就業市場包或長時間的單獨重寫，免費產品就會開始讓人感覺很小。合作者一名。历史以小时为单位。 AI按天計算。編譯超時。 Git 和完整的歷史記錄位於付費計劃或您離開時丟失的校園許可證的後面。此瀏覽器非常適合作為具有共用緩衝區的瀏覽器。它從未被建構為一個完整的研究工作區：帶有 ATS 檢查的簡歷、專案分叉、多格式導出、LaTeX 旁邊的 Typst、離線幾週、無限的本地歷史記錄。

這是 Overleaf 仍然獲得開放選項卡的地方，免費套餐和產品範圍耗盡的地方，以及當這些純文件存在於您下載一次的免費桌面應用程式 ([Oleafly](https://github.com/Oleafly/Oleafly)) 中時發生的變化。

## Overleaf 上的幾年真正買下了你

**仍然存在的優點**

- 即時多用戶編輯、評論和聊天——仍然是「今晚三人一篇摘要」的最佳選擇
- 合著者只需打開連結即可進行零安裝
- 龐大的模板庫和出版商/機構肌肉記憶
- 校園 SSO 和站點許可證，讓您在校園內可以輕鬆使用付費功能
- 視覺/代碼切換和潤色，教導該領域“在線 LaTeX”的含義

**保持纖薄的地方（特別是免費的）**

已發布的個人計畫（重新檢查 [Overleaf 定價](https://www.overleaf.com/user/subscription/plans)；數位變更）：

|免費|付費/組織|
| --- | --- |
| **每個項目 1 位合作者** | 10（學生/標準）或無限制（專業）|
| **5 次人工智慧使用/天** |更高米；付費完整助理； Pro = 最大 AI |
| **基本編譯逾時** | **24×** 基本上逾時 |
| **歷史記錄：過去 24 小時** |完整歷史 |
|整合（Git/GitHub、Dropbox、Zotero/Mendeley 等）|許多計劃的保費|
|學生 ~$8–10/月 · 標準 ~$17–21/月 · 專業版 ~$33–42/月 · 大學：聯絡銷售 | |

因此，免費層是一個真正的編輯器，適用於大多數單獨的雲端工作。當您需要第二位合著者、上個月的版本、更長的編譯或超過五次人工智慧推動時，它就會變成演示。

还有一个与付费专区无关的薄弱环节：产品的用途。 Overleaf 针对浏览器中的协作 LaTeX 文档进行了优化。作為一個地方，它的實力較弱：

- 擁有包含分叉和血統的論文、論文、海報和簡歷的組合
- 將相同項目匯出到 Word、HTML、Markdown、PowerPoint (Beamer)、EPUB，無需使用其他工具
- 在工作申請交給您之前執行 ATS/輔助功能預檢
- 將 Typst 和 Markdown 與 LaTeX 放在同一個函式庫和一個 Git 模型下
- 在飛機上或鎖定的醫院網路上離線工作
- 將人工智慧與您自己的密鑰或本地模型一起使用，每次編輯都作為批准差異
- 將歷史視為真正的 Git，您可以永遠在終端中打開

這些都是研究台問題。背頁首先針對多人遊戲進行了優化；桌子的其餘部分從來沒有得到同樣的重量。

## 論文寫作：雙面

**背頁。 ** 在段落中間分享紙本草稿是毫無摩擦的。文件上有評論。對於永遠不會接觸 Git 的群體來說，這就是整個產品。編輯很有能力。預覽對於大多數文章來說都很好。您永遠不是必須為本科生安裝 TeX Live 的人。

**论文写作仍然很痛苦。 ** 專案範圍的智慧受到圍繞完整索引建構的桌面研究編輯器的限制：跨章節重命名巨集、即時檢查「\cref」和多鍵引用、200頁樹的結構視圖、鍵入時進行 KaTeX 預覽、忽略「\commands」的語法。免费编译超时会影响复杂的论文。免费历史记录一天后就会消失。您無法像分叉儲存庫那樣真正將提交版本分叉到實驗分支中 - 您在雲端複製專案並希望您記住哪個是哪個。

**Oleafly side。 ** 本文是磁碟上的多檔案專案。項目範圍的轉到定義、引用、重新命名、即時引用/引用診斷（包括混亂的 `\eqref` / `\cref` 系列）、結構視圖、使用實參形狀定義的巨集的完成、TexLab/Tinymist（如果可用）、即時數學預覽、離線 Harper + Hunspell（僅限散文）。 PDF 工作區具有耐過時的 SyncTeX、跨頁、可拆卸視窗。在您的 CPU 上自動編譯，並出現人性化錯誤。書籍規模的 CI（約 6,200 行）是編輯器的測試方式。

**人們通常如何分割它。 ** 即時共同創作保留在 Overleaf 上。深度多檔案創作、離線週、無限本地編譯和歷史記錄移動本地。很多人都在同一個普通文件上執行這兩種操作。

## 機器讀取的履歷和文檔

Overleaf 将编译一个简历类。它將就業市場 PDF 視為一種產品，但效果不佳：考慮 ATS 的模板、確定性的可選文本，以及顯示解析器式摘錄實際看到的內容（名稱、部分、風險）的預檢面板，以及您可以採取行動的分數。網路履歷製作者以按月付費的方式出售該故事，並在其 SaaS 中提供陷阱佈局。

Oleafly 提供履歷表的範本、Preflight 和免費的 Git，因此「產業履歷」、「學術履歷」和「獎學金」是具有完整歷史記錄的分叉項目，而不是名為「cv_final_v4」的三個雲端副本。

如果您唯一的輸出是共享論文，請跳過本節。如果您也從同一個辦公桌發送申請，您很快就會注意到差距。

## 分叉、克隆、譜系

雲端“複製項目”存在。研究部門想要的是更接近 git 分支：完整的歷史、可見的血統、無需接觸相機就緒樹即可進行實驗。 Oleafly 的圖書館將項目視為書架上的書籍； fork 複製項目及其 Git 歷史記錄；血統顯示在卡片上。透過 GitHub 推/拉的克隆式工作流程是免費的。

背面的免費歷史記錄是 24 小時。付費歷史記錄更好；它仍然是一個服務時間表，而不是帳戶死亡時您保留的儲存庫。

## 匯出和移交

期刊门户网站需要 PDF，通常还需要源 zip 文件。 PI 想要 Word。课程网站需要 PDF。會談需要幻燈片。書籍需要 EPUB。 Overleaf 的世界主要是来自云 LaTeX 的 PDF 加上下载源。这涵盖了很多学术界。

Oleafly 的匯出選單具有上下文感知功能：始終為 PDF 和來源 zip； Word、HTML、Markdown、透過託管 Pandoc 的純文字；來自 Beamer 的 PowerPoint； EPUB 用於書籍類別專案；圖圖像專案的 PNG 路徑。保真度各不相同（老實說，複雜的 LaTeX → DOCX），但路徑是在應用程式內且免費的。

## AI，在白天使用儀表

背面免費：每天使用 5 次 AI。付費計劃提高了上限並解鎖了助手。組織可以為所有人停用人工智慧。

Oleafly：AI 預設為關閉。你的鑰匙或奧拉馬。當您需要託管時有九個提供者。 Agent可以编辑、编译、阅读日志、检查PDF文本、搜索文献。每次写入都是一个批准差异；删除需要明确确认；首先是 Git 检查点。內聯詢問-AI。適用於外部客戶的 MCP。我們不會向您出售代幣。

透過每日上限和訂閱階梯提供便利的託管服務，或自備模型和可檢查的編輯。選擇您可以向實驗室或 IRB 解釋的信任模型。

## 多引擎現實

Overleaf 是一個 LaTeX（和朋友）雲端。 Typst 在其他地方也有自己的網路故事。 Markdown 筆記存在於另一個工具中。

Oleafly 在一個函式庫中執行 LaTeX (Tectonic)、Typst 和 Markdown，並管理編譯器、一個 Git 模型、一個 PDF 介面。模板按引擎過濾。這是一種不同的產品形狀——研究台，而不是另一個 LaTeX 選項卡。

## 離線、隱私權、所有權

瀏覽器：沒有網絡，沒有編輯器。草稿按照他們的條款保存在他們的伺服器上。匯出是您的逃生口，直到它不再（帳戶訪問、計劃更改、畢業）。

本機工作區：普通資料夾、真正的 Git、離線編輯和快取編譯、可選的嚴格離線模式。沒有 Oleafly 帳戶。無產品遙測。套件、引文、託管人工智慧、GitHub、更新網路——只要您提出要求。

## 嘗試兩者，但不要戲劇化

1. 壓縮 Overleaf 原始碼。
2. 從下列位置安裝 Oleafly
   [發布頁面](https://github.com/Oleafly/Oleafly/releases/latest)。
3.進口；編譯一次；在真實的論文或履歷上寫一天。
4. 保留您仍需要的任何即時多人遊戲的 Overleaf 項目。

Tectonic 仍然可能會遇到沉重的出版商類別 - 報告這些；他們制定了路線圖。大多數 ACM/IEEE/Elsevier 風格的論文和論文都很好。

## 結束

Overleaf 迎来了它的十年。當今晚三個人需要同一段時，免費多人遊戲仍然感覺很神奇。對於所有權、深度編輯、分叉、匯出、多引擎工作、無限歷史記錄和您控制的 AI，免費的本地辦公桌更合適。下載 Oleafly 一次，保留 Overleaf 以供即時衝刺（如果您仍然需要），並根據真實論文而不是特徵矩陣做出決定。
