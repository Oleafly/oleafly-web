临床手稿和拨款叙述通常包括敏感细节，甚至
在去识别化最终完成之前。将每次击键都交给第三方
编辑器既是一种政策决定，也是一种工具偏好。 IRB、数据使用
协议，医院 IT 并不关心云编辑器是否方便
晚上 11 点。

这篇文章是关于起草和排版的，你可以向他们解释
合规性。将其视为工作流程建议，而不是法律审查。

## 普通文件更容易推理

一个包含“.tex”和数字的文件夹可以位于加密磁盘、医院中
笔记本电脑图像，或气隙机器。您可以将合规性指向一条路径。
浏览器项目需要信任供应商的访问模型、导出路径和
子处理者列表。

[Oleafly](https://github.com/Oleafly/Oleafly/releases/latest) 的构建是
故意方式：没有帐户，没有产品遥测，项目作为普通文件夹
使用真正的 Git 存储库。 [隐私页面](/privacy/) 很短，因为
文档不需要 Oleafly 服务器即可存在。网络是为了你的行动
take（包、可选的引文查找、托管人工智能（如果启用的话）、GitHub），
并非针对草稿的每次击键。

如果政策禁止云人工智能，请关闭助手或将其指向本地
模型。编辑器、编译循环和 Git 仍然可以工作。

## 无需使用 Word 即可跟踪更改

格兰特 PI 仍然要求“跟踪变更”。在 LaTeX 领域，这通常意味着
Git 历史记录以及合著者的 PDF 注释，或者简短的 Word 导出
拒绝安装任何东西的人。将“.tex”保留为事实来源；
请参阅[只讲 Word 的合著者](/learn/collaborator-uses-word/)。

在 Oleafly 中，每个项目从第一天起就是一个 Git 存储库：自动检查点
成功编译和空闲编辑后，并排差异，一键式
恢复，当您需要私人遥控器时可选 GitHub。你可以分叉整个
将应用程序打包到第二个项目（完整历史）中以尝试冒险的削减
而不触及提交副本。如果您使用可选的人工智能助手，它
第一次编辑之前的检查点，只有通过批准才能进行更改
差异。

名称在目标或部分之后提交（`aim2-methods-cut`），以便 PI 可以略读
无需像软件工程师那样阅读差异即可了解历史。

## 离线在医院很有用

临床网络会阻止随机 SaaS 域。本地编译器不断写入
可能在 EHR 会话之间。 Oleafly 在应用程序中提供了 Tectonic（和 Typst）；
包首次使用后会缓存，离线模式可以拒绝网络
编译器。拼写检查和语法在散文上本地运行（它们跳过命令并
数学）。这些是医院 IT 通常关心的限制，因此本地
研究编辑经常出现。

当您修复页面限制时，源代码旁边的 SyncTeX 和 PDF 很重要
在 Wi-Fi 不可靠的护理站计算机上。

## 模板、页数限制和印前检查

NIH 风格和基础模板涉及边距、字体和页码。
几何和字体包比巧妙的宏更重要。编译为 PDF 并
每次重大剪辑后检查页数，而不是门户网站前一天晚上
关闭。当合适时，从图库中的已知模板开始；仍然匹配
当前字体、边距和结构的 FOA（具体目标为一页
表示一页）。

当 PDF 必须经得起机器阅读器的考验（简历、某些机构
门户），预检显示结构和解析器式提取结果
在您提交之前。这些是您可以阅读并采取行动的启发式风险信号。

## 多 PI 协作

按部分或目标拥有自己的文件。一个人拥有主“.bib”或共享
Zotero集团出口。就合著者是否编辑 TeX 或返回 PDF 注释达成一致。
仅在政策需要时才在经批准的机构 Git 主机上使用私有遥控器
它；并非所有拨款草案都属于公共 GitHub。

## 参考书目管理器

共享 Zotero 组导出多个 PI 可以刷新的“.bib”。导入到
项目，添加新引用时粘贴 DOI，并验证缺失的字段
在提交之前，年份不会在组装的 PDF 中显示为“[?]”：
[BibTeX 验证器](/tools/bibtex-validator/)。 Oleafly 完成并检查
当你写作时，根据项目参考书目的引用键，太糟糕了
`\cite` 键在日志出现之前出现。

## 数字和 PHI

切勿将可识别的患者数据放入用于特定目的的图表或标题中。
回购其他人可以克隆。使用去识别化的原理图。仍然存储任何东西
在与临床数据集相同的控制下敏感，而不是紧邻
公共方法图。

## 这不是什么

本地优先仍需接受 IRB 审查、数据使用协议和
去识别化。打开托管 AI 或推送遥控器，一些字节会离开
机器根据这些服务的政策。本地优先更改的是默认值
起草敏感叙述的路径：您控制的文件夹、编辑器
离线运行，您可以恢复历史记录，而无需向供应商询问
出口。

## 实用的启动设置

1、创建本地项目；一旦包被缓存就启用离线编译。
2. 除非政策和团队就提供商达成一致，否则不要使用人工智能。
3. 仅在经批准的主机上使用专用遥控器。
4. 章节所有权和单一书目所有者。
5. 在每次对目标和研究策略进行重大削减后进行页数检查。

写得就像合规官员会询问草稿在哪里一样。如果答案
是“加密笔记本电脑上的文件夹，Git 历史记录本地，可选私有
远程”，你的状况比“我们从未使用过的服务帐户”更好
已审查。”
