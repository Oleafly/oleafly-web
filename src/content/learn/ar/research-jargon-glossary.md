# معجم المصطلحات البحثية

يتحدث الباحثون لهجة. لا أحد يسلمك القاموس، وها هو: المصطلحات التي ستسمعها في عامك الأول، سطر واحد لكل منها. قم بالتصفح الآن، وعُد كلما أربكك الاجتماع.

## من الألف إلى الياء

| مصطلح | معنى |
| --- | --- |
| الملخص | ملخص من 150 إلى 250 كلمة في أعلى الورقة؛ غالبًا ما يكون الجزء الوحيد الذي يقرأه الناس |
| آو | في أي مكان على الأرض: منطقة زمنية للموعد النهائي، مما يعني أن لديك الوقت حتى يصل آخر مكان على الكوكب إلى منتصف الليل |
| ايه بي سي | رسوم معالجة المقالة، رسوم النشر بالذهب [الوصول المفتوح](/learn/open-access-doi-explained/) |
| قطعة أثرية | الكود أو البيانات أو المواد الموجودة في الورقة، والتي يتم تقييمها رسميًا في بعض الأحيان للحصول على شارة |
| أرخايف | [خادم الطباعة المسبقة] الكبير المجاني (/learn/what-is-arxiv/)، يُنطق "أرشيف" |
| جاهزة للكاميرا | النسخة النهائية المنسقة من قبل الناشر للورقة المقبولة؛ الاسم يسبق الكاميرات المشاركة |
| اقتباس | مؤشر رسمي للعمل السابق؛ وأيضا وحدة الاعتماد الأكاديمي |
| CFP | دعوة لتقديم الأوراق: إعلان المكان عن الموضوع والموعد النهائي والقواعد |
| المؤلف المقابل | المؤلف المدرج الذي يتعامل مع جميع رسائل البريد الإلكتروني المتعلقة بالورقة |
| مكتب رفض | الرفض من قبل المحرر أو الرؤساء قبل أي مراجعة، عادةً بسبب انتهاكات النطاق أو القواعد |
| أعمى مزدوج | قم بالمراجعة حيث يتم إخفاء المؤلفين والمراجعين عن بعضهم البعض، راجع [مراجعة النظراء، مفككة](/learn/peer-review-explained/) |
| دوي | معرف دائم للورقة، مثل 10.1145/xxxxx؛ الطريقة الموثوقة للاستشهاد |
| وآخرون. | اللاتينية "وغيرها"؛ "سميث وآخرون." يعني سميث بالإضافة إلى بقية قائمة المؤلفين |
| مؤشر ح | مقياس الباحث: عدد الأوراق البحثية التي تحتوي على عدد لا يقل عن عدد الاستشهادات لكل منها؛ التعامل مع الشك |
| عامل التأثير | متوسط ​​الاستشهادات الأخيرة لكل ورقة بحثية للمجلة؛ وكيل هيبة، تعامل أيضًا بالتشكيك |
| إيرب | مجلس المراجعة المؤسسية: لجنة الأخلاقيات التي يجب أن توافق على الدراسات التي تشمل البشر |
| الكلمة الرئيسية | الحديث المدعو الكبير الذي يفتتح يوم المؤتمر |
| مراجعة مضاءة | قراءة وتلخيص العمل الموجود حول موضوع |
| إل إن سي إس |سلسلة الإجراءات الصفراء لـ Springer، راجع [ACM وIEEE والأصدقاء](/learn/acm-ieee-and-friends/) |
| مراجعة رئيسية | حكم المجلة: مطلوب إصلاحات جوهرية، ثم إعادة المراجعة |
| الجدة | ما إذا كان العمل يقدم شيئًا جديدًا حقًا؛ الفأس المفضل لدى المراجعين |
| الكمبيوتر | لجنة البرنامج: مجمع المراجعين للمؤتمر |
| بي | الباحث الرئيسي: الأستاذ الذي يقود المختبر والحاصل على المنحة |
| الملصق | ملخص مطبوع تقدمه واقفاً بجانبه في إحدى جلسات المؤتمر |
| ما قبل الطباعة | ورقة تمت مشاركتها علنًا قبل مراجعة النظراء |
| وقائع | المجموعة المنشورة من الأوراق المقبولة في المؤتمر |
| دحض | رد المؤلفين القصير على المراجعات قبل القرار |
| أعمال ذات صلة | قسم الورق يضع عملك بين الأوراق السابقة |
| الاستنساخ | ما إذا كان بإمكان الآخرين إعادة تشغيل عملك والحصول على نفس النتائج |
| سيج | مجموعة المصالح الخاصة؛ مجتمعات ACM الفرعية (SIGPLAN، SIGGRAPH) |
| أعمى واحد | قم بالمراجعة حيث يعرف المراجعون المؤلفين ولكن ليس العكس |
| رقم التقديم | معرف ورقتك المجهول أثناء المراجعة؛ ستحفظه لا إرادياً |
| مواد تكميلية | ملاحق أو أدلة أو مقاطع فيديو إضافية مقدمة بجانب الورقة |
| استطلاع | ورقة ترسم منطقة بحثية بأكملها |
| المكان | يتم نشر أي أوراق بحثية عن أي مكان، راجع [المجلات والمؤتمرات وورش العمل](/learn/journals-vs-conferences/) |
| نسخة السجل | النسخة الرسمية المنشورة من ورقة |

## كيفية استخدام هذا

لا تحفظه. قم بوضع إشارة مرجعية عليها، ثم اذهب لقراءة شيء حقيقي: تعرض [جولة التشريح الورقي](/learn/paper-anatomy-tour/) هذه الكلمات في بيئتها الطبيعية، و[ما هي الورقة البحثية في الواقع](/learn/what-is-a-research-paper/) تربط الكلمات الكبيرة معًا.
