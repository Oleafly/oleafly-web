[LaTeX Workshop](https://marketplace.visualstudio.com/items?itemName=James-Yu.latex-workshop) в VS Code превосходен. Бесплатно, MIT, тщательно поддерживается. Если ваша неделя связана с рецептами компиляции в свободной форме, texdoc, Docker/WSL/remote, Live Share или магазином полных расширений, сохраните этот стек. Он создан для такой жизни.

Этот пост предназначен для тех случаев, когда вам нужно приложение, ориентированное на документы: многофайловые документы, компиляторы, PDF, Git, цитаты, рисунки и корректура уже объединены воедино. Бесплатный и с открытым исходным кодом (AGPL). LaTeX, Типст, Маркдаун. Обычные папки. Нет аккаунта.

Карта функций и ярлыки: [Из LaTeX Workshop](https://github.com/Oleafly/Oleafly/blob/main/docs/ComingFromLatexWorkshop.md).

## Редактор

CodeMirror 6 с индексом всего проекта по LaTeX, Typst, Markdown и BibTeX.

Что вы на самом деле получаете изо дня в день:

- Переход к определению, поиск ссылок, переименование меток и макросов (предупреждения о конфликтах)
- Оперативная проверка на наличие неработающих ссылок, плохих цитат, отсутствующих включений (`\cref`, `\eqref`, ссылки на диапазон, …)
- Локальные + просмотры структуры проекта; фильтруй и прыгай
- Дополнения для ключей, путей и макросов, которые определяет ваш проект (`\newcommand`, формы аргументов xparse)
- поддержка `.tex`, `.ltx`, `.sty`, `.cls`; фрагменты аргументов; проверки окружающей среды
- TexLab для LaTeX (установка по желанию); Корабли Tinymist для Typst
- Единая диагностика: синтаксис, компиляция, языковой сервис, ссылки, цитаты, орфография, грамматика.
- Живой предварительный просмотр математики KaTeX; источник остается редактируемым
- Harper + Hunspell только в автономном режиме (команды и математические операции замаскированы)
- Визуальный режим для обычных структур; Вим; слэш-команды; вкладки с несколькими файлами
- Следующим будет завершение команд с учетом пакетов из большого корпуса (данные MIT LaTeX Workshop, предоставленные с указанием авторства)

Рабочая область PDF: непрерывная прокрутка, развороты, поиск, контур, съемное окно. Двунаправленный SyncTeX между файлами глав. Сопоставление все еще работает, пока ожидается перестройка. Последний хороший PDF-файл сохраняется. Отмените действие скомпилированного исходного набора, и предварительный просмотр станет текущим без полной перекомпиляции.

CI книжного масштаба: рукопись на 6200 строк, многосемейная математика, главы, цитаты, корректура, бюджет производительности при прокрутке, вводе, вставке, отмене, завершении, перекомпиляции и SyncTeX.

LaTeX Workshop — мощное расширение обычной IDE. Oleafly поставляет этот цикл документов уже собранным, поэтому вы не подключаете один и тот же стек из настроек и выбираете торговую площадку каждый семестр.

## Компиляторы в приложении

Tectonic (LaTeX) и Typst поставляются вместе с приложением. Уценка через управляемый Pandoc, когда вам это нужно. Сначала скомпилируйте пакеты кэшей; после этого кэшированные сборки работают в автономном режиме. Автономный режим может привязать компилятор к кешу.

Автокомпиляция (устранение дребезга, возможность отмены, последние победы). `Cmd/Ctrl-Enter` перекомпилируйте. Кнопка остановки. Гуманизированные карты ошибок на линии. Последний хороший PDF-файл, пока работает новая сборка.

Рецепты, цепочки latexmk, экранирование оболочки и собственный .latexmkrc остаются в рулевой рубке LaTeX Workshop. Для большинства статей и диссертаций требуется только надежный контролируемый механизм.

Шаблоны: 23 стартовых набора в комплекте (IEEE, ACM, Elsevier, Beamer, диссертации, резюме, бланки Typst и т. д.) плюс 99 в загружаемых пакетах. Сохраните любой проект как шаблон. Дополнительное создание шаблона AI при настройке модели.

## Библиотека, Git, инструменты исследования

Проекты как книги: цвет обложки, значок движка, происхождение вилки, предварительный просмотр последней PDF-страницы при наведении, закладки, поиск `/docs` в каждом документе. Fork сохраняет полную историю Git для рискованного переписывания рядом с отправленной копией.

Настоящий Git с первого дня. Промежуточный анализ, параллельные различия (редактируемое рабочее дерево), удаление, восстановление. Автоматические контрольные точки после успешной компиляции и простоя редактирования; ИИ запускает контрольную точку перед первой записью. GitHub необязательно (PAT или OAuth потока устройства). Терминал `git log` соответствует приложению.

Вставьте DOI/arXiv/title → dedupe → `.bib` → `\cite`. Пакетный импорт BibTeX, RIS, EndNote, Zotero RDF. Поиск по цитированию через arXiv, Semantic Scholar, Crossref, PubMed, OpenAlex. Компоновщик диаграмм для редактируемого TikZ. Валидатор, таблицы, уравнения, лабораторный поиск, сроки, преобразование PDF в LaTeX, преобразование изображений в LaTeX с концептуальной моделью.

## Предпечатная проверка, экспорт, конфиденциальность

Предварительная проверка: структура, неопределенные ссылки, повторяющиеся метки, предварительный просмотр извлечения в стиле парсера, результаты, ориентированные на чтение с экрана. Каждый флаг риска имеет достаточный контекст, чтобы вы могли проверить его самостоятельно, не доверяя оценкам «черного ящика».

Экспорт: PDF всегда; DOCX/HTML/Markdown, когда доступен Pandoc; PowerPoint для колод; EPUB для книг; исходный ZIP для передачи.

Нет аккаунта Oleafly. Нет телеметрии продукта. Отчеты о сбоях открывают предварительно заполненную проблему GitHub, которую вы просматриваете. Сеть для пакетов, шаблонов, размещенного ИИ, цитат, обновлений, GitHub. Редактирование, кэшированная компиляция, грамматика, проверка орфографии и локальный Git работают в автономном режиме.

## Когда LaTeX Workshop все еще подходит

- Рецепты в свободной форме, latexmk, Shell-Escape, `.latexmkrc`
- texdoc в редакторе
- Docker, WSL, удаленная разработка.
- Live Share и многопользовательское редактирование в реальном времени
- Работа на торговой площадке VS Code для работы без документов.

Oleafly — это публичная бета-версия. Тяжелые файлы издательского класса все еще могут споткнуться о Tectonic; сообщите о них.

## Попробуйте

1. Загрузите с
   [страница релизов](https://github.com/Oleafly/Oleafly/releases/latest)
   (подпись/нотариально заверенная macOS; Windows может использовать SmartScreen один раз).
2. Импортируйте файлы .tex, .bib и рисунки (или начните с шаблона).
3. Составьте один раз, а затем в течение дня пишите на настоящей бумаге.

Оставьте VS Code установленным. Одни и те же файлы работают в любом приложении. Если рабочий день в Oleafly проходит лучше, перенесите больше проектов; если рецепты и пульт по-прежнему выигрывают для данного дерева, оставьте это дерево в Мастерской.
