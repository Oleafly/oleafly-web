# Глосарій наукового жаргону

Дослідники розмовляють діалектом. Вам ніхто не дає словник, тож ось він: терміни, які ви почуєте на першому курсі, по одному рядку. Переглядайте зараз, повертайтеся, коли зустріч вас бентежить.

## А до Я

| Термін | Значення |
| --- | --- |
| Анотація | Резюме від 150 до 250 слів у верхній частині статті; часто єдина частина, яку люди читають |
| AoE | Будь-де на Землі: часовий пояс крайнього терміну, тобто у вас є час до опівночі в останньому місці на планеті |
| БТР | Плата за обробку статті, плата за публікацію золота [відкритий доступ](/learn/open-access-doi-explained/) |
| Артефакт | Код, дані або матеріали, що стоять за документом, іноді офіційно оцінюються для бейджа |
| arXiv | Великий безкоштовний [сервер препринтів](/learn/what-is-arxiv/), вимовляється як «архів» |
| Готовий до камери | Остаточна версія прийнятої статті у форматі видавця; назва передує використанню камер |
| Цитування | Формальний покажчик попередньої роботи; також одиниця академічного кредиту |
| CFP | Оголошення теми, дедлайну та правил проведення |
| Автор-кореспондент | Зазначений автор, який обробляє всю електронну пошту про статтю |
| Стіл відхилений | Відхилення редактором або керівниками перед будь-яким рецензуванням, зазвичай через порушення обсягу чи правил |
| Подвійний сліпий | Огляд, де автори та рецензенти приховані один від одного, див. [рецензування, розшифровано](/learn/peer-review-explained/) |
| DOI | Постійний ідентифікатор паперу, наприклад 10.1145/xxxxx; надійний спосіб цитування |
| та ін. | латинське «та інші»; "Сміт та ін." означає Сміта плюс решту списку авторів |
| h-індекс | Показник дослідника: h статей із щонайменше h цитуваннями кожна; ставитися скептично |
| Імпакт-фактор | Середнє нещодавнє цитування на статтю для журналу; проксі престижу, також ставтеся скептично |
| IRB | Інституційна ревізійна рада: комітет з етики, який має схвалити дослідження за участю людей |
| Keynote | Велика запрошена доповідь, яка відкриває день конференції |
| Літ огляд | Читання та конспектування наявної роботи з теми |
| LNCS |Серія жовтих матеріалів Springer, див. [ACM, IEEE та друзі](/learn/acm-ieee-and-friends/) |
| Основна редакція | Вердикт журналу: потрібні суттєві виправлення, потім перегляньте |
| Новинка | Чи робить робота щось справді нове; улюблена сокира рецензентів |
| ПК | Програмний комітет: рецензентний пул конференції |
| ПІ | Головний дослідник: професор, який керує лабораторією та має грант |
| Плакат | Роздруковане резюме, яке ви представляєте поруч із ним на сесії конференції |
| Препринт | Стаття, опублікована перед рецензуванням |
| Збірник матеріалів | Опублікований збірник прийнятих доповідей конференції |
| Спростування | Коротка відповідь авторів на відгуки перед рішенням |
| Схожі роботи | Розділ паперів, що позиціонує вашу роботу серед попередніх робіт |
| Відтворюваність | Чи можуть інші повторити вашу роботу й отримати ті самі результати |
| SIG | Група спеціальних інтересів; Підспільноти ACM (SIGPLAN, SIGGRAPH) |
| Одинарна штора | Рецензія, де рецензенти знають авторів, але не навпаки |
| Номер подання | Анонімний ідентифікатор вашої роботи під час перевірки; мимоволі запам'ятаєш |
| Додатковий матеріал | Додаткові додатки, докази або відео, подані разом із документом |
| Опитування | Папір, що відображає цілу область дослідження |
| Місце проведення | Публікуються будь-які довідкові матеріали, див. [журнали, конференції та семінари](/learn/journals-vs-conferences/) |
| Версія запису | Офіційна опублікована копія паперу |

## Як це використовувати

Не запам'ятовуйте це. Додайте це в закладки, а потім прочитайте щось справжнє: [подорож з паперової анатомії](/learn/paper-anatomy-tour/) показує ці слова в їхньому природному середовищі існування, а [що насправді таке дослідницька стаття](/learn/what-is-a-research-paper/) об’єднує великі.
