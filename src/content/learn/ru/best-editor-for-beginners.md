# Выберите редактор, который вы действительно откроете

Лучший редактор LaTeX для новичка — не самый мощный. Именно он позволяет с наименьшими трудностями перейти от пустого файла к скомпилированному PDF-файлу. Ранняя компиляция часто имеет большее значение, чем какая-либо отдельная функция. Четыре возможности охватывают все, что вам нужно с первого дня.

Во-первых, компиляция должна работать без установки вручную многогигабайтного дистрибутива TeX. Во-вторых, вам нужен параллельный предварительный просмотр PDF-файла с помощью SyncTeX, поэтому щелчок в PDF-файле позволяет перейти к соответствующей строке исходного текста и обратно. В-третьих, ваши файлы должны храниться на диске в формате .tex, чтобы вы могли заархивировать их, отправить по электронной почте или поместить в Git без необходимости экспорта. В-четвертых, ошибки должны поступать в виде читаемых сообщений, а не только в виде необработанного журнала TeX.

## Реальные варианты

| Редактор | Настройка | Работает оффлайн | Заметки |
| --- | --- | --- | --- |
| Олифлай | Скачать приложение | Редактирование всегда; при компиляции используются кэшированные пакеты | Включенный движок, история Git, дополнительный искусственный интеллект с вашим собственным ключом |
| TeXShop / TeXworks | Сначала установите дистрибутив TeX | Да | Минимальный и надежный |
| VS Code + семинар по LaTeX | Сначала установите дистрибутив TeX | Да | Подходит, если вы уже работаете в VS Code |
| На обороте | Создать аккаунт в браузере | Ограниченная | Нулевая установка; проекты живут на своих серверах |

Две средние строки имеют общую скрытую стоимость: прежде чем редактор станет полезным, вы сами устанавливаете и поддерживаете TeX Live или MiKTeX. Именно на этом останавливаются многие новички. Опция браузера удаляет настройку, но перемещает ваши файлы в учетную запись. Более подробно компромиссы описаны в [проект браузера и папка на диске](/learn/overleaf-vs-local/).

## Разумное значение по умолчанию

Если вам нужны локальные файлы без администрирования TeX, начните с [Oleafly](https://github.com/Oleafly/Oleafly/releases/latest): компилятор поставляется внутри приложения и загружает пакеты в первый раз, когда они нужны документу. Какой бы редактор вы ни выбрали, соедините его с [учебником по первому документу](/learn/first-document/) и держите под рукой [шпаргалку](/learn/cheatsheet/). Редактор имеет меньшее значение, чем составление вашей первой страницы сегодня.
