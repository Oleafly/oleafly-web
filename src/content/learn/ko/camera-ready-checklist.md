# 당황하지 않고 카메라 준비 완료

수락되었습니다! 축하 행사가 끝나면 마지막 마감일인 카메라 준비가 완료됩니다. 이름은 출판사가 인쇄를 위해 페이지 사진을 찍을 때의 유물입니다. 오늘은 독자들이 영원히 보게 될 것과 마찬가지로 진행 과정에 들어가는 최종 버전을 의미합니다. 이 이후에는 어떤 편집자도 오타를 수정하지 않습니다. 그 부분은 당신에게 달려 있습니다.

## 제출과 카메라 준비 사이의 변경 사항

제출된 버전은 검토자를 위해 조정되었습니다. 카메라 지원은 영구 녹화용이며 다음과 같은 몇 가지 사항이 변경됩니다.

| 아이템 | 제출된 버전 | 카메라 지원 |
|---|---|---|
| 저자 이름 | 숨김(이중맹검) | 실명, 소속, 이메일 |
| 감사의 말씀 | 생략 | 자금, 보조금, 감사 |
| 페이지 제한 | 검토 제한 | +1 페이지인 경우가 많지만 정확함 |
| 저작권 차단 | 자리 표시자 또는 없음 | 출판사 블록, DOI, ISBN |
| 자기 인용 | 3인칭("Smith 외.") | "우리의 이전 작업"이라고 말할 수 있습니다 |
| 반박 약속 | 약속 | 실제로 배송됨 |

익명화 해제는 이름을 다시 추가하는 것 이상입니다. 귀하의 신원과 관련하여 작성한 모든 장소의 출처를 검색하십시오. 일반적인 숨김 지점은 [이중 맹검 검토를 위한 익명화](/learn/anonymization-double-blind/)를 참조한 다음 모두 뒤집으세요.

## 정확한 페이지 제한, 다시 한번

카메라 준비 제한은 의자뿐만 아니라 게시자에 의해 시행되며 추가 콘텐츠(작성자 차단, 승인)가 공간을 차지합니다. 갑자기 여섯 줄이 넘어가면 솔직하게 하십시오. 띄어쓰기 명령을 남용하기보다는 산문과 그림을 촘촘하게 하십시오. 게시자가 형식을 확인하기 때문에 [범죄 없는 페이지 제한](/learn/page-limits-without-crimes/)의 기술이 여기에 이중으로 적용됩니다.

## 글꼴이 포함되어야 합니다.

사람을 물어뜯는 놈이 바로 이것이다. 출판사는 자동화된 검사를 실행하며 거부 이유 중 가장 큰 이유는 일반적으로 플로팅 도구에서 내보낸 그림 PDF를 통해 밀수입되는 비포함 글꼴입니다. `pdffonts yourpaper.pdf`를 확인하세요. 모든 글꼴에는 "emb: yes"가 표시되어야 합니다. 그렇지 않은 경우 범인은 거의 항상 인물입니다. 글꼴을 포함하거나 적절하게 생성된 PDF로 다시 내보냅니다.

## 최종 교정: 참고문헌 먼저

참조는 엔트로피가 집중되는 곳입니다. 업로드하기 전에:

- [ ] 아니요 "??" 로그의 인용 또는 정의되지 않은 참조
- [ ] 모든 참고문헌 항목에는 장소, 연도 및 대소문자가 올바르게 표시된 제목이 있습니다.
- [ ] 저자 이름의 철자가 정확함(사람들은 자신의 이름을 알아차림)
- [ ] arXiv 전용 인용이 존재하는 출판 버전으로 업데이트되었습니다.
- [ ] 참조의 URL이 여전히 확인됩니다.

그런 다음 전체 논문을 큰 소리로 한 번 읽어보세요. 느리고 작동합니다.

## 소스 업로드 문제

대부분의 게시자는 PDF뿐만 아니라 LaTeX 소스를 원하며 빌드 시스템은 까다롭습니다. '.bbl'을 포함하고, 비표준 패키지를 피하고, 파일 레이아웃을 따릅니다. 깨끗한 소스 ZIP을 내보내고(Oleafly는 이 작업을 한 단계로 수행함) 업로드하기 전에 빈 폴더에서 처음부터 테스트 컴파일합니다. 컴퓨터에 있는 파일 때문에 빌드되는 경우 게시자의 시스템에서 이를 알아냅니다.

## 일회성 체크리스트

- [ ] 이름, 소속, 이메일이 복원되고 수정되었습니다.
- [ ] 감사의 말과 자금 지원 번호가 추가되었습니다.
- [ ] 출판사 이메일에서 붙여넣은 저작권 블록/DOI 정보
- [ ] 페이지 제한을 정확히 충족했습니다.
- [ ] `pdffonts`는 포함된 모든 글꼴을 표시합니다.
- [ ] 참고문헌 교정
- [ ] 처음부터 깨끗한 소스 ZIP 컴파일
- [ ] 하루 여유를 두고 업로드됨

그러면 영구적으로 완료됩니다. [발표](/learn/present-your-paper/)에 대해 생각해 볼 시간입니다.
