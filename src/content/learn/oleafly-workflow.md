# A week of writing in Oleafly

## A simple paper loop

1. **Library:** create a project from a [template](/templates/).
2. **Write** with autocomplete and slash commands.
3. **Compile** and click through with SyncTeX.
4. **Cite** from a `.bib` file (and optionally check it with the [BibTeX validator](/tools/bibtex-validator/)).
5. **History:** Git commits on compile; push to GitHub when you are ready.
6. **AI (optional):** chat that can edit and compile, using your own API key.

No Oleafly account. The project folder on disk is the product.

Docs: [Getting started](/docs/getting-started/), [Philosophy](/docs/philosophy/).
