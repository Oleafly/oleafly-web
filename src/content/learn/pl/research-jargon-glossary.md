# Glosariusz żargonu badawczego

Naukowcy posługują się dialektem. Nikt nie wręcza ci słownika, więc oto on: terminy, które usłyszysz na pierwszym roku, po jednym wierszu każdy. Przeglądaj teraz i wróć, gdy spotkanie Cię zdezorientuje.

## A do Z

| Termin | Znaczenie |
| --- | --- |
| Streszczenie | Streszczenie zawierające od 150 do 250 słów u góry artykułu; często jedyna część, którą ludzie czytają |
| Obszarowe | Gdziekolwiek na Ziemi: strefa czasowa z ostatecznym terminem, co oznacza, że ​​masz czas, aż w ostatnim miejscu na planecie wybije północ |
| APC | Opłata za przetwarzanie artykułu, opłata za publikację złota [otwarty dostęp](/learn/open-access-doi-explained/) |
| Artefakt | Kod, dane lub materiały zawarte w artykule, czasami formalnie oceniane w celu uzyskania odznaki |
| arXiv | Duży darmowy [serwer preprintów](/learn/what-is-arxiv/), wymawiany jako „archiwum” |
| Gotowy do aparatu | Ostateczna wersja zaakceptowanego artykułu w formacie wydawcy; nazwa poprzedza użycie kamer |
| Cytat | Formalne wskazanie wcześniejszej pracy; także jednostka zaliczenia akademickiego |
| WPRyb | Zaproszenie do składania artykułów: ogłoszenie tematu, terminu i zasad |
| Autor do korespondencji | Wymieniony autor, który obsługuje całą pocztę e-mail dotyczącą artykułu |
| Odrzucenie biurka | Odrzucenie przez redaktora lub przewodniczących przed jakąkolwiek recenzją, zwykle z powodu naruszenia zakresu lub zasad |
| Podwójna ślepa | Sprawdź, gdzie autorzy i recenzenci są przed sobą ukryci, patrz [recenzja partnerska, dekodowana](/learn/peer-review-explained/) |
| DOI | Stały identyfikator gazety, np. 10.1145/xxxxx; niezawodny sposób cytowania |
| i in. | łacińskie „i inne”; „Smith i in.” oznacza Smitha i resztę listy autorów |
| indeks h | Wskaźnik badacza: h artykułów, z których każda ma co najmniej h cytowań; traktować sceptycznie |
| Współczynnik wpływu | Średnia liczba ostatnich cytowań na artykuł w czasopiśmie; prestiżowy pełnomocnik, także traktuj sceptycznie |
| IRB | Instytucjonalna Komisja Rewizyjna: komisja etyczna, która musi zatwierdzać badania z udziałem ludzi |
| Keynote | Wielkie wystąpienie na zaproszenie otwierające dzień konferencji |
| Litowa recenzja | Czytanie i podsumowanie dotychczasowej pracy na dany temat |
| LNC |Seria żółtych postępowań Springera, zobacz [ACM, IEEE i przyjaciele](/learn/acm-ieee-and-friends/) |
| Ważna rewizja | Werdykt czasopisma: wymagane są istotne poprawki, a następnie ponowna recenzja |
| Nowość | Czy dzieło wnosi coś naprawdę nowego; ulubiony topór recenzentów |
| komputer | Komitet programowy: grono recenzentów konferencji |
| PI | Kierownik projektu: profesor kierujący laboratorium i posiadający grant |
| Plakat | Wydrukowane podsumowanie, które prezentujesz stojąc obok niego podczas sesji konferencyjnej |
| Przeddruk | Artykuł udostępniony publicznie przed recenzją |
| Postępowanie | Opublikowany zbiór artykułów zaakceptowanych na konferencji |
| Obalenie | Krótka odpowiedź autorów na recenzje przed decyzją |
| Powiązana praca | Sekcja papierowa pozycjonująca Twoją pracę wśród wcześniejszych prac |
| Powtarzalność | Czy inni mogą ponownie uruchomić Twoją pracę i uzyskać takie same wyniki |
| SIG | Grupa specjalnego zainteresowania; Podspołeczności ACM (SIGPLAN, SIGGRAPH) |
| Pojedyncza roleta | Recenzja, w której recenzenci znają autorów, ale nie odwrotnie |
| Numer zgłoszenia | anonimowy identyfikator Twojej pracy podczas recenzji; zapamiętasz to mimowolnie |
| Materiał uzupełniający | Dodatkowe załączniki, dowody lub filmy przesłane wraz z artykułem |
| Ankieta | Artykuł mapujący cały obszar badawczy |
| Miejsce | Wszelkie artykuły lokalne są publikowane, zobacz [czasopisma, konferencje i warsztaty](/learn/journals-vs-conferences/) |
| Wersja zapisu | Oficjalna opublikowana kopia artykułu |

## Jak tego używać

Nie zapamiętuj tego. Dodaj go do zakładek, a potem przeczytaj coś prawdziwego: [wycieczka po anatomii papieru](/learn/paper-anatomy-tour/) pokazuje te słowa w ich naturalnym środowisku i [czym właściwie jest praca naukowa](/learn/what-is-a-research-paper/) łączy te najważniejsze.
