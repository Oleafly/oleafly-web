Работа по математике представляет собой структуру обозначений и доказательств. LaTeX используется по умолчанию, поскольку оба
становится болезненно в Word, если аргумент длится больше страницы. Компилятор
не самая сложная часть. Согласованность – это: номера теорем скачут, когда вы вставляете
лемма, буква «V», означающая три разные вещи, и доказательства, оставляющие
Знак QED плавает на следующей строке.

Это практическая подготовка для курсовой работы, заметок arXiv и глав диссертации.
Украдите то, что вам нужно; игнорируйте остальное, пока не станет больно.

##амстм рано, до первой леммы

Загрузите «amsthm», прежде чем придумывать специальную жирную «теорему». заголовки:

```latex
\usepackage{amsthm}
\theoremstyle{plain}
\newtheorem{theorem}{Theorem}[section]
\newtheorem{lemma}[theorem]{Lemma}
\newtheorem{proposition}[theorem]{Proposition}
\newtheorem{corollary}[theorem]{Corollary}
\theoremstyle{definition}
\newtheorem{definition}{Definition}[section]
\newtheorem{example}{Example}[section]
\theoremstyle{remark}
\newtheorem*{remark}{Remark}
```

Нумерация по разделам обеспечивает стабильность ссылок при вставке материала над разделом.
результат. Совместное использование счетчика («[теоремы]») для лемм и предложений является обычным явлением.
по чистой математике; прикладные работы иногда нумеруют все самостоятельно. Выберите один
и придерживайтесь его на протяжении всего документа.

Урок: [блоки теорем и доказательств](/learn/theorems-proofs/).

## Доказательства, которые заканчиваются чисто

Используйте среду «доказательство», чтобы отметка об окончании корректуры располагалась в нужном месте:

```latex
\begin{proof}
  ...
\end{proof}
```

Если последняя строка представляет собой отображаемое уравнение, завершите ее `\qedhere`, чтобы поле выглядело
не является сиротой в следующей строке. Вложенные доказательства (утверждение внутри доказательства) работают.
лучше использовать среду «заявок» с собственными короткими доказательствами, чем использовать отступы
проза, которая никогда не закрывается.

Для домашних заданий, где инструктор хочет отмечать шаги вручную, по-прежнему используйте LaTeX.
чистый PDF-файл для отправки, но сохраняйте черновую работу в отдельном файле заметок, чтобы вы могли
не удалять единственную правильную строку при переписывании.

## Макрогигиена

Определите символы один раз:

```latex
\newcommand{\R}{\mathbb{R}}
\newcommand{\N}{\mathbb{N}}
\newcommand{\eps}{\varepsilon}
\DeclareMathOperator{\Hom}{Hom}
\DeclareMathOperator{\Spec}{Spec}
```

Если два понятия имеют одну и ту же букву, устраните неоднозначность с помощью макросов (`\VectSpace` vs
`\RandomVar`) вместо повторного использования `V` с разными шрифтами. Соавторы не будут
угадайте, какой шрифт означает какой объект. Когда лист с обозначениями вырастает за пределы экрана,
поместите его в `notation.tex` и `\input`, чтобы все редактировали один файл.

Инструменты искусственного интеллекта любят изобретать новые символы. Если вы его используете, вставьте свой макроблок в
в приглашении и требованию использовать только определенные имена. Та же дисциплина применяется
без AI: новый символ → добавить на лист → затем ввести.

## Выравнивание для длинных производных

`align` и `split` делают многострочные вычисления читабельными. Число только выстраивает вас
будет цитироваться с помощью `\eqref`. За стеной пронумерованных уравнений труднее следить, чем за
короткое повествование с двумя размеченными строками.

```latex
\begin{align}
  f(x)
  &= g(x) + h(x) \label{eq:decomp} \\
  &= \cdots
\end{align}
```

Для одного многострочного уравнения, которое должно содержать одно число, используйте `split`
внутри `уравнения`. Для случаев `cases` или `aligned` лучше самодельного массива
трубы.

## Перекрестные ссылки, которые сохраняются при изменении порядка

Никогда не пишите «по теореме 2.3» голым текстом. Используйте `\ref` или, с `cleveref`,
`\cref{thm:main}`. Метки идут после заголовка или строки заголовка теоремы, а не
раньше. Если две главы имеют одинаковые метки типа `thm:main`, добавьте префикс к главе.
(`ch3-thm:main`), иначе при объединении файлов вы получите неправильные цели.

Переход к определению в рамках всего проекта и проверка неработающих ссылок в режиме реального времени помогают при работе с несколькими файлами.
тезисы. Сейчас это нормальная территория редактора-исследователя, а не роскошь.

## Многофайловые заметки и тезисы

Даже длинный набор домашних заданий становится проще благодаря корневому файлу и входным разделам. Тезисы
почти всегда требуется `\include` для каждой главы и `\includeonly`, пока вы ее разрабатываете
главу за раз. Храните рисунки в `figures/ch3/`, чтобы изменить порядок глав.
не ломать пути.

Полные компиляции диссертаций выполняются медленно. Режим черновой фигуры, экстернализация тяжелого TikZ и
по возможности компилируйте только ту главу, которую вы редактируете. См.
[файлы разделенных глав](/learn/split-chapter-files/) и
[ускорить компиляцию](/learn/ускорить-компиляцию/).

## Когда PDF-файл доступен

Курсовая работа по-прежнему нуждается в скучной оболочке: поля по учебной программе, номера страниц,
звание, а иногда и заявление об академической честности.
[краткая справка](/learn/cheatsheet/) описывает это, чтобы вы могли уделить внимание
доказательство.

Сохраняйте исходник. Размеченный PDF-файл без `.tex` — это тупик, когда следующая проблема
set повторно использует одну и ту же преамбулу. Локальная папка с историей Git (или исследовательская папка).
редактор, который компилирует контрольные точки) превосходит `final_v3_really.pdf` на
рабочий стол.

## Прежде чем отправить

Убедитесь, что теоремы и леммы имеют единую схему нумерации, каждый символ в
тело определяется в листе макроса, а доказательства используют `proof`/`\qedhere`
где это необходимо. Нумеруйте только те уравнения, которые вы приводите. Все перекрестные ссылки должны быть
`\ref`/`\cref`, а не жестко закодированные числа. Откройте PDF-файл один раз: встроенные шрифты, поля.
соответствовать брифу.

## Домашнее задание против бумаги

В домашней работе ясность важнее продуманности упаковки. Для главы статьи или диссертации
инвестируйте в настройку теоремы и лист макросов один раз, а затем используйте повторно. Не восстанавливать
нумерация в середине проекта, потому что в сообщении в блоге предлагался другой стиль.

## Делимся с соавторами

Отправьте PDF-файл для чтения и репозиторий (или zip-архив с исходниками) для редактирования. Если
соавтор возвращает только отсканированную разметку, применяет ее в тот же день и фиксирует. Несвежий
стопки бумаг — это то, как два человека по-разному «исправляют» одну и ту же лемму.

После этой настройки LaTeX практически исчезает, и вы можете думать о математике.
