# De verklarende woordenlijst van onderzoeksjargon

Onderzoekers spreken een dialect. Niemand geeft je het woordenboek, dus hier is het: de termen die je in je eerste jaar zult horen, elk één regel. Blader nu en kom terug wanneer een vergadering u in de war brengt.

## A tot Z

| Termijn | Betekenis |
| --- | --- |
| Samenvatting | De samenvatting van 150 tot 250 woorden bovenaan een artikel; vaak het enige deel dat mensen lezen |
| AoE | Waar dan ook op aarde: een tijdzone met deadline, wat betekent dat je tijd hebt tot de laatste plaats op de planeet middernacht is |
| APC | Artikelverwerkingskosten, de vergoeding voor goud [open access](/learn/open-access-doi-explained/) publiceren |
| Artefact | De code, gegevens of materialen achter een paper, soms formeel geëvalueerd voor een badge |
| arXiv | De grote gratis [preprint-server](/learn/what-is-arxiv/), uitgesproken als "archief" |
| Cameraklaar | De definitieve, door een uitgever opgemaakte versie van een geaccepteerd artikel; de naam dateert van vóór de camera's |
| Citaat | Een formele verwijzing naar eerder werk; tevens de eenheid van academisch krediet |
| GVB | Call for papers: aankondiging van onderwerp, deadline en regels door een locatie |
| Corresponderende auteur | De vermelde auteur die alle e-mail over het artikel afhandelt |
| Bureau afwijzing | Afwijzing door de redacteur of voorzitter voorafgaand aan een beoordeling, meestal vanwege overtredingen van de reikwijdte of regels |
| Dubbelblind | Review waar auteurs en reviewers voor elkaar verborgen zijn, zie [peer review, decoded](/learn/peer-review-explained/) |
| DOI | Een permanent ID voor een papier, zoals 10.1145/xxxxx; de betrouwbare manier om te citeren |
| et al. | Latijnse "en anderen"; "Smit et al." betekent Smith plus de rest van de auteurslijst |
| h-index | Een onderzoeksstatistiek: h papers met elk minstens h citaties; behandel met scepsis |
| Impactfactor | Gemiddelde recente citaties per artikel voor een tijdschrift; een prestige-proxy, ook met scepticisme behandelen |
| IRB | Institutional Review Board: de ethische commissie die onderzoeken waarbij mensen betrokken zijn moet goedkeuren |
| Hoofdnoot | Het grote uitgenodigde gesprek dat een conferentiedag opent |
| Verlichte recensie | Het bestaande werk over een onderwerp lezen en samenvatten |
| LNCS |Springer's gele proceedingsreeks, zie [ACM, IEEE, and Friends](/learn/acm-ieee-and-friends/) |
| Grote herziening | Tijdschriftoordeel: substantiële verbeteringen nodig, daarna opnieuw bekijken |
| Nieuwigheid | Of het werk iets echt nieuws doet; favoriete bijl van recensenten |
| pc | Programmacommissie: de reviewerspool voor een congres |
| PI | Hoofdonderzoeker: de hoogleraar die het lab leidt en de beurs bezit |
| Affiche | Een gedrukte samenvatting die u ernaast presenteert tijdens een conferentiesessie |
| Voordruk | Een paper dat openbaar werd gedeeld vóór peer review |
| Procedure | De gepubliceerde verzameling geaccepteerde papers van een conferentie |
| Weerlegging | Korte reactie van de auteurs op recensies vóór het besluit |
| Gerelateerd werk | Het papieren gedeelte waarin uw werk tussen eerdere artikelen wordt geplaatst |
| Reproduceerbaarheid | Of anderen uw werk kunnen herhalen en dezelfde resultaten kunnen behalen |
| SIG | Speciale belangengroep; Subcommunities van ACM (SIGPLAN, SIGGRAPH) |
| Enkelblind | Review waarbij reviewers de auteurs kennen, maar niet andersom |
| Inzendingsnummer | De anonieme ID van uw document tijdens beoordeling; je zult het onwillekeurig onthouden |
| Aanvullend materiaal | Extra bijlagen, proefdrukken of video's die naast het artikel worden ingediend |
| Enquête | Een paper dat een heel onderzoeksgebied in kaart brengt |
| Locatie | Overal waar papers worden gepubliceerd, zie [tijdschriften, conferenties en workshops](/learn/journals-vs-conferences/) |
| Versie van record | De officieel gepubliceerde kopie van een artikel |

## Hoe dit te gebruiken

Onthoud het niet. Maak er een bladwijzer van en lees dan iets echts: de [paper anatomy tour](/learn/paper-anatomy-tour/) toont deze woorden in hun natuurlijke habitat, en [wat een onderzoekspaper eigenlijk is](/learn/what-is-a-research-paper/) verbindt de groten met elkaar.
