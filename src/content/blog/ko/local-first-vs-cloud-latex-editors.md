Cloud LaTeX 편집자가 승리한 이유는 간단한 이유입니다. 바로 설정이 필요하지 않기 때문입니다. 탭을 열고 컴파일하세요.
수년 동안 그것은 TeX 배포판과 싸우는 가장 쉬운 방법이었습니다.
노트북, 그리고 많은 사람들이 여전히 그것을 선호합니다.

하지만 설정은 더 이상 대부분의 문서에서 어려운 부분이 아닙니다. 다음과 같은 엔진
Tectonic은 데스크탑 앱 내부로 배송되고 필요에 따라 패키지를 가져올 수 있습니다.
설치 및 컴파일은 대략 클라우드 계정을 만드는 데 걸리는 시간입니다. 는
물어볼 가치가 있는 질문은 구독으로 여전히 무엇을 구매하는지, 그리고 귀하가 무엇을 구매하는지입니다.
그것을 위해 넘겨주세요.

## 클라우드에서 포기하는 것

귀하의 원고는 다른 사람의 데이터베이스에 있습니다. 내보내기는 일반적으로 다음까지 작동합니다.
계획이 변경되거나, 회사가 인수되거나, 기능이 사라지는 동안
마감일은 그대로 유지됩니다.

미사용 암호화는 외부인의 접근을 차단합니다. 서비스 자체는 여전히 볼 수 있습니다
인프라를 통과하는 초안, 보조금 및 미공개 결과.

지연 시간은 또 다른 조용한 비용입니다. 귀하의 컴퓨터에서 처리되는 키 입력은 거의
항상 더 빠르게. 컴파일 대기열 및 무료 계층 시간 초과는 다음과 같은 경우에만 표시됩니다.
빌드는 당신 것이 아닙니다.

오프라인은 또 다른 격차입니다. 비행기 안, 병원 지하실, 보안 구역
개방형 네트워크가 없는 실험실에서는 브라우저 편집기가 단지 빈 탭일 뿐입니다.

일부 호스팅 편집자는 전체 기록, 변경 사항 추적 또는 Git/GitHub 동기화도 제공합니다.
유료 등급보다 뒤처져 있습니다. 로컬 Git은 당신이 어떤 플랜을 구입했는지 상관하지 않습니다.

## 로컬 우선 변경 사항

프로젝트는 열 수 있는 폴더에 있는 일반 파일입니다. 역사는 현실이 될 수 있다 Git you
모든 터미널에서 검사하세요. 컴파일은 대기열 없이 CPU에서 실행됩니다. 귀하의 파일
Git 기록은 공급업체 계정의 건강 상태에 의존하지 않습니다.

실시간 다중 사용자 타이핑은 여전히 ​​브라우저 도구가 승리하는 분야입니다. 많은 연구
몇 주가 다르게 보입니다: 솔로 드래프트, 여행, 제한된 네트워크, 원함
소유권이 있거나 전체 프로젝트를 색인화하는 전체 문서 편집기가 필요합니다.
연구소에서는 이미 코드에 대한 풀 요청을 분기하고 공개하고 있습니다. 논문도 똑같이 사용할 수 있습니다
커서를 공유할 필요가 없는 공동 저자를 위한 비동기 패턴입니다.

## 여전히 네트워크가 발생합니다(의도적으로).

로컬 도구는 여전히 최초 사용 패키지, 템플릿 팩, 인용을 요청합니다.
메타데이터, 호스팅된 AI(켜는 경우), Git 원격 및 업데이트. 요점은
기본값: 초안 작성 및 캐시된 컴파일이 디스크에 유지됩니다.

프로젝트, 메타데이터, 빌드 및 Git 기록은 로컬에 저장됩니다. 네트워크는 다음과 같은 경우에 실행됩니다.
필요한 조치를 취합니다. 편집 및 캐시된 컴파일이 작동해야 합니다.
오프라인. DOI를 붙여넣거나 클라우드 모델을 활성화하면 해당 요청이 원하는 곳으로 전달됩니다.
그들을 겨냥했습니다. 가장하는 대신 개인 정보 보호 관련 글에서 명확하게 말하세요.
네트워크는 절대 발생하지 않습니다.

## 종이 주변의 더미

연구 주간은 결코 "단지 편집자"가 아닙니다. 일반적으로 다음이 혼합되어 있습니다.

- 실제 프로젝트 인텔리전스를 갖춘 글쓰기 환경
- TeX 배포 및 패키지 유지 관리
- SyncTeX가 포함된 PDF 뷰어
- Git 클라이언트 및 원격 호스트
- 인용 조회 및 참고문헌 위생
- 문법 및 철자 도구
- 다이어그램 또는 그림 파이프라인
- 마감일 및 기타 보조 도구

로컬 연구 작업 공간은 해당 조각이 같은 곳에 있을 때 유용합니다.
일반 폴더 프로젝트: 프로젝트 인식 편집기(참조, 인용, 매크로, 구조,
수학 미리보기, 오프라인 교정), 감독된 컴파일, PDF 작업 공간
오래 지속되는 SyncTeX, 자동 Git 체크포인트, 가져오기 및 내보내기, 프리플라이트
제출하기 전에 차이점을 표시해야 하는 선택적 에이전트입니다.

## 올리플리가 어울리는 곳

[Oleafly](https://github.com/Oleafly/Oleafly)는 무료,
LaTeX, Typst 및 Markdown을 위한 오픈 소스 데스크톱 작업 공간입니다. 번들로 제공
컴파일러. 포크 및 검색 기능이 있는 프로젝트 라이브러리. 프로젝트 전체 편집자
인텔리전스(정의, 참조, 이름 바꾸기, 실시간 참조/인용 확인, 구조
뷰, 인수 모양이 있는 매크로, 가능한 경우 TexLab/Tinymist). 라이브
수학 미리보기. 오프라인 Harper 및 Hunspell은 산문에만 해당됩니다. 통합된 PDF
재구축이 보류 중인 동안에도 여전히 매핑되는 양방향 SyncTeX입니다. 실제 Git
자동 체크포인트 및 선택적 GitHub. 인용 검색 및 붙여넣기. 다이어그램
편집 가능한 TikZ의 작곡가. 비행 전. 키를 사용한 선택적인 승인 관리 AI
또는 지역 Ollama.

[개인정보 페이지](/privacy/)는 의도적으로 짧게 유지됩니다. Oleafly 계정 없음, 없음
제품 원격 측정. 초안은 컴퓨터에 저장됩니다. 호스팅된 AI, 인용 조회 및
GitHub는 귀하의 키와 귀하의 정책에 따라 해당 서비스와 대화합니다.
행동.

설치하지 않고 살짝 맛보고 싶다면 [무료 브라우저]
도구](/tools/) 클라이언트 측을 실행합니다. 데스크탑 앱은 인텔리전스,
컴파일, 히스토리, 프로젝트 트리가 실제로 만납니다.

## 클라우드가 여전히 승리할 때

실시간 공동 작성이 제품인 경우 브라우저에 머무르십시오.
공동작업자가 아무것도 설치하지 않거나 기관이 이미 설치한 경우
제출을 위해 호스팅된 편집기에서 표준화되었습니다.

도구를 실제로 있는 주와 연결하세요. 라이브 다중 사용자가 필요한 경우
입력하고 브라우저에 머무르세요(또는 공동 작성자가 비동기로 작업할 수 있는 경우 Git을 사용하세요). 당신이
소유권, 오프라인 깊이, 전체 현지 연구 편집자에 더 관심을 갖고,
원고를 디스크에 파일로 보관하고, 컴퓨터에서 PDF를 만들고,
모든 Git 도구가 열 수 있는 저장소의 기록입니다.
