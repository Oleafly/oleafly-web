# 더 큰 유형과 더 작은 유형

LaTeX의 유형 크기는 두 가지 수준으로 설정됩니다. 클래스 옵션에서 한 번 선택한 문서 전체 기본 크기와 달라야 하는 범위에 대한 로컬 스위치입니다. 기본 크기는 다른 모든 것을 결정합니다. 머리글, 각주 및 지역 크기는 모두 이를 기준으로 정의됩니다.

## 문서 전체

```latex
\documentclass[11pt]{article} % 10pt, 11pt, 12pt common
```

class 옵션은 본문 텍스트의 크기를 설정합니다. '10pt'가 기본값이고 '11pt'와 '12pt'가 일반적인 대안입니다. 표준 클래스는 이 세 가지만 지원합니다. 옵션을 변경하면 제목 크기, 각주 크기 및 줄 간격이 모두 기본에서 파생되므로 전체 문서의 비율이 조정됩니다. 12pt 이상의 기본 크기가 필요한 경우 'extarticle' 또는 KOMA-Script 클래스와 같은 클래스는 더 넓은 범위의 옵션을 허용합니다.

## 로컬 스위치

```latex
{\large larger} {\Large larger}
{\small smaller} {\footnotesize notes}
{\tiny tiny}
```

이는 인수가 있는 명령이 아니라 선언입니다. `\large`는 해당 지점에서 현재 그룹이 끝날 때까지 크기를 변경하며 `{\largelarge}` 주위의 중괄호는 도달 범위를 제한합니다. 가장 작은 것부터 가장 큰 것까지의 전체 래더는 `\tiny`, `\scriptsize`, `\footnotesize`, `\small`, `\normalsize`, `\large`, `\Large`, `\LARGE`, `\huge`, `\Huge`입니다. 각 단계는 클래스 옵션에 따라 구체적인 크기에 매핑되므로 '12pt' 아래의 '\large'는 '10pt' 아래의 '\large'보다 큽니다. 스위치는 고정된 크기가 아니라 본문 텍스트에서 벗어난 단계로 생각하십시오.

줄 간격에는 미묘함이 있습니다. 크기 스위치는 활성화된 동안 끝나는 단락에 대해서만 기준선 거리를 조정합니다. 더 큰 크기의 다중 단락 범위의 경우 `{\large ... \par}`와 같이 닫는 중괄호 앞에 `\par`로 끝나서 그룹 내에서 단락 나누기를 유지합니다. 그렇지 않으면 마지막 단락이 큰 글자 아래에서 보통 크기의 줄 간격을 유지하고 줄이 충돌합니다.

## 크기 대 구조

제목을 위조하기 위해 크기 스위치를 사용하지 마세요. `\section`과 그 관련 요소는 크기를 설정하고 제목에 번호를 매기고 목차에 추가하며 PDF 책갈피를 만듭니다. 손으로 만든 `{\Large \textbf{...}}` 줄은 그런 것을 전혀 제공하지 않습니다. 동일한 아이디어가 강조에도 적용됩니다. [글꼴과 싸우지 않는 강조](/learn/bold-italic/)에서 다룹니다. 표 아래 각주 크기의 설명이나 제목 페이지의 줄과 같이 실제 로컬 요구에 맞게 수동 크기 스위치를 예약하십시오. 문서의 모든 제목에 스타일을 다시 지정해야 하는 경우 각 제목의 크기를 직접 조정하는 대신 클래스를 변경하거나 'titlesec'과 같은 패키지를 사용하세요.
