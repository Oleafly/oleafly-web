# Give the model your symbol table

Paste a short **notation table** and your macros:

```latex
% vectors: bold italic \vect{x}
% matrices: bold upright \mat{A}
% expectation: \E{X}
```

Instruct: "Use only these macros; do not invent new variable names for the same concept."
