# Цей пакет не встановлено

Рано чи пізно компіляція зупиняється на рядку на зразок `! Помилка LaTeX: файл 'siunitx.sty' не знайдено`. Повідомлення означає саме те, що в ньому сказано: ваш документ запитував пакет через `\usepackage{siunitx}`, і компілятор не зміг знайти файл `.sty` пакета на вашій машині. З вашим документом все не так. Дистрибутиви LaTeX не постачають кожен пакет за замовчуванням, і виправлення залежить від того, який дистрибутив ви запускаєте.

## TeX Live

TeX Live, стандартний дистрибутив для Linux і macOS (як MacTeX), містить менеджер пакетів під назвою `tlmgr`. Встановіть відсутній пакет із терміналу:

```
tlmgr install siunitx
```

Якщо було встановлено повний TeX Live, а це багато гігабайт, усе вже присутнє, і ця помилка не повинна виникати. Зазвичай він з’являється з меншими «базовими» або «малими» схемами встановлення. Зауважте, що аргументом для `tlmgr` є назва пакета, а не назва файлу, тому розширення `.sty` не має.

## MiKTeX

MiKTeX, поширений у Windows, має два механізми. Його функція інсталяції на льоту виявляє відсутній файл під час компіляції та пропонує отримати його, або запитуючи вас, або продовжуючи автоматично залежно від налаштувань. Крім того, відкрийте консоль MiKTeX, перейдіть на вкладку «Пакунки», знайдіть пакет і встановіть його там. Якщо здається, що інсталяція на льоту зависає при компіляції, це зазвичай очікує на діалогове вікно підтвердження, приховане за іншим вікном.

## Тектонічний

Механізм Tectonic, який поєднує в собі Oleafly, пропускає ручний етап: пакети завантажуються на вимогу під час компіляції та потрапляють у локальний кеш механізму. Перша компіляція, яка використовує `siunitx`, отримує його; пізніші компіляції повторно використовують кеш. Цей перший запуск може тривати довше, поки завантажуються залежності, і для цього потрібне підключення до мережі.

## Під час встановлення не виправляє

Якщо менеджер пакетів повідомляє, що такого пакета не існує, перевірте правопис на сторінці пакета на CTAN, центральному архіві пакетів LaTeX на ctan.org. Дві невідповідності становлять більшість упертих випадків. По-перше, файл і пакет можуть мати різні назви, оскільки дистрибутивний пакет може містити кілька файлів `.sty`. Пошук CTAN за точною назвою файлу `.sty` з повідомлення про помилку вирішує цю проблему. По-друге, помилка іноді називає файл із вашого власного проекту, наприклад файл класу, який шаблон забув включити, і жоден менеджер пакунків не може це надати. Файл має надходити з того місця, де був шаблон.

Остання замітка про стару пораду: завантаження окремого файлу `.sty` з Інтернету в папку вашого проекту справді працює, оскільки LaTeX спочатку шукає в поточному каталозі, але заморожує цей пакунок у випадковій версії та приховує його від оновлень. Віддавайте перевагу менеджеру пакунків і зберігайте трюк ручного копіювання на випадок надзвичайних ситуацій наближається до дедлайну.
