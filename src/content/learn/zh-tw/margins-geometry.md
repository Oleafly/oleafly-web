# 一個包中的邊距

LaTeX 的預設邊距看起來很大，尤其是在 A4 紙上。這是設計使然：預設的目標是大約 66 個字元的舒適行長，這非常適合閱讀，但很少是大學模板、期刊或您自己的品味所要求的。您無需手動調整六個低階長度，而是使用「geometry」套件設定頁面並用簡單的術語描述您想要的佈局。

## 您實際使用它的兩種方式

```latex
\usepackage[margin=1in]{geometry}
% or
\usepackage[a4paper,top=2.5cm,bottom=2.5cm,left=2.5cm,right=2.5cm]{geometry}
```

第一種形式是快速形式：「margin=1in」在單一選項中將所有四個邊距設為一英寸，並且幾何圖形重新計算文字寬度和高度以匹配。這是標準的“美國論文”外觀，也是草稿的合理預設值。

第二種形式說明了一切。 `a4paper` 声明物理纸张尺寸（对于美国信函使用 `letterpaper`）。如果没有它，几何图形将继承文档类所假定的任何内容，这可能与您的 PDF 查看器或打印机的期望不匹配。然后，“top”、“bottom”、“left”和“right”选项独立设置每个边距，因此非对称布局与对称布局一样简单。您可以自由混合单位：“in”、“cm”、“mm”和“pt”都可以。

一切都發生在序言中，在「\begin{document}」之前。 Geometry 讀取一次選項並從中匯出整個頁面佈局，這就是為什麼它比手動調整更不容易出錯的原因。

## 印刷本的裝訂膠印

如果要列印和裝訂文檔，內邊距需要額外的空間，以便文字不會消失在書脊中。將「bindingoffset=0.5cm」加入選項中，幾何圖形會將每個頁面上的文字區塊向外移動。在「twoside」文件中，它會在左頁和右頁之間正確地交替移動，這對於手動操作來說很乏味。

## 不該做什麼

避免將幾何體與手動 `\setlength{\textwidth}{...}` 混合，除非您知道原因。 LaTeX 的頁面佈局是一個由相互依賴的長度組成的網路（`\textwidth`、`\oddsidemargin`、`\headheight` 等），幾何圖形將所有這些長度作為一個一致的系統進行管理。載入幾何圖形後直接更改一個長度通常會導致其他長度不一致，最終導致文字溢出頁面或邊距與您要求的不同。如果您需要在文件中進行更改，geometry 可以為此提供 `\newgeometry{...}` 和 `\restoregeometry`。

在調整任何內容之前請注意：如果您正在為期刊或會議寫作，類別文件已經對所需的邊距進行了編碼，並且在頂部添加幾何圖形可能會違反提交格式。儲存您控製版面的文件（例如論文、筆記或履歷）的頁邊距調整，並先檢查您的[文件類](/learn/document-sculpture/) 已經為您提供了什麼。
