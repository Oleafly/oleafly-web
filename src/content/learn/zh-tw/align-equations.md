# 排列的多線方程

多個步驟的推導最好將等號堆疊在一列中，這樣眼睛就可以追蹤行與行之間發生的變化。 `amsmath` 套件為此提供了 `align` 環境，另外還提供了一些相關的環境，用於處理不符合您想要的對齊情況。

```latex
\usepackage{amsmath}
\begin{align}
 a &= b + c \\
 d &= e + f + g
\end{align}
```

## 如何對齊讀取

每一行都是一個方程，以「\\」結尾；最後一行不需要。 “&”標記對齊點，每行的“&”位於同一列。將“&”直接放在等號之前是標準習慣，因此等號堆疊在一起並且左側懸垂到左側。每行都有自己的方程式編號；將 `align*` 寫入 number none，或將 `\notag` 加到各個行以跳過這些行，如[方程式的數字和指標](/learn/number-equations/) 所示。

環境自行開啟顯示數學，因此它不能位於 `\[ ... \]` 或 `$ ... $` 內；將其嵌套在另一個數學環境中會產生令人困惑的錯誤。

## 家庭

|環境|目的|
| --- | --- |
| `對齊` |多條線，對齊 |
| `對齊*` |相同，未編號|
| `聚集` |多行，居中|
| `分裂` |多行單方程式數 |
| `多行` |長方程式在沒有對齊的情況下被打破 |

`gather` 處理多個沒有共享對齊點的方程式；它將每一行居中並為每一行編號。 「split」在單一數字下建構一個多線方程，並且必須位於「equation」內部。 `multiline` 打破了一個過長的公式，沒有對齊，第一行左對齊，最後一行右對齊。最後兩個在[不適合的方程式](/learn/break-long-equations/) 中詳細處理。

有兩個問題決定使用哪一個：這些線是獨立的方程還是一個破碎的方程，以及是否有一個值得堆疊的對齊點？分離並對齊：`align`。分開並居中：『聚集』。單一且對齊：`split`。單行且未對齊：「多行」。

## 常見錯誤

沒有“&”的行仍然可以編譯，但它獨立居中並且沒有任何內容。一行上的兩個“&”開始第二列對，“align”讀取為並排設定的第二列方程；如果您的輸出有向右行進的方程，請計算您的＆符號。最後一行的尾部「\\」新增一個空白行，它顯示為區塊下方的奇數垂直空間。在 [live Playground](/live/) 中輸入三步驟推導來觀察對齊情況。
