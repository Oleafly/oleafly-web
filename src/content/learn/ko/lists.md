# 글머리 기호, 숫자 및 정의 목록

LaTeX의 목록은 환경입니다. `\begin{...}`으로 목록을 열고, `\end{...}`로 닫고, 각 항목을 `\item`으로 표시합니다. 그런 다음 LaTeX는 번호 매기기, 글머리 기호, 들여쓰기 및 간격을 처리합니다. 마지막 부분이 핵심입니다. 손으로 번호를 다시 매기는 일이 없으며, 번호가 매겨진 목록에서 세 번째 항목을 삭제하면 4부터 10까지의 항목이 자동으로 3부터 9가 됩니다.

## 세 가지 목록 환경

```latex
\begin{itemize}
 \item Bullet
\end{itemize}

\begin{enumerate}
 \item Numbered
\end{enumerate}

\begin{description}
 \item[Term] Definition style
\end{description}
```

'itemize'는 정렬되지 않은 글머리 기호 목록을 생성하며 항목에 가정 목록과 같이 순서가 없을 때 올바른 선택입니다. '열거'는 각 항목에 자동으로 번호를 매깁니다. 이는 순서대로 발생하는 단계나 다시 참조하려는 항목에 대해 원하는 것입니다. 섹션에서와 마찬가지로 열거형에서 `\item` 뒤에 `\label`을 추가하고 나중에 `\ref`로 해당 번호를 참조할 수도 있습니다.

'설명'은 세 가지 중 가장 잘 알려지지 않았지만 매우 유용합니다. 각 `\item`은 대괄호로 묶인 선택적 인수를 취하고 해당 인수는 뒤에 정의 텍스트가 있는 레이블로 굵게 인쇄됩니다. 이는 용어집, 표기 목록 또는 "용어:설명" 구조를 위한 자연스러운 환경입니다.

## 중첩

다단계 목록을 위한 중첩 환경입니다. 외부 목록의 `\item` 안에 완전한 `\begin{itemize} ... \end{itemize}` 블록을 넣으면 LaTeX는 이를 들여쓰기하고 글머리 기호 기호를 자동으로 전환합니다. 중첩은 각 수준에서 번호 매기기 스타일을 변경하는 '열거'에도 동일하게 적용됩니다. 즉, 아라비아 숫자, 문자, 로마 숫자 순입니다. LaTeX는 읽기 가능한 문서 요구 사항보다 더 많은 네 가지 수준의 중첩을 지원합니다. 세 가지 수준의 깊이가 있는 경우 자료는 아마도 대신 산문이나 테이블을 원할 것입니다.

## 맞춤 라벨

모든 단일 항목은 선택적 인수를 사용하여 자체 마커를 재정의할 수 있습니다. `\item[(a)]`는 글머리 기호나 숫자 대신 "(a)"를 인쇄합니다. 이는 일회성 사례에 유용하지만 전체 목록의 스타일을 다시 지정하려는 경우 모든 항목을 수동으로 변경하면 자동화가 실패합니다. 이를 위해서는 `\begin{enumerate}[label=(\alph*)]`와 같은 항목을 작성하여 한 곳에서 전체 목록의 레이블을 다시 지정할 수 있는 `enumitem` 패키지를 로드하고 수직 간격을 좁힐 수 있는 옵션도 제공합니다.

초보자가 흔히 저지르는 실수는 '\item' 항목 사이에 간격을 두기 위해 빈 줄을 두는 것입니다. 빈 줄은 목록 내에서 무해하지만 시각적으로 아무 작업도 수행하지 않습니다. 간격은 목록 환경 자체 또는 'enumitem' 옵션에 의해 제어됩니다. 또 다른 하나: 모든 목록 환경에는 텍스트 앞에 최소한 하나의 `\item`이 포함되어야 합니다. 그렇지 않으면 "뭔가 잘못되었습니다. 아마도 \항목이 누락되었습니다"라는 혼란스러운 오류가 발생합니다. [라이브 놀이터](/live/)에서 세 가지 환경을 모두 실험해 볼 수 있습니다.
