# LaTeX가 Word를 능가할 때(그리고 그렇지 않을 때)

두 도구 모두 보편적으로 더 나은 것은 아닙니다. 워드 프로세서는 직접적인 조작에 최적화되어 있습니다. 눈에 보이는 것은 문서입니다. LaTeX는 구조를 최적화합니다. 문서를 일반 텍스트로 설명하면 컴파일러가 이를 조판합니다. 어떤 모델이 승리할지는 부족의 충성도가 아니라 당신 앞에 놓인 문서에 달려 있습니다.

## LaTeX가 학습 곡선을 얻는 곳

방정식이 가장 명확한 경우입니다. Word의 방정식 편집기는 숙제 문제에 적합합니다. 상호 참조가 포함된 100개의 번호가 매겨진 방정식을 거치는 것은 고통스럽습니다. LaTeX에서 `\label`과 `\ref`는 아무리 재구성하더라도 모든 숫자를 정확하게 유지합니다. 이에 대해서는 [상호 참조](/learn/cross-references/) 강의에서 자세히 다룹니다.

긴 구조의 문서는 동일한 방식으로 작동합니다. 별도의 파일로 구성된 챕터, 자동 목차, 일관된 제목 스타일로 구성된 논문은 LaTeX에서는 일상적이지만 워드 프로세서에서는 깨지기 쉽습니다. 인용은 동일한 패턴을 따릅니다. 수백 개의 항목이 있는 BibTeX 데이터베이스는 모든 저널 스타일에 맞게 자체적으로 재구성되며, 여기서 직접 관리하는 참조 목록은 빠르게 저하됩니다. 메커니즘은 [인용 추가](/learn/add-citations/)를 참조하세요.

시간이 지남에 따라 두 가지 더 조용한 장점이 복합됩니다. LaTeX 소스는 일반 텍스트이므로 Git은 이를 명확하게 비교하고 버전화할 수 있으며, 동일한 소스는 몇 년 후 어떤 시스템에서든 레이아웃 드리프트 없이 동일한 PDF를 생성합니다.

## Word나 Google Docs가 적합한 경우

협업이 문서일 때 직접 조작 편집자가 승리합니다. 공동 작성자가 기술적 지식이 없고 추적된 변경 내용으로만 작업하며 오늘 오후에 의견을 제시해야 하는 경우 공유 문서가 실용적인 답입니다. 또한 LaTeX 설정 비용이 조판 반환보다 더 많은 짧은 일회성 편지와 '.docx' 파일만 허용하는 출판사 또는 HR 부서에서도 승리합니다.

## 실제로 작동하는 하이브리드

LaTeX에 원본을 보관하고 필요한 사람들을 위해 초안을 내보냅니다. PDF는 주석을 수집합니다. Pandoc에서 생성된 DOCX는 '.docx' 요구 사항을 충족합니다. 해당 라운드의 결정은 정식 버전으로 남아 있는 '.tex' 파일에 다시 병합됩니다. [Word 기반 공동작업자와 작업](/learn/collaborator-uses-word/) 강의에서는 이 루프를 안내합니다.

## 짧은 답변

몇 달에 걸쳐 인용, 번호 지정, 상호 참조 또는 수정하는 모든 작업에 LaTeX를 사용하세요. LaTeX의 사회적 비용이 조판상의 이점을 초과할 경우 워드 프로세서를 사용하십시오. 두 판단 모두 타당하며 대부분의 연구자들은 특정 연도에 두 도구를 모두 사용합니다.
