# Il glossario del gergo della ricerca

I ricercatori parlano un dialetto. Nessuno ti passa il dizionario, quindi eccolo qui: i termini che sentirai durante il primo anno, una riga ciascuno. Scorri ora, torna ogni volta che una riunione ti confonde.

## Dalla A alla Z

| Termine | Significato |
| --- | --- |
| Estratto | Il riassunto di 150-250 parole nella parte superiore di un documento; spesso l'unica parte letta dalle persone |
| AoE | Ovunque sulla Terra: un fuso orario con scadenza, il che significa che hai tempo fino a quando l'ultimo posto sul pianeta non raggiunge la mezzanotte |
| APC | Spese per l'elaborazione degli articoli, spese per la pubblicazione di gold [open access](/learn/open-access-doi-explained/) |
| Artefatto | Il codice, i dati o i materiali dietro un documento, a volte valutati formalmente per un badge |
| arXiv | Il grande [server di prestampa](/learn/what-is-arxiv/) gratuito, pronunciato "archivio" |
| Pronto per la fotocamera | La versione finale, formattata dall'editore, di un articolo accettato; il nome è antecedente al coinvolgimento delle telecamere |
| Citazione | Un puntatore formale al lavoro precedente; anche l'unità di credito accademico |
| PCP | Call for papers: annuncio da parte della sede di argomento, scadenza e regole |
| Autore corrispondente | L'autore elencato che gestisce tutte le e-mail relative all'articolo |
| Rifiuto della scrivania | Rifiuto da parte del redattore o dei presidenti prima di qualsiasi revisione, solitamente per violazioni dell'ambito o delle regole |
| Doppio cieco | Revisione in cui autori e revisori sono nascosti gli uni dagli altri, vedere [peer review, decodificata](/learn/peer-review-explained/) |
| DOI | Un ID permanente per un documento, come 10.1145/xxxxx; il modo affidabile per citare |
| et al. | latino "e altri"; "Smith et al." significa Smith più il resto dell'elenco degli autori |
| indice h | Una metrica del ricercatore: h articoli con almeno h citazioni ciascuno; trattare con scetticismo |
| Fattore di impatto | Citazioni recenti medie per articolo per una rivista; una procura di prestigio, da trattare anche con scetticismo |
| IRB | Comitato di revisione istituzionale: il comitato etico che deve approvare gli studi che coinvolgono esseri umani |
| Nota fondamentale | Il grande intervento su invito che apre una giornata di convegno |
| Recensione illuminata | Leggere e riassumere il lavoro esistente su un argomento |
| LNCS |Serie di procedimenti gialli di Springer, vedere [ACM, IEEE e amici](/learn/acm-ieee-and-friends/) |
| Revisione principale | Verdetto del diario: sono necessarie correzioni sostanziali, quindi riesame |
| Novità | Se il lavoro fa qualcosa di veramente nuovo; l'ascia preferita dai recensori |
| PC | Comitato di programma: il pool di revisori per una conferenza |
| P.I. | Ricercatore principale: il professore che dirige il laboratorio e detiene la borsa di studio |
| Manifesto | Un riassunto stampato da presentare accanto ad esso durante una sessione della conferenza |
| Prestampa | Un documento condiviso pubblicamente prima della revisione tra pari |
| Atti | La raccolta pubblicata dei documenti accettati di una conferenza |
| Confutazione | Breve risposta degli autori alle revisioni prima della decisione |
| Lavoro correlato | La sezione degli articoli che posiziona il tuo lavoro tra gli articoli precedenti |
| Riproducibilità | Se altri possono rieseguire il tuo lavoro e ottenere gli stessi risultati |
| SIG | Gruppo di interesse speciale; Sottocomunità ACM (SIGPLAN, SIGGRAPH) |
| Cieco singolo | Recensione in cui i revisori conoscono gli autori ma non viceversa |
| Numero di presentazione | L'ID anonimo del tuo articolo durante la revisione; lo memorizzerai involontariamente |
| Materiale supplementare | Appendici, prove o video aggiuntivi inviati insieme al documento |
| Sondaggio | Un documento che mappa un'intera area di ricerca |
| Sede | In qualsiasi luogo in cui i documenti vengono pubblicati, vedere [riviste, conferenze e workshop](/learn/journals-vs-conferences/) |
| Versione del record | La copia ufficiale pubblicata di un articolo |

## Come usarlo

Non memorizzarlo. Aggiungilo ai segnalibri, poi vai a leggere qualcosa di reale: il [tour di anatomia cartacea](/learn/paper-anatomy-tour/) mostra queste parole nel loro habitat naturale e [cos'è effettivamente un documento di ricerca](/learn/what-is-a-research-paper/) collega insieme quelli più importanti.
