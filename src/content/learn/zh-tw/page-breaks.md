# 強製或拒絕分頁

LaTeX 決定頁面結束位置。大多數情況下，它的決定很好，但有時您需要推翻它：章節標題會在頁面底部擱淺，表格太晚一行，或者您希望報告的每一章都重新開始。 LaTeX 為此提供了一小部分命令，從嚴格的命令到禮貌的建議。

```latex
\newpage % end page
\clearpage % end page + flush floats
\cleardoublepage
\pagebreak[3] % soft request
\nopagebreak
```

## 艱難的突破

`\newpage` 立即結束目前頁面並開始新頁面。它是最鈍的工具，也是您在繪圖時最常用的工具。

`\clearpage` 做同樣的事情，但先刷新所有掛起的浮動。 LaTeX 中的圖形和表格是浮動的：它們會漂移到演算法找到空間的任何地方，有時會漂移到您編寫它們的位置之後的頁面。 `\clearpage` 會在繼續之前強制將到目前為止已排隊的每個浮動到頁面上，因此在章節末尾或您不希望出現任何掉隊的部分之前，這是正確的命令。如果文件末尾的數字似乎堆積如山，那麼放置在適當位置的「\clearpage」通常可以解決問題；請參閱[為什麼人物移動](/learn/figure-wrong-position/) 以了解完整故事。

`\cleardoublepage` 在雙面文件中更進一步：刷新浮動後，它確保下一頁是右側（奇數）頁面，如果需要，則插入空白的左側頁面。書籍章節傳統上在右側打開，並且“book”類在每個“\chapter”處為您調用它。

## 軟請求

`\pagebreak[n]` 沒有指令。它問。 0 到 4 之間的可選數字表示強度：`\pagebreak[1]` 表示“這裡休息一下就好”，`\pagebreak[4]` 表示“這裡休息，句號”。中間的值讓 LaTeX 權衡你的願望和它自己的間距判斷，這通常會產生比硬的“\newpage”更好看的頁面，因為“\pagebreak”拉伸內容以填充頁面而不是留下間隙。

`\nopagebreak` 是相反的請求：它不鼓勵在此時中斷。它在標題之後或您想要與其簡介一起保留的簡短清單之前非常有用。與 `\pagebreak` 一樣，它接受 0 到 4 之間的可選強度。

## 什麼時候該接觸這些

常見的錯誤是在草稿中散佈“\newpage”來修復佈局，然後隨著文字的增長，每次修復都會出錯。分頁符號取決於它們之前的所有內容，因此今天看起來完美的手動分頁符號可能會在下一次修訂後留下半空的頁面。合理的工作流程是先編寫整個文檔，然後只在最後一遍添加中斷，在確切位置可以協商的情況下，優先使用軟“\pagebreak[3]”而不是硬命令。
