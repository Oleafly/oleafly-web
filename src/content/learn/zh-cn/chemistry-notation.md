# 化学式和结构

化学符号对抗 LaTeX 的默认值。数学模式将元素符号显示为斜体，就好像它们是变量一样，而文本模式则根本没有下标。两个包分工。 `mhchem` 根据简单的化学家符号排版公式和反应，而 `chemfig` 绘制结构图。

## mhchem 的公式和反应

```latex
\usepackage[version=4]{mhchem}
\ce{H2O}
\ce{CO2 + C -> 2CO}
```

`version=4` 选项选择当前语法。所有化学物质都在“\ce{...}”内部，它以化学家书写的方式读取其内容。在 `\ce{H2O}` 中，2 自动成为下标，并且元素符号按照约定保持直立。在反应中，“+”得到适当的间距，“->”成为反应箭头，CO之前的2被识别为化学计量系数，因此它在基线上保持完整大小。

相同的符号按比例放大。电荷作为上标，因此 `\ce{SO4^2-}` 给出带有 2 个电荷的硫酸盐。物质的状态附在括号中，如`\ce{H2O(l)}`；平衡箭头写作“<=>”；和 `\ce{^{14}C}` 在符号前放置同位素编号。 `\ce` 在文本和数学模式下都有效，因此公式可以放在句子中，没有额外的分隔符。

## 使用 chemfig 构建结构

```latex
\usepackage{chemfig}
\chemfig{H-C(-[2]H)(-[6]H)-H}
```

`\chemfig` 从紧凑的线性代码中绘制结构。原子被写成它们的符号，“-”画出与下一个原子的键。括号内的数字设置键的方向，从东以逆时针方向旋转 45 度：“[2]”指向正上方，“[6]”指向正下方。括号从当前原子打开分支，因此“C(-[2]H)(-[6]H)”向上生长一个氢，向下生长一个氢，而主链继续向右延伸。这个例子是扁平的甲烷：一个中心碳与四个氢键合。双键和三键写为“=”和“~”，并且对于环状和芳香结构有专用的环语法。

## 实用笔记

将两个工具保持在各自的车道上。对于从左到右作为公式或方程阅读的任何内容，请使用“mhchem”；当分子的几何形状是点时，请使用“chemfig”。两者都使用标准 LaTeX 引擎进行编译，无需外部绘图程序。

初学者通常会犯的错误是在纯数学模式下编写公式。 `$H_2O$` 可以编译，但它像变量一样将 H 和 O 设置为斜体，这按照惯例是错误的。 `\ce{H2O}` 产生直立形式，需要较少的打字。这两个套餐都可以在[live Playground](/live/) 中尝试。
