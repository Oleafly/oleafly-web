# PDF 뷰어의 텍스트가 흐릿함

PDF는 깔끔하게 컴파일되지만 화면에서 텍스트가 부드럽거나 울퉁불퉁해 보이고 확대하면 상태가 좋아지기는커녕 나빠집니다. 시청자에게는 아무런 문제가 없습니다. 문서에 비트맵 글꼴이 포함되어 있습니다. 문자 모양을 확장 가능한 윤곽선으로 저장하는 대신 하나의 고정 해상도로 렌더링된 픽셀 그리드로 저장합니다. PDF 용어로 보면 Type 3 글꼴입니다. 생성된 해상도로 종이에 인쇄할 수 있기 때문에 문제가 수십 년 동안 지속되었지만 화면에서는 기본 수준이 아닌 다른 확대/축소 수준에서 흐릿해졌습니다. 최신 윤곽선 형식(Type 1, TrueType, OpenType)은 모양이 수학 곡선이므로 깔끔하게 확장됩니다.

## 진단 확인

확대/축소는 빠른 테스트입니다. 윤곽선 글꼴은 800%로 매우 선명하게 유지되고 비트맵은 눈에 보이는 픽셀로 분해됩니다. 확실하게 하려면 PDF 뷰어에서 문서 속성을 열고 글꼴 패널을 살펴보세요. Adobe Reader에서는 파일, 속성, 글꼴 아래에 있으며 "유형 3"으로 나열된 모든 글꼴은 비트맵입니다. arXiv와 많은 출판사가 Type 3 글꼴이 포함된 제출물을 거부하기 때문에 이 확인은 미학적 측면을 넘어서 중요합니다.

## 비트맵의 출처와 수정 사항

일반적인 소스는 오래된 글꼴 설정입니다. 매우 오래된 TeX 설치는 METAFONT를 통해 Computer Modern을 비트맵으로 렌더링했으며 일부 레거시 패키지와 고대 `\usepackage{times}` 시대 스택은 여전히 ​​비트맵 변형을 가져옵니다. 기존 글꼴 명령을 최신 스택으로 교체하여 문제를 해결하세요.

```latex
\usepackage{newtxtext,newtxmath}
```

이는 [Times, Arial, Helvetica와 유사한 스택](/learn/times-arial-helvetica/)에 자세히 설명된 대로 일치하는 수학으로 Times의 개요를 제공합니다. Times가 아닌 기본 모양을 원할 경우 `\usepackage{lmodern}`은 Computer Modern을 그 개요 후속 버전인 Latin Modern으로 바꿉니다. XeLaTeX 또는 LuaLaTeX 및 'fontspec'을 사용하여 컴파일하면 문제가 완전히 회피됩니다. 해당 엔진은 구성별 윤곽선인 OpenType 시스템 글꼴을 사용하기 때문입니다. Oleafly가 번들로 제공하는 XeTeX 기반 Tectonic과 같은 최신 엔진은 자체적으로 유형 3 텍스트를 생성하지 않습니다. 거기에 비트맵 글꼴이 나타나면 포함된 그래픽을 통해 도착하는 것입니다.

## 같은 문제의 그림 버전

PDF의 흐릿한 텍스트는 항상 문서 글꼴이 아닙니다. 단락은 선명하지만 플롯 내부의 레이블이 흐릿한 경우 그림 자체는 래스터 이미지(일반적으로 플롯의 PNG 스크린샷 또는 화면 해상도로 내보낸 다이어그램)입니다. 치료법은 한 단계 위의 동일한 아이디어입니다. 플로팅 도구에서 그림을 벡터 PDF로 내보내 텍스트도 윤곽선이 됩니다. 형식 지침은 [그림에 드롭](/learn/insert-images/)에 있습니다.

수정 후에는 기본 확대/축소에서 눈을 믿지 말고 글꼴 패널을 다시 확인하세요. 하나의 피규어 또는 하나의 패키지가 남겨진 단일 유형 3 항목이면 제출물을 반송하기에 충분합니다.
