# Маркеры, цифры и списки определений

Списки в LaTeX представляют собой среды: вы открываете один с помощью `\begin{...}`, закрываете его с помощью `\end{...}` и отмечаете каждую запись с помощью `\item`. Затем LaTeX самостоятельно обрабатывает нумерацию, маркеры, отступы и интервалы. В этой последней части и есть суть. Вы никогда ничего не перенумеровываете вручную, и если вы удалите третью запись в нумерованном списке, записи с четвертой по десятую автоматически станут с третьей по девятую.

## Три среды списка

```latex
\begin{itemize}
 \item Bullet
\end{itemize}

\begin{enumerate}
 \item Numbered
\end{enumerate}

\begin{description}
 \item[Term] Definition style
\end{description}
```

`itemize` создает неупорядоченный маркированный список и является правильным выбором, когда записи не имеют последовательности, например, список предположений. `enumerate` автоматически нумерует каждую запись, что вам нужно для шагов, которые происходят по порядку, или для элементов, к которым вы планируете вернуться. Вы даже можете поместить `\label` после `\item` в перечислении и ссылаться на его номер позже с помощью `\ref`, как если бы вы это делали с разделом.

«Описание» — наименее известное из трех, но очень полезное. Каждый `\item` принимает необязательный аргумент в квадратных скобках, и этот аргумент печатается жирным шрифтом в виде метки с текстом определения, следующим за ним. Это естественная среда для глоссариев, списков обозначений или любой структуры «термин: объяснение».

## Вложение

Среды гнездования для многоуровневых списков. Поместите полный блок `\begin{itemize} ... \end{itemize}` внутри `\item` внешнего списка, и LaTeX сделает для него отступ и автоматически переключит символ маркера. То же самое работает и для enumerate, где вложение меняет стиль нумерации на каждом уровне: сначала арабские цифры, затем буквы, а затем римские цифры. LaTeX поддерживает четыре уровня вложенности, что больше, чем нужно любому читаемому документу. Если вы обнаружите, что у вас есть три уровня глубины, материал, вероятно, будет представлять собой прозу или таблицу.

## Пользовательские метки

Любой отдельный элемент может переопределить свой собственный маркер с помощью необязательного аргумента: `\item[(a)]` печатает «(a)» вместо маркера или номера. Это удобно для единичных случаев, но если вы хотите изменить стиль всего списка, изменение каждого элемента вручную приведет к отказу от автоматизации. Для этого загрузите пакет enumitem, который позволяет вам писать такие вещи, как `\begin{enumerate}[label=(\alph*)]`, чтобы переименовать весь список в одном месте, а также дает вам возможность уменьшить вертикальный интервал.

Распространенная ошибка новичков — оставлять пустую строку между записями `\item` в надежде освободить их. Пустая строка внутри списка безвредна, но визуально она ничего не делает. Интервал контролируется самой средой списка или опциями enumitem. Еще один: каждая среда списка должна содержать хотя бы один `\item` перед любым текстом, иначе вы получите сбивающую с толку ошибку «Что-то не так — возможно, отсутствует \item».
