# 해당 패키지가 설치되어 있지 않습니다

조만간 컴파일은 `! LaTeX 오류: 'siunitx.sty' 파일을 찾을 수 없습니다. 이 메시지는 정확히 말하는 내용을 의미합니다: 귀하의 문서가 `\usepackage{siunitx}`를 통해 패키지를 요청했고 컴파일러가 귀하의 컴퓨터에서 패키지의 `.sty` 파일을 찾을 수 없었습니다. 귀하의 문서에는 아무런 문제가 없습니다. LaTeX 배포판은 기본적으로 모든 패키지를 제공하지 않으며 수정 사항은 실행하는 배포판에 따라 다릅니다.

## TeX 라이브

Linux 및 macOS(MacTeX와 같은)의 표준 배포판인 TeX Live에는 `tlmgr`이라는 패키지 관리자가 포함되어 있습니다. 터미널에서 누락된 패키지를 설치합니다.

```
tlmgr install siunitx
```

수 기가바이트에 달하는 전체 TeX Live가 설치된 경우 모든 것이 이미 존재하므로 이 오류가 발생하지 않아야 합니다. 일반적으로 더 작은 '기본' 또는 '소형' 설치 구성표에서 나타납니다. `tlmgr`에 대한 인수는 파일 이름이 아니라 패키지 이름이므로 `.sty` 확장자가 없습니다.

## MiKTeX

Windows에서 흔히 사용되는 MiKTeX에는 두 가지 메커니즘이 있습니다. 즉시 설치 기능은 컴파일 중에 누락된 파일을 감지하고 이를 가져오도록 제안하며, 설정에 따라 메시지를 표시하거나 자동으로 진행합니다. 또는 MiKTeX 콘솔을 열고 패키지 탭으로 이동하여 패키지를 검색하고 설치하세요. 즉시 설치로 인해 컴파일이 중단된 것처럼 보이는 경우 일반적으로 다른 창 뒤에 숨겨진 확인 대화 상자를 기다리고 있습니다.

## 텍토닉

Oleafly가 번들로 제공하는 Tectonic 엔진은 수동 단계를 건너뜁니다. 패키지는 컴파일 중에 요청 시 다운로드되어 엔진의 로컬 캐시에 저장됩니다. `siunitx`를 사용하는 첫 번째 컴파일은 이를 가져옵니다. 나중에 컴파일하면 캐시를 재사용합니다. 첫 번째 실행은 종속성을 다운로드하는 동안 시간이 더 오래 걸릴 수 있으며 네트워크 연결이 필요합니다.

## 설치해도 문제가 해결되지 않을 때

패키지 관리자가 해당 패키지가 없다고 보고하는 경우 ctan.org의 중앙 LaTeX 패키지 아카이브인 CTAN의 패키지 페이지에서 철자를 확인하세요. 가장 완고한 경우에는 두 가지 불일치가 설명됩니다. 첫째, 배포 패키지에는 여러 개의 `.sty` 파일이 포함될 수 있으므로 파일과 패키지의 이름이 다를 수 있습니다. 오류 메시지에서 정확한 '.sty' 파일 이름을 CTAN으로 검색하면 이 문제가 해결됩니다. 둘째, 오류는 템플릿에 포함하지 않은 클래스 파일과 같이 자신의 프로젝트에 있는 파일의 이름을 지정하는 경우가 있는데, 어떤 패키지 관리자도 이를 제공할 수 없습니다. 파일은 템플릿이 있던 곳에서 가져와야 합니다.

오래된 조언에 대한 마지막 참고 사항: LaTeX는 현재 디렉터리를 먼저 검색하기 때문에 인터넷에서 단독 `.sty` 파일을 프로젝트 폴더로 다운로드하는 것이 작동하지만 해당 패키지를 무작위 버전으로 동결하고 업데이트에서 숨깁니다. 패키지 관리자를 선호하고 마감일이 가까워지는 긴급 상황에 대비해 수동 복사 요령을 유지하세요.
