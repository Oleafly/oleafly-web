## クラウドがまだ勝つとき

リアルタイム共同編集が製品である場合、ブラウザーに留まります。
共同研究者が何もインストールしない場合、またはあなたの教育機関がすでにインストールしている場合
投稿用にホストされたエディターで標準化されています。

実際の週にツールを合わせてください。ライブマルチユーザーが必要な場合
入力するだけで、ブラウザーに留まります (または、共同作成者が非同期で作業できる場合は Git を使用します)。もしあなたが
所有権、オフラインの深さ、完全なローカルリサーチエディターを重視します。
原稿をファイルとしてディスク上に保存し、マシン上で PDF を構築して保存します。
どの Git ツールでも開くことができるリポジトリ内の履歴。
