# 相機就緒，無需恐慌

公認！慶祝活動結束後，最後一個最後期限到來了：準備拍照。這個名字是出版商拍攝你的頁面進行印刷時留下的痕跡。今天，這意味著進入訴訟程序的最終版本，就像讀者將永遠看到的那樣。此後沒有編輯修復您的拼字錯誤。那部分由你承擔。

## 提交和相機就緒之間有什麼變化

您提交的版本已針對審閱者進行了調整。相機就緒是為了永久記錄，但有幾件事發生了變化：

|项目 |提交版本 |相机就绪 |
|---|---|---|
|作者姓名 |隱藏（雙盲）|真名、隸屬關係、電子郵件 |
|致谢 |省略 |资金、赠款、感谢 |
|頁數限制 |審核限額|通常+1頁，但準確|
|版權區塊 |佔位符或無 |出版商區塊、DOI、ISBN |
|自引 |第三人稱（「史密斯等人」）|可以說「我們之前的工作」|
|反驳承诺|承诺|实际交付|

去匿名化不僅僅是重新添加名字。在來源中搜尋您圍繞您的身分所寫的每個位置；請參閱[雙盲審查的匿名化](/learn/anonymization-double-blind/) 以了解通常的隱藏點，然後將它們全部反轉。

## 再次強調確切的頁數限制

相機就緒限制是由出版商強制執行的，而不僅僅是主席，而且額外的內容（作者區塊、致謝）會佔用空間。如果你突然多了六行，請誠實地做：收緊散文和數字，而不是濫用間距命令。 [無犯罪的頁數限制](/learn/page-limits-without-crimes/) 中的技術在這裡雙重適用，因為出版商會檢查格式。

## 必須嵌入字體

這是咬人的。出版商會進行自動檢查，第一個拒絕原因是非嵌入字體，通常是由繪圖工具導出的圖形 PDF 偷偷帶入的。檢查“pdffonts yourpaper.pdf”：每個字體都應該顯示“emb：yes”。如果沒有，罪魁禍首幾乎總是一個人物；使用嵌入的字體或正確生成的 PDF 重新匯出它。

## 最終校對：參考文獻優先

參考文獻是熵集中的地方。上傳之前：

- [ ] 不 」？？」日誌中的引用或未定義的引用
- [ ] 每個參考書目條目都有地點、年份和正確大小寫的標題
- [ ] 作者姓名拼字正確（人們注意到自己的名字）
- [ ] 僅限 arXiv 的引文已更新為現有的已發布版本
- [ ] 引用中的 URL 仍可解析

然後大聲朗讀整篇論文一次。它很慢並且有效。

## 來源上傳怪癖

大多數出版商想要您的 LaTeX 原始程式碼，而不僅僅是 PDF，並且他們的建置系統非常挑剔：包含“.bbl”，避免非標準包，遵循他們的文件佈局。匯出一個乾淨的來源 ZIP（Oleafly 一步完成）並在上傳之前在一個空資料夾中從頭開始測試編譯它。如果它只是由於計算機上的雜散文件而構建，則發布者的系統會發現。

## 一次性清單

- [ ] 姓名、隸屬關係、電子郵件已恢復並更正
- [ ] 添加了致谢和资助编号
- [ ] 版權區塊/從發布者電子郵件貼上的 DOI 信息
- [ ] 完全满足页数限制
- [ ] `pdffonts` 显示所有嵌入的字体
- [ ] 參考文獻校對
- [ ] 干净的源 ZIP 从头开始编译
- [ ] 已上传，还有一天时间

然後就永久完成了。是时候考虑[展示它](/learn/present-your-paper/)。
