# 연구작성 도구상자, 그때와 지금

모든 세대의 연구자들은 도구가 영구적이라고 생각합니다. 결코 그렇지 않습니다. 논문이 어떻게 작성되었는지, 그리고 현재 도구 상자가 어떤 모습인지 간략하게 살펴보고 의도적으로 선택할 수 있습니다.

## 이전 시대

1980년대에는 논문을 **타자기로 입력**하고 방정식을 손으로 입력하여 저널에 우편으로 보냈습니다. 그런 다음 워드 프로세서가 등장했습니다. 취약한 번호 매기기, 이미지로 붙여넣은 방정식, 단락이 움직일 때 폭발하는 그림 레이아웃이 포함된 수십 년간의 **워드 템플릿**. 협업이란 **파일을 이메일로 주고받는 것**을 의미합니다. `paper_final_v3_REALLY_FINAL_jw_edits.docx`는 농담이 아니라 역사입니다. LaTeX는 이 모든 과정을 통해 존재했지만([TeX의 45년](/learn/history-of-tex-latex/) 참조) 터미널에서 컴파일하고 이메일로도 공유했습니다.

## 오늘의 도구상자

| 도구 | 카테고리 | 잘하는 것 |
| --- | --- | --- |
| 뒷면 | 클라우드 LaTeX 편집기 | 브라우저에서 실시간 공동 편집, 설정 필요 없음 |
| TeXstudio / TeXmaker | 로컬 LaTeX IDE | 클래식 데스크탑 편집, 무료 |
| VS Code + LaTeX 워크숍 | 로컬 IDE | 이미 VS Code에 살고 있다면 강력합니다 |
| 올리플리 | 로컬 우선 작업 공간 | 컴파일러가 번들로 포함된 LaTeX, Typst 및 Markdown |
| 조테로 | 참조 관리자 | 인용 수집, 정리 및 내보내기 |
| 구글 학술검색 | 발견 | 논문 검색 및 인용 추적 |
| arXiv | 디스커버리 + 사전 인쇄 | 최신 작품을 무료로 읽으려면 [인쇄 전 세계](/learn/what-is-arxiv/) |를 참조하세요.
| 타이프스트 | 새로운 조판 시스템 | .tex를 요구하는 장소가 없을 때 빠르고 현대적인 문서 |

**검색** 도구는 논문을 찾고, **참고문헌 관리자**는 찾은 내용을 정리하고, **편집자**는 이를 모두 PDF로 변환합니다. 당신은 각각 하나씩으로 끝날 것입니다.

## 클라우드 vs 로컬, 솔직히 말해서

**Overleaf**는 설치를 완전히 제거하여 LaTeX를 주류로 만들었으며 실시간 공동 편집은 진정한 킬러 ​​기능입니다. 공동 작성자가 동시에 같은 문서를 입력하고 싶다면 Overleaf와 같은 클라우드 도구가 더 좋습니다.

**로컬 우선** 도구는 거래를 뒤집습니다. 파일은 일반 파일로 컴퓨터에 있고 기차나 병원 방화벽 뒤에서 작업할 수 있습니다. 구독이나 서버의 유지 여부에 관계없이 버전 기록은 독점 타임라인이 아닌 실제 [Git](/learn/oleafly-workflow/)입니다. 로컬 LaTeX의 고전적인 어려움은 수 기가바이트의 TeX 배포판을 설치하는 것이었습니다. 변경된 부분입니다.

## 올리플리가 어울리는 곳

Oleafly는 무료 오픈 소스, 로컬 우선 데스크톱 작업 공간입니다. LaTeX 및 Typst용 컴파일러는 번들로 제공되므로 설치할 배포가 없습니다. 인용은 [DOI 또는 arXiv ID](/learn/open-access-doi-explained/)로 가져올 수 있고, 프로젝트는 정직한 역사가 있는 Git 저장소이며, 장소 템플릿이 내장되어 있으며, 선택적인 AI 도우미가 원할 때 도움을 줍니다. 목표는 클라우드 경로만큼 마찰이 적은 로컬 경로를 만드는 것입니다. 거래에 대해 공정하게 말하면 실시간 동시 공동 편집의 경우 Overleaf가 여전히 더 강력한 선택입니다. 파일 소유권과 오프라인 작업의 경우 로컬 우선이 우선합니다. 많은 사람들이 로컬에서 초안을 작성하고 Git을 통해 동기화하는 등 두 가지를 모두 사용합니다.

## 고민하지 않고 선택하기

이번 달에 가장 큰 마찰을 제거하는 것부터 시작하세요. .tex 파일은 테이블의 모든 도구에서 이식 가능합니다. 이러한 이식성은 [LaTeX 대 Word](/learn/latex-vs-word/)에서 다루는 일반 텍스트 작성의 진정한 장점입니다. 그런 다음 [첫 번째 문서](/learn/first-document/)를 작성하고 작업에 따라 도구 상자가 성장하도록 하세요.
