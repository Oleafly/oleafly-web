# 研究写作工具箱的过去和现在

每一代研究人员都认为其工具是永久性的。他们从来都不是。快速浏览一下论文是如何撰写的，以及工具箱现在的样子，以便您可以谨慎地选择您的工具。

## 之前的时间

进入 20 世纪 80 年代，论文**在打字机上**，用手写下方程式，然后邮寄给期刊。然后出现了文字处理器：数十年的 **Word 模板**，编号脆弱，方程式粘贴为图像，图形布局在段落移动时会爆炸。协作意味着**来回通过电子邮件发送文件**：`paper_final_v3_REALLY_FINAL_jw_edits.docx` 不是一个笑话，它是历史。 LaTeX 在这一切中一直存在（参见 [TeX 45 年](/learn/history-of-tex-latex/)），但您在终端中编译了它并通过电子邮件共享了它。

## 今天的工具箱

|工具|类别 |擅长什么 |
| --- | --- | --- |
|背页|云 LaTeX 编辑器 |浏览器实时协同编辑，零设置|
| TeXstudio/TeXmaker |本地 LaTeX IDE |经典桌面编辑，免费 |
| VS Code + LaTeX 研讨会 |本地IDE |如果您已经使用 VS Code，那么功能强大 |
|油叶 |本地优先工作区 |捆绑编译器的 LaTeX、Typst 和 Markdown |
|佐特罗 |参考经理 |收集、组织和导出引文 |
|谷歌学术|发现 |搜索论文并跟踪引用|
| arXiv |发现+预印本|免费阅读最新作品，请参阅[预印本世界](/learn/what-is-arxiv/) |
|打字员 |全新排版系统|当没有场地需要 .tex 时，快速、现代的文档 |

**发现**工具查找论文，**参考管理器**组织您找到的内容，**编辑器**将其全部转换为 PDF。您最终会得到其中一个。

## 老实说，云与本地

**Overleaf** 通过完全删除安装使 LaTeX 成为主流，其实时协作编辑确实是其杀手级功能。如果您的合著者想要同时输入同一个文档，那么像 Overleaf 这样的云工具现在更适合。

**本地优先**工具扭转了这一局面：您的文件以普通文件的形式存在于您的计算机上，您可以在火车上或在医院防火墙后面工作，一切都不依赖于订阅或服务器的存活，并且版本历史记录是真实的 [Git](/learn/oleafly-workflow/)，而不是专有的时间线。本地 LaTeX 的典型难题是安装一个多 GB 的 TeX 发行版。这是已经改变的部分。

## Oleafly 适合的地方

Oleafly 是一个免费、开源、本地优先的桌面工作区。 LaTeX 和 Typst 的编译器是捆绑在一起的，因此无需安装发行版。可以通过 [DOI 或 arXiv ID](/learn/open-access-doi-explained/) 获取引文，项目是具有诚实历史的 Git 存储库，内置场地模板，并且可选的 AI 助手可以在您需要时提供帮助。目标是使本地路径与云路径一样低摩擦。公平地说：对于实时同步共同编辑，Overleaf 仍然是更强的选择。对于文件的所有权和离线工作，本地优先胜出。许多人都使用两者，在本地起草并通过 Git 同步。

## 毫不痛苦地选择

从这个月为你消除最多摩擦的事情开始。 .tex 文件可以跨桌面上的每个工具移植。这种可移植性是纯文本写作的真正优势，[LaTeX vs Word](/learn/latex-vs-word/) 对此进行了介绍。然后编写您的[第一个文档](/learn/first-document/)，并让工具箱随着工作而增长。
