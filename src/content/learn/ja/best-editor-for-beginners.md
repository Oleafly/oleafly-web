# 実際に開くエディタを選択してください

初心者にとって最適な LaTeX エディタは、最も強力なものではありません。これは、最も手間をかけずに、空のファイルからコンパイルされた PDF を作成する方法です。早期にコンパイルすることは、多くの場合、単一の機能よりも重要です。 4 つの機能で初日に必要なものをカバーします。

まず、マルチギガバイトの TeX ディストリビューションを手動でインストールしなくてもコンパイルが機能するはずです。次に、SyncTeX を使用して PDF を並べてプレビューしたいとします。そのため、PDF をクリックすると、一致するソース行にジャンプして元に戻ります。 3 番目に、ファイルはディスク上にプレーンな `.tex` である必要があるため、エクスポート手順なしでファイルを圧縮したり、電子メールで送信したり、Git に保存したりできます。第 4 に、エラーは生の TeX ログとしてだけでなく、読み取り可能なメッセージとして届く必要があります。

## 現実的な選択肢

|編集者 |セットアップ |オフラインでも動作します |メモ |
| --- | --- | --- | --- |
|オレフライ |アプリをダウンロード |常に編集しています。コンパイルはキャッシュされたパッケージを使用します。バンドルされたエンジン、Git 履歴、オプションの独自キー AI |
| TeXShop / TeXworks |まず TeX ディストリビューションをインストールします。はい |最小限で信頼性の高い |
| VS コード + LaTeX ワークショップ |まず TeX ディストリビューションをインストールします。はい |すでに VS Code で作業している場合に適しています |
|裏紙 |ブラウザでアカウントを作成する |限定 |ゼロインストール。プロジェクトはサーバー上に存在します。

中央の 2 行は隠れたコストを共有しています。エディターが役立つようになる前に、TeX Live または MiKTeX を自分でインストールして保守する必要があります。多くの初心者がそこでつまづくのです。ブラウザ オプションを使用すると、セットアップは削除されますが、ファイルはアカウントに移動されます。トレードオフについては、[ブラウザ プロジェクトとディスク上のフォルダー](/learn/overleaf-vs-local/) で詳しく説明します。

## 妥当なデフォルト

TeX 管理なしでローカル ファイルが必要な場合は、[Oleafly](https://github.com/Oleafly/Oleafly/releases/latest) から始めます。コンパイラーはアプリ内に同梱されており、ドキュメントで初めてパッケージが必要になったときにパッケージをダウンロードします。どのエディタを選択する場合でも、[最初のドキュメント チュートリアル](/learn/first-document/) と組み合わせて、[チートシート](/learn/cheatsheet/) を近くに置いてください。エディターは、今日最初のページをコンパイルすることよりも重要です。
