# Pick an editor you will actually open

You want four things on day one:

1. **Compile without installing TeX Live by hand**
2. **Side-by-side PDF preview** with SyncTeX
3. **Plain files on disk** you can zip, email, or put in Git
4. **Clear errors** instead of a raw TeX log only

## Options

| Editor | Setup | Offline | Notes |
| --- | --- | --- | --- |
| **Oleafly** | Download app | Full | Bundled engine, Git history, optional your-own-key AI |
| TeXshop / TeXworks | Needs TeX distro | Full | Minimal and solid |
| VS Code + LaTeX Workshop | Needs TeX distro | Full | Great if you already live in VS Code |
| Overleaf | Account in browser | Limited | Zero install; files live in the cloud |

## Recommendation

If you want **local-first** with no TeX admin: start with [Oleafly](https://github.com/Oleafly/Oleafly/releases/latest). Pair any editor with the [first document tutorial](/learn/first-document/) and the [cheatsheet](/learn/cheatsheet/).
