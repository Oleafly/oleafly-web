# 区分的な定義

区分関数は、絶対値、ReLU アクティベーション、税区分スケジュールなど、そのドメインのさまざまな部分にさまざまな式を与えます。タイプセットの規則は、1 つの縦長の左中括弧でケースごとに 1 行を構成し、各行に式とそれが適用される条件を示します。 `amsmath` パッケージは `cases` 環境を提供し、手動で中括弧のサイズを変更することなく、まさにこのレイアウトを生成します。

## ケースの環境

```latex
\[
f(x) =
\begin{cases}
 x^2 & x \ge 0 \\
 -x & x < 0
\end{cases}
\]
```

これを 1 行ずつ読んでみると、全体が `\[ ... \]` 内にあるため、独立した行に数式が表示されます。 `f(x) =` は通常の数学であり、その後 `\begin{cases}` によって区分ブロックが開きます。内部には、各行に '&' で区切られた 2 つの列があります。左側が数式、右側が条件です。行は「\\」で終わりますが、最後の行には必要ありません。 LaTeX はコンパイル時に、両方の行にまたがる高さの左中括弧を 1 つ描画し、一方の列に式を配置し、別の列に条件を配置します。

ここでは「&」が実際に機能します。これがないと、各行は 1 つの塊となり、条件が垂直方向に整列しません。これにより、`x^2` と `-x` は左端を共有し、`x \ge 0` と `x < 0` は独自の左端を共有するため、定義がスキャン可能になります。

これをコンパイルするには 2 つのことが必要です。まず、プリアンブルの `\usepackage{amsmath}` ですが、これは `cases` がコア LaTeX の一部ではないためです。次に、環境は数学モード内である必要があります。 `cases` は数学コンテンツを構築しますが、それ自体では数学モードを開きません。どちらかが欠落している場合は、「環境ケースが未定義です」または「$ が挿入されていません」というエラーが発生します。後者については、[不足ドルの挿入](/learn/missing-dollar/) で説明されています。

## 単語を追加する

出版されている区分的定義のほとんどには、「if」という単語が含まれており、多くの場合、最後の「otherwise」が含まれています。条件列は数学モードであるため、適切な間隔でドキュメントのフォントに表示するには、単純な単語が `\text{...}` である必要があります。

```latex
\[
f(x) =
\begin{cases}
 x^2 & \text{if } x \ge 0 \\
 -x & \text{otherwise}
\end{cases}
\]
```

`\text{if }` 内のスペースに注意してください。数学モードでは入力されたスペースは無視されますが、「\text」内のスペースは実数であるため、右中括弧の前にスペースを 1 つ置くことで、「if」とその後の条件が分離されます。

## バリエーションとよくある間違い

数式が縦長の分数であり、窮屈に見える場合は、`mathtools` パッケージが、各数式の表示スタイルを設定するドロップイン置換機能である `dcases` を提供します。中括弧が右側に属する鏡像状況用の「rcases」もあります。

最もよくある間違いは、行間の `\\` を忘れることです。これにより、2 つのケースが黙って 1 つの長い行にマージされます。コンパイルされた出力に数式に含まれる条件が示されている場合は、最初に行の区切りを数えます。 [プレイグラウンド](/live/)では、ライブ環境を実験できます。
