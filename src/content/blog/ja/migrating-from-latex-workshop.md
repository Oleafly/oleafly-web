VS Code の [LaTeX ワークショップ](https://marketplace.visualstudio.com/items?itemName=James-Yu.latex-workshop) は優れています。無料、MIT、注意深く管理されています。フリーフォームのコンパイル レシピ、texdoc、Docker/WSL/リモート、Live Share、または完全な拡張機能マーケットプレイスを使用して週を実行する場合は、そのスタックを保持してください。その人生のために作られています。

この投稿は、複数ファイルの論文、コンパイラ、PDF、Git、引用、図、校正がすでに接続されている、ドキュメントファーストのアプリが必要な場合に向けてのものです。無料のオープンソース (AGPL)。 LaTeX、Typst、マークダウン。プレーンフォルダー。アカウントがありません。

機能マップとショートカット: [LaTeX Workshop から提供](https://github.com/Oleafly/Oleafly/blob/main/docs/ComingFromLatexWorkshop.md)。

## 編集者

LaTeX、Typst、Markdown、BibTeX にわたるプロジェクト全体のインデックスを備えた CodeMirror 6。

実際に日々得られるもの:

- 定義に移動し、参照を検索し、ラベルとマクロの名前を変更します (クラッシュ警告)
- 壊れた参照、不正な引用、欠落しているインクルード (`\cref`、`\eqref`、範囲参照など) をライブ チェックします。
- ローカル + プロジェクト構造ビュー;フィルターとジャンプ
- プロジェクトが定義するキー、パス、マクロの補完 (`\newcommand`、xparse 引数の形状)
- `.tex`、`.ltx`、`.sty`、`.cls` のサポート;引数のスニペット。環境チェック
- LaTeX 用 TexLab (オプトイン設定); Tinymist が Typst のために出荷
- 統合診断: 構文、コンパイル、言語サービス、参照、引用、スペル、文法
- ライブ KaTeX 数学プレビュー;ソースは編集可能なままです
- Harper + Hunspell 散文のみでオフライン (コマンドと数学はマスクされています)
- 一般的な構造のビジュアルモード。ヴィム;スラッシュコマンド。複数ファイルのタブ
- 大規模なコーパスからのパッケージ対応コマンド補完が次に登場 (LaTeX Workshop の MIT データ、帰属表示付きで販売)

PDF ワークスペース: 連続スクロール、スプレッド、検索、アウトライン、取り外し可能なウィンドウ。章ファイル間の双方向 SyncTeX。再構築の保留中もマッピングは引き続き機能します。最後に正常な PDF がそのまま残ります。コンパイルされたソース セットを元に戻すと、完全な再コンパイルを行わずにプレビューを最新の状態に戻すことができます。

本規模の CI: 最大 6,200 行の原稿、マルチファミリー数学、章、引用、校正、スクロール/入力/貼り付け/元に戻す/完了/再コンパイル/SyncTeX のパフォーマンス バジェット。

LaTeX Workshop は、一般的な IDE の強力な拡張機能です。 Oleafly はこのドキュメント ループをすでに組み立てて出荷しているため、学期ごとに設定やマーケットプレイスの選択から同じスタックを配線する必要はありません。

## アプリ内のコンパイラー

Tectonic (LaTeX) と Typst はアプリに同梱されています。必要なときにマネージド Pandoc 経由で Markdown を実行します。まずキャッシュパッケージをコンパイルします。その後、キャッシュされたビルドはオフラインで動作します。オフライン モードでは、コンパイラをキャッシュにロックできます。

自動コンパイル (デバウンス、キャンセル可能、最新の勝利)。 「Cmd/Ctrl-Enter」で再コンパイルします。停止ボタン。ライン上の人間化されたエラー カード。新しいビルドが実行される間の最後の正常な PDF。

レシピ、latexmk チェーン、シェルエスケープ、およびカスタム `.latexmkrc` は LaTeX Workshop のホイールハウスに残ります。ほとんどの論文や学位論文には、信頼性の高い教師付きエンジンのみが必要です。

テンプレート: 23 個のバンドルされたスターター (IEEE、ACM、Elsevier、Beamer、論文、履歴書、Typst ブランクなど) と 99 個のダウンロード可能なパック。任意のプロジェクトをテンプレートとして保存します。モデルのセットアップ時にオプションで AI テンプレートを生成します。

## ライブラリ、Git、リサーチツール

本としてのプロジェクト: カバーの色、エンジン バッジ、フォークの系統、最後の PDF ページのホバー プレビュー、ブックマーク、すべてのドキュメントの `/docs` 検索。 Fork は、危険な書き換えに備えて、送信コピーの横に完全な Git 履歴を保存します。

初日から本物の Git を。ステージング、並列差分 (作業ツリー編集可能)、破棄、復元。コンパイルとアイドル編集が成功した後の自動チェックポイント。 AI は最初の書き込みの前にチェックポイントを実行します。 GitHub はオプション (PAT またはデバイスフロー OAuth)。ターミナルの「git log」はアプリと一致します。

DOI / arXiv / title → dedupe → `.bib` → `\cite` を貼り付けます。 BibTeX、RIS、EndNote、Zotero RDF をバッチインポートします。 arXiv、Semantic Sc​​holar、Crossref、PubMed、OpenAlex にわたる引用検索。 Diagram Composer から編集可能な TikZ へ。バリデータ、テーブル、方程式、ラボ検索、期限、PDF から LaTeX へ、ビジョン モデルを使用した画像から LaTeX へ。

## オプションの AI

設定するまでオフです。 OpenAI、Anthropic、Z.AI、Groq、OpenRouter、DeepSeek、Mistral、xAI、Ollama。ディスク上で暗号化されたキー。リクエストは選択したプロバイダーに送信されます。

アシスタントは、編集、編集、ログの読み取り、PDF テキストの抽出、文献の検索、計画の維持を行います。書き込みは承認差分です。削除には個別の確認が必要です。選択項目に対して Ask-AI をインライン化します。クロード コード、カーソル、および友人のためのループバック MCP。 AI をオフにしても、エディター、コンパイル、Git、引用は引き続き機能します。

## プリフライト、エクスポート、プライバシー

プリフライト: 構造、未定義の参照、重複ラベル、パーサー スタイルの抽出プレビュー、スクリーン リーダー指向の結果。各リスク フラグには、ブラックボックス スコアを信頼するのではなく、自分でチェックできる十分なコンテキストが付属しています。

エクスポート: 常に PDF。 Pandoc が使用可能な場合は DOCX/HTML/Markdown。デッキ用の PowerPoint。書籍の場合は EPUB。ハンドオフ用のソース ZIP。

Oleafly アカウントはありません。製品テレメトリはありません。クラッシュ レポートでは、レビューした事前入力された GitHub の問題が開きます。パッケージ、テンプレート、ホスト型 AI、引用、更新、GitHub のネットワーク。編集、キャッシュされたコンパイル、文法、スペルチェック、ローカル Git はオフラインでも機能します。

## LaTeX Workshop がまだ適合する場合

- 自由形式のレシピ、latexmk、シェルエスケープ、`.latexmkrc`
- エディターの texdoc
- Docker、WSL、リモート開発
- ライブシェアとライブマルチユーザー編集
- ドキュメント以外の作業のための VS Code マーケットプレイス内での生活

Oleafly はパブリックベータ版です。重いパブリッシャー クラス ファイルは依然として Tectonic にトリップする可能性があります。それらを報告してください。

## 試してみてください

1. からダウンロードします。
   [リリースページ](https://github.com/Oleafly/Oleafly/releases/latest)
   (macOS は署名/公証済み。Windows は SmartScreen を 1 回行う場合があります)。
2. `.tex`、`.bib`、および図をインポートします (またはテンプレートから開始します)。
3. 一度コンパイルしたら、実際の紙に 1 日書きます。

VS Code をインストールしたままにしておきます。同じファイルはどちらのアプリでも機能します。 Oleafly で実際の紙の作業がうまくいく場合は、より多くのプロジェクトを移行してください。レシピとリモートが依然として特定のツリーで勝っている場合は、そのツリーをワークショップに残します。
