# 첫 번째 논문, 처음부터 끝까지

누구나 첫 번째 논문은 불가능하다고 느낍니다. 단일 단계가 어렵기 때문이 아니라 전체 파이프라인을 한 번에 보여 주는 사람이 없기 때문입니다. 모든 단계에 연결된 강의가 포함된 전체 파이프라인이 한 페이지에 표시됩니다. 이것을 북마크에 표시하고 이동하면서 단계를 건너십시오.

## 로드맵

| 무대 | 당신이 하는 일 | 일반적인 시간 | 여기서 시작하세요 |
|---|---|---|---|
| 1. 게임 이해 | 종이가 무엇이고 어떻게 만들어지는지 알아보세요 | 주말 | [연구 논문이란 무엇인가요?](/learn/what-is-a-research-paper/), [종이 해부학 둘러보기](/learn/paper-anatomy-tour/) |
| 2. 읽고 수집하기 | 관련 작품을 읽고, 터치한 모든 참고자료를 저장하세요 | 2~4주, 진행 중 | [인용 추가](/learn/add-citations/) |
| 3. 장소를 선택하세요 | 목표와 마감일을 선택하세요. 시계가 설정됩니다 | 며칠 | [장소 선택](/learn/choose-your-venue/), [마감일 수명 주기](/learn/deadline-lifecycle/) |
| 4. 프로젝트 설정 | 첫날부터 장소 템플릿, Git | 오후 | [첫 번째 문서](/learn/first-document/), [GitHub과 동기화](/learn/sync-with-github/) |
| 5. 작업 수행 + 쓰기 | 연구와 글쓰기가 인터리브됩니다. 일찍, 나쁘게, 자주 쓰기 | 대량: 1-3개월 | [초록 작성](/learn/write-an-abstract/) |
| 6. 그림 및 인용 | 그림을 읽기 쉽게 만들고 참고문헌을 깔끔하게 정리하세요 | 1~2주 | [인용 추가](/learn/add-citations/) |
| 7. 내부 검토 | 공동저자나 친구가 전체 초안을 읽습니다. | 동결 1주일 전 | [동료 검토, 설명](/learn/peer-review-explained/) |
| 8. 세련되고 핏 | 자르고, 조이고, 페이지 제한을 솔직하게 | 마지막 주 | [범죄 없는 페이지 제한](/learn/page-limits-without-crimes/) |
| 9. 제출 | 메타데이터, PDF 업로드가 하루 일찍 완료 | 1일(2인 계획) | [제출 시스템 둘러보기](/learn/submission-systems-tour/) |
| 10. 반박 | 증거를 바탕으로 리뷰에 응답 | 몇 가지 강렬한 일 | [반박 및 수정](/learn/rebuttals-and-revisions/) |
| 11. 카메라 지원 | 최종 영구 버전 | 접수 후 1~2주 | [당황 없는 카메라 준비](/learn/camera-ready-checklist/) |
| 12. 현재 | 말하다,포스터, 복도 대화 | 컨퍼런스 | [강연, 포스터 및 컨퍼런스](/learn/present-your-paper/) |
| 13. 공유 | 사전 인쇄 게시, 코드 공개 | 하루 | [arXiv에 게시](/learn/post-to-arxiv/) |

## 일정 기대치

첫 번째 논문은 일반적으로 아이디어부터 제출까지 6~12개월이 소요되며 이는 느린 것이 아니라 정상적인 현상입니다. 도중에 거부되는 것도 정상적인 현상입니다. 많은 우수한 논문이 착륙하기 전에 한두 번 거부되었습니다. 9단계와 10단계를 반복할 때마다 용지가 더 강해집니다.

두 가지 습관이 무엇보다 타임라인을 압축합니다.

- **첫 주부터 작성하세요.** 메모는 단락이 되고 섹션이 됩니다. 지난 2주 동안 아무도 논문을 쓰지 않았습니다. 그들은 하나를 조립합니다.
- **기록을 유지하세요.** 초기에 자주 커밋하여 실험이나 단락이 실제로 손실되는 일이 없도록 하세요. Oleafly와 같은 로컬 우선 작업 공간은 편집기를 떠나지 않고도 실제 Git 체크포인트와 차이점을 제공합니다. 그러면 "초안을 어겼습니다."가 "어제 버전을 복원했습니다."로 바뀌게 됩니다.

## 감동적인 진실

13단계는 많은 것처럼 들립니다. 실제로 이는 전체 경력에 대해 모든 논문마다 동일한 루프입니다. 첫 번째 패스는 느리고 혼란스러울 것입니다. 두 번째는 단지 느릴 것입니다. 세 번째에는 다른 사람에게 AoE 마감일을 설명하는 연구실 동료가 됩니다.

장소를 선택하고 달력에 마감일을 입력한 후 1단계부터 시작하세요. 루프는 학습 가능하며 이제 지도가 제공됩니다.
