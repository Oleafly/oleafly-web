# 註腳、參考文獻和附錄：誰做什麼

一篇論文有三個地方可以放置不屬於主流的材料，每個地方都有不同的工作。將正確的內容放在正確的位置，讓讀者保持導向。把它們混在一起，你的論文讀起來就像一個垃圾抽屜。

## 註腳：禮貌的一面

註腳是指值得一說但不值得打斷句子的內容：URL、澄清、警告、「我們感謝審稿人的這一觀察」。

```latex
We use the standard split.\footnote{Available at
\url{https://example.org/data}.}
```

謹慎使用它們。每段都有註腳的論文是一篇自相矛盾的論文。如果內容很重要，請將其提升為文字。如果它是可引用的先前工作，則它屬於參考文獻。有些場所禁止在 URL 中添加腳註，以利於正確引用，因此請檢查模板。

## 參考文獻：證據線索

當你引用一篇作品時，你是在指出一個主張背後的證據：這個事實是在那裡建立的，這個方法是他們引入的，這個資料集來自這裡。參考文獻清單是你所建立的基礎的完整地圖，審稿人會仔細檢查它，包括丟失的條目和固定在實際上並不支持它們的引文上的聲明。

在 LaTeX 中，機制是自動的：文字中的「\cite{key}」、「.bib」檔案中的條目以及清單自行呈現。

```latex
Transformers \cite{vaswani2017attention} replaced recurrence
with attention.
```

完整的工作流程位於[新增引文](/learn/add-itations/) 和[建立參考書目](/learn/create-bibliography/)。 Oleafly 可以從 DOI 查找中填入「.bib」條目，這優於手動輸入作者清單。

## 附錄：溢出室

附錄包含支援論文的資料，但會破壞其流程：完整的證明、額外的結果表、超參數網格、提示範本、資料集文件。規則是主要論文必須獨立。從未打開過附錄的讀者仍然應該被說服；打開它的讀者應該會發現他們所承諾的每一個細節。

```latex
\appendix
\section{Full proofs}
```

在 `\appendix` 之後，各節自動將自己標為 A、B、C。

## 補充資料：PDF 以外

補充資料是 PDF 中根本無法存在的所有內容：程式碼、數據、影片、互動式簡報。許多場所將其收集為單獨上傳，並有自己的大小限制。將其視為可重複性故事的一部分，並從方法部分明確引用它，以便讀者知道它的存在。

## 誰真正讀了什麼

|部分|審稿人行為 |
|---|---|
|註腳|順便讀一下，很快就忘了 |
|參考文獻 |掃描缺失的工作，尤其是他們自己的工作 |
|附錄|當論文中的主張需要檢查時打開|
|補充|由運行您的程式碼的一位審閱者開啟 |

這在實踐中意味著什麼：永遠不要在腳註或附錄中隱藏任何重要的內容。審稿者對正文進行評判，「答案在附錄F」從來沒有軟化過審稿。把你最好的材料放在瀏覽器能找到的地方，讓後面的材料做它最擅長的事情：靜靜地拿著收據。
