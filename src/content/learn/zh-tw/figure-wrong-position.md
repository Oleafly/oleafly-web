# 逃離該區域的人物

你把一個數字放在第 4 節的結尾，它會印在第 5 節的中間，或是在本章的最後與其他三個數字堆積在一起。數字是浮動的：LaTeX 將它們在來源中的位置視為起點，而不是目的地，並移動它們以保持頁面完整。漂浮物也必須按順序出現，因此無法放置的一個圖形會阻擋其後面的所有圖形。一般的放置系統在[浮標實際著陸的地方](/learn/position-figures/)中有介紹。本課程是當浮動最終到達您無法接受的地方時的升級階梯。

## 第一步：檢查放置選項

確保環境顯示“[htbp]”，而不是單獨的“[h]”。這些字母授予將浮動元素放置在此處、頁面頂部、底部或專用浮動頁面上的權限。僅授予“h”是導致數字失控的最常見原因，因為噹噹前頁面沒有空間時，LaTeX 在任何地方都沒有合法的位置並無限期地向前移動。

## 第二步：移動程式碼

浮標可以晚於其源位置漂移，但絕不能早於其漂移。如果該圖出現得太晚，請將環境在來源中向上移動，最好是在包含第一個「\ref」的段落之前。這一編輯修復了令人驚訝的比例的展示位置投訴。

## 第三步：圍欄部分

`placeins` 套件提供了 `\FloatBarrier`，這是一個強制在文字繼續之前放置所有待處理浮動的命令：

```latex
\usepackage{placeins}
% ...
\FloatBarrier
\section{Next section}
```

將屏障放在一個部分的末尾，該部分中的任何圖形都不會洩漏到下一個部分。 LaTeX 可能會插入額外的垂直空間來沖洗浮動，這通常是靠近分節符的可接受的價格。

## 第四步：H 錘

`float` 套件添加了一個大寫的 `H` 說明符，完全消除了浮動：

```latex
\usepackage{float}
\begin{figure}[H]
```

「[H]」圖形準確地列印其程式碼所在的位置，就像一個大段落一樣。代價是LaTeX無法再平衡其周圍的頁面，因此當圖形無法容納剩餘空間時，您可能會得到很大的空白間隙。將其視為一兩個頑固浮動的最後手段，而不是預設值。

##第五步：縮小圖形

非常大的浮動會被推遲，因為很少有頁面有空間容納它們。將“width=0.9\textwidth”減少到“0.7\textwidth”，或從圖像檔案中修剪空白，通常可以讓 LaTeX 放置一個一直推到章節末尾的圖形。

一個值得保留的習慣：在文字穩定後進行一次調整。您新增或刪除的每個段落都會重新排列頁面，因此起草過程中的佈局手術是您需要重做的工作。
