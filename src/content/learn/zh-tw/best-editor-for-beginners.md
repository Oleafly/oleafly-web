# 選擇一個您將實際開啟的編輯器

對於初學者來說最好的 LaTeX 編輯器並不是最強大的。它可以讓您以最少的摩擦從空文件轉換為已編譯的 PDF。儘早編譯通常比任何單一功能都更重要。四種功能可滿足您第一天的需求。

首先，編譯應該可以在不手動安裝多 GB TeX 發行版的情況下進行。其次，您希望使用 SyncTeX 進行並排 PDF 預覽，因此在 PDF 中按一下會跳到符合的原始程式碼行並返回。第三，您的檔案在磁碟上應該是純“.tex”，這樣您就可以壓縮它們、透過電子郵件發送它們，或者將它們放入 Git 中，而無需匯出步驟。第四，錯誤應該以可讀訊息的形式到達，而不僅僅是原始的 TeX 日誌。

## 現實的選擇

|編輯|設定 |離線工作 |筆記|
| --- | --- | --- | --- |
|油葉 |下載應用程式 |始終編輯；編譯使用快取的包|捆綁引擎、Git 歷史記錄、可選的您自己的金鑰 AI |
| TeXShop/TeXworks |首先安裝 TeX 發行版 |是的 |最小且可靠 |
| VS Code + LaTeX 研討會 |首先安裝 TeX 發行版 |是的 |如果您已經在 VS Code 中工作，那麼非常適合 |
|背頁|在瀏覽器中建立帳戶 |有限公司|零安裝；專案在他們的伺服器上運行|

中間兩行共用一個隱藏成本：在編輯器可用之前，您需要自行安裝和維護 TeX Live 或 MiKTeX。這就是許多初學者停滯不前的地方。瀏覽器選項會刪除設置，但會將您的文件移至帳戶中。 [瀏覽器專案與磁碟上的資料夾](/learn/overleaf-vs-local/) 中更深入地介紹了權衡。

## 合理的預設值

如果您想要無需 TeX 管理的本機文件，請從 [Oleafly](https://github.com/Oleafly/Oleafly/releases/latest) 開始：編譯器在應用程式內部提供，並在文件第一次需要它們時下載套件。無論您選擇哪個編輯器，請將其與[第一個文件教學](/learn/first-document/)配對，並將[cheatsheet](/learn/cheatsheet/)放在附近。今天編輯你的第一頁比編輯更重要。
