[LaTeX Workshop](https://marketplace.visualstudio.com/items?itemName=James-Yu.latex-workshop) у VS Code чудовий. Безкоштовно, MIT, ретельно обслуговується. Якщо ваш тиждень працює на рецептах компіляції у вільній формі, texdoc, Docker/WSL/remote, Live Share або на ринку повних розширень, збережіть цей стек. Він створений для такого життя.

Ця публікація призначена для тих випадків, коли вам потрібна програма для роботи з документами: документи з кількома файлами, компілятори, PDF, Git, цитати, малюнки та вичитка вже об’єднані разом. Безкоштовний і відкритий код (AGPL). LaTeX, Typst, Markdown. Прості папки. Немає облікового запису.

Карта функцій і ярлики: [З LaTeX Workshop](https://github.com/Oleafly/Oleafly/blob/main/docs/ComingFromLatexWorkshop.md).

## Редактор

CodeMirror 6 із індексом для всього проекту в LaTeX, Typst, Markdown і BibTeX.

Що ви насправді отримуєте щодня:

- Перейдіть до визначення, знайдіть посилання, перейменуйте мітки та макроси (попередження про конфлікти)
- Перевірки в реальному часі на несправні посилання, погані посилання, відсутні включення (`\cref`, `\eqref`, посилання діапазону, …)
- Види локальної + структури проекту; фільтр і стрибок
- Завершення для ключів, шляхів і макросів, які визначає ваш проект (`\newcommand`, форми аргументів xparse)
- підтримка `.tex`, `.ltx`, `.sty`, `.cls`; фрагменти аргументів; перевірки середовища
- TexLab для LaTeX (налаштування за бажанням); Кораблі Tinymist для Typst
- Уніфікована діагностика: синтаксис, компіляція, мовний сервіс, посилання, цитати, правопис, граматика
- Live KaTeX math previews; джерело залишається редагованим
- Harper + Hunspell офлайн лише для прози (команди та математика замасковані)
- Візуальний режим для загальних структур; Vim; команди слеша; багатофайлові вкладки
- Завершення команд з урахуванням пакетів із великого корпусу наступне (дані MIT LaTeX Workshop, постачальник із зазначенням авторства)

Робоча область PDF: безперервне прокручування, розвороти, пошук, контур, відокремлюване вікно. Двонаправлений SyncTeX між файлами розділів. Відображення все ще працює, поки очікується перебудова. Останній якісний PDF-файл залишається активним. Скасуйте скомпільований вихідний код, і попередній перегляд стане поточним без повної перекомпіляції.

Книжковий CI: ~6200 рядків рукопису, мультисімейна математика, розділи, цитати, вичитка, бюджет продуктивності на прокручування/введення/вставлення/скасування/завершення/повторне компілювання/SyncTeX.

LaTeX Workshop — це потужне розширення загальної IDE. Oleafly надсилає цей цикл документів у зібраному вигляді, тому ви не підключаєте один і той самий стек із налаштувань і вибору на ринку кожного семестру.

## Компілятори в додатку

Tectonic (LaTeX) і Typst постачаються разом із програмою. Уцінка через керований Pandoc, коли вам це потрібно. Спочатку скомпілюйте пакети кешу; після цього кешовані збірки працюють в автономному режимі. Автономний режим може заблокувати компілятор до кешу.

Автокомпіляція (відмовлення, можливість скасування, останні перемоги). `Cmd/Ctrl-Enter` перекомпілювати. Кнопка зупинки. Гуманізовані картки помилок на лінії. Останній якісний PDF під час роботи нової збірки.

Рецепти, ланцюжки latexmk, shell-escape і власний `.latexmkrc` залишаються в рубці LaTeX Workshop. Для більшості робіт і дисертацій потрібен лише надійний керований механізм.

Шаблони: 23 комплекти початкових (IEEE, ACM, Elsevier, Beamer, тези, резюме, бланки Typst, …) плюс 99 у пакетах для завантаження. Збережіть будь-який проект як шаблон. Додаткове створення шаблону штучного інтелекту під час налаштування моделі.

## Бібліотека, Git, інструменти дослідження

Проекти як книги: колір обкладинки, значок двигуна, гілка лінії, попередній перегляд останньої сторінки PDF, закладки, пошук `/docs` у кожному документі. Fork зберігає повну історію Git для ризикованого перезапису поруч із копією подання.

Справжній Git з першого дня. Постановка, паралельні відмінності (робоче дерево з можливістю редагування), скасування, відновлення. Автоматичні контрольні точки після успішної компіляції та простою редагування; AI запускає контрольну точку перед першим записом. GitHub необов’язково (PAT або OAuth потоку пристрою). Термінал `git log` відповідає програмі.

Вставте DOI / arXiv / title → dedupe → `.bib` → `\cite`. Пакетний імпорт BibTeX, RIS, EndNote, Zotero RDF. Пошук цитат у arXiv, Semantic Scholar, Crossref, PubMed, OpenAlex. Композитор діаграм до редагованого TikZ. Валідатор, таблиці, рівняння, лабораторний пошук, терміни, PDF-to-LaTeX, image-to-LaTeX із моделлю зору.

Помічник редагує, компілює, читає журнали, витягує текст PDF, шукає літературу, веде плани. Записи є відмінностями схвалення. Для видалення потрібно окреме підтвердження. Вбудований Ask-AI на вибір. Loopback MCP для Claude Code, Cursor та друзів. Якщо штучний інтелект вимкнено, редактор, компіляція, Git і цитування все ще працюють.

## Підготовка до друку, експорт, конфіденційність

Переддрукова перевірка: структура, невизначені посилання, повторювані мітки, попередній перегляд вилучення у стилі синтаксичного аналізатора, результати, орієнтовані на зчитувач екрана. Кожна позначка ризику має достатньо контексту, щоб ви могли перевірити це самостійно, замість того, щоб довіряти оцінці чорної скриньки.

Експорт: PDF завжди; DOCX/HTML/Markdown, коли Pandoc доступний; PowerPoint для колод; EPUB для книг; вихідний ZIP для передачі.

Немає облікового запису Oleafly. Немає телеметрії продукту. Звіти про збої відкривають попередньо заповнену проблему GitHub, яку ви переглядаєте. Мережа для пакетів, шаблонів, розміщеного ШІ, цитат, оновлень, GitHub. Редагування, кешована компіляція, граматика, перевірка орфографії та локальний Git працюють офлайн.

## Коли LaTeX Workshop все ще підходить

- Рецепти вільної форми, latexmk, shell-escape, `.latexmkrc`
- texdoc в редакторі
- Docker, WSL, віддалена розробка
- Live Share і живе багатокористувацьке редагування
- Життя на ринку VS Code для недокументної роботи

Oleafly є публічною бета-версією. Важкі файли класу видавця все ще можуть збити Tectonic; повідомити про них.

## Спробуйте

1. Завантажити з
   [сторінка випусків](https://github.com/Oleafly/Oleafly/releases/latest)
   (підписано/нотаріально завірено в macOS; Windows може використовувати SmartScreen один раз).
2. Імпортуйте `.tex`, `.bib` та фігури (або почніть із шаблону).
3. Складіть один раз, потім напишіть на справжньому папері протягом дня.

Тримайте VS Code встановленим. Ті самі файли працюють в обох програмах. Якщо день на справжньому папері проходить краще в Oleafly, перенесіть більше проектів; якщо рецепти та пульт все ще виграють для певного дерева, залиште це дерево в Майстерні.
