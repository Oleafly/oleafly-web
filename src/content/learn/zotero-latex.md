# Zotero into a .bib file

1. Install **Better BibTeX** for Zotero.
2. Export collection as `.bib` with stable citekeys.
3. Enable auto-export on change.
4. Point LaTeX at that file.

Keep Zotero as the reference database; keep `.bib` in the paper repo for reproducibility.
