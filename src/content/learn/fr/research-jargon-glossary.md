# Le glossaire du jargon de la recherche

Les chercheurs parlent un dialecte. Personne ne vous tend le dictionnaire, alors le voici : les termes que vous entendrez en première année, une ligne chacun. Parcourez maintenant, revenez chaque fois qu'une réunion vous déroute.

## A à Z

| Terme | Signification |
| --- | --- |
| Résumé | Le résumé de 150 à 250 mots en haut d’un article ; souvent la seule partie que les gens lisent |
| Zone d'E | Partout sur Terre : un fuseau horaire limite, ce qui signifie que vous avez le temps jusqu'à ce que le dernier endroit de la planète atteigne minuit |
| APC | Frais de traitement des articles, frais pour l'or [open access](/learn/open-access-doi-explained/) publication |
| Artefact | Le code, les données ou les matériaux derrière un article, parfois formellement évalués pour un badge |
| arXiv | Le grand [serveur de préimpression] gratuit (/learn/what-is-arxiv/), prononcé « archive » |
| Prêt pour l'appareil photo | La version finale, formatée par l'éditeur, d'un article accepté ; le nom est antérieur à l'implication des caméras |
| Citation | Un indicateur formel de travaux antérieurs ; également l'unité de crédit académique |
| PCP | Appel à communications : annonce du sujet, de la date limite et des règles d'un lieu |
| Auteur correspondant | L'auteur répertorié qui gère tous les e-mails concernant l'article |
| Rejet de bureau | Rejet par le rédacteur en chef ou les présidents avant toute révision, généralement pour violation de la portée ou des règles |
| Double aveugle | Vérifiez où les auteurs et les réviseurs sont cachés les uns des autres, voir [évaluation par les pairs, décodé](/learn/peer-review-explained/) |
| DOI | Une identification permanente pour un journal, comme 10.1145/xxxxx ; le moyen fiable de citer |
| et coll. | Latin « et autres » ; "Smith et coll." signifie Smith plus le reste de la liste des auteurs |
| indice h | Une métrique de chercheur : h articles avec au moins h citations chacun ; traiter avec scepticisme |
| Facteur d'impact | Citations récentes moyennes par article pour une revue ; un mandataire de prestige, à traiter également avec scepticisme |
| CISR | Institutional Review Board : le comité d'éthique qui doit approuver les études impliquant des humains |
| Discours d'ouverture | La grande conférence invitée qui ouvre une journée de conférence |
| Revue éclairée | Lire et résumer les travaux existants sur un sujet |
| LNCS |Série d'actes jaunes de Springer, voir [ACM, IEEE et amis](/learn/acm-ieee-and-friends/) |
| Révision majeure | Verdict du journal : des correctifs importants sont nécessaires, puis une nouvelle révision |
| Nouveauté | Si l’œuvre fait quelque chose de véritablement nouveau ; la hache préférée des critiques |
| PC | Comité de programme : le pool de relecteurs pour une conférence |
| IP | Chercheur principal : le professeur qui dirige le laboratoire et détient la bourse |
| Affiche | Un résumé imprimé que vous présentez à côté lors d'une séance de conférence |
| Préimpression | Un article partagé publiquement avant examen par les pairs |
| Actes | La collection publiée des articles acceptés d'une conférence |
| Réfutation | La brève réponse des auteurs aux critiques avant la décision |
| Travaux connexes | La section papier positionnant votre travail parmi les articles antérieurs |
| Reproductibilité | Si d'autres peuvent réexécuter votre travail et obtenir les mêmes résultats |
| SIG | Groupe d'intérêt spécial ; Sous-communautés ACM (SIGPLAN, SIGGRAPH) |
| Store simple | Revue où les évaluateurs connaissent les auteurs mais pas l'inverse |
| Numéro de soumission | L'identifiant anonyme de votre article lors de la révision ; vous le mémoriserez involontairement |
| Matériel supplémentaire | Annexes, preuves ou vidéos supplémentaires soumises avec l'article |
| Enquête | Un article cartographiant tout un domaine de recherche |
| Lieu | Partout où les articles sont publiés, voir [journaux, conférences et ateliers](/learn/journals-vs-conferences/) |
| Version du dossier | La copie officielle publiée d'un article |

## Comment l'utiliser

Ne le mémorisez pas. Ajoutez-le à vos favoris, puis allez lire quelque chose de réel : la [visite de l'anatomie papier](/learn/paper-anatomy-tour/) montre ces mots dans leur habitat naturel, et [ce qu'est réellement un document de recherche](/learn/what-is-a-research-paper/) relie les plus grands ensemble.
