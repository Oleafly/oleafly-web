Cloud LaTeX 编辑器获胜的原因很简单：零设置。打開一個選項卡，編譯。
多年来，这是摆脱 TeX 发行版的最简单方法
筆記型電腦，很多人仍然喜歡它。

不過，對於大多數文件來說，設定不再是困難的部分。引擎喜歡
Tectonic 可以在桌面應用程式中傳送並按需提取包，因此
安裝和編譯大約是建立雲端帳戶所需的時間。的
值得一問的問題是訂閱仍然會為你帶來什麼，以及你會得到什麼
交出它。

## 你在雲中放棄了什麼

您的手稿位於其他人的資料庫中。匯出通常有效，直到
計劃發生變化、公司被收購或某個功能消失，而您的
截止日期維持不變。

靜態加密可將外人拒於門外。服務本身還是可以看到的
透過其基礎設施的草案、贈款和未發表的結果。

延遲是另一個安靜的成本。您的機器上處理的擊鍵幾乎是
總是更加敏捷。編譯隊列和免費層超時僅在以下情況顯示
構建不是你的。

線下是另一個差距。在飛機上、醫院地下室或安全的地方
在沒有開放網路的實驗室中，瀏覽器編輯器只是一個空白標籤。

一些託管編輯器還提供完整的歷史記錄、追蹤變更或 Git/GitHub 同步
落後於付費等級。 Local Git 並不在乎你購買了哪個計劃。

## 本地優先的變化是什麼

項目是您可以打開的資料夾中的純文件。歷史可以是真的 Git you
從任何終端進行檢查。編譯在您的 CPU 上運行，沒有佇列。你的文件
Git 歷史記錄並不依賴供應商帳戶的健康狀況。

即時多用戶輸入仍然是瀏覽器工具獲勝的地方。大量研究
幾週看起來有所不同：單獨起草、旅行、受限的網路、想要
所有權，或需要一個完整的文檔編輯器來索引整個專案。
實驗室已經分支並開放了代碼拉取請求。論文可以使用相同的
適用於不需要共享遊標的共同作者的非同步模式。

## 網路仍然發生（故意）

本機工具仍可取得首次使用套件、範本包、引用
元資料、託管人工智慧（如果您開啟它）、Git 遠端和更新。重點是
預設值：起草和快取編譯保留在磁碟上。

專案、元資料、建置和 Git 歷史記錄都在本地保存。網路運作時
你採取了需要它的行動。編輯和快取編譯應該可以工作
離線。貼上 DOI 或啟用雲端模型，這些請求就會發送到您的位置
瞄準了他們。在任何隱私文章中清楚地說出這一點，而不是假裝
網路永遠不會發生。

## 紙堆周圍

研究週幾乎從來都不是「只是編輯」。它通常是以下內容的組合：

- 具有真實專案智慧的寫作環境
- TeX 分發和包裝維護
- 帶 SyncTeX 的 PDF 檢視器
- Git客戶端和遠端主機
- 引文查找及參考書目衛生
- 文法和拼字工具
- 圖表或圖形管道
- 截止日期和其他輔助工具

當這些部分位於同一位置時，本地研究工作空間會很有用
普通資料夾項目：項目感知編輯器（參考文獻、引用、巨集、結構、
數學預覽、離線校對）、監督編譯、PDF 工作區
耐過時的 SyncTeX、自動 Git 檢查點、匯入和匯出、預檢
在提交之前，可選代理必須顯示差異。

## Oleafly 適合的地方

[Oleafly](https://github.com/Oleafly/Oleafly) 是為此類別建構的：免費，
LaTeX、Typst 和 Markdown 的開源桌面工作區。捆綁式
编译器。具有叉子和搜索功能的項目庫。项目范围的编辑器
情報（定義、參考文獻、重命名、即時引用/引用檢查、結構
視圖、帶有參數形狀的巨集、TexLab/Tinymist（如果可用）。直播
数学预习。僅離線哈珀和亨斯佩爾散文。集成 PDF 与
雙向 SyncTeX 在重建掛起時仍然可以對應。真正的 Git
自動檢查點和可選的 GitHub。引文搜索和粘贴。圖解
可編輯 TikZ 的作曲家。飞行前。可選的批准門控人工智慧與您的金鑰
或當地的奧拉馬。

[隱私頁面](/privacy/) 故意保持簡短：沒有 Oleafly 帳戶，沒有
產品遙測。草稿存在於您的機器上。託管人工智慧、引文查找和
GitHub 根據其政策與這些服務進行對話，使用您的金鑰和您的
行動。

如果您想小嚐鮮而不安裝，[免費瀏覽器
工具](/tools/) 運行客戶端。桌面應用程式是智慧的所在，
編譯、歷史和專案樹實際上滿足。

## 當雲仍然獲勝時

當即時共同創作是產品時，當
合作者不會安裝任何東西，或當您的機構已經
將提交的託管編輯器進行標準化。

將工具與您實際擁有的星期相匹配。如果您需要即時多用戶
鍵入內容，留在瀏覽器中（或當合著者可以非同步工作時使用 Git）。如果你
更關心所有權、線下深度和完整的本地研究編輯，
將手稿作為文件保存在磁碟上，在您的電腦上建立 PDF，然後保留
任何 Git 工具都可以開啟的儲存庫中的歷史記錄。
