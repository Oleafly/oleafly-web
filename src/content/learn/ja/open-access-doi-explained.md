# オープンアクセス、ペイウォール、DOI

紙のリンクをクリックし、39.95 ドルを要求するページにアクセスし、タブを閉じて、ため息をつきます。研究者なら誰でもこのループを知っています。このレッスンでは、その背後にあるシステムと、そこを通る自由なドアについて説明します。

## DOI: 論文の本拠地

**DOI** (デジタル オブジェクト識別子) は、「10.1145/3297858.3304013」のような、出版物に割り当てられる永続的な ID です。先頭に「https://doi.org/」を付けると、出版社が Web サイトのデザインを変更した場合でも、その論文に解決され続けることが保証されたリンクが得られます。ウェブリンクは腐ります。 DOI はそうではありません。

DOI は引用に重要です。 DOI は 1 つの論文を一意に識別するため、ツールは DOI だけから完全な書誌レコードを検索できます。 DOI を Oleafly に貼り付けると、既製の BibTeX エントリが取得されます。著者リストを手入力する必要はありません。この仕組みは、[引用を追加](/learn/add-citations/) と [参考文献を作成](/learn/create-bibliography/) にあります。論文に DOI が記載されている場合は、それを使用します。これは、これまでの紙の中で最も信頼性の高いハンドルです。

## ペイウォールが存在する理由

従来、出版社は大学図書館に雑誌の購読料を請求し、購読料を払っていない読者には記事ごとに料金を支払っていました。奇妙なことに、著者には論文の代金は支払われず、査読者にも査読の報酬は支払われないのに、読むにはお金がかかります。この取り決めが、**オープンアクセス**運動が存在する理由です。

|用語 |意味 |誰が支払う |

|ペイウォール (従来型) |読者またはその図書館が料金を支払います。読者側 |
|ゴールドオープンアクセス |最終版は出版社のサイトで誰でも無料で入手可能 |通常、著者は APC 経由で |
|グリーンオープンアクセス |出版社版はペイウォールのままで、著者は無料のコピー (プレプ​​リント サーバーまたは個人サイト) をセルフアーカイブします。誰も |
|ダイヤモンドオープンアクセス |無料で読んで無料で公開 |会場スポンサー |

**APC** は、論文処理料の略で、ゴールド オープン アクセスに対して著者 (実際にはその助成金や大学) が支払う料金です。これらは 1 紙あたり数百ドルから数千ドルかかります。正当な会場では、支払い能力のない著者に対して APC を免除します。主に偽のレビューを含む APC を収集するために存在する場所は、ハゲタカジャーナルと呼ばれます。投稿を懇願するメールを送ってくる「ジャーナル」には気をつけてください。

## プレプリント: すでに獲得したフリーパス

実際に最も簡単なオープンアクセスはグリーンです。著者は自分の原稿を [arXiv または兄弟サーバー](/learn/what-is-arxiv/) に投稿し、誰でも無料で利用でき、ペイウォール版が形式的になります。ほとんどのパブリッシャーはこれを明示的に許可しています。したがって、ペイウォールにぶつかったときは次のようになります。

1. 正確なタイトルを検索します。通常、arXiv または作成者がホストする PDF が表示されます。
2. 著者の Web ページを確認します。
3. 大学図書館のアクセスを利用します。
4. 責任著者に電子メールを送信します。彼らはほとんどの場合、PDF を喜んで送ってくれます。

## 著者として注意すべき理由

無料で読める論文は、より多く読まれ、引用されます。自分の著作物を出版するときは、会場で許可されている場合はプレプリントを投稿し、論文をリストするすべての場所に DOI を含め、他の人が引用したものを見つけられるように参考文献を DOI クリーンに保ちます。これらのステップがプロセス全体のどこに到達するかは、[最初の論文ロードマップ](/learn/first-paper-roadmap/) でマッピングされ、このすべての機構を実行している発行者は [ACM、IEEE、Springer、Elsevier](/learn/acm-ieee-and-friends/) でデコードされます。
