# Assistant inside Oleafly

Oleafly's assistant uses **your** API key. It does not send drafts to an Oleafly server for model calls.

## What it can do

- Chat with project context
- Inline edits with a reviewable diff
- Compile and inspect results
- Help with figures and TikZ
