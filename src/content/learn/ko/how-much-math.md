# 논문에는 얼마나 많은 수학이 필요합니까?

귀하의 주장이 요구하는 만큼만, 단 하나의 기호 이상은 아닙니다. 논문의 수학은 정교한 신호가 아닙니다. 그것은 정밀 도구입니다. 가장 잘 쓰여진 논문은 산문이 모호할 경우 표기법을 사용하고 표기법이 잡음이 될 경우 산문을 사용합니다.

## 표기는 장식이 아니라 정확성이다

독자가 도메인과 공동 도메인을 정확히 알아야 할 경우 $f: \mathcal{X} \to \mathcal{Y}$라고 씁니다. 그렇지 않은 경우 "모델이 이미지를 라벨에 매핑합니다"라고 작성합니다. 평범한 영어일 수 있지만 기호 수프로 렌더링된 단락은 엄격해 보이지 않고 회피적인 것처럼 보이며 검토자는 실제로 주장되고 있는 것이 있는지 확인하기 위해 이를 다시 번역합니다. 진술을 공식화하기 전에 다음과 같이 질문하십시오. 기호 버전이 산문 버전에서 허용하는 오독을 배제합니까? 그렇지 않다면 산문을 유지하십시오.

## 모든 기호를 한 번 정의한 다음 절대 재정의하지 마세요.

독자의 작업 기억은 가장 부족한 자원입니다. 규율:

- 처음 사용할 때 각 기호를 소개합니다. "$n$을 샘플 수로 둡니다."
- 전체 논문에 대한 기호당 하나의 의미. $\alpha$가 섹션 3의 학습률이라면 섹션 5에서는 유의 수준이 될 수 없습니다.
- 표기가 많은 논문의 경우 초기에 작은 표기 표를 사용하는 것이 좋습니다.

| 습관 | 독자에게 미치는 영향 |
|---|---|
| 처음 사용할 때 정의된 기호 | 뒤로 사냥할 필요가 없습니다 |
| 하나의 기호, 하나의 의미 | 상황에 대해 절대로 추측하지 마세요 |
| 표기표 | 전체 논문에 대한 지도가 있습니다 |

## 참조할 때만 방정식 번호를 매기세요

방정식 번호는 약속입니다. "우리는 이것을 다시 지적할 것입니다." 모든 것에 번호를 매기면 중요한 방정식이 중요하지 않은 방정식 아래에 묻히게 됩니다.

```latex
\begin{equation}
  \mathcal{L} = \mathcal{L}_{\text{task}} + \lambda \mathcal{L}_{\text{reg}}
  \label{eq:loss}
\end{equation}
```

`\eqref{eq:loss}`로 참조하세요. 인용하지 않은 표시 수학의 경우 `\[ ... \]` 또는 별표 표시된 환경을 사용하고 숫자를 건너뜁니다. 참조 방법은 [상호 참조](/learn/cross-references/)에서 다룹니다.

## 정리 환경을 한 번에

논문이 내용을 증명하는 경우 "정리 1"을 손으로 굵은 글씨로 표시하기보다는 "정리", "정리" 및 "증명" 환경으로 주장을 감싸십시오. 정리 1은 스스로 번호를 매기고, 상호 참조를 깔끔하게 하며, 주장된 내용과 논평 내용을 정확하게 표시합니다. 설정 및 사용법은 [정리 및 증명](/learn/theorems-proofs/)에 있습니다.

## 일관성이 전투의 절반입니다

규칙을 선택하고 전체 논문에 적용하세요.

- 벡터는 굵은 글씨($\mathbf{x}$) 또는 화살표로 표시되며, 둘 다 사용할 수 없습니다.
- 행렬은 대문자로 굵게, 스칼라는 기울임꼴로 소문자로 표시됩니다.
- 칠판이나 붓글씨($\mathbb{R}$, $\mathcal{D}$)로 일관되게 설정합니다.
- 그림과 표의 관례는 본문과 동일합니다.

사용자 정의 매크로를 사용하면 일관성이 저렴해집니다. `\newcommand{\vx}{\mathbf{x}}`를 한 번 정의하면 나중에 표기법을 변경하면 전체 문서를 찾는 대신 한 줄로 편집할 수 있습니다.
