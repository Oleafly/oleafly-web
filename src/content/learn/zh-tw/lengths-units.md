# pt、em、文字寬度

LaTeX 中幾乎每個佈局指令都需要一個長度：垂直空間、影像寬度、邊距、標線厚度。長度是一個數字加一個單位，單位的選擇決定了佈局是否在字體大小或頁面幾何形狀發生變化時適應，或者打破了它的變化。

|單位 |意義|
| --- | --- |
| `pt` |點（基點）|
| `em` |字體相對寬度 |
| `前` |字體相對高度 |
| `公分` / `毫米` / `吋` |絕對|
| `\textwidth` |文字區塊的寬度 |
| `\線寬` |目前列/小頁的寬度 |

## 絕對與相對單位

`pt` 是印表機的點，TeX 的基本單位。字體大小和許多內部預設值均以磅為單位表示，在 TeX 的計算中，一英寸為 72.27 磅。 「cm」、「mm​​」和「in」是熟悉的絕對單位，適用於真正的物理要求，例如規定的一英寸邊距。

`em` 和 `ex` 根據目前字體縮放：em 大致是表示為寬度的字體大小，ex 大約是小寫 x 的高度。他們的優勢在於比例。如果文件從 10pt 類型移動到 12pt 類型（其中硬編碼的「\vspace{12pt}」變得太緊或太鬆），「\vspace{1em}」將保持視覺一致。

## 文件給你的長度

`\textwidth` 是頁面文字區塊的寬度。 `\linewidth` 是目前容器的寬度，它等於普通文字中的 `\textwidth`，但在小型頁面、清單或列中會變窄。前面的小數可以縮放其中之一，這是調整數字大小的標準方法：

```latex
\vspace{1em}
\includegraphics[width=0.5\textwidth]{f.pdf}
```

第一行插入一個 em 的垂直空間。第二個將影像設定為文字區塊寬度的一半，因此如果邊距發生變化，圖形會隨之重新縮放，並且永遠不會溢出到邊距中。在小型頁面或兩列佈局中，偏好 `0.5\linewidth`，因為 `\textwidth` 比您實際擁有的空間更寬。

長度也可設定。 `\setlength{\parindent}{0pt}` 刪除段落縮進，並且相同的指令調整大多數命名的佈局長度。

常見的錯誤是以公分為單位計算尺寸。它一直有效，直到文件類別、紙張尺寸或邊距發生變化，然後每個數字都需要手動重新調整。以“\textwidth”或“\linewidth”的分數表示的寬度在所有這些變更中保持不變，這就是為什麼模板幾乎專門使用它們的原因。
