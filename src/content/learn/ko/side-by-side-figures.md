# 한 행에 두 개의 패널

때로는 고유한 캡션과 고유한 그림 번호가 있는 두 개의 이미지가 서로 옆에 있어야 하는 경우도 있습니다. 이를 위해 특별한 패키지가 필요하지 않습니다. 단일 `그림` 환경 내의 일반 `미니페이지` 상자가 작업을 수행하며 두 이미지가 하나의 부동 소수점에 있기 때문에 LaTeX는 이를 다른 페이지로 분리할 수 없습니다.

## 패턴

```latex
\begin{figure}[htbp]
 \centering
 \begin{minipage}{0.48\textwidth}
 \includegraphics[width=\linewidth]{a.pdf}
 \caption{Left}
 \end{minipage}\hfill
 \begin{minipage}{0.48\textwidth}
 \includegraphics[width=\linewidth]{b.pdf}
 \caption{Right}
 \end{minipage}
\end{figure}
```

'미니페이지'는 미니어처 페이지처럼 동작하는 상자입니다. 선택한 너비가 고정되어 있고 내용이 해당 너비 안에 포장되어 쌓입니다. 여기서 각 미니페이지는 '0.48\textwidth'를 사용하며 이는 텍스트 너비의 48%를 의미합니다. 이는 의도적으로 4%를 청구되지 않은 상태로 남겨두고 두 상자 사이의 '\hfill'은 확장하여 채울 수 있는 확장 가능한 공간으로, 한 패널은 왼쪽 여백으로, 다른 패널은 오른쪽으로 밀어냅니다. 두 너비를 모두 `0.5\textwidth`로 설정하면 구분할 공간 없이 정확히 선 너비의 합이 되며 두 번째 상자는 다음 줄로 떨어지게 됩니다. 이는 병렬 레이아웃이 이상하게 수직으로 쌓이는 가장 일반적인 이유입니다.

각 미니페이지 내에서 `width=\linewidth`는 전체 페이지가 아닌 주변 상자의 너비에 맞게 이미지 크기를 조정합니다. 대신 `\textwidth`를 사용하면 각 이미지를 전체 텍스트 블록만큼 넓게 만들어 오버플로를 보장하는 실수가 자주 발생합니다.

캡션이 어디에 있는지 확인하세요: 각 미니페이지 내부. 그러면 각 패널에 자체 번호가 포함된 전체 캡션이 제공되므로 이 그림은 예를 들어 그림 3과 그림 4가 한 행에 표시됩니다. 외부 `[htbp]` 배치 옵션은 LaTeX가 선호하는 순서에 따라 여기, 페이지 상단, 하단 또는 부동 페이지에 부동을 배치할 수 있음을 알려줍니다.

## 상단 정렬 및 콘텐츠 혼합

두 이미지의 높이가 다른 경우 미니페이지는 기본적으로 중앙에 정렬되므로 수직 정렬이 어긋나게 보일 수 있습니다. 대신 `\begin{minipage}[t]{0.48\textwidth}`를 작성하여 상단에 정렬하세요. 미니페이지는 포함된 내용에도 신경 쓰지 않으므로 동일한 레이아웃은 테이블 옆에 그림을 배치하거나 하위 그림 스타일 패키지가 설계되지 않은 설명 텍스트 단락 옆에 이미지를 배치합니다.

## 하위 그림을 대신 사용해야 하는 경우

이 패턴이 제공할 수 없는 한 가지는 단일 공유 캡션과 단일 그림 번호 아래에 레이블이 지정된 (a) 및 (b) 패널입니다. 두 개의 독립적인 그림이 아닌 "그림 5(a)"를 원하는 순간에는 [하위 그림](/learn/subFigures-abc/)으로 전환하세요. 경험 법칙: 미니페이지는 우연히 이웃인 피규어를 위한 것이고, 하위 피규어는 우연히 부품을 가지고 있는 하나의 피규어를 위한 것입니다.
