# 소스를 깨는 문자

LaTeX는 몇 가지 일상적인 문자를 구문으로 예약하고 리터럴 문자를 의미하는 문자를 입력하면 컴파일이 중지되거나 출력이 자동으로 엉망이 됩니다. 각 예약 문자에는 이스케이프가 있으며 전체 세트가 하나의 작은 테이블에 맞습니다.

| 숯 | 코드 |
| --- | --- |
| % | `\%` |
| $ | `\$` |
| & | `\&` |
| # | `\#` |
| _ | `\_` |
| { } | `\{` `\}` |
| ~ | `\textasciitilde` |
| \ | `\textbackslash` |

## 이스케이프되지 않은 캐릭터의 작업

`%`는 주석을 시작하므로 주석부터 줄 끝까지의 모든 내용이 삭제됩니다. 이는 일반적인 "내 문장이 사라졌습니다" 버그입니다. 보고서에 50%를 적으면 나머지 줄이 전혀 오류 없이 사라집니다. `$`는 수학 모드를 전환하므로 잘못된 문자는 텍스트를 조용히 이탤릭체로 표시하거나 오타와는 거리가 먼 오류를 발생시킵니다. `&`는 테이블과 `align` 블록의 정렬 탭입니다. 그 외부에서는 "잘못 배치된 정렬 탭"으로 인해 실패합니다. `#`은 매크로 매개변수를 표시합니다. `_` 및 `^`는 수학 모드에 속하며 텍스트에서는 [자체 교훈이 있음](/learn/missing-dollar/) "Missing $ insert"를 발생시킵니다. `~`는 줄바꿈되지 않는 공백이므로 URL이나 경로에 입력된 물결표는 조용히 공백이 됩니다. `\`는 모든 명령을 시작하므로 자체적으로 이스케이프할 수 없습니다. `\\`는 줄바꿈이고 리터럴 문자에는 `\textbackslash`가 필요합니다.

## 실제로 탈출

처음 6자의 경우 이스케이프는 백슬래시 접두사이며 다른 명령에서도 동일하게 작동합니다.

```latex
The run reached 87\% accuracy; results are in
\texttt{results\_v2.csv}, and the job cost \$40.
```

밑줄은 `\texttt` 내부에서도 이스케이프가 필요하다는 점에 유의하세요. 두 가지 명령 스타일 이스케이프인 `\textasciitilde`와 `\textbackslash` 뒤에는 `{}` 또는 문자가 올 때 공백이 와야 합니다. 그러면 명령 이름이 다음 단어를 삼키지 않습니다.

전체 코드, 경로 또는 URL의 경우 이스케이프를 완전히 건너뜁니다. `\verb|...|` 및 `verbatim` 환경은 모든 특수 문자가 해제된 상태로 내용을 입력한 대로 정확하게 인쇄하며 `url` 패키지의 `\url{...}`은 물결표가 포함된 링크를 처리합니다.

가장 세게 물어뜯는 문자는 조용히 실패하는 문자이며 `%`가 그 목록의 선두에 있습니다. 붙여넣은 텍스트가 일반적인 원인입니다. URL, 셸 명령 및 재무 수치는 모두 예약된 문자를 포함합니다. PDF에서 문장이 누락되면 다른 것보다 먼저 해당 소스 줄에서 '%'만 검색하세요.
