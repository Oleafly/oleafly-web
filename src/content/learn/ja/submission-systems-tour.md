# HotCRP、EasyChair、OpenReview、CMT

あなたの論文は会議に参加しません。それは提出システム、つまり PDF をアップロードし、メタデータを入力し、後でレビューを読む Web サイトに移動します。何度も会うことになる4人ですが、それぞれに個性があります。

## ビッグ 4

|システム |性格 | | で会えます。
|---|---|---|
|ホットCRP |高速、最小限、システム担当者に愛される |システムおよびセキュリティに関するカンファレンス (SOSP、USENIX) |
|イージーチェア |ベテランさん。どこにでもある功利主義 |ワークショップ、世界中の多くの CS カンファレンス |
|オープンレビュー |公開されているレビューが頻繁に表示される | ML 会場 (ICLR、NeurIPS) |
| CMT | Microsoft の主力製品、フォーム重視 |ビジョンおよび ML カンファレンス (CVPR) |

それらはすべて同じ中核的な仕事をします。違いは細部に宿ります。 OpenReview はあなたのレビューを世界に公開することがあります。 HotCRP はすべてのコメントについて電子メールを送信します。 CMT にはトピック選択グリッドがあり、クリックするまでに 10 分かかります。

## 早めにアカウントを作成してください

これは締め切りの夜ではなく、提出することを決めた週に行います。

- [ ] 毎日チェックするメールでアカウントを作成します
- [ ] 確認メールが実際に届くことを確認する
- [ ] 共著者もアカウントを持っているかどうかを確認してください (OpenReview プロファイルは新規ユーザーの承認に数日かかる場合があります)
- [ ] ドラフトの送信を開始して、どのフィールドが存在するかを確認します。

最後のものが重要です。会場によっては、倫理に関する声明、再現性チェックリスト、競合領域など、思いがけない質問をされることもあります。 1週間おきに発見したほうがよいでしょう。

## PDF のみとソースのアップロード

ほとんどの会場では、提出時に PDF が必要です。一部の出版社、そしてカメラの準備が整った時点でほぼすべての出版社が、あなたの LaTeX ソースも必要としています。必要に応じて圧縮できるようにプロジェクトを整理整頓してください。 Oleafly はソース ZIP を直接エクスポートします。これは、送信システムが期待する形状とまったく同じです。

## メタデータフィールド

PDF 以外にも、次の情報を入力する必要があります。

- **タイトルと要約**、プレーンテキストとして。 LaTeX の数学を単語または Unicode で書き直します。
- **トピック**、論文を査読者に送付するチェックボックス。正直に選んでください。
- **対立**、あなたをレビューすべきではない人々や機関: アドバイザー、最近の共著者、同僚。これを間違えるとレビューが無効になる可能性があるため、徹底的に確認してください。
- **匿名確認**、二重盲検会場で。 [二重盲検レビューのための匿名化](/learn/anonymization-double-blind/) を参照してください。

## 11:59 AoE の現実

締め切りの夜になると、最後の 1 時間に何千人もの人が提出し、システムが遅くなります。昼食時には数秒かかったアップロードも、午後 11 時 50 分には数分かかります。修正方法は簡単で、誰もそれに従う人はいません。作業バージョンを早めに提出してください。

## 期限まで更新可能

ここが解放的な部分です。服従は一度ではないのです。すべての主要なシステムでは、期限が切れるまでは何度でも PDF を置き換えることができます。したがって、完全ではあるが不完全なバージョンを前日に提出し、磨き続けます。ネットワークが 11 時 58 分に停止した場合、悲劇ではなく、システム内での本当の服従が生じます。

提出後の次の目的は、[ピアレビュー、説明](/learn/peer-review-explained/) で、反対側で何が起こっているかを理解することです。
