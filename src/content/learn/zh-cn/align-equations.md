# 排列的多线方程

多个步骤的推导最好将等号堆叠在一列中，这样眼睛就可以跟踪行与行之间发生的变化。 `amsmath` 包为此提供了 `align` 环境，另外还提供了一些相关的环境，用于处理不符合您想要的对齐情况。

```latex
\usepackage{amsmath}
\begin{align}
 a &= b + c \\
 d &= e + f + g
\end{align}
```

## 如何对齐读取

每一行都是一个方程，以“\\”结尾；最后一行不需要。 “&”标记对齐点，每行的“&”位于同一列。将“&”直接放在等号之前是标准习惯，因此等号堆叠在一起并且左侧悬垂到左侧。每行都有自己的方程式编号；将 `align*` 写入 number none，或将 `\notag` 添加到各个行以跳过这些行，如[方程的数字和指针](/learn/number-equations/) 中所示。

环境自行打开显示数学，因此它不能位于 `\[ ... \]` 或 `$ ... $` 内；将其嵌套在另一个数学环境中会产生令人困惑的错误。

## 家庭

|环境|目的|
| --- | --- |
| `对齐` |多条线，对齐 |
| `对齐*` |相同，未编号|
| `聚集` |多行，居中|
| `分裂` |多行单方程数 |
| `多行` |长方程在没有对齐的情况下被打破 |

`gather` 处理多个没有共享对齐点的方程；它将每一行居中并为每一行编号。 “split”在单个数字下构建一个多线方程，并且必须位于“equation”内部。 `multiline` 打破了一个过长的公式，没有对齐，第一行左对齐，最后一行右对齐。最后两个在[不适合的方程](/learn/break-long-equations/) 中详细处理。

有两个问题决定使用哪一个：这些线是独立的方程还是一个破碎的方程，以及是否有一个值得堆叠的对齐点？分离并对齐：`align`。分开并居中：‘聚集’。单一且对齐：`split`。单行且未对齐：“多行”。

## 常见错误

没有“&”的行仍然可以编译，但它独立居中并且没有任何内容。一行上的两个“&”开始第二列对，“align”读取为并排设置的第二列方程；如果您的输出有向右行进的方程，请计算您的＆符号。最后一行的尾部“\\”添加一个空行，它显示为块下方的奇数垂直空间。在 [live Playground](/live/) 中输入三步推导来观察对齐情况。
