# 段落、分隔符號和空白

在文字處理程式中，您可以按 Enter 鍵並觀察間隙來調整段落形狀。 LaTeX 的工作方式不同：原始文字描述結構，編譯器決定間距。一旦你知道 LaTeX 如何開始一個段落，以及如何在需要時覆蓋它，你就可以避免初學者通常遇到的格式衝突。

## 段落如何運作

原始碼中的空白行開始一個新段落。這就是整個規則。一個空白行或五個空白行，沒有區別； LaTeX 將它們折疊成一個段落分隔符。同樣，原始程式碼中的單一換行符被視為普通空格，因此您可以將原始文字以您喜歡的任何寬度換行並自由重排，而無需更改輸出。

命令“\par”與空白行的含義完全相同。您很少會自己鍵入它，但您會在巨集和類別文件中看到它，其中文字空行寫起來很尷尬。

`\\` 完全是另一回事：它強制在當前段落內換行，而不開始新的段落。新行沒有段落縮進，也沒有額外的垂直空間。它存在於換行符是內容的地方，例如地址、詩歌和表格的行。用它來結束普通段落是典型的初學者錯誤，因為它會產生一個從未真正結束的段落，當兩個段落疊加時，LaTeX 可能會抱怨「這裡沒有結束行」。

```latex
First paragraph.

Second paragraph, with a forced break\\
on this line.
```

## 新增垂直空間

有時您需要故意留出間隙，例如在簽名區塊之前或標題頁的邏輯部分之間。

```latex
\vspace{1em}
\bigskip \medskip \smallskip
```

`\vspace{1em}` 精確插入您要求的垂直空間，採用 LaTeX 已知的任何單位（`em`、`pt`、`cm` 等）。三個跳過指令是預設數量：「\smallskip」、「\medskip」和「\bigskip」插入小、中和大間隙，其大小由文件類別定義，這使它們在整個文件中保持一致。優先選擇跳過而不是手動調整的“\vspace”值，因為如果您更改類別或字體大小，它們會進行調整。

一個有用的細節：頁面頂部的「\vspace」被悄悄刪除，因為 LaTeX 假設頁面邊界處的彈性空間是無意的。如果您確實需要保留它，請使用帶有星號的“\vspace*{1em}”。

## 所有段落之間的空格

不要使用「\\」來在段落之間留出空間。如果您希望每個段落都用間隙分隔而不是用縮進標記，那麼這是一個文檔範圍的設計決策：使用“parskip”包在序言中設置一次，或者重新考慮標題和結構是否可以更好地傳達分隔。有關此權衡的另一半，請參閱[段落縮排](/learn/paragraph-indent/)。
