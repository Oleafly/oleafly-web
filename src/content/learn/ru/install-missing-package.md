# Этот пакет не установлен

Рано или поздно компиляция останавливается на строке типа `! Ошибка LaTeX: файл siunitx.sty не найден. Сообщение означает именно то, что оно говорит: ваш документ запросил пакет через `\usepackage{siunitx}`, и компилятор не смог найти файл `.sty` пакета на вашем компьютере. С вашим документом все в порядке. Дистрибутивы LaTeX по умолчанию не поставляют все пакеты, и исправление зависит от того, какой дистрибутив вы используете.

## TeX Live

TeX Live, стандартный дистрибутив для Linux и macOS (как MacTeX), включает в себя менеджер пакетов под названием tlmgr. Установите недостающий пакет из терминала:

```
tlmgr install siunitx
```

Если был установлен полный TeX Live, а это много гигабайт, то все уже присутствует и такой ошибки быть не должно. Обычно он появляется при использовании меньших «базовых» или «малых» схем установки. Обратите внимание, что аргументом `tlmgr` является имя пакета, а не имя файла, поэтому расширение `.sty` не требуется.

## МиКТекс

MiKTeX, распространенный в Windows, имеет два механизма. Его функция установки «на лету» обнаруживает отсутствующий файл во время компиляции и предлагает загрузить его, либо запрашивая вас, либо действуя автоматически в зависимости от настроек. Альтернативно откройте консоль MiKTeX, перейдите на вкладку «Пакеты», найдите пакет и установите его там. Если установка «на лету» приводит к зависанию компиляции, обычно она ожидает диалогового окна подтверждения, скрытого за другим окном.

## Тектонический

Движок Tectonic, входящий в состав Oleafly, пропускает ручной этап: пакеты загружаются по требованию во время компиляции и помещаются в локальный кеш движка. Первая компиляция, использующая siunitx, извлекает его; позже компилирует повторно использовать кеш. Первый запуск может занять больше времени, пока загружаются зависимости, и для этого требуется подключение к сети.

## При установке не исправляет

Если менеджер пакетов сообщает, что такого пакета не существует, проверьте написание на странице пакета в CTAN, центральном архиве пакетов LaTeX на ctan.org. Два несоответствия объясняют большинство сложных случаев. Во-первых, файл и пакет могут иметь разные имена, поскольку дистрибутив может содержать несколько файлов `.sty`. Поиск в CTAN точного имени файла `.sty` из сообщения об ошибке решает эту проблему. Во-вторых, ошибка иногда называет файл из вашего собственного проекта, например файл класса, который шаблон забыл включить, и ни один менеджер пакетов не может его предоставить. Файл должен быть получен из того места, где находился шаблон.

Последнее замечание по поводу старого совета: загрузка единственного файла `.sty` из Интернета в папку вашего проекта работает, поскольку LaTeX сначала выполняет поиск в текущем каталоге, но замораживает этот пакет в случайной версии и скрывает его от обновлений. Предпочитайте менеджер пакетов и сохраняйте возможность копирования вручную на случай чрезвычайных ситуаций, приближающихся к дедлайну.
