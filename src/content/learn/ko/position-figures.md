# 수레가 실제로 착륙하는 곳

LaTeX의 그림과 표는 부동 소수점입니다. 이는 소스의 코드 위치가 지침이 아니라 제안임을 의미합니다. LaTeX는 페이지를 균등하게 채우고, 페이지가 반쯤 비어 있는 것을 방지하고, 페이지의 그림 크기와 같은 인쇄상의 제한을 준수하기 위해 부동 위치를 이동합니다. 이것은 워드 프로세서에서 발생하는 가장 큰 문화 충격이며 배치 시스템을 이해하면 이에 맞서 싸우는 시간을 절약할 수 있습니다.

## htbp의 의미

모든 float 환경은 LaTeX가 넣을 수 있는 선택적 인수 목록을 취합니다.

```latex
\begin{figure}[htbp] % here, top, bottom, page of floats
```

각 편지는 허가입니다. `h`는 코드가 나타나는 텍스트 지점에서 부동 소수점 "여기"를 허용합니다. `t`는 페이지 상단을 허용하고 `b`는 페이지 하단을 허용하며 `p`는 그림과 표만 포함하는 전용 플로트 페이지를 허용합니다. LaTeX는 작성하는 각 페이지에 대해 대략적으로 해당 순서대로 평가하여 간격 및 페이지 균형에 대한 내부 규칙을 충족하는 첫 번째 배치를 취합니다. 문자는 순위가 매겨진 소망을 표현하기보다는 옵션을 부여하므로 4개를 모두 나열하면 LaTeX가 플로트를 가깝고 합리적인 곳에 배치할 수 있는 가장 많은 공간을 제공합니다. 인수를 완전히 생략하면 기본값은 `h` 없이 `[tbp]`입니다. 이것이 바로 맨손으로 그림이 다음 페이지의 맨 위로 이동하는 이유입니다.

## "여기"를 강제하면 역효과가 나는 이유

`[h]`를 쓰는 것만으로도 확실한 해결 방법처럼 보이지만 일반적으로 상황이 더 악화됩니다. float가 현재 페이지의 나머지 공간에 맞지 않고 `h`가 사용자가 부여한 유일한 권한인 경우 LaTeX는 이를 이 페이지에 배치하거나 합법적으로 다른 페이지에 배치할 수 없습니다. 그래서 그것은 `h`를 만족하는 지점을 기다리면서 페이지마다 부동소수점을 전달합니다. 플로트도 순서대로 유지되어야 하므로 이후의 모든 피규어는 붙어 있는 피규어 뒤에 줄을 서고 전체 더미는 챕터가 끝날 때 자주 버려집니다. `[h!]`와 같이 느낌표를 추가하면 LaTeX는 간격 규칙 중 일부를 완화하지만 존재하지 않는 공간을 만들 수는 없습니다.

## 실제로 효과가 있는 습관

먼저 `[htbp]`를 기본값으로 유지하고 초안을 작성하는 동안 완벽한 픽셀 배치를 유지하세요. 왜냐하면 추가하거나 삭제하는 모든 단락이 어쨌든 페이지를 다시 섞기 때문입니다. 둘째, LaTeX는 해당 지점부터 홈 검색을 시작하고 부동소수점은 코드보다 나중에 이동할 수 있지만 코드보다 먼저 이동할 수 없으므로 처음 참조하는 단락 옆 소스에 그림 환경을 배치합니다. 셋째, "아래 그림"이 아닌 "그림 3은 파이프라인을 보여줍니다"와 같이 번호별로 그림을 참조하는 산문을 작성하여 플로트가 착륙하는 곳마다 텍스트가 올바르게 유지되도록 합니다.

플로트가 여전히 수용할 수 없는 위치에 있는 경우 플로트 장벽과 '[H]' 배치를 포함한 더 강력한 도구가 있으며 [섹션에서 도망가는 그림](/learn/Figure-wrong-position/)에 설명되어 있습니다. 초안을 작성하는 동안이 아니라 텍스트가 안정되면 글쓰기가 끝날 때 접근하세요.
