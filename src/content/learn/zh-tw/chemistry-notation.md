# 化學式與結構

化學符號對抗 LaTeX 的預設值。數學模式將元素符號顯示為斜體，就好像它們是變數一樣，而文字模式則根本沒有下標。兩個包分工。 `mhchem` 根據簡單的化學家符號排版公式和反應，而 `chemfig` 繪製結構圖。

## mhchem 的公式和反應

```latex
\usepackage[version=4]{mhchem}
\ce{H2O}
\ce{CO2 + C -> 2CO}
```

`version=4` 選項選擇目前語法。所有化学物质都在“\ce{...}”内部，它以化学家书写的方式读取其内容。在 `\ce{H2O}` 中，2 自动成为下标，并且元素符号按照约定保持直立。在反应中，“+”得到适当的间距，“->”成为反应箭头，CO之前的2被识别为化学计量系数，因此它在基线上保持完整大小。

相同的符號按比例放大。電荷作為上標，因此 `\ce{SO4^2-}` 給出帶有 2 個電荷的硫酸鹽。物質的狀態附在括號中，如`\ce{H2O(l)}`；平衡箭頭寫作「<=>」；和 `\ce{^{14}C}` 在符號前放置同位素編號。 `\ce` 在文字和數學模式下都有效，因此公式可以放在句子中，沒有額外的分隔符號。

## 使用 chemfig 建構結構

```latex
\usepackage{chemfig}
\chemfig{H-C(-[2]H)(-[6]H)-H}
```

`\chemfig` 從緊湊的線性程式碼中繪製結構。原子被寫成它們的符號，“-”畫出與下一個原子的鍵。括號內的數字設定鍵的方向，從東以逆時針方向旋轉 45 度：「[2]」指向正上方，「[6]」指向正下方。括號從目前原子打開分支，因此「C(-[2]H)(-[6]H)」向上生長一個氫，向下生長一個氫，而主鏈繼續向右延伸。這個例子是扁平的甲烷：一個中心碳與四個氫鍵合。雙鍵和三鍵寫為“=”和“~”，並且對於環狀和芳香結構有專用的環語法。

## 實用筆記

将两个工具保持在各自的车道上。對於從左到右作為公式或方程式閱讀的任何內容，請使用“mhchem”；當分子的幾何形狀是點時，請使用“chemfig”。两者都使用标准 LaTeX 引擎进行编译，无需外部绘图程序。

初學者通常會犯的錯誤是在純數學模式下寫公式。 `$H_2O$` 可以編譯，但它像變數一樣將 H 和 O 設為斜體，這按照慣例是錯誤的。 `\ce{H2O}` 產生直立形式，需要較少的打字。這兩個套餐都可以在[live Playground](/live/) 中嘗試。
