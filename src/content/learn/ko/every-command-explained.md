# LaTeX 세계의 모든 \명령 설명

이 페이지는 Oleafly Learn의 모든 강의에 나타나는 모든 LaTeX 명령 및 환경과 실제 논문에서 만날 수 있는 더 넓은 표준 어휘를 정의합니다. 커널, amsmath, hyperref, graphicx, booktabs, biblatex, TikZ, Beamer 및 연구원이 실제로 로드하는 패키지입니다. 카테고리별로 훑어보거나 방금 만난 명령에 대해 Ctrl/Cmd-F를 사용하여 페이지를 검색하세요. 각 항목은 한 줄로 구성됩니다. 즉, 해당 항목이 수행하는 작업과 중요한 위치, 해당 항목이 제공되는 패키지입니다.

## 문서 클래스 및 설정

| 명령 | 그것이 하는 일 |
| --- | --- |
| `\documentclass{기사}` | 모든 문서의 첫 번째 줄: 전체 레이아웃을 선택합니다. 기사는 논문의 기본 선택입니다. |
| `\documentclass{보고서}` | 더 긴 보고서를 위한 클래스: `\chapter`를 추가하고 자체 페이지에서 초록을 시작합니다. |
| `\documentclass{책}` | 도서 클래스: 장, 양면 레이아웃, 앞/메인/뒤 내용. |
| `\documentclass{편지}` | `\opening`, `\closing` 및 주소 명령을 사용하는 통신용 클래스입니다. |
| `\documentclass{beamer}` | '프레임' 환경에서 구축된 슬라이드 프레젠테이션을 위한 클래스입니다. |
| `\documentclass[11pt,a4paper]{기사}` | 일반적인 클래스 옵션: 글꼴 크기(10pt, 11pt, 12pt), 용지(a4paper, letterpaper), `twocolumn`, `twoside`, `landscape`, `draft`, `titlepage`. |
| `\usepackage{amsmath}` | 기능을 추가하기 위해 프리앰블에 패키지를 로드합니다. |
| `\usepackage[margin=1in]{기하학}` | 페이지 여백과 용지 크기(형상)를 설정합니다. |
| `\제목{...}` | 나중에 `\maketitle`에 의해 인쇄되는 문서 제목을 저장합니다. |
| ``작성자{...}` | `\maketitle`에 대한 작성자 목록을 저장합니다. 여러 저자를 `\and`로 구분하세요. |
| `\그리고` | `\author{...}` 내 저자 이름 사이의 구분 기호입니다. |
| ``날짜{...}` | `\maketitle`로 표시된 날짜를 저장합니다. `\date{}`는 이를 숨기고, `\date{\today}`는 오늘을 표시합니다. |
| ``오늘` | 컴파일 타임에 현재 날짜를 인쇄합니다. |
| `\maketitle` | `\title`, `\author`, `\date`에서 제목 블록을 인쇄합니다. |
| ``\감사합니다{...}` | 제목이나 저자 이름에 각주를 첨부합니다. 자금이나 연락처 정보를 원하시면. |
| ``\연구소{...}` | Beamer 및 Springer LNCS 클래스에서 사용하는 작성자 소속 명령입니다. |
| ``\inst{1}` | LNCS 및 Beamer 작성자 목록의 소속 위 첨자 표시: `Ada Lovelace\inst{1}`. |
| `\키워드{...}` | 출판사에서 해당 논문의 키워드 목록을 인쇄합니다.acmart 및 llncs와 같은 클래스. |
| `\주소{...}` | 편지 클래스: 편지지의 보낸 사람 주소를 저장합니다. |
| ``서명{...}` | 문자 클래스: 닫는 부분에 인쇄된 이름을 저장합니다. |
| ``\opening{친애하는 ...}` | letter 클래스: 인사말을 인쇄하고 편지 본문을 시작합니다. |
| ``\closing{감사합니다,}` | letter 클래스: 승인 및 서명 블록을 인쇄합니다. |
| `\LaTeX` | LaTeX 로고를 올리고 내린 문자로 인쇄합니다. |
| `\TeX` | E가 낮아진 TeX 로고를 인쇄합니다. |
| `\입력{파일}` | 마치 거기에 입력한 것처럼 다른 .tex 파일을 해당 위치에 붙여넣습니다. |
| `\include{chapter1}` | 새 페이지에서 시작하는 장 파일을 입력합니다. `\includeonly`를 통해 부분 컴파일을 활성화합니다. |
| `\includeonly{1장,3장}` | 실제로 컴파일되는 `\include` 파일을 제한하는 서문 목록입니다. |
| `\hypersetup{...}` | 링크 색상, PDF 메타데이터 등의 하이퍼참조 옵션을 구성합니다. |
| ``\AtBeginDocument{...}` | `\begin{document}` 바로 뒤에 코드를 실행합니다. 이는 늦은 설정에 유용합니다. |
| ``\AtEndDocument{...}` | 문서가 끝나기 직전에 코드를 실행합니다. |
| `\makeatletter` | 내부 명령을 사용하거나 패치할 수 있도록 일시적으로 `@`를 문자로 만듭니다. |
| ``makeatother` | `\makeatletter` 이후 `@`를 정상으로 복원합니다. |
| `\typeout{...}` | 디버깅에 편리한 메시지를 컴파일 로그와 터미널에 인쇄합니다. |
| `\보호` | `\caption` 또는 `\section`과 같은 이동 인수 내에서 깨지기 쉬운 명령을 보호합니다. |
| `\목록파일` | 버그 보고서를 위해 로드된 모든 파일과 해당 버전을 기록하는 서문 명령입니다. |

## 구조 및 섹션화

| 명령 | 그것이 하는 일 |
| --- | --- |
| ``\부분{...}` | 도서 및 보고서 수업에서 챕터 위의 최고 수준 부서입니다. |
| ``\장{...}` | 책과 보고서 수업의 장 제목에 번호가 매겨져 있습니다(기사에는 없음). |
| `\섹션{...}` | 기사의 최상위 제목에 번호가 매겨져 있습니다. |
| `\하위 섹션{...}` | `\section` 아래 한 수준 아래에 번호가 매겨진 제목입니다. |
| `\subsubsection{...}` | `\subsection` 아래에 한 수준 아래에 번호가 매겨진 제목입니다. |
| ``\단락{...}` | 최하위 제목: 단락 시작 부분에 굵은 제목을 붙입니다. |
| ``하위 단락{...}` | `\paragraph` 아래 한 수준, 거의 필요하지 않습니다. |
| `\섹션*{...}` | 별표 섹션은 숫자나 TOC 항목 없이 제목을 인쇄합니다. |
| `\부록` | 다음 장이나 섹션이 부록 A, B, C가 되도록 번호 매기기를 전환합니다. |
| `\부록페이지` | 별도의 "부록" 구분 페이지(부록 패키지)를 인쇄합니다. |
| `\목차` | 섹션화 명령으로 작성된 목차를 인쇄합니다. |
| ``그림 목록` | 페이지 번호와 함께 모든 그림 캡션 목록을 인쇄합니다. |
| `\listoftables` | 페이지 번호와 함께 모든 테이블 캡션 목록을 인쇄합니다. |
| `\머리말` | 콘텐츠 이전 페이지에 대한 북클래스 스위치: 로마자 페이지 번호, 번호가 없는 장. |
| ``주요사항' | 북클래스의 주요 내용으로 다시 전환합니다: 아랍어 페이지 번호, 번호가 매겨진 장. |
| `\backmatter` | 마지막 페이지에 대한 북클래스 스위치: 장에 번호 매기기가 중지됩니다. |
| `\addcontentsline{toc}{chapter}{...}` | 목차(또는 그림/표 목록)에 항목을 수동으로 추가합니다. |
| `\addtocontents{toc}{...}` | 콘텐츠 파일에 임의의 자료(예: 간격)를 씁니다. |
| ``\setcounter{secnumlength}{3}` | 절편 번호의 깊이를 제어합니다. |
| ``\setcounter{toclength}{2}` | 목차의 깊이를 제어합니다. |

## 명령 및 환경 정의

| 명령 | 그것이 하는 일 |
| --- | --- |
| `\newcommand{\R}{\mathbb{R}}` | 자신만의 명령을 정의합니다. 이름이 이미 있으면 오류가 발생합니다. |
| `\renewcommand{...}{...}` | 기존 명령을 재정의합니다. 존재하지 않으면 오류가 발생합니다. |
| ``\providecommand{...}{...}` | 아직 정의되지 않은 경우에만 명령을 정의합니다. 그렇지 않으면 조용히 아무것도 하지 않습니다. |
| ``\NewDocumentCommand' | 유연한 선택적 인수(LaTeX3/xparse)를 갖춘 최신 명령 정의. |
| `\newenvironment{이름}{시작 코드}{종료 코드}` | `\begin` 및 `\end`에서 실행되는 코드를 사용하여 고유한 환경을 정의합니다. |
| ``\renewenvironment{이름}{...}{...}` | 기존 환경을 재정의합니다. |
| ``수학 보장{...}` | 매크로의 수학 콘텐츠가 수학 모드 내부와 외부 모두에서 작동하도록 만듭니다. |
| ``\DeclareMathOperator{\E}{E}` | 올바른 연산자 이름을 정의합니다. 별표 표시된 양식은 아래에 제한을 둡니다(amsmath). |
| `\DeclareMathOperator*{\argmin}{arg\,min}` | 별표 형식: 연산자는 표시 수학(amsmath)에서 아래 제한을 사용합니다. |
| ``\newtheorem{lemma}{Lemma}` | 정리와 유사한 환경(amsthm)을 선언합니다. |
| `\foo` | 실제 LaTeX 명령이 아닌 `\newcommand` 강의에 나오는 사용자 정의 매크로의 이름 예입니다. |
| ``abs{x}` | 절대값 막대를 조판하는 사용자 정의 명령 강의의 사용자 정의 매크로 예입니다. |
| ``\mat{A}` | 굵은 행렬 기호에 대한 사용자 정의 명령 강의의 사용자 정의 매크로 예입니다. |
| ``\vect{v}` | 굵은 벡터 기호에 대한 사용자 정의 명령 강의의 사용자 정의 매크로 예입니다. |
| `\세트{...}` | 크기가 설정된 중괄호를 조판하는 사용자 정의 명령 강의의 사용자 정의 매크로 예입니다. |
| `\citepair` | 표준 명령이 아닌 사용자 정의 명령 강의의 사용자 정의 인용 도우미 매크로 예입니다. |
| `\E` | 기대값에 대한 사용자 정의 연산자의 예는 일반적으로 다음과 같이 정의됩니다.`\DeclareMathOperator` 또는 `\newcommand`. |
| `\R` | 실수에 대한 사용자 정의 매크로의 예: `\newcommand{\R}{\mathbb{R}}`. |
| `\argmax`, `\argmin` | arg max / arg min에 대한 연산자 이름은 이 과정에서 `\DeclareMathOperator*`로 정의되므로 아래 첨자가 표시됩니다. |

## 카운터 및 길이

| 명령 | 그것이 하는 일 |
| --- | --- |
| `\newcounter{예제}` | 새 카운터를 생성하고 선택적으로 부모에 의해 재설정됩니다: `\newcounter{examples}[section]`. |
| ``\setcounter{페이지}{1}` | 카운터 값을 설정합니다. 여기서 페이지 번호를 다시 시작합니다. |
| `\addtocounter{예제}{2}` | 아무것도 인쇄하지 않고 카운터에 값을 추가합니다. |
| ``\stepcounter{예}` | 카운터를 1씩 증가시킵니다. |
| `\refstepcounter{예제}` | 카운터를 증가시켜 다음 `\label`의 대상으로 만듭니다. |
| `\값{예}` | 산술 또는 비교에 사용하기 위해 카운터 값을 읽습니다. |
| `\아랍어{예제}` | 카운터를 아라비아 숫자(1, 2, 3)로 인쇄합니다. |
| `\roman{예제}`, `\Roman{예제}` | 카운터를 소문자 또는 대문자 로마 숫자로 인쇄합니다. |
| ``\alph{예제}`, ``\Alph{예제}` | 카운터를 소문자 또는 대문자로 인쇄합니다. |
| ``\fnsymbol{각주}` | 카운터를 각주 기호(별표, 단검 등)로 인쇄합니다. |
| ``\newlength{\mygap}` | 새로운 길이 레지스터를 생성합니다. |
| ``\setlength{\parskip}{6pt}` | 길이 레지스터에 값을 할당합니다. |
| ``\addtolength{\textheight}{1cm}` | 기존 길이에 추가됩니다. |
| ``\settowidth{\mygap}{text}` | 길이를 일부 텍스트의 자연스러운 너비로 설정합니다. |
| `\교감` | 첫 번째 줄 단락 들여쓰기의 길이입니다. `\setlength{\parindent}{0pt}`로 설정하세요. |
| `\parskip` | 단락 사이의 세로 간격 길이입니다. `\setlength`로 설정하세요. |
| `\선폭` | 현재 줄의 길이, 크기 조정에 편리함: `width=\linewidth`. |
| `\textwidth` | 페이지의 전체 텍스트 블록 너비의 길이입니다. |
| `\textheight` | 페이지의 전체 텍스트 블록 높이의 길이입니다. |
| `\열너비` | 다중 열 레이아웃에서 한 열의 너비입니다. |
| `\baselineskip` | 연속된 선의 기준선 사이의 수직 거리입니다. |
|``linespread{1.3}` | 전체 문서의 행간(줄 간격)을 조정합니다. 적용하려면 `\selectfont` 또는 크기 명령이 필요합니다. |

## 단락, 줄 바꿈 및 하이픈 넣기

| 명령 | 그것이 하는 일 |
| --- | --- |
| `\\` | 단락, 표 및 배열 내에서 현재 줄을 끝냅니다. |
| ``\\[6pt]` | 줄바꿈 뒤에 추가 수직 공간이 있습니다. |
| `\newline` | 양쪽 정렬 및 페이지 나누기를 허용하지 않고 줄을 바꿉니다. |
| `\linebreak` | 여기서 정렬된 줄 바꿈을 요청합니다. 선택사항 `[0-4]`는 주장을 설정합니다. |
| `\nolinebreak` | 이 시점에서 줄 바꿈을 방지합니다. |
| `\par` | 소스의 빈 줄과 동일하게 단락을 끝냅니다. |
| `\noindent` | 뒤에 오는 단락의 첫 번째 줄 들여쓰기를 억제합니다. |
| `\indent` | 그렇지 않으면 억제될 첫 번째 줄 들여쓰기를 강제합니다. |
| `\-` | 단어 내에 허용되는 하이픈 넣기 지점을 표시합니다. |
| `\하이픈 넣기{데이터 세트}` | LaTeX에서 특정 단어에 하이픈을 넣는 방법을 가르치는 서문 목록입니다. |
| `\엉성한` | 간격 규칙을 완화하여 줄이 더 쉽게 끊어지고 상자가 너무 많이 채워지는 것을 방지합니다. |
| ``까다로움' | `\sloppy` 뒤에 엄격한 간격 규칙을 복원합니다. |
| `\raggedright` | 다음 텍스트를 양쪽 정렬하는 대신 왼쪽 정렬합니다. |
| `\raggedleft` | 다음 텍스트를 오른쪽 정렬합니다. |
| `\센터링` | 현재 그룹 내에서 뒤에 오는 모든 항목을 중앙에 배치합니다. 피규어의 이미지입니다. |
| `\동일페이지` | 현재 그룹 내에서 페이지 나누기를 권장하지 않습니다. |
| `\enlargethispage{\baselineskip}` | 한 줄을 더 압축하기 위해 현재 페이지만 조금 더 크게 만듭니다. |
| ``~`` | 줄바꿈 없는 공백: `그림~1`은 같은 줄에 숫자를 유지합니다. |

## 간격

| 명령 | 그것이 하는 일 |
| --- | --- |
| ``쿼드' | 대문자 M 너비 정도의 가로 공백을 삽입합니다. |
| `\qquad` | `\quad` 공간의 두 배를 삽입합니다. |
| `\enspace` | 가로 공간의 절반 '\quad'를 삽입합니다. |

| `\댓글{...}` | 의사 코드 줄의 오른쪽 정렬 주석입니다. |
| `\Require`, `\Ensure` | 알고리즘 상단에 있는 전제조건과 사후조건 라인. |

## 언어, 인용 및 편집 패키지

| 명령 | 그것이 하는 일 |
| --- | --- |
| ``select언어{독일어}` | 활성 언어를 전환합니다: 하이픈 넣기, 캡션, 날짜(바벨). |
| ``\외국어{프랑스어}{...}` | 다른 언어의 규칙(바벨)에 따라 짧은 구절을 조판합니다. |
| ``\인용문{...}` | 올바르게 중첩되고 지역화되는 컨텍스트 인식 따옴표(csquotes)입니다. |
| ``\todo{이 문제를 해결하세요}` | 해야 할 일을 표시하는 여백 메모(todonotes) |
| `\listoftodos` | 모든 할일 메모(todonotes) 목록을 인쇄합니다. |
| ``누락된 그림{...}` | 아직 만들지 않은 그림에 대한 자리 표시자 상자(todonotes)입니다. |
| `\xspace` | 매크로 끝에 구두점이 뒤따르지 않는 한 공백을 추가합니다(xspace). |
| `\patchcmd{\cmd}{find}{replace}{ok}{fail}` | 기존 매크로의 정의를 제자리에 패치합니다(etoolbox). |
| `\apptocmd`, `\pretocmd` | 기존 매크로(etoolbox)에 코드를 추가하거나 앞에 추가합니다. |
| `\newtoggle{draft}`, `\toggletrue{draft}`, `\iftoggle{draft}{...}{...}` | 경량 부울 플래그(etoolbox). |

## 한 줄에 레이아웃과 타이포그래피 패키지

| 패키지 또는 명령 | 그것이 하는 일 |

| `간격`(환경) | 내용에 대한 사용자 정의 줄 간격 요소를 설정합니다(setspace). |

| `parskip`(패키지) | 단락을 차단하도록 문서를 전환합니다. 사이에 공백이 있고 들여쓰기가 없습니다. |
| `마이크로타입`(패키지) | 정당화를 향상시키는 미묘한 돌출과 확장; 그냥 로드하세요. |
| `multicols`(환경) | 두 열 클래스 옵션(다중 열)이 없는 균형 잡힌 다중 열 텍스트입니다. |

## 일반적인 환경

환경은 `\begin{name}`으로 열리고 `\end{name}`으로 닫힌 지역입니다. 둘 사이의 모든 것은 해당 환경의 동작을 가져옵니다. 전체 내용은 [명령 대 환경](/learn/commands-environments/)에 있습니다. 범용적인 것:

| 환경 | 그것이 하는 일 |
| --- | --- |
| `문서` | 모든 문서의 본문은 `\begin{document}`와 `\end{document}` 사이에 있습니다. |
| '추상' | 수업의 표준 제목과 레이아웃을 사용하여 논문 초록을 인쇄합니다. |
| `제목 페이지` | 손으로 만든 전체 제목 페이지를 래핑합니다. 페이지 번호가 없습니다. |
| '센터' | 내용을 가로로 가운데에 맞춥니다. |
| `flushleft` | 내용을 왼쪽 정렬하고 오른쪽으로 정렬합니다. |
| '플러시라이트' | 내용을 오른쪽 정렬하고 왼쪽으로 정렬합니다. |
| `항목화` | 글머리 기호 목록 각 항목은 `\item`으로 시작합니다. |
| 열거하다 | 번호가 매겨진 목록; 각 항목은 `\item`으로 시작합니다. |
| `설명` | 라벨이 있는 목록; 항목은 `\item[Label]`로 시작합니다. |
| `\항목` | 항목화, 열거 또는 설명 목록 내에서 하나의 항목을 시작합니다. |
| '인용문' | 짧은 인용을 위한 들여쓰기 블록, 단락 들여쓰기 없음. |
| '인용문' | 단락 들여쓰기를 사용하여 긴 인용문을 위한 들여쓰기 블록입니다. |
| '운문' | 시의 들여쓰기 블록으로, '\\'가 각 절의 끝 부분입니다. |
| `엉성한` | 편안한 줄 바꿈, `\sloppy` 환경 형식으로 단락을 조판합니다. |
| `목록` | 항목별 및 친구가 정의되는 일반 목록 작성기입니다. |
| `trivlist` | 매크로 정의 내에서 사용되는 레이블이나 여백이 없는 기본 목록입니다. |
| `파일 내용` | 컴파일 타임에 파일에 본문을 씁니다. .tex 안에 .bib를 배송합니다. |
| '부록' | 부록 장을 래핑하여 `\appendixpage` 및 부록별 도구(부록 패키지)를 활성화합니다. |
