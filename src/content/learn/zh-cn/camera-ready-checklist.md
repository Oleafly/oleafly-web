# 相机就绪，无需恐慌

公认！庆祝活动结束后，最后一个最后期限到来了：准备拍照。这个名字是出版商拍摄你的页面进行印刷时留下的痕迹。今天，这意味着进入诉讼程序的最终版本，就像读者将永远看到的那样。此后没有编辑修复您的拼写错误。那部分由你承担。

## 提交和相机就绪之间有什么变化

您提交的版本已针对审阅者进行了调整。相机就绪是为了永久记录，但有几件事发生了变化：

|项目 |提交版本 |相机就绪 |
|---|---|---|
|作者姓名 |隐藏（双盲）|真实姓名、隶属关系、电子邮件 |
|致谢 |省略 |资金、赠款、感谢 |
|页数限制 |审核限额|通常+1页，但准确|
|版权块 |占位符或无 |出版商区块、DOI、ISBN |
|自引 |第三人称（“史密斯等人”）|可以说“我们之前的工作”|
|反驳承诺|承诺|实际交付|

去匿名化不仅仅是重新添加名字。在来源中搜索您围绕您的身份所写的每个位置；请参阅[双盲审查的匿名化](/learn/anonymization-double-blind/) 了解通常的隐藏点，然后将它们全部反转。

## 再次强调确切的页数限制

相机就绪限制是由出版商强制执行的，而不仅仅是主席，而且额外的内容（作者区块、致谢）会占用空间。如果你突然多了六行，请诚实地做：收紧散文和数字，而不是滥用间距命令。 [无犯罪的页数限制](/learn/page-limits-without-crimes/) 中的技术在这里双重适用，因为出版商会检查格式。

## 必须嵌入字体

这是咬人的。出版商会进行自动检查，第一个拒绝原因是非嵌入字体，通常是由绘图工具导出的图形 PDF 偷偷带入的。检查“pdffonts yourpaper.pdf”：每种字体都应该显示“emb：yes”。如果没有，罪魁祸首几乎总是一个人物；使用嵌入的字体或正确生成的 PDF 重新导出它。

## 最终校对：参考文献优先

参考文献是熵集中的地方。上传之前：

- [ ] 不 ”？？”日志中的引用或未定义的引用
- [ ] 每个参考书目条目都有地点、年份和正确大小写的标题
- [ ] 作者姓名拼写正确（人们注意到自己的名字）
- [ ] 仅限 arXiv 的引文已更新为现有的已发布版本
- [ ] 引用中的 URL 仍可解析

然后大声朗读整篇论文一次。它很慢并且有效。

## 源上传怪癖

大多数出版商想要您的 LaTeX 源代码，而不仅仅是 PDF，并且他们的构建系统非常挑剔：包含“.bbl”，避免非标准包，遵循他们的文件布局。导出一个干净的源 ZIP（Oleafly 一步完成）并在上传之前在一个空文件夹中从头开始测试编译它。如果它只是由于计算机上的杂散文件而构建，则发布者的系统会发现。

## 一次性清单

- [ ] 姓名、隶属关系、电子邮件已恢复并更正
- [ ] 添加了致谢和资助编号
- [ ] 版权块/从发布者电子邮件粘贴的 DOI 信息
- [ ] 完全满足页数限制
- [ ] `pdffonts` 显示所有嵌入的字体
- [ ] 参考文献校对
- [ ] 干净的源 ZIP 从头开始编译
- [ ] 已上传，还有一天时间

然后就永久完成了。是时候考虑[展示它](/learn/present-your-paper/)。
