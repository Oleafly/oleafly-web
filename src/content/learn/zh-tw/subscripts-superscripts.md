# 不會爆炸的指數

下標和上標是每個人在 LaTeX 中學習的第一個數學語法，也是每個人產生的第一個令人困惑的輸出的來源。下劃線“_”降低後面的字符，插入符號“^”升高它，並且兩者都適用於一個字符，除非您另有說明。這項單字元規則幾乎存在於您所見過的每一個損壞的索引背後。

## 基本形式

```latex
x_i x^2
x_{ij} x^{2n}
x_i^2 x_{i_j}^{2n}
```

`x_i` 在下標位置放置一個 `i`，而 `x^2` 則產生一個 `2`。因為 `_` 和 `^` 只抓取下一個標記，所以任何超過一個字元的字元都必須用大括號括起來：`x_{ij}` 為兩個字母加上下標，而 `x^{2n}` 則引發整個 `2n`。您可以將下標和上標以任意順序附加到同一個符號，LaTeX 會正確地堆疊它們：`x_i^2`。腳本也嵌套。在“x_{i_j}”中，“j”是“i”的下標，而“i”本身也是“x”的下標，並且每個級別都設定得逐漸變小。

多字元腳本**必須**使用大括號：“x_ij”是“x_i”，然後是“j”。 LaTeX 不會將此報告為錯誤，因為「x_i」後跟變數「j」是完全合法的數學。這個公式編譯起來，乍看之下幾乎是正確的，但意義卻有所不同。儘早養成戴牙套的習慣。如有疑問，請支撐腳本。

同樣的陷阱也出現在界線和界線中。 `\sum_i=1^n` 並不像看起來那樣。正確的形式是“\sum_{i=1}^{n}”，其中整個“i=1”是一個大括號下標。如果您完全在數學模式之外使用“_”或“^”，則會出現[插入缺失美元](/learn/missing-dollar/)中涵蓋的經典錯誤。

## 質數和點

```latex
f' f'' \dot{x} \ddot{x}
```

對於導數，你很少需要文字上標。撇號鍵產生一個質數：「f」渲染為一個質數的 f，有兩個質數的 f''`，LaTeX 會自行處理升高和間距，因此不需要「f^{\prime}」。對於物理風格中的時間導數，「\dot{x}」在 x 上放置一個點，「\ddot{x}」在 x 上放置兩個點。這些是重音，所以他們將他們的論點放在大括號中。

還有一個微妙之處：如果您需要在素數後添加上標，只需將它們鏈接起來即可，例如“f”^2”。LaTeX 將它們組合成一個上標簇。

## 檢查你的輸出

內化大括號規則的最快方法是在 [live Playground](/live/) 中並排鍵入 `x_ij` 和 `x_{ij}` 並觀察差異渲染。每當編譯文件中的索引看起來有細微錯誤時，首先要檢查的是缺少一對大括號。
