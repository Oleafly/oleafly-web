# 페이지 나누기를 강제하거나 거부합니다.

LaTeX는 페이지가 끝나는 위치를 결정합니다. 대부분의 경우 잘 결정되지만 때로는 이를 무시해야 합니다. 섹션 제목이 페이지 하단에 표시되거나, 표가 한 줄 너무 늦게 표시되거나, 보고서의 각 장이 새로 시작되기를 원합니다. LaTeX는 이를 위한 어려운 명령부터 정중한 제안까지 작은 명령 세트를 제공합니다.

```latex
\newpage % end page
\clearpage % end page + flush floats
\cleardoublepage
\pagebreak[3] % soft request
\nopagebreak
```

## 힘든 휴식

`\newpage`는 현재 페이지를 즉시 종료하고 새 페이지를 시작합니다. 이것은 가장 무뚝뚝한 도구이며 초안을 작성하는 동안 가장 많이 사용하게 될 도구입니다.

`\clearpage`는 동일한 작업을 수행하지만 먼저 보류 중인 모든 부동 소수점을 플러시합니다. LaTeX의 그림과 표는 부동 소수점입니다. 알고리즘이 공간을 찾는 곳으로 이동하며 때로는 작성한 지점 이후의 페이지로 이동합니다. `\clearpage`는 계속 진행하기 전에 지금까지 대기열에 있던 모든 플로트를 페이지에 강제로 적용하므로 장 끝이나 낙오자를 원하지 않는 섹션 앞에 있는 올바른 명령입니다. 문서 끝에 숫자가 쌓여 있는 것처럼 보이면 일반적으로 잘 배치된 `\clearpage`를 사용하는 것이 해결책입니다. 전체 내용을 보려면 [도형이 움직이는 이유](/learn/Figure-wrong-position/)를 참조하세요.

`\cleardoublepage`는 양면 문서에서 한 단계 더 나아갑니다. 플로트를 플러시한 후 다음 페이지가 오른쪽(홀수) 페이지인지 확인하고 필요한 경우 빈 왼쪽 페이지를 삽입합니다. 책 장은 전통적으로 오른쪽에서 열리고 `book` 클래스는 모든 `\chapter`에서 이를 호출합니다.

## 소프트 요청

`\pagebreak[n]`은 명령을 내리지 않습니다. 그것은 묻습니다. 0에서 4까지의 선택적 숫자는 얼마나 강력한지 나타냅니다. `\pagebreak[1]`은 "여기서 중단하는 것이 좋을 것입니다"를 의미하고, `\pagebreak[4]`는 "여기서 중단, 마침표"를 의미합니다. 중간 값을 사용하면 LaTeX는 자체 간격 판단과 비교하여 원하는 값을 평가할 수 있습니다. 이는 일반적으로 하드 `\newpage`보다 더 보기 좋은 페이지를 생성합니다. `\pagebreak`는 공백을 남기지 않고 페이지를 채우기 위해 내용을 늘이기 때문입니다.

`\nopagebreak`는 반대 요청입니다. 해당 시점에서 중단을 권장하지 않습니다. 제목 바로 뒤나 소개와 함께 보관하려는 짧은 목록 바로 앞에 유용합니다. `\pagebreak`와 마찬가지로 0에서 4까지의 선택적 강도를 허용합니다.

## 언제 도달해야 할까요?

일반적인 실수는 레이아웃을 수정하기 위해 초안에 `\newpage`를 뿌리고 텍스트가 커짐에 따라 모든 수정 사항이 잘못되는 것을 지켜보는 것입니다. 페이지 나누기는 이전의 모든 사항에 따라 달라지므로 오늘은 완벽해 보이는 수동 나누기가 다음 개정 후에는 반쯤 비어 있는 페이지를 남길 수 있습니다. 정상적인 작업 흐름은 전체 문서를 먼저 작성하고 최종 패스 중에만 나누기를 추가하는 것입니다. 정확한 위치를 협상할 수 있는 경우 하드 명령보다 소프트 `\pagebreak[3]`를 선호합니다.
