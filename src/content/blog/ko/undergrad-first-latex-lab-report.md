실험실 보고서를 완성하기 위해 LaTeX를 마스터할 필요는 없습니다. 템플릿이 필요합니다.
몇 가지 명령과 첫날부터 작동하는 컴파일 버튼이 있습니다. 다른 모든 것은 가능합니다
나중 과정에서 논문 수준의 문서를 요구할 때까지 기다리십시오.

이는 완벽한 조판보다 깨끗한 PDF를 우선시하는 짧은 경로입니다.

## 가능하다면 멀티 기가바이트 설치를 건너뛰세요.

번들 엔진이 포함된 데스크톱 조사 편집기(예:
[Oleafly](https://github.com/Oleafly/Oleafly/releases/latest))를 통해 PDF를 얻을 수 있습니다.
TeX Live를 관리하지 않고. 템플릿, 오류 카드가 표시되는 줄에 표시됩니다.
깨짐, 클릭하여 점프할 수 있는 소스 옆의 PDF,
별도의 Git 코스. 강사가 특정 배포판을 요구하거나
뒷면에 강좌 노트를 따르세요. 그렇지 않으면 시작을 위해 최적화하십시오.

클라우드 편집기는 코스에서 이미 사용하고 있는 경우에도 좋습니다. 목표는 PDF입니다.
툴체인 ID가 아닌 시간에 맞춰야 합니다.

## 스켈레톤을 훔친 다음 절반을 삭제합니다.

간단한 `기사` 템플릿에서 시작하세요.

```latex
\documentclass[11pt]{article}
\usepackage[margin=1in]{geometry}
\usepackage{amsmath,graphicx}
\begin{document}
\title{Lab 3: RC circuits}
\author{Your Name \and Lab Partner}
\date{Due date}
\maketitle

\section{Objective}
\section{Method}
\section{Results}
\section{Discussion}
\section{Conclusion}
\end{document}
```

자세한 내용: [첫 번째 PDF 컴파일](/learn/first-document/) 및
[빠른 참조](/learn/cheatsheet/).

루브릭에서 요구하지 않는 섹션을 삭제하세요. 40개 묶음 논문을 복사하지 마세요
"만일의 경우"라는 서문. 추가 패키지는 초보자가 오류를 발생시키는 방법입니다.
읽다.

## 교과서가 아닌 실험실을 위한 방정식

인라인: `$F = ma$`. 표시하다:

```latex
\[
  v = v_0 + at
\]
```

나중에 인용할 내용에만 `\eqref`를 사용하여 번호를 매기세요. TA가 불확실성을 요구한 경우,
10줄짜리 `정렬`이 아닌 문장이나 작은 표에 넣으세요.
아직 이해합니다. 분수: `\frac{a}{b}`. 제곱근: `\sqrt{x}`.

컴파일 로그에 무서운 내용이 나오면 첫 번째 오류만 수정한 다음
다시 컴파일하십시오. 이후의 오류는 첫 번째 오류로 인한 잡음인 경우가 많습니다.

## 한 인물, 잘 했어요

분석 도구에서 플롯을 PDF 또는 PNG로 내보냅니다. 다음과 함께 포함하십시오:

```latex
\begin{figure}[htbp]
  \centering
  \includegraphics[width=0.85\textwidth]{plot.pdf}
  \caption{Measured voltage vs time for trial 2.}\label{fig:vr}
\end{figure}
```

본문에서: `그림~\ref{fig:vr} 은...`을 보여줍니다. 그림 아래 캡션. 라벨
캡션 뒤에. 그림이 잘못된 페이지로 떠 있는 경우 너비가 약간 줄어듭니다.
한 시간 동안 배치 옵션과 싸우기 전에:
[플로트 배치](/learn/Figure-wrong-position/).

## 고통 없는 식탁

몇 행의 경우 간단한 `표 형식`이면 충분합니다. 상단에 `table`로 캡션을 입력하세요.
+ `\캡션`. TA가 스캔할 수 있도록 번호를 정렬하세요. 당신은 필요하지 않습니다
연구실 1의 출판급 'booktabs'. 가능하다면 수직선 수프는 피하세요.

## 박사 학위 참고문헌 작업 흐름이 없는 참고 문헌

세 개의 인용의 경우 수동 목록이 작동합니다.

```latex
\begin{thebibliography}{9}
\bibitem{textbook}
  Author, \emph{Title}, year.
\end{thebibliography}
```

자세한 내용을 보려면 Google Scholar 또는 Zotero에서 '.bib'를 내보내고 키를 정리하세요.
짧고 읽기 쉽습니다. 깨진 인용은 `[?]`로 인쇄됩니다.
[미스터리 인용 표시 지우기](/learn/citation-question-mark/).

과정에서 요구하는 방식(IEEE, APA-ish 또는
간단한 번호가 매겨진 목록). 저널과 일치하는 기준표 비트를 일치시킵니다.

## 일반적인 초보자 오류

- `\includegraphics` 이전에 `\usepackage{graphicx}`를 잊어버린 경우
- 텍스트 내 `%` 및 `_`와 같은 특수 문자를 이스케이프하지 않고 사용
- 일치하지 않는 `$` 수학 구분 기호
- 공백이 포함된 파일 이름(`myplot.pdf`)에는 다음이 포함됩니다.
- 컴파일한 폴더와 다른 폴더를 편집하는 경우

속도를 늦추고 첫 번째 로그 줄을 수정한 후 다시 컴파일하세요.

## PDF를 제출하고 소스를 유지하세요.

LMS에서 요구하는 내용(보통 PDF)을 제출하세요. `.tex`와 숫자를
코스가 끝난 후에도 여전히 남아 있는 폴더입니다. 앞으로는 뼈대를 재사용할 것입니다.
다음 보고서를 위해. 편집자가 Git 기록을 자동으로 유지하는 경우에도
더 나은 점은 올바른 방정식을 삭제하기 전의 버전을 복구할 수 있다는 것입니다.

## 첫 번째 세션은 90분입니다.

오늘 밤에 시작하는 경우:

1. 템플릿을 열거나 위의 뼈대를 붙여넣습니다.
2. 기준표에서 제목, 이름, 섹션 제목을 입력합니다.
3. 이미 정확하다고 알고 있는 방정식 하나를 추가합니다.
4. 하나의 플롯을 내보냅니다. 그것을 포함하십시오; 캡션을 작성하세요. 결과에 인용하세요.
5. 코스에서 요구하는 방식으로 두 개의 참고 문헌을 추가합니다.
6. PDF가 빈 기사가 아닌 보고서처럼 보일 때까지 컴파일합니다.

루브릭이 다 다루어지면 중단하세요. 패키지 옵션에 밤을 보내지 마십시오.

## 뭔가 고장났을 때

첫 번째 오류만 읽으십시오. 일반적인 수정 사항: '$' 누락, 패키지 누락
그래픽, 잘못된 파일 이름, 추가 `}`. 이전에 컴파일 버전의 복사본을 저장하세요.
다시 돌아갈 수 있도록 큰 편집이 이루어졌습니다. 같은 반 친구의 서문이 해당 강좌에 적합한 경우,
전체 논문 스택이 아닌 그들이 사용한 최소 패키지를 빌리십시오.

## 성공의 모습

PDF가 열리고 여백이 적당해 보이고 그림에 캡션이 있고 방정식이 표시됩니다.
읽을 수 있고 루브릭 항목의 제목이 명확합니다. 처음에는 이 정도면 충분해요
LaTeX 연구실 보고서. 타이포그래피 완벽함은 실제로 필요한 종이를 기다릴 수 있습니다.
그것.
