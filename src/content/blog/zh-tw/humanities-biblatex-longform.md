## 更喜歡 biblatex 的靈活性

`biblatex` 比經典的更好地處理腳註、詳細樣式和速記
適用於大多數人文學科工作流程的 BibTeX：

```latex
\usepackage[backend=biber,style=verbose-ibid]{biblatex}
\addbibresource{sources.bib}
```

常见的替代方案包括“authortitle”、“verbose”、特定于期刊的样式、
或您所在部門的任何規定。先匹配手冊，再挑選
最接近的 biblatex 風格。背景：
[BibTeX 或 biblatex](/learn/bibtex-vs-biblatex/)。

運行 **biber** （或您的風格需要的後端），而不僅僅是 pdflatex。空
參考書目幾乎總是後端或路徑錯誤。驗證條目
提交之前：[BibTeX 驗證器](/tools/bibtex-validator/)。

## 檔案與網路資源

信件、手稿和網站需要記錄「@article」條目的字段
不關心：

- `@unpublished` 或 biblatex `@online` 用於帶有 `urldate` 的網路資源
- 手稿的檔案位置、館藏、作品集
- 穩定的按鍵，兩年後你仍能理解

不完整的條目會悄悄失敗，直到參考書目看起來稀疏為止。更喜歡一個
「.bib」（或項目的一小部分）在複製貼上腳註文字上漂移
與引用的作品不同步。

## 註腳與尾註

許多人文學科風格都需要腳註。 `biblatex` 詳細樣式和
`\footcite` / 自動腳註引用涵蓋了很多內容。如果
部門需要尾註，請儘早配置。轉換三章
投稿那週的註腳引用情況很慘。

保持實質旁白簡短。如果脚注是一个完整的段落，询问是否
它屬於正文。讀者可以略讀。

## 章節和重要版本

书籍长度的项目需要“书籍”、“回忆录”或大学论文课程
每章「\include」：

```latex
\include{chapters/ch1-intro}
\include{chapters/ch2-archive}
```

其他章節的交叉引用應使用 `\ref` / `\cref`，而不是硬編碼
當您重新排序時，「請參閱第 4 章」字串會消失。列出的結構視圖
跨文件的標題有助於撰寫 200 頁的草稿。編譯也是如此
當你修改一章時`\includeonly`。

重要版本和平行文字有專門的套件。不要發明一個
使用原始迷你頁進行佈局，直到您檢查是否有維護類
對於您的語言來說已經存在。

## 引文和語言

使用適合論文語言的引號（`csquotes` 有助於
嵌套引號和語言感知標記）。區塊引用長於幾行
應使用引用環境，而不是插入的手動縮排
兩列佈局或邊距發生變化時。

對於多語言項目，XeLaTeX 或 LuaLaTeX 附帶 `fontspec` 和一種語言
與堆疊 20 世紀 90 年代的「inputenc」駭客相比，安裝 package 沒有那麼痛苦。選擇字體
在你用無法使用的字體寫第三章之前覆蓋你需要的腳本
渲染它們。

## 圖片、地圖和合理使用說明

地圖和手稿照片通常是外部 PDF/PNG，而不是 TikZ。
帶有來源和權限狀態的標題。將高解析度母版保留在室外
git 歷史（如果它們很大的話）；將壓縮後的資料提交到論文中
實際使用，並在自述文件中註明大師居住的地方。

## 多年筆記的本地所有權

論文是一棵多年的文件樹。僅將其保留在瀏覽器項目中
當學生轉學或失去存取權限時，與一個帳戶綁定是一種風險
畢業後。

普通資料夾加 Git，本地編譯，老化效果更好。
[Oleafly](https://github.com/Oleafly/Oleafly/releases/latest) 的目標是
一種長文檔。您可以獲得跨章節、專案範圍的結構視圖
參考文獻和引用，散文的離線拼寫和語法（它跳過引用鍵），以及
無需帳戶即可實現真正的 Git 檢查點。您仍然可以在以下位置開啟相同的文件
任何其他編輯器。所有權是重點。

## 委員會持續存在的工作流程

第一年根據手冊凍結引文風格，並保留一個
具有穩定密鑰的書目資料庫。將章節文件置於版本控制之下
附有私人遙控器。前言（摘要、致謝、目錄）應
遵循羅馬/阿拉伯頁面的大學課程規則。編譯完整的 PDF
即使您使用“\includeonly”起草，也會每月一次，因此跨章節參考不會
最後給你一個驚喜。

## 預提交

- Biber/bibtex 运行干净；没有“[?]”引用。
- 腳註風格與部門相符。
- 章節交叉引用在重新排序後更新。
- 字体嵌入；页边距与论文办公室清单相符。
- 源文件和 PDF 均已存档，而不仅仅是上传门户收据。

## 索引和回溯內容

書籍類別項目有時需要索引（`imakeidx` 和朋友）。預算
真正的索引傳遞時間；自動標記每個大寫單字產生
垃圾。轉錄附錄應使用清晰的編號，以確保主要內容
章節可以`\ref`。

## 委員會草稿與存款 PDF

編號行草稿或寬邊距可以幫助標記，但存款 PDF 必須
與論文辦公室樣本相符。保留類別選項或單獨的“草稿”標誌
這樣您就無需在存款早上手動編輯保證金。

儘早獲得引文引擎。論證更值得關注
比上週的書目之爭更重要。
