# O glossário de jargões de pesquisa

Os pesquisadores falam um dialeto. Ninguém lhe entrega o dicionário, então aqui está: os termos que você ouvirá no primeiro ano, uma linha cada. Dê uma olhada agora e volte sempre que uma reunião o confundir.

## A a Z

| Prazo | Significado |
| --- | --- |
| Resumo | O resumo de 150 a 250 palavras no topo de um artigo; muitas vezes a única parte que as pessoas leem |
| AoE | Em qualquer lugar da Terra: um fuso horário, o que significa que você tem tempo até que o último lugar do planeta chegue à meia-noite |
| APC | Taxa de processamento de artigos, a taxa para publicação de ouro [acesso aberto](/learn/open-access-doi-explained/) |
| Artefato | O código, dados ou materiais por trás de um artigo, às vezes avaliado formalmente para um crachá |
| arXiv | O grande [servidor de pré-impressão](/learn/what-is-arxiv/) gratuito, pronunciado "archive" |
| Pronto para câmera | A versão final, formatada pelo editor, de um artigo aceito; o nome é anterior ao envolvimento das câmeras |
| Citação | Um indicador formal de trabalho anterior; também a unidade de crédito acadêmico |
| PCP | Chamada de trabalhos: divulgação do local sobre tema, prazo e regras |
| Autor correspondente | O autor listado que trata de todos os e-mails sobre o artigo |
| Rejeição de mesa | Rejeição pelo editor ou presidentes antes de qualquer revisão, geralmente por violação de escopo ou regra |
| Duplo cego | Revise onde autores e revisores estão ocultos uns dos outros, consulte [revisão por pares, decodificada](/learn/peer-review-explained/) |
| DOI | Um ID permanente para um documento, como 10.1145/xxxxx; a maneira confiável de citar |
| e outros. | Latim "e outros"; "Smith e outros." significa Smith mais o resto da lista de autores |
| índice h | Uma métrica do pesquisador: h artigos com pelo menos h citações cada; tratar com ceticismo |
| Fator de impacto | Média de citações recentes por artigo de um periódico; um procurador de prestígio, também trata com ceticismo |
| IRB | Conselho de Revisão Institucional: o comitê de ética que deve aprovar estudos envolvendo seres humanos |
| Palestra | A grande palestra convidada que abre um dia de conferência |
| Revisão literária | Ler e resumir o trabalho existente sobre um tema |
| LNCS |Série de procedimentos amarelos da Springer, consulte [ACM, IEEE e amigos](/learn/acm-ieee-and-friends/) |
| Revisão importante | Veredicto do jornal: são necessárias correções substanciais e, em seguida, reavaliar |
| Novidade | Se o trabalho faz algo genuinamente novo; machado favorito dos críticos |
| PC | Comitê do programa: grupo de revisores para uma conferência |
| PI | Pesquisador principal: o professor que lidera o laboratório e é bolsista |
| Pôster | Um resumo impresso que você apresenta ao lado dele em uma sessão de conferência |
| Pré-impressão | Um artigo compartilhado publicamente antes da revisão por pares |
| Processos | A coleção publicada de artigos aceitos em uma conferência |
| Refutação | A breve resposta dos autores às revisões antes da decisão |
| Trabalhos relacionados | A seção de artigos posicionando seu trabalho entre artigos anteriores |
| Reprodutibilidade | Se outras pessoas podem repetir o seu trabalho e obter os mesmos resultados |
| SIG | Grupo de interesse especial; Subcomunidades da ACM (SIGPLAN, SIGGRAPH) |
| Cego único | Revisão onde os revisores conhecem os autores, mas não vice-versa |
| Número de apresentação | A identificação anônima do seu artigo durante a revisão; você vai memorizá-lo involuntariamente |
| Material complementar | Apêndices extras, provas ou vídeos enviados junto com o trabalho |
| Pesquisa | Um artigo mapeando toda uma área de pesquisa |
| Local | Em qualquer lugar onde os artigos sejam publicados, consulte [revistas, conferências e workshops](/learn/journals-vs-conferences/) |
| Versão do registro | A cópia oficial publicada de um artigo |

## Como usar isso

Não memorize isso. Marque-o e leia algo real: o [tour de anatomia do papel](/learn/paper-anatomy-tour/) mostra essas palavras em seu habitat natural e [o que realmente é um artigo de pesquisa](/learn/what-is-a-research-paper/) une os grandes.
