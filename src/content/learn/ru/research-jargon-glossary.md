# Глоссарий исследовательского жаргона

Исследователи говорят на диалекте. Словарь вам никто не передает, и вот он: термины, которые вы услышите на первом курсе, по одной строчке каждый. Просмотрите сейчас и возвращайтесь всякий раз, когда встреча сбивает вас с толку.

## от А до Я

| Срок | Значение |
| --- | --- |
| Аннотация | Краткое изложение объемом от 150 до 250 слов в верхней части статьи; часто люди читают только часть |
| Область | В любой точке Земли: часовой пояс с крайним сроком, означающий, что у вас есть время до тех пор, пока последнее место на планете не достигнет полуночи |
| БТР | Плата за обработку статьи, плата за золото [открытый доступ](/learn/open-access-doi-explained/) публикация |
| Артефакт | Код, данные или материалы, лежащие в основе статьи, иногда формально оцениваемые для получения значка |
| arXiv | Большой бесплатный [сервер препринтов](/learn/what-is-arxiv/), произносится как «архив» |
| Готов к работе с камерой | Окончательная версия принятой статьи в формате издателя; название появилось раньше, чем были задействованы камеры |
| Цитирование | Формальный указатель на предыдущую работу; также единица академического кредита |
| КФП | Прием документов: объявление места проведения о теме, сроках и правилах |
| Автор-корреспондент | Указанный автор, который обрабатывает всю электронную почту о статье |
| Стол отклонить | Отказ редактором или председателем перед рецензированием, обычно из-за нарушения объема или правил |
| Двойной слепой | Обзор, в котором авторы и рецензенты скрыты друг от друга, см. [рецензирование, расшифровано](/learn/peer-review-explained/) |
| DOI | Постоянный идентификатор бумаги, например 10.1145/xxxxx; надежный способ цитировать |
| и др. | латинское «и другие»; «Смит и др.». означает Смит плюс остальные участники списка авторов |
| индекс Хирша | Метрика исследователя: h статей, каждая из которых имеет не менее h цитирований; относиться со скептицизмом |
| Импакт-фактор | Среднее количество недавних цитирований на статью журнала; престижное доверенное лицо, также относитесь со скептицизмом |
| ИРБ | Институциональный наблюдательный совет: комитет по этике, который должен одобрить исследования с участием людей |
| Основной доклад | Большой приглашенный доклад, открывающий день конференции |
| Лит обзор | Чтение и подведение итогов имеющейся работы по теме |
| ЛНКС |Серию желтых материалов Спрингера см. в [ACM, IEEE и друзья](/learn/acm-ieee-and-friends/) |
| Основная редакция | Вердикт журнала: необходимы существенные исправления, затем перепроверка |
| Новинка | Содержит ли работа что-то действительно новое; любимый топор рецензентов |
| ПК | Программный комитет: состав рецензентов конференции |
| ПИ | Главный исследователь: профессор, возглавляющий лабораторию и обладатель гранта |
| Плакат | Распечатанное резюме, которое вы представляете, стоя рядом с ним на сессии конференции |
| Препринт | Документ, опубликованный перед рецензированием |
| Труды | Опубликованный сборник докладов конференции |
| Опровержение | Краткий ответ авторов на отзывы перед принятием решения |
| Связанные работы | Раздел статей, позиционирующий вашу работу среди предыдущих статей |
| Воспроизводимость | Могут ли другие повторить вашу работу и получить те же результаты |
| СИГ | Группа особых интересов; Подсообщества ACM (SIGPLAN, SIGGRAPH) |
| Одиночный слепой | Рецензия, в которой рецензенты знают авторов, но не наоборот |
| Номер подачи | Анонимный идентификатор вашей статьи во время проверки; ты запомнишь это невольно |
| Дополнительный материал | Дополнительные приложения, доказательства или видео, представленные вместе с статьей |
| Опрос | Статья, отображающая целую область исследований |
| Место проведения | В любом месте, где публикуются статьи, см. [журналы, конференции и семинары](/learn/journals-vs-conferences/) |
| Версия записи | Официальная опубликованная копия статьи |

## Как это использовать

Не запоминайте это. Добавьте это в закладки, а затем прочитайте что-нибудь настоящее: [бумажный тур по анатомии](/learn/paper-anatomy-tour/) показывает эти слова в их естественной среде обитания, и [что на самом деле представляет собой исследовательская работа](/learn/what-is-a-research-paper/) связывает большие из них воедино.
