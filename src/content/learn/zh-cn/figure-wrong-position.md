# 逃离该区域的人物

你把一个数字放在第 4 节的末尾，它会打印在第 5 节的中间，或者在本章的末尾与其他三个数字堆积在一起。数字是浮动的：LaTeX 将它们在源中的位置视为起点，而不是目的地，并移动它们以保持页面完整。漂浮物也必须按顺序出现，因此无法放置的一个图形会挡住其后面的所有图形。一般的放置系统在[浮标实际着陆的地方](/learn/position-figures/)中有介绍。本课程是当浮动最终到达您无法接受的地方时的升级阶梯。

## 第一步：检查放置选项

确保环境显示“[htbp]”，而不是单独的“[h]”。这些字母授予将浮动元素放置在此处、页面顶部、底部或专用浮动页面上的权限。仅授予“h”是导致数字失控的最常见原因，因为当当前页面没有空间时，LaTeX 在任何地方都没有合法的位置并无限期地向前移动。

## 第二步：移动代码

浮标可以晚于其源位置漂移，但绝不能早于其漂移。如果该图出现得太晚，请将环境在源中向上移动，最好是在包含第一个“\ref”的段落之前。这一编辑修复了令人惊讶的比例的展示位置投诉。

## 第三步：围栏部分

`placeins` 包提供了 `\FloatBarrier`，这是一个强制在文本继续之前放置所有待处理浮动的命令：

```latex
\usepackage{placeins}
% ...
\FloatBarrier
\section{Next section}
```

将屏障放在一个部分的末尾，该部分中的任何图形都不会泄漏到下一个部分中。 LaTeX 可能会插入额外的垂直空间来冲洗浮动，这通常是靠近分节符的可接受的价格。

## 第四步：H 锤

`float` 包添加了一个大写的 `H` 说明符，完全消除了浮动：

```latex
\usepackage{float}
\begin{figure}[H]
```

“[H]”图形准确地打印其代码所在的位置，就像一个大段落一样。代价是LaTeX无法再平衡其周围的页面，因此当图形无法容纳剩余空间时，您可能会得到很大的空白间隙。将其视为一两个顽固浮动的最后手段，而不是默认值。

##第五步：缩小图形

非常大的浮动会被推迟，因为很少有页面有空间容纳它们。将“width=0.9\textwidth”减少到“0.7\textwidth”，或者从图像文件中修剪空白，通常可以让 LaTeX 放置一个一直推到章节末尾的图形。

一个值得保留的习惯：在文本稳定后进行一次调整。您添加或删除的每个段落都会重新排列页面，因此起草过程中的布局手术是您需要重做的工作。
