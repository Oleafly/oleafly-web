# 講演、ポスター、カンファレンスそのもの

受付メール、カメラの準備完了、フライトの予約。さて、誰も教えてくれない部分、それがカンファレンスです。ここでは実際に何が起こるのか、そしてそれを上手に利用する方法を紹介します。

## 話

あなたの論文が口頭枠を獲得した場合は、通常 10 ～ 20 分間の講演と質問を行います。数学は残酷かつ自由です。論文を発表することはできません。論文を読みに行くアイデア、主要人物、および理由を 1 つずつ提示できます。

- [ ] 聴衆が覚えておくべき重要な一文
- [ ] 1 分あたりおよそ 1 スライド、少なくても問題ありません
- [ ] 大きなフォント、大きな数字、最小限のテキスト
- [ ] 少なくとも 3 回、大声でリハーサルをします。1 回はタイミングを取るためだけです。
- [ ] 最も可能性の高い 2 つの質問に備える

表記が論文と一致するように、LaTeX でデッキを構築します。[Beamer Basics](/learn/beamer-basics/) でそこに到達します。

## ポスターセッション

ほとんどの受理された論文はポスターとして発表され、ポスター セッションは多くの場合、カンファレンスの最良の部分です。ポスター セッションは、あなたの仕事に立ち寄ることを選んだまさに人々との 2 時間の直接会話です。 2 メートル離れた場所からでも読みやすいものをデザインし、ピッチの 3 つのバージョンを用意します。通りすがりの人用の 30 秒バージョン、興味のある人用の 2 分バージョン、そして飛行機の中で論文を読む人用の長いバージョンです。 LaTeX 側については、[会議ポスター](/learn/conference-poster/) を参照してください。

## ライトニング トークと録音

初めての人を驚かせる 2 つの形式:

- **ライトニング トーク**: 一部の会場では、すべてのポスターに 1 ～ 2 分のティーザー スロットが与えられます。スライド 1 枚、主張 1 枚、「ポスター 42 まで探しに来てください」。
- **録画**: 多くのカンファレンスでは、講演の事前録画ビデオが必要で、イベントの数週間前にアップロードされ、独自の期限が設定されています。発表者への指示メールを注意深く確認してください。この期限は第 4 段落に隠されています。

## ネットワーキングが実際のポイントです

会談は録音されている。論文はオンラインにあります。後でダウンロードできないのは廊下です。セッション間の会話、ポスターでの質問、同じ論文を引用する人々との夕食などです。そうした会話の中には、コラボレーション、ポスドクのオファー、そして生涯の同僚となるものもあります。

ネットワーキングが恐ろしいと思われる場合は、組み込みのチート コードを使用してください。人々に自分の仕事について尋ねてください。研究者は自分の研究について話すのが大好きで、「ポスターを見ましたが、X はどのように処理しましたか?」と話します。それは完全な社会戦略です。自分の地域から少し離れたところでの講演にも参加してください。そこから新しいアイデアが生まれます。

## アーティファクトとコードのリリース

期待は変化しています。査読者と読者は、論文の背後にあるコード、データ、成果物が公開されることをますます期待しています。多くの会場では、バッジ付きのアーティファクト評価トラックを実行しています。実践編：

- [ ] 主な結果を再現する方法を記載した README を含むパブリック リポジトリ
- [ ] ピン依存関係のバージョン
- [ ] 論文とポスターからリポジトリをリンクします
- [ ] コードを明示的にライセンスする

プロジェクトがすでに GitHub 同期を使用して Git に存在している場合 ([GitHub との同期](/learn/sync-with-github/) を参照)、リリースはほとんどがクリーンアップ パスであり、移行ではありません。

## カンファレンス終了後

最終バージョンを人々が見つけられる場所に投稿し、Web サイトを更新し、一文の要点を共有します。それから休んでください。次のレッスン、[最初の論文、エンドツーエンド](/learn/first-paper-roadmap/) では、このパイプライン全体を 1 つのマップに配置します。
