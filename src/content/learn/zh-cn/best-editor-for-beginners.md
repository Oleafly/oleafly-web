# 选择一个您将实际打开的编辑器

对于初学者来说最好的 LaTeX 编辑器并不是最强大的。它可以让您以最少的摩擦从空文件转换为已编译的 PDF。尽早编译通常比任何单个功能都更重要。四种功能可满足您第一天的需求。

首先，编译应该可以在不手动安装多 GB TeX 发行版的情况下进行。其次，您希望使用 SyncTeX 进行并排 PDF 预览，因此在 PDF 中单击会跳转到匹配的源代码行并返回。第三，您的文件在磁盘上应该是纯“.tex”，这样您就可以压缩它们、通过电子邮件发送它们，或者将它们放入 Git 中，而无需导出步骤。第四，错误应该以可读消息的形式到达，而不仅仅是原始的 TeX 日志。

| VS Code + LaTeX 研讨会 |首先安装 TeX 发行版 |是的 |如果您已经在 VS Code 中工作，那么非常适合 |
|背页|在浏览器中创建帐户 |有限公司|零安装；项目在他们的服务器上运行|

中间两行共享一个隐藏成本：在编辑器可用之前，您需要自己安装和维护 TeX Live 或 MiKTeX。这就是许多初学者停滞不前的地方。浏览器选项会删除设置，但会将您的文件移至帐户中。 [浏览器项目与磁盘上的文件夹](/learn/overleaf-vs-local/) 中更深入地介绍了权衡。

## 合理的默认值

如果您想要无需 TeX 管理的本地文件，请从 [Oleafly](https://github.com/Oleafly/Oleafly/releases/latest) 开始：编译器在应用程序内部提供，并在文档第一次需要它们时下载包。无论您选择哪个编辑器，请将其与[第一个文档教程](/learn/first-document/)配对，并将[cheatsheet](/learn/cheatsheet/)放在附近。今天编辑你的第一页比编辑更重要。
