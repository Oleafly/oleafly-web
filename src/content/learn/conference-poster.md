# Posters at A0

Options:

- **tikzposter:** block-based academic posters
- **beamerposter:** Beamer heritage at large paper sizes
- **Custom geometry + TikZ:** full control, more work

Start from a working template in the [gallery](/templates/), set paper size to A0/A1, and print from PDF.
