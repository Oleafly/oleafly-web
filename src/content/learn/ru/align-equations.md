# Многострочные уравнения, которые выстраиваются в линию

Вывод из нескольких шагов лучше всего выглядит, когда знаки равенства расположены в одном столбце, чтобы глаз мог отслеживать, что изменилось от строки к строке. Пакет amsmath предоставляет для этого среду выравнивания, а также небольшую семью родственников для случаев, когда выравнивание не то, что вам нужно.

```latex
\usepackage{amsmath}
\begin{align}
 a &= b + c \\
 d &= e + f + g
\end{align}
```

## Как читается выравнивание

Каждая строка представляет собой одно уравнение, заканчивающееся `\\`; последняя строка не нуждается ни в чем. `&` отмечает точку выравнивания, и `&` каждой строки попадает в один и тот же столбец. Размещение `&` непосредственно перед знаком равенства является стандартной привычкой, поэтому знаки равенства складываются друг в друга, а левые части свисают влево. Каждая строка получает свой номер уравнения; напишите `align*` для номера none или добавьте `\notag` к отдельным строкам, чтобы пропустить только их, как показано в [числа и указатели для уравнений](/learn/number-equations/).

Среда сама открывает математические функции отображения, поэтому она не должна находиться внутри `\[ ... \]` или `$ ... $`; вложение его в другую математическую среду приводит к запутанным ошибкам.

## Семья

| Окружение | Цель |
| --- | --- |
| `выровнять` | Несколько строк, выровненных |
| `выровнять*` | То же, без номера |
| `собрать` | Несколько строк по центру |
| `раскол` | Многострочный номер уравнения |
| `многострочный` | Длинное уравнение нарушено без выравнивания |

`gather` обрабатывает несколько уравнений без общей точки выравнивания; он центрирует каждую строку и нумерует каждую. `split` строит одно многострочное уравнение под одним номером и должно находиться внутри `equation`. `multline` разбивает одну слишком длинную формулу без выравнивания: первая строка сбрасывается по левому краю, а последняя – по правому краю. Последние два подробно рассматриваются в [уравнениях, которые не подходят](/learn/break-long-equations/).

Два вопроса решают, что использовать: являются ли линии отдельными уравнениями или одним ломаным уравнением, и есть ли точка выравнивания, которую стоит сложить? Разделить и выровнять: `align`. Отдельно и по центру: «собрать». Одиночный и выровненный: `сплит`. Одиночный и невыровненный: «многострочный».

## Распространенные ошибки

Строка без `&` по-прежнему компилируется, но центрируется независимо и ничего не выравнивается. Два `&` в строке начинают вторую пару столбцов, которая `align` читается как второй столбец уравнений, расположенных рядом; если ваши выходные данные содержат уравнения, идущие вправо, посчитайте амперсанды. Завершающий `\\` в последней строке добавляет пустую строку, которая отображается как нечетное вертикальное пространство под блоком.
