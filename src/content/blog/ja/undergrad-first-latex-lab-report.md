ラボレポートを完成させるために LaTeX をマスターする必要はありません。テンプレートが必要です。
いくつかのコマンドと、初日から機能するコンパイル ボタン。それ以外はすべてできる
後のコースで論文クラスの文書が要求されるまで待ちます。

これは、完璧な組版よりもきれいな PDF を優先する短い方法です。

## 可能であれば、マルチギガバイトのインストールをスキップしてください

バンドルされたエンジンを備えたデスクトップリサーチエディター (例:

TeX Live を管理せずに。ライン上にテンプレートやエラー カードが表示されます。
壊れていて、ソースの横にある PDF をクリックしてジャンプでき、ファイル履歴がありません。
別の Git コース。インストラクターが特定の配布物を必要とする場合、または
裏面のコースノートに従ってください。それ以外の場合は、起動用に最適化します。

コースですでにクラウド エディターを使用している場合は、クラウド エディターも問題ありません。目標はPDFです
時間通りに、ツールチェーンのアイデンティティではありません。

## スケルトンを盗み、その半分を削除します

単純な「article」テンプレートから始めます。

```latex
\documentclass[11pt]{article}
\usepackage[margin=1in]{geometry}
\usepackage{amsmath,graphicx}
\begin{document}
\title{Lab 3: RC circuits}
\author{Your Name \and Lab Partner}
\date{Due date}
\maketitle

\section{Objective}
\section{Method}
\section{Results}
\section{Discussion}
\section{Conclusion}
\end{document}
```

詳細: [最初の PDF をコンパイル](/learn/first-document/) および
[クイックリファレンス](/learn/cheatsheet/)。

ルーブリックに要求されていないセクションを削除します。 40パッケージの論文をコピーしないでください
前文は「念のため」。追加パッケージは、初心者ができないエラーを引き起こす方法です
読んでください。

## 教科書用ではなく研究室用の方程式

インライン: `$F = ma$`。画面：

```latex
\[
  v = v_0 + at
\]
```

後で引用するものにのみ `\eqref` を付けて番号を付けます。 TA が不確実性について尋ねた場合、
それを10行の「整列」ではなく、文または小さな表に入れてください。
まだ理解しています。分数: `\frac{a}{b}`。平方根: `\sqrt{x}`。

コンパイル ログに何か恐ろしいことが書かれている場合は、最初のエラーだけを修正してから、
再コンパイルします。その後のエラーは、最初のエラーのノイズであることがよくあります。

## 1 つのフィギュア、よくできました

分析ツールからプロットを PDF または PNG としてエクスポートします。以下を含めてください:

```latex
\begin{figure}[htbp]
  \centering
  \includegraphics[width=0.85\textwidth]{plot.pdf}
  \caption{Measured voltage vs time for trial 2.}\label{fig:vr}
\end{figure}
```

テキスト内: `Figure~\ref{fig:vr} shows...`。図の下のキャプション。ラベル
キャプションの後。図が間違ったページに飛んでしまう場合は、幅を少し縮小してください
配置オプションと 1 時間格闘する前に、次のことを行ってください。
[フロート配置](/learn/figure-wrong-position/)。

数行の場合は、単純な「表形式」で十分です。上に「表」というキャプションを入れます
+ `\キャプション`。 TA がスキャンできるように番号を揃えます。必要ありません

## PhD 参考文献ワークフローを使用しない参考文献

3 つの引用の場合、手動リストが機能します。

```latex
\begin{thebibliography}{9}
\bibitem{textbook}
  Author, \emph{Title}, year.
\end{thebibliography}
```

さらに詳しくは、Google Scholar または Zotero から `.bib` をエクスポートし、キーをクリーンアップしてください。
短くて読みやすいです。壊れた引用は `[?]` として出力されます:
[謎の引用マークをクリアする](/learn/citation-question-mark/)。

コースで要求される方法 (IEEE、APA っぽい、または
単純な番号付きリスト)。ルーブリックの一致は日記の一致に勝ります。

## 初心者によくあるエラー

- `\includegraphics`の前の`\usepackage{graphicx}`を忘れます
- テキスト内の「%」や「_」などの特殊文字をエスケープせずに使用する
- `$` 数学区切り文字の不一致
- ブレークインクルードを含むスペースを含むファイル名 (`my plot.pdf`)
- コンパイルしたフォルダーとは別のフォルダーを編集する

速度を落とし、最初のログ行を修正し、再コンパイルします。

## PDF を提出し、ソースは保管しておいてください

LMS が要求するものを送信します (通常は PDF)。 `.tex` と数字を
コース終了後も残っているフォルダー。将来的にはスケルトンを再利用します
次のレポートのために。エディターが Git 履歴を自動的に保持する場合でも、
より良い方法: 正しい方程式を削除する前のバージョンを復元できます。

## 最初のセッションは 90 分

今夜から始める場合:

1. テンプレートを開くか、上記のスケルトンを貼り付けます。
2. ルーブリックのタイトル、名前、セクション見出しを入力します。
3. すでに正しいとわかっている方程式を 1 つ追加します。
4. 1 つのプロットをエクスポートします。それを含めてください。それにキャプションを付ける。結果でそれを引用します。
5. コースで要求される方法で 2 つの参考文献を追加します。
6. PDF が空の記事ではなくレポートのように見えるまでコンパイルします。

ルーブリックが覆われたら停止します。パッケージオプションに一晩を費やさないでください。

## 何かが壊れたとき

最初のエラーのみを読み取ります。共通の修正: `$` の欠落、パッケージの欠落
グラフィック、間違ったファイル名、余分な `}`。コンパイル前にバージョンのコピーを保存してください
大きな編集を行ったので、元に戻れます。クラスメートの前文がコースに役立つ場合は、
論文の束全体ではなく、彼らが使用した最小限のパッケージを借用します。

## 成功とはどのようなものか

PDF が開き、余白は適度にあり、図にはキャプションがあり、方程式は
読みやすく、ルーブリック項目の見出しが明確です。最初はそれで十分です
LaTeX ラボのレポート。タイポグラフィーの完成度は、実際に必要な論文を待つ必要があります
それ。
