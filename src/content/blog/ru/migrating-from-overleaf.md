В течение многих лет [Overleaf](https://www.overleaf.com/) был ответом по умолчанию на вопрос «как мне вообще запустить LaTeX?» Поделитесь ссылкой. Следите за курсором соавтора. Компилируем в облаке. Этот въезд настоящий. Для многопользовательских бумажных спринтов это все еще так.

Как только вы живете там ради диссертации, пакета услуг на рынке труда или длительного сольного переписывания, бесплатный продукт начинает казаться вам маленьким. Один соавтор. История измеряется часами. ИИ посчитал за день. Скомпилируйте таймауты. Git и полная история связаны с платными планами или кампусной лицензией, которую вы теряете при увольнении. Браузер превосходно справляется с ролью браузера с общим буфером. Он никогда не создавался как полноценное исследовательское рабочее пространство: резюме с проверками ATS, разветвление проектов, многоформатный экспорт, Typst рядом с LaTeX, офлайн-недели, неограниченная местная история.

Вот где Overleaf по-прежнему получает открытую вкладку, где заканчивается уровень бесплатного пользования и объем продукта, и что меняется, когда эти простые файлы находятся в бесплатном настольном приложении ([Oleafly](https://github.com/Oleafly/Oleafly)) которое вы загружаете один раз.

## Какие годы на Overleaf на самом деле купили тебя

**Плюсы, которые по-прежнему актуальны**

- Многопользовательское редактирование, комментарии и чат в режиме реального времени — по-прежнему лучший вариант для «трех человек, одного резюме, сегодня вечером».
- Нулевая установка для соавтора, который будет открывать только ссылку.
- Огромная галерея шаблонов и мышечная память издателя/институциональной организации.
- Кампусный единый вход и лицензии для сайтов, благодаря которым платные функции можно использовать бесплатно, пока вы находитесь на территории кампуса.
- Переключение Visual/Code и доработка, которая научила пользователей понимать, что означает «онлайн LaTeX».

**Там, где все остается тонким (особенно бесплатно)**

Опубликованные отдельные планы (перепроверьте [цены на обороте](https://www.overleaf.com/user/subscription/plans); цифры перемещаются):

| Бесплатно | Платный / орг |
| --- | --- |
| **1 соавтор** на проект | 10 (Студенческий/Стандартный) или безлимитный (Pro) |
| **5 использований ИИ в день** | Более высокие метры; полноценный Ассистент на платной основе; Про = максимальный ИИ |
| **Базовый тайм-аут компиляции** | **24×** базовый тайм-аут |
| **История: за последние 24 часа** | Полная история |
| Интеграции (Git/GitHub, Dropbox, Zotero/Mendeley,…) | Премиум на многие планы |
| Студент ~ 8–10 долларов в месяц · Стандартный ~ 17–21 доллар в месяц · Pro ~ 33–42 доллара в месяц · Университеты: контакты отдела продаж | |

Таким образом, бесплатный уровень — это настоящий редактор для преимущественно индивидуальной работы в облаке. Он превращается в демо-версию в тот момент, когда вам нужен второй соавтор, версия прошлого месяца, более длинная компиляция или более пяти подталкиваний ИИ.

Есть и вторая тонкость, которая не связана с платным доступом: для чего предназначен продукт. Overleaf оптимизирует работу с документами LaTeX для совместной работы в браузере. Он слабее как место для:

- Иметь портфолио статей, диссертаций, плакатов и резюме с разветвлением и происхождением.
- Экспортируйте один и тот же проект в Word, HTML, Markdown, PowerPoint (Beamer), EPUB без использования других инструментов.
- Запустите предварительную проверку ATS/доступности до того, как заявление о приеме на работу покинет ваши руки.
— Держите Typst и Markdown рядом с LaTeX в одной библиотеке и одной модели Git.
- Работайте офлайн в самолете или в закрытой больничной сети.
- Используйте ИИ со своим собственным ключом или локальной моделью, при этом каждое редактирование рассматривается как разница для утверждения.
- Относитесь к истории как к реальному Git, который можно открывать в терминале вечно.

Это проблемы исследовательского отдела. Overleaf в первую очередь оптимизирован для многопользовательской игры; остальная часть стола никогда не имела прежнего веса.

## Бумага для письма: обе стороны

**На оборотной стороне.** Делиться черновиком в середине абзаца не составляет труда. Комментарии доступны в документе. Для групп, которые никогда не прикоснутся к Git, это весь продукт. Редактор компетентный. Предварительный просмотр подходит для большинства статей. Вы никогда не тот человек, который должен устанавливать TeX Live для студентов.

**Там, где написание статей по-прежнему вредно.** Интеллектуальность всего проекта ограничена настольным исследовательским редактором, построенным на основе полного указателя: переименование макроса по главам, проверка `\cref` и цитат с несколькими ключами, структурирование представлений в виде 200-страничного дерева, предварительный просмотр KaTeX во время ввода, грамматика, игнорирующая `\commands`. Бесплатные таймауты компиляции требуют сложных тезисов. Бесплатная история испаряется через день. Вы не можете по-настоящему разветвить отправленную версию на экспериментальную ветку, как вы разветвляете репозиторий — вы дублируете проект в облаке и надеетесь, что запомните, что есть что.

**Олистовая сторона.** Статья представляет собой многофайловый проект на диске. Переход к определению в масштабе всего проекта, ссылки, переименование, живая диагностика ссылок/цитирования (включая беспорядочное семейство `\eqref` / `\cref`), структурные представления, дополнения для макросов, которые вы определили с реальными формами аргументов, TexLab/Tinymist, когда доступно, предварительный просмотр математических функций в реальном времени, автономный Harper + Hunspell только для прозы. Рабочая область PDF с устойчивым к устаревшим файлам SyncTeX, разворотами и съемным окном. Автоматическая компиляция на вашем процессоре с гуманизированными ошибками. CI книжного масштаба (~6200 строк) — это способ тестирования редактора.

**Как люди обычно разделяют это.** Совместное редактирование в реальном времени остается на Overleaf. Глубокая разработка нескольких файлов, автономные недели, неограниченная локальная компиляция и локальное перемещение истории. Многие люди делают и то, и другое с одними и теми же простыми файлами.

## Резюме и документы, которые считывают машины

Overleaf составит класс резюме. Что он не будет делать хорошо, так это относиться к PDF-файлу рынка труда как к продукту: шаблоны, ориентированные на ATS, детерминированный выбираемый текст и панель Preflight, которая показывает, что на самом деле видит отрывок в стиле парсера (имя, разделы, риски) - с оценками, на которые вы можете воздействовать. Разработчики веб-резюме продают эту историю за ежемесячную плату и размещают макет в своем SaaS.

Oleafly предлагает шаблоны, ориентированные на резюме, Preflight и бесплатный Git, поэтому «отраслевое резюме», «научное резюме» и «стипендия» — это разветвленные проекты с полной историей, а не три облачные копии с именем «cv_final_v4».

Если ваш единственный результат — это совместная статья, пропустите этот раздел. Если вы также отправляете заявки с одного и того же стола, вы быстро заметите этот пробел.

## Форкирование, клонирование, происхождение

Облачный «копирующий проект» существует. Исследовательские отделы хотят, чтобы это было ближе к git-форку: полная история, видимое происхождение, эксперименты, не касаясь дерева, готового для камеры. Библиотека Oleafly относится к проектам как к книгам на полке; fork копирует проект и его историю Git; Родословная указана на карте. Рабочие процессы в стиле клонирования через GitHub push/pull бесплатны.

Бесплатная история на оборотной стороне составляет 24 часа. Платная история лучше; это по-прежнему временная шкала обслуживания, а не репозиторий, который вы сохраните, если учетная запись умрет.

## Экспорт и передача

Журнальным порталам нужен PDF-файл и часто исходный zip-файл. ПИ хотят Word. Сайты курсов хотят PDF. Переговорам нужны слайды. Книги хотят EPUB. Мир Overleaf — это, прежде всего, PDF из облачного LaTeX плюс источник загрузки. Это охватывает многие научные круги.

Меню экспорта Oleafly является контекстно-зависимым: PDF и исходный zip всегда; Word, HTML, Markdown, обычный текст через управляемый Pandoc; PowerPoint от Beamer; EPUB для проектов, похожих на книги; Фигуры PNG-пути для графических проектов. Точность варьируется (будьте честны о сложном LaTeX → DOCX), но путь внутри приложения и бесплатный.

## AI, со счетчиком при дневном свете

На оборотной стороне бесплатно: пять использований ИИ в день. Платные планы повышают ограничение и разблокируют Ассистента. Организации могут отключить ИИ для всех.

Oleafly: AI отключен по умолчанию. Твой ключ или Оллама. Девять провайдеров, когда вы хотите разместиться. Агент может редактировать, компилировать, читать журналы, проверять текст PDF, искать литературу. Каждая запись — это проверка одобрения; удаление требует отдельного подтверждения; Сначала контрольная точка Git. Встроенный Ask-AI. MCP для внешних клиентов. Мы не продаем вам токены.

Удобство хостинга с ежедневным ограничением и лестницей подписки или возможность использования собственной модели и проверяемых изменений. Выберите модель доверия, которую вы сможете объяснить лаборатории или IRB.

## Многомоторная реальность

Overleaf — это облако LaTeX (и его друзей). У Typst есть своя веб-история в другом месте. Заметки Markdown живут в еще одном инструменте.

Oleafly запускает LaTeX (Tectonic), Typst и Markdown в одной библиотеке с управлением компиляторами, одной моделью Git и одной поверхностью PDF. Фильтр шаблонов по движку. Это другая форма продукта — исследовательский стол, а не еще одна вкладка LaTeX.

## Оффлайн, конфиденциальность, право собственности

Браузер: нет сети, нет редактора. Черновики живут на их серверах в соответствии с их условиями. Экспорт — это ваш выход, пока он не исчезнет (доступ к учетной записи, изменение плана, выпуск).

Локальное рабочее пространство: простые папки, настоящий Git, автономное редактирование и кэшированные компиляции, дополнительный строгий автономный режим. Нет аккаунта Oleafly. Нет телеметрии продукта. Сеть для пакетов, цитат, размещенного искусственного интеллекта, GitHub, обновлений — когда вы спросите.

## Где Overleaf все еще побеждает

- Живой многопользовательский ввод и комментарии в этот час
- Соавторы с нулевой установкой
- Институциональный SSO и «Оверлиф уже есть у всех»
- Привычки издателя, которые по умолчанию открывают облачный проект.

Живой мультиплеер для Oleafly находится в планах. До тех пор используйте Git для совместной работы, или вы оставляете Overleaf для живого спринта и локальное приложение для глубокой недели. Поскольку все представляет собой простые файлы, переключение туда и обратно — это скучная инфраструктура, а не проект миграции.

## Где свободное локальное рабочее пространство вырывается вперед

- Полная глубина редактора (индекс проекта, макросы, структура, предварительный математический анализ, проверка с учетом прозы, языковые серверы)
- Рабочая область PDF с устойчивым к устареванию SyncTeX
- Real Git + бесплатная синхронизация с GitHub + форк проекта с историей
- Typst + Markdown рядом с LaTeX
- Поиск/вставка/импорт цитат, составление диаграмм, предварительная проверка, многоформатный экспорт
- ИИ под вашими ключами с различиями в одобрении или полностью локальный
- 0 долларов навсегда, AGPL, загрузите один раз

## Пробую и то и другое, без драмы

1. Заархивируйте исходный текст Overleaf.
2. Установите Oleafly из
   [страница релизов](https://github.com/Oleafly/Oleafly/releases/latest).
3. Импорт; скомпилировать один раз; написать за день на настоящей бумаге или резюме.
4. Сохраните проект Overleaf для любой многопользовательской игры, которая вам еще понадобится.

Tectonic все еще может наткнуться на тяжелые издательские классы — сообщите о них; они формируют дорожную карту. Большинство статей и диссертаций в стиле ACM/IEEE/Elsevier подходят.

## Закрытие

Overleaf заслужил свое десятилетие. Бесплатная многопользовательская игра по-прежнему кажется волшебством, когда сегодня вечером трем людям нужен один и тот же абзац. Для владения, глубокого редактирования, разветвлений, экспорта, работы с несколькими движками, неограниченной истории и ИИ, которым вы управляете, бесплатный локальный рабочий стол является более честным решением. Загрузите Oleafly один раз, сохраните Overleaf для живых спринтов, если они вам все еще нужны, и принимайте решения на основе реальных документов, а не матрицы функций.
