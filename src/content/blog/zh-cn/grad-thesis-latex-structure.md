这篇论文是一篇很长的论文，附有官僚主义。 LaTeX 处理长
纸好。官僚通常是2009年写的大学班级档案
最后在不同的 TeX Live 上进行了测试。

尽早开始构建结构，即使章节仍然是空的。在之间移动内容
最后一个月的文件是交叉引用和图形路径中断的原因。

## 接受类文件，隔离其余部分

将大学“.cls”（以及所需的“.bst”/徽标文件）放入项目中。
不要重写该类。将您的宏、包和章节内容放入
您控制的文件：

```text
thesis/
  main.tex
  macros.tex
  chapters/
  figures/
  university.cls
```

如果课程在现代引擎上中断，请分类
[无法编译的大学类文件](/learn/fix-broken-template/)。
记录论文办公室接受的引擎（pdfLaTeX vs XeLaTeX vs
LuaLaTeX），然后再投资“fontspec”。

## 委员会期望的首要事项

摘要、奉献、致谢、目录、列表的罗马页码
数字/表格；主要章节为阿拉伯文。书籍/报告课程公开
`\frontmatter` / `\mainmatter`;基于文章的模板需要手动
`\页码`。指南：
[先罗马后阿拉伯](/learn/front-matter-page-numbers/)。

标题页内容通常必须与研究生院的 Word 样本相匹配。
准确地复制措辞。这里的创造力让 PDF 被拒绝
清单。

## 章节作为文件

一根多根包括：

```latex
\include{chapters/intro}
\include{chapters/background}
\include{chapters/methods}
\include{chapters/results}
\include{chapters/conclusion}
```

即使合著者为论文提供帮助，您也可以自己拥有章节。
将数字保留在“figures/chapter3/”下，以便重新排序时路径保持稳定。
在起草完整论文时使用“\includeonly{chapters/methods}”
不是每个方程编辑的成本：
[分割章节文件](/learn/split-chapter-files/)。

标签在整个项目中应该是唯一的（`eq:ch3-main`，而不是`eq:main`
每个文件）。项目范围的结构视图和实时参考检查帮助
200 页树。

## 首字母缩略词和符号

词汇表包功能强大且复杂。对于许多论文来说，需要手动维护
前面的符号列表就足够了。如果您需要自动扩展
首字母缩略词，在本周之前预算一天学习“额外词汇表”
提交，而不是在此期间。

在“macros.tex”中定义数学宏，并将该文件视为共享法则。符号
介于第二章和第五章之间的内容对于迂腐的考官来说是一份礼物。

## 参考书目

整个论文的一个“.bib”，或仔细合并的一小部分。稳定的按键。
软绑定前验证：
[BibTeX 验证器](/tools/bibtex-validator/)。与部门风格相匹配
想要（数字、作者年份、脚注重的人文风格）。请勿混合
biblatex 和经典 BibTeX 堆叠在一个序言中。

＃＃ 速度

完整的论文编译速度很慢。图形的草稿模式、`\includeonly` 和
TikZ 将购买时间外部化。注意事项：
[缩短等待 PDF 的时间](/learn/speed-up-compilation/)。

每周保持一次“完整编译”仪式，这样你仍然会看到跨章节的失败
早。

## 备份与历史记录不同

Dropbox 副本是备份。 Git 是一个关于争论如何改变的故事。
当章节编译时提交。推送到私有 GitHub 或 GitLab 远程。

[Oleafly](https://github.com/Oleafly/Oleafly/releases/latest) 初始化一个
每个项目的真实存储库，成功编译和空闲编辑后的检查点，
并在项目范围的结构视图和 SyncTeX 旁边一键恢复
仍然可以跨章节文件工作。这使得这个习惯更难改掉。
你可以通过任何编辑器和细心的 Git 获得同样的纪律；论文
不应该依赖于记住在第十八个月执行“git init”。

## 委员会反馈循环

为不会开源的读者导出 PDF。跟踪问题中的评论或
共享文档，但在 TeX 中应用编辑。当委员会成员返回
扫描标记 PDF，用日期和版本命名文件，以便您知道哪个
引用的源代码提交。

## 软绑定和硬绑定清单

在打印或存款之前：

- 类文件和引擎符合论文办公室规则。
- 封面页码正确；如果需要，可以提供签名页。
- 所有`\ref`/`\cite` 解析；没有`[?]`。
- 如果需要，列出图表；字幕一致。
- 页边距和字体大小通过检查表 PDF（打印测试页）。
- 源代码 + PDF + 提交哈希在存款后存档。

## 图、表和页面“列表”

许多论文办公室需要一份图表清单。字幕必须是
保持一致，不要将整个方法部分转储到 20 行标题中。使用
列表的简短标题和正文中的较长解释性标题（如果
类支持可选的短标题。

## 抄袭和之前的出版物

如果章节重新混合已发表的论文，请遵循大学的收录规则
和合著者许可。保留每篇之前已接受的论文的 PDF 和论文
版本控制中的章节，并附有有关更改内容的注释（符号、扩展
实验，统一介绍）。

## 从本月开始，而不是你写的月份

在提出大纲时创建骨架。编译的空章节
算作进步。大多数后期恐慌是结构性债务加上顽固的债务
类文件，不是科学上的空白。尽早还清这笔债务。
