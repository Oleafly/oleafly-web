# That package is not installed

**TeX Live:** `tlmgr install siunitx`

**MiKTeX:** Console → Packages, or install-on-the-fly.

**Oleafly / Tectonic:** packages download on demand into the engine's cache.

If a package is truly absent, check the package name on CTAN.
