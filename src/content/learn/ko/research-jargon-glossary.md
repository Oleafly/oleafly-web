# 연구 전문 용어집

연구원들은 방언을 사용합니다. 아무도 당신에게 사전을 건네주지 않기 때문에 여기에 있습니다: 첫해에 듣게 될 용어는 한 줄에 하나씩 있습니다. 지금 훑어보고 회의에서 혼란스러울 때마다 다시 방문하세요.

## A부터 Z까지

| 기간 | 의미 |
| --- | --- |
| 초록 | 논문 상단에 150~250 단어 요약; 종종 사람들이 읽는 유일한 부분 |
| 범위 | 지구상 어느 곳이든: 마감 시간대, 지구상의 마지막 장소가 자정에 도달할 때까지 시간이 있음을 의미 |
| APC | 기사 처리 비용, 골드[오픈 액세스](/learn/open-access-doi-explained/) 출판 수수료 |
| 유물 | 때로는 공식적으로 배지로 평가되는 종이 뒤의 코드, 데이터 또는 자료 |
| arXiv | 대형 무료 [사전 인쇄 서버](/learn/what-is-arxiv/), "아카이브"로 발음됨 |
| 카메라 지원 | 승인된 논문의 최종 출판사 형식 버전입니다. 이름은 카메라가 관련되기 이전 |
| 인용 | 이전 작업에 대한 공식적인 지침 또한 학점의 단위 |
| CFP | 논문 모집: 장소의 주제, 마감일 및 규칙 발표 |
| 교신저자 | 논문에 관한 모든 이메일을 처리하는 나열된 저자 |
| 데스크 거부 | 일반적으로 범위 또는 규칙 위반으로 인해 검토 전에 편집자 또는 의장이 거부 |
| 이중맹검 | 저자와 리뷰어가 서로 숨겨져 있는 리뷰는 [피어 리뷰, 디코딩](/learn/peer-review-explained/) |
| 도이 | 10.1145/xxxxx와 같은 논문의 영구 ID입니다. 신뢰할 수 있는 인용 방법 |
| 외. | 라틴어 "및 기타"; “스미스 등.” Smith와 나머지 저자 목록을 의미 |
| h-지수 | 연구자 지표: 각각 적어도 h회 인용된 h개의 논문; 회의적으로 대하다 |
| 영향 요인 | 저널의 논문당 평균 최근 인용 횟수입니다. 권위 있는 대리인, 역시 회의적인 태도로 대하다 |
| IRB | 기관 검토 위원회: 인간과 관련된 연구를 승인해야 하는 윤리 위원회 |
| 기조연설 | 컨퍼런스 데이를 여는 대규모 초청강연 |
| 조명 리뷰 | 특정 주제에 대한 기존 작업 읽기 및 요약 |
| LNCS |Springer의 노란색 절차 시리즈는 [ACM, IEEE 및 친구들](/learn/acm-ieee-and-friends/) |
| 주요 개정 | 저널 평결: 상당한 수정이 필요하고 재검토 |
| 참신함 | 해당 작업이 진정으로 새로운 것을 수행하는지 여부 리뷰어들이 가장 좋아하는 도끼 |
| PC | 프로그램 위원회: 컨퍼런스 리뷰어 풀 |
| PI | 연구책임자: 연구실을 이끌고 연구비를 보유한 교수 |
| 포스터 | 컨퍼런스 세션에서 옆에 서서 발표하는 인쇄된 요약 |
| 사전 인쇄 | 피어 리뷰 전에 공개적으로 공유된 논문 |
| 절차 | 학회에서 승인된 논문 모음 |
| 반박 | 결정 전 리뷰에 대한 저자의 짧은 응답 |
| 관련업무 | 이전 논문 중에서 귀하의 작업을 포지셔닝하는 논문 섹션 |
| 재현성 | 다른 사람들이 귀하의 작업을 다시 실행하고 동일한 결과를 얻을 수 있는지 여부 |
| 시그 | 특별이익단체 ACM의 하위 커뮤니티(SIGPLAN, SIGGRAPH) |
| 싱글블라인드 | 리뷰어가 저자를 알고 있지만 그 반대는 아닌 리뷰 |
| 제출번호 | 심사 중 논문의 익명 ID 당신은 그것을 무의식적으로 외울 것입니다 |
| 보충 자료 | 논문과 함께 제출된 추가 부록, 교정본, 동영상 |
| 설문조사 | 전체 연구 분야를 매핑하는 논문 |
| 장소 | 논문이 출판되는 모든 장소는 [저널, 컨퍼런스 및 워크숍](/learn/journals-vs-conferences/) |
| 기록 버전 | 공식 출판된 논문 사본 |
