수년 동안 "LaTeX를 어떻게 시작하나요?"에 대한 기본 답변은 [Overleaf](https://www.overleaf.com/)였습니다. 링크를 공유하세요. 공동저자의 커서를 살펴보세요. 클라우드에서 컴파일합니다. 그 진입로가 진짜입니다. 멀티플레이어 종이 스프린트의 경우 여전히 그렇습니다.

논문, 취업 시장 패키지 또는 장기간의 단독 재작성을 위해 그곳에 거주하면 무료 제품이 작게 느껴지기 시작합니다. 협력자 1명. 시간 단위로 측정된 기록입니다. AI는 하루에 계산됩니다. 컴파일 시간 초과. Git 및 전체 기록은 퇴사 시 상실되는 유료 요금제 또는 캠퍼스 라이선스 뒤에 있습니다. 브라우저는 공유 버퍼를 갖춘 브라우저라는 점에서 탁월합니다. 완전한 연구 작업 공간으로 구축된 적이 없습니다. ATS 검사, 프로젝트 포크, 다중 형식 내보내기, LaTeX 옆의 Typst, 오프라인 주, 무제한 로컬 기록으로 재개됩니다.

Overleaf가 여전히 오픈 탭을 획득하는 곳, 무료 계층과 제품 범위가 부족한 곳, 그리고 해당 일반 파일이 한 번 다운로드하는 무료 데스크톱 앱([Oleafly](https://github.com/Oleafly/Oleafly))에 있을 때 변경되는 사항은 다음과 같습니다.

## Overleaf에서 실제로 몇 년 동안 당신을 샀습니까?

**여전히 유지되는 전문가**

- 실시간 다중 사용자 편집, 댓글 및 채팅 - 여전히 "세 사람, 하나의 초록, 오늘밤"을 위한 최고의 옵션
- 링크만 여는 공동저자를 위한 제로 설치
- 거대한 템플릿 갤러리 및 출판사/기관 근육 메모리
- 캠퍼스에 있는 동안 유료 기능을 무료로 사용할 수 있는 캠퍼스 SSO 및 사이트 라이센스
- "온라인 LaTeX"의 의미를 현장에 알려주는 시각적/코드 전환 및 개선

**얇게 유지되는 곳(특히 무료)**

게시된 개별 요금제([Overleaf 가격](https://www.overleaf.com/user/subscription/plans)을 다시 확인하세요. 숫자 이동):

| 무료 | 유료/조직 |
| --- | --- |
| 프로젝트당 **1명의 공동작업자** | 10명(학생/표준) 또는 무제한(Pro) |
| **일일 AI 사용 5회** | 더 높은 미터; 유료의 전체 어시스턴트; 프로 = 최대 AI |
| **기본 컴파일 시간 초과** | **24×** 기본 시간 초과 |
| **기록: 지난 24시간** | 전체 역사 |
| 통합(Git/GitHub, Dropbox, Zotero/Mendeley, …) | 다양한 플랜의 프리미엄 |
| 학생 ~$8~10/월 · 표준 ~$17~21/월 · 프로 ~$33~42/월 · 대학교: 영업팀에 문의 | |

따라서 무료 계층은 대부분 단독 클라우드 작업을 위한 실제 편집기입니다. 두 번째 공동저자, 지난 달 버전, 더 긴 컴파일 또는 5개 이상의 AI 넛지가 필요한 순간 ​​데모로 전환됩니다.

페이월에 관한 것이 아닌 두 번째 얇음이 있습니다. 바로 제품의 용도입니다. Overleaf는 브라우저에서 협업 LaTeX 문서를 최적화합니다. 다음과 같은 장소로는 약합니다.

- Forking과 Lineage를 갖춘 논문, 논문, 포스터, 이력서 포트폴리오를 소유하세요.
- 다른 도구를 추가할 필요 없이 동일한 프로젝트를 Word, HTML, Markdown, PowerPoint(Beamer), EPUB로 내보냅니다.
- 입사 지원서가 손에서 떠나기 전에 ATS/접근성 프리플라이트를 실행하세요.
- 하나의 라이브러리와 하나의 Git 모델에서 LaTeX 옆에 Typst 및 Markdown을 유지합니다.
- 비행기나 폐쇄된 병원 네트워크에서 오프라인으로 작업
- 모든 편집을 승인 차이로 사용하여 자체 키 또는 로컬 모델과 함께 AI를 사용하십시오.
- 기록을 터미널에서 영원히 열 수 있는 실제 Git으로 처리합니다.

그것은 연구 책상 문제입니다. Overleaf는 먼저 멀티플레이어에 최적화되었습니다. 책상의 나머지 부분은 결코 같은 무게를 갖지 않았습니다.

## 종이 쓰기: 양면

**뒷면.** 단락 중간에 종이 초안을 공유하면 원활하게 작업할 수 있습니다. 댓글은 문서에 게시됩니다. Git을 전혀 건드리지 않는 그룹의 경우 그것이 전체 제품입니다. 편집자는 유능하다. 미리보기는 대부분의 기사에 적합합니다. 당신은 학부생을 위해 TeX Live를 설치해야 하는 사람이 아닙니다.

**문서 작성이 여전히 아픈 곳.** 전체 색인을 기반으로 구축된 데스크톱 연구 편집기 옆에 프로젝트 전체 인텔리전스가 제한됩니다. 장 전체에 걸쳐 매크로 이름 바꾸기, `\cref` 및 다중 키 인용 실시간 확인, 200페이지 트리에 대한 구조 보기, 입력하는 동안 KaTeX 미리 보기, `\명령`을 무시하는 문법 등이 있습니다. 무료 컴파일 시간 초과는 복잡한 논문을 물었습니다. 무료 기록은 하루가 지나면 사라집니다. 리포지토리를 포크하는 방식으로 제출 버전을 실험 브랜치로 실제로 포크할 수는 없습니다. 클라우드에서 프로젝트를 복제하고 어느 것이 어느 것인지 기억하기를 바랍니다.

**Oleafly 측면.** 이 논문은 디스크에 있는 다중 파일 프로젝트입니다. 프로젝트 전반의 정의로 이동, 참조, 이름 바꾸기, 실시간 참조/인용 진단(지저분한 `\eqref` / `\cref` 계열 포함), 구조 보기, 실제 인수 형태로 정의한 매크로 완성, TexLab/Tinymist(사용 가능한 경우), 실시간 수학 미리보기, 오프라인 Harper + Hunspell(산문에서만). 오래된 SyncTeX, 스프레드, 분리 가능한 창을 갖춘 PDF 작업 공간. 인간화된 오류로 CPU에서 자동 컴파일됩니다. 북스케일 CI(~6,200줄)는 편집기를 테스트하는 방법입니다.

**사람들이 일반적으로 분할하는 방법.** 실시간 공동 작성은 Overleaf에 유지됩니다. 심층적인 다중 파일 작성, 오프라인 주간, 무제한 로컬 컴파일 및 기록 로컬 이동. 많은 사람들이 동일한 일반 파일에서 두 가지 작업을 모두 수행합니다.

## 기계가 읽는 이력서와 문서

Overleaf는 이력서 클래스를 컴파일합니다. 잘 작동하지 않는 것은 직업 시장 PDF를 제품으로 취급하는 것입니다. ATS 기반 템플릿, 결정론적 선택 가능한 텍스트, 그리고 파서 스타일 추출이 실제로 확인하는 내용(이름, 섹션, 위험)을 표시하는 Preflight 패널과 조치를 취할 수 있는 점수가 있습니다. 웹 이력서 작성자는 해당 스토리를 SaaS의 월별 요금과 트랩 레이아웃으로 판매합니다.

Oleafly는 이력서 중심 템플릿, Preflight 및 무료 Git을 제공하므로 "산업 CV", "학계 CV" 및 "펠로우십"은 'cv_final_v4'라는 이름의 3개 클라우드 복사본이 아니라 전체 기록을 포함하는 포크된 프로젝트입니다.

유일한 출력이 공유 문서인 경우 이 섹션을 건너뛰세요. 동일한 데스크에서 애플리케이션도 배송하는 경우에는 격차를 빨리 알 수 있습니다.

## 분기, 복제, 계보

클라우드 "복사 프로젝트"가 존재합니다. 연구 데스크가 원하는 것은 git 포크에 더 가깝습니다. 즉, 전체 기록, 가시적 계보, 카메라 지원 트리를 건드리지 않고 실험하는 것입니다. Oleafly의 도서관은 프로젝트를 선반 위의 책으로 취급합니다. 포크는 프로젝트와 해당 Git 기록을 복사합니다. 카드에 계보가 표시됩니다. GitHub 푸시/풀을 통한 복제 스타일 워크플로는 무료입니다.

오버리프 무료 기록은 24시간입니다. 유료 기록이 더 좋습니다. 이는 여전히 서비스 타임라인이지 계정이 소멸된 경우 보관하는 저장소가 아닙니다.

## 내보내기 및 전달

저널 포털에서는 PDF를 원하고 종종 소스 zip을 원합니다. PI는 Word를 원합니다. 코스 사이트에서는 PDF를 원합니다. 회담에서는 슬라이드를 원합니다. 책은 EPUB를 원합니다. Overleaf의 세계는 주로 클라우드 LaTeX의 PDF와 다운로드 소스입니다. 그것은 많은 학계를 다루고 있습니다.

Oleafly의 내보내기 메뉴는 상황을 인식합니다. PDF 및 소스 zip은 항상; 관리되는 Pandoc을 통한 Word, HTML, Markdown, 일반 텍스트; Beamer의 PowerPoint; 책과 같은 프로젝트를 위한 EPUB; 이미지 프로젝트에 대한 그림 PNG 경로입니다. 충실도는 다양하지만(복잡한 LaTeX → DOCX에 대해 솔직하게 말하면) 경로는 앱 내이며 무료입니다.

## AI, 낮에 미터를 사용함

Overleaf 무료: 하루에 AI 5회 사용. 유료 요금제는 한도를 높이고 어시스턴트를 잠금 해제합니다. 조직은 모든 ​​사람을 위해 AI를 비활성화할 수 있습니다.

Oleafly: 기본적으로 AI가 꺼져 있습니다. 열쇠 또는 ​​Ollama. 호스팅을 원하는 경우 9개의 공급자. 에이전트는 로그를 편집, 컴파일, 읽기, PDF 텍스트 확인, 문헌 검색 등을 할 수 있습니다. 모든 쓰기는 승인 차이입니다. 삭제에는 별도의 확인이 필요합니다. 먼저 Git 체크포인트를 사용하세요. 인라인 Ask-AI. 외부 클라이언트용 MCP. 우리는 귀하에게 토큰을 판매하지 않습니다.

일일 한도 및 구독 사다리 또는 직접 모델 가져오기 및 검사 가능한 편집을 통해 편리함을 호스팅합니다. 연구소나 IRB에 설명할 수 있는 신뢰 모델을 선택하세요.

## 다중 엔진 현실

Overleaf는 LaTeX(및 친구들) 클라우드입니다. Typst에는 다른 곳에서도 자체 웹 스토리가 있습니다. 마크다운 노트는 또 다른 도구에 있습니다.

Oleafly는 하나의 라이브러리에서 LaTeX(Tectonic), Typst 및 Markdown을 실행하며 컴파일러는 하나의 Git 모델, 하나의 PDF 표면을 관리합니다. 템플릿은 엔진별로 필터링됩니다. 그것은 다른 LaTeX 탭이 아니라 연구 데스크라는 다른 제품 형태입니다.

## 오프라인, 개인 정보 보호, 소유권

브라우저: 네트워크도 없고 편집기도 없습니다. 초안은 해당 조건에 따라 서버에 게시됩니다. 내보내기는 그렇지 않을 때까지 탈출구입니다(계정 액세스, 계획 변경, 졸업).

로컬 작업 공간: 일반 폴더, 실제 Git, 오프라인 편집 및 캐시된 컴파일, 선택적 엄격한 오프라인 모드. Oleafly 계정이 없습니다. 제품 원격 측정이 없습니다. 요청하면 패키지, 인용, 호스팅 AI, GitHub, 업데이트를 위한 네트워크를 구축할 수 있습니다.

## Overleaf가 여전히 승리하는 곳

- 이번 시간 실시간 다중 사용자 입력 및 댓글
- 제로 설치 공동저자
- 기관 SSO 및 "모든 사람이 이미 Overleaf를 보유하고 있습니다"
- 기본적으로 클라우드 프로젝트를 열어주는 퍼블리셔 습관

Oleafly의 라이브 멀티플레이어가 로드맵에 있습니다. 그때까지는 Git이 공동 작업 경로이거나 라이브 스프린트를 위해 Overleaf를 유지하고 한 주 동안 로컬 앱을 유지합니다. 모든 것이 일반 파일이기 때문에 앞뒤로 전환하는 것은 마이그레이션 프로젝트라기보다는 지루한 인프라입니다.

## 무료 로컬 작업 공간이 앞서가는 곳

- 전체 편집기 깊이(프로젝트 색인, 매크로, 구조, 수학 미리보기, 산문 인식 교정, 언어 서버)
- 오래된 SyncTeX를 갖춘 PDF 작업 공간
- Real Git + 무료 GitHub 동기화 + 기록이 포함된 프로젝트 포크
- LaTeX 옆의 Typst + Markdown
- 인용 검색/붙여넣기/가져오기, 다이어그램 작성, 프리플라이트, 다중 형식 내보내기
- 승인 차이가 있는 키 아래의 AI 또는 완전히 로컬인 AI
- 영원히 $0, AGPL, 한 번 다운로드

## 마무리

Overleaf는 10년을 맞이했습니다. 오늘 밤 세 사람이 같은 문단을 필요로 할 때 무료 멀티플레이어는 여전히 마법처럼 느껴집니다. 소유권, 심층 편집, 포크, 내보내기, 다중 엔진 작업, 무제한 기록 및 AI 제어를 위해서는 무료 로컬 데스크가 더 적합합니다. Oleafly를 한 번 다운로드하고, 여전히 필요한 경우 라이브 스프린트를 위해 Overleaf를 유지하고, 기능 매트릭스가 아닌 실제 논문에서 결정하세요.
