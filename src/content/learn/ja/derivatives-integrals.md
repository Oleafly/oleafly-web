# 微分と積分

微積分記法は、LaTeX がその地位を確立し始める場所です。積み上げ微分分数、制限付きの積分符号、および変数上のドットはすべて、それぞれ 1 つまたは 2 つのコマンドです。このレッスンでは、これまでに作成するほぼすべての導関数と積分を生成するいくつかのコマンドに加えて、洗練された紙と下書きを区別する小さな間隔の習慣について説明します。

## デリバティブ

```latex
\frac{dy}{dx}
\frac{\partial f}{\partial x}
\nabla f \quad \nabla^2 f
f'(x) \quad \dot{x}
```

通常の導関数は単なる分数です。`\frac{dy}{dx}` は `dy` を `dx` の上に積み上げます。偏導関数の場合、`d` を `\partial` に置き換えます。これにより、波状の部分記号が出力されます。 `\frac{\partial f}{\partial x}` が標準形式です。高次の部分関数も同じパターンに従います (例: `\frac{\partial^2 f}{\partial x \partial y}`)。

`\nabla` はグラデーション シンボルを与えます。これは通常のシンボルであるため、他のものと同じようにそれを発生させることができます。ラプラシアンの場合は `\nabla^2 f` です。コンパクトな記法では、`f'(x)` はアポストロフィ キーを直接使用し、LaTeX は 1 つ以上の `''` マークを適切に隆起した素数に変換します。 Newton の時間導関数のドット表記は、引数の上に 1 つまたは 2 つのドットを配置するアクセント コマンド `\dot{x}` および `\ddot{x}` に由来しています。

スタイルの選択の 1 つは、微分 `d` を直立させて `\mathrm{d}` と書くことを求めるジャーナルもあります。そうする場合は、プリアンブルで `\newcommand{\dd}{\mathrm{d}}` を一度定義し、後で選択を反転できるように `\frac{\dd y}{\dd x}` と記述します。

## 積分

```latex
\int_a^b f(x)\,dx
\iint_D f\,dA
```

`\int` は整数記号であり、よく知られた下付き文字と上付き文字の構文によって制限が付加されます。下限は _a 、上限は `^b` です。インライン計算では、線をコンパクトに保つ​​ために、制限値は記号の横に配置されます。表示数学では、(和とは異なり) 積分の符号の横に表示されますが、これが標準的な規則です。二重積分と三重積分には、等高線積分の `\oint` とともに、繰り返される符号を正しく配置する独自のコマンド `\iint` と `\iiint` が与えられます。

`dx` の前の `\,` は細いスペースです。これがないと、`f(x)dx` は被積分関数を微分に直接実行するため、目がそれらを解く必要があります。薄い空間は広く守られている慣例なので、被積分関数、`\,`、微分という順に習慣づけてください。

## 試してみてよくある間違い

これらのスニペットは、[ライブ プレイグラウンド](/live/) に入力するとレンダリングされます。これは、ドキュメントに組み込まれる前に派生スタックをチェックする迅速な方法です。 `$` および `\[` 区切り文字がまだ新しい場合は、[数学モードの基本](/learn/math-mode/) を参照してください。

ここで最も一般的な間違いは、スタックされた `\frac` が必要な表示計算でスラッシュを使用して `d/dx` スタイルの導関数を入力したこと、または複数文字制限の中括弧を忘れたことです。つまり、`\int_a^b+1` は上付き文字に `b` だけを入れます。式全体が呼び出されるように `\int_a^{b+1}` と書きます。
