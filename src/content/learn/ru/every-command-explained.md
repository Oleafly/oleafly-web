# Объяснение каждой \команды во вселенной LaTeX

На этой странице описаны все команды LaTeX и среда, которые появляются в любом уроке Oleafly Learn, а также более широкий стандартный словарь, который вы встретите в реальных документах. Kernel, amsmath, Hyperref,graphicx, booktabs, biblatex, TikZ, Beamer и пакеты, которые исследователи фактически загружают. Просмотрите его по категориям или найдите на странице команду, которую вы только что встретили, с помощью Ctrl/Cmd-F. Каждая запись представляет собой одну строку: что она делает и, где это важно, из какого пакета она взята.

## Классы документов и настройка

| Команда | Что он делает |
| --- | --- |
| `\documentclass{статья}` | Первая строка каждого документа: выбирает общий макет; «статья» — выбор по умолчанию для статей. |
| `\documentclass{отчет}` | Класс для более длинных отчетов: добавляет `\chapter` и запускает аннотацию на отдельной странице. |
| `\documentclass{книга}` | Класс для книг: главы, двусторонняя раскладка, лицевая/основная/конечная. |
| `\documentclass{letter}` | Класс для корреспонденции с командами `\opening`, `\closing` и адресами. |
| `\documentclass{проектор}` | Класс для слайд-презентаций, созданных на основе фреймов. |
| `\documentclass[11pt,a4paper]{статья}` | Общие параметры класса: размер шрифта (10 пт, 11 пт, 12 пт), бумага (а4, Letter), «двухколоночный», «двусторонний», «альбомная», «черновик», «титульный лист». |
| `\usepackage{amsmath}` | Загружает пакет в преамбуле для добавления функций. |
| `\usepackage[margin=1in]{geometry}` | Устанавливает поля страницы и размер бумаги (геометрию). |
| `\title{...}` | Сохраняет заголовок документа, напечатанный позже с помощью `\maketitle`. |
| `\author{...}` | Сохраняет список авторов `\maketitle`; разделите нескольких авторов с помощью `\and`. |
| `\и` | Разделитель между именами авторов внутри `\author{...}`. |
| `\date{...}` | Сохраняет дату, указанную `\maketitle`; `\date{}` скрывает его, `\date{\today}` показывает сегодняшний день. |
| `\сегодня` | Печатает текущую дату во время компиляции. |
| `\maketitle` | Печатает основную надпись из `\title`, `\author` и `\date`. |
| `\спасибо{...}` | Прикрепляет сноску к заголовку или имени автора, например. для финансирования или контактной информации. |
| `\institut{...}` | Команда принадлежности автора, используемая Beamer и классом Springer LNCS. |
| `\inst{1}` | Надстрочный маркер принадлежности в списках авторов LNCS и Beamer: `Ада Лавлейс\inst{1}`. |
| `\keywords{...}` | Печатает список ключевых слов статьи в издательстве.такие классы, как acmart и llncs. |
| `\адрес{...}` | Класс Letter: хранит адрес отправителя фирменного бланка. |
| `\подпись{...}` | Класс Letter: хранит имя, напечатанное под закрытием. |
| `\opening{Дорогой ...}` | класс Letter: печатает приветствие и запускает тело письма. |
| `\closing{С уважением,}` | класс Letter: печатает блок подписи и подписи. |
| `\LaTeX` | Печатает логотип LaTeX с поднятыми и опущенными буквами. |
| `\TeX` | Печатает логотип TeX с заниженной буквой E. |
| `\input{файл}` | Вставляет на место другой файл .tex, как если бы вы его там напечатали. |
| `\include{chapter1}` | Вводит файл главы, начиная с новой страницы; включает частичную компиляцию через `\includeonly`. |
| `\includeonly{chapter1,chapter3}` | Список преамбул, ограничивающий фактически компилируемые файлы `\include`. |
| `\hypersetup{...}` | Настраивает параметры гиперссылки, такие как цвета ссылок и метаданные PDF. |
| `\AtBeginDocument{...}` | Запускает код сразу после `\begin{document}`, что полезно при поздней настройке. |
| `\AtEndDocument{...}` | Запускает код непосредственно перед завершением документа. |
| `\makeatletter` | Временно преобразует `@` в букву, чтобы вы могли использовать или исправлять внутренние команды. |
| `\ makeatother` | Восстанавливает `@` в нормальное состояние после `\makeatletter`. |
| `\typeout{...}` | Выводит сообщение в журнал компиляции и на терминал, что удобно для отладки. |
| `\защитить` | Защищает хрупкую команду внутри движущегося аргумента, такого как `\caption` или `\section`. |
| `\listfiles` | Команда преамбулы, которая регистрирует каждый загруженный файл и его версию для отчетов об ошибках. |

## Структура и секционирование

| Команда | Что он делает |
| --- | --- |
| `\part{...}` | Подразделение самого высокого уровня, над главами, в классах книг и отчетов. |
| `\глава{...}` | Нумерованный заголовок главы в классах книг и отчетов (не в статье). |
| `\section{...}` | Нумерованный заголовок верхнего уровня в статье. |
| `\subsection{...}` | Нумерованный заголовок на один уровень ниже `\section`. |
| `\subsubsection{...}` | Нумерованный заголовок на один уровень ниже `\subsection`. |
| `\параграф{...}` | Заголовок самого низкого уровня: жирный заголовок в начале абзаца. |
| `\subparagraph{...}` | На один уровень ниже `\paragraph`, требуется редко. |
| `\section*{...}` | При выделенном разделе заголовок печатается без номера или содержания. |
| `\приложение` | Изменяет нумерацию, поэтому следующие главы или разделы становятся Приложением A, B, C. |
| `\appendixpage` | Печатает отдельную разделительную страницу «Приложения» (пакет приложений). |
| `\tableofcontents` | Печатает оглавление, созданное на основе команд секционирования. |
| `\listoffigures` | Печатает список всех подписей к рисункам с номерами страниц. |
| `\listoftables` | Печатает список всех заголовков таблиц с номерами страниц. |
| `\frontmatter` | Переключатель класса книги для страниц предварительного содержимого: римские номера страниц, ненумерованные главы. |
| `\mainmatter` | Книжный класс переключается обратно на основное содержание: арабские номера страниц, пронумерованные главы. |
| `\backmatter` | Переключение класса книги для конечных страниц: главы перестают нумероваться. |
| `\addcontentsline{toc}{chapter}{...}` | Вручную добавляет запись в оглавление (или список рисунков/таблиц). |
| `\addtocontents{toc}{...}` | Записывает произвольный материал (например, пробелы) в файл содержимого. |
| `\setcounter{secnumlength}{3}` | Управляет глубиной разделения чисел. |
| `\setcounter{toclength}{2}` | Управляет глубиной содержания. |

## Определение команд и сред

| Команда | Что он делает |
| --- | --- |
| `\newcommand{\R}{\mathbb{R}}` | Определяет вашу собственную команду; ошибки, если имя уже существует. |
| `\renewcommand{...}{...}` | Переопределяет существующую команду; ошибки, если его нет. |
| `\providecommand{...}{...}` | Определяет команду, только если она еще не определена; в противном случае молча ничего не делает. |
| `\НовыйДокументКомманд` | Современное определение команды с гибкими дополнительными аргументами (LaTeX3/xparse). |
| `\newenvironment{name}{начальный код}{конечный код}` | Определяет вашу собственную среду с кодом, запускаемым в `\begin` и `\end`. |
| `\renewenvironment{name}{...}{...}` | Переопределяет существующую среду. |
| `\ensuremath{...}` | Заставляет математическое содержимое макроса работать как внутри, так и вне математического режима. |
| `\DeclareMathOperator{\E}{E}` | Определяет прямое имя оператора; форма со звездочкой устанавливает ограничения ниже (amsmath). |
| `\DeclareMathOperator*{\argmin}{arg\,min}` | Форма со звездочкой: оператор принимает пределы, указанные ниже в математических вычислениях (amsmath). |
| `\newtheorem{lemma}{Лемма}` | Объявляет среду, подобную теореме (amsthm). |
| `\фу` | Пример имени пользовательского макроса в уроке `\newcommand`, а не настоящей команды LaTeX. |
| `\abs{x}` | Пример пользовательского макроса из урока по пользовательским командам, который набирает полосы абсолютных значений. |
| `\mat{A}` | Пример пользовательского макроса из урока по пользовательским командам для жирного матричного символа. |
| `\vect{v}` | Пример пользовательского макроса из урока по пользовательским командам для жирного векторного символа. |
| `\set{...}` | Пример пользовательского макроса из урока по пользовательским командам, который набирает фигурные скобки определенного размера. |
| `\citepair` | Пример определяемого пользователем вспомогательного макроса цитирования из урока по пользовательским командам, а не стандартной команды. |
| `\E` | Пример определяемого пользователем оператора ожидания, обычно определяемого с помощью`\DeclareMathOperator` или `\newcommand`. |
| `\R` | Пример пользовательского макроса для действительных чисел: `\newcommand{\R}{\mathbb{R}}`. |
| `\argmax`, `\argmin` | Имена операторов для arg max/arg min, определенные в этом курсе с помощью `\DeclareMathOperator*`, поэтому индексы располагаются ниже. |

## Счетчики и длины

| Команда | Что он делает |
| --- | --- |
| `\newcounter{examples}` | Создает новый счетчик, который может быть сброшен родительским элементом: `\newcounter{examples}[section]`. |
| `\setcounter{page}{1}` | Устанавливает значение счетчика, здесь перезапускает нумерацию страниц. |
| `\addtocounter{examples}{2}` | Добавляет значение к счетчику, ничего не печатая. |
| `\stepcounter{examples}` | Увеличивает счетчик на единицу. |
| `\refstepcounter{examples}` | Увеличивает счетчик и делает его целью для следующего `\label`. |
| `\value{examples}` | Считывает значение счетчика для использования в арифметических операциях или сравнениях. |
| `\арабский{примеры}` | Печатает счетчик в виде арабских цифр: 1, 2, 3. |
| `\roman{examples}`, `\Roman{examples}` | Печатает счетчик в виде римских цифр в нижнем или верхнем регистре. |
| `\alph{examples}`, `\Alph{examples}` | Печатает счетчик строчными или прописными буквами. |
| `\fnsymbol{footnote}` | Печатает счетчик в виде символов сноски: звездочки, кинжала и т. д. |
| `\newlength{\mygap}` | Создает новый регистр длины. |
| `\setlength{\parskip}{6pt}` | Присваивает значение регистру длины. |
| `\addtolength{\textheight}{1см}` | Добавляет к существующей длине. |
| `\settowidth{\mygap}{текст}` | Устанавливает длину, равную естественной ширине некоторого текста. |
| `\parindent` | Длина отступа первой строки абзаца; устанавливается с помощью `\setlength{\parindent}{0pt}`. |
| `\парскип` | Длина вертикального промежутка между абзацами; устанавливается с помощью `\setlength`. |
| `\linewidth` | Длина текущей строки, удобная для изменения размера: `width=\linewidth`. |
| `\textwidth` | Длина полнотекстового блока на странице. |
| `\texteight` | Длина высоты полнотекстового блока на странице. |
| `\columnwidth` | Ширина одного столбца в макете с несколькими столбцами. |
| `\baselineskip` | Расстояние по вертикали между базовыми линиями последовательных линий. |
|`\linespread{1.3}` | Масштабирует интерлиньяж (межстрочный интервал) для всего документа; для вступления в силу требуется `\selectfont` или команда размера. |

## Абзацы, разрывы строк и расстановка переносов

| Команда | Что он делает |
| --- | --- |
| `\\` | Завершает текущую строку внутри абзацев, таблиц и массивов. |
| `\\[6pt]` | Разрыв строки с дополнительным вертикальным пробелом после него. |
| `\новая строка` | Разбивает строку, не выравнивая ее и не допуская разрыва страницы. |
| `\linebreak` | Здесь запрашивается обоснованный разрыв строки; необязательный `[0-4]` устанавливает настойчивость. |
| `\nolinebreak` | Препятствует разрыву строки в этом месте. |
| `\пар` | Завершает абзац так же, как и пустая строка в исходном коде. |
| `\ноиндент` | Подавляет отступ первой строки следующего абзаца. |
| `\отступ` | Принудительно устанавливает отступ первой строки там, где в противном случае он был бы подавлен. |
| `\-` | Отмечает разрешенную точку переноса внутри слова. |
| `\hyphenation{набор данных}` | Список преамбул, обучающий LaTeX расставлять переносы в определенных словах. |
| `\ небрежный` | Смягчает правила интервалов, поэтому строки легче разрываются, избегая переполнения блоков. |
| `\ суетливый` | Восстанавливает строгие правила пробелов после `\sloppy`. |
| `\raggedright` | Следующий текст выравнивается по левому краю, а не выравнивается. |
| `\raggedleft` | Выравнивает следующий текст по правому краю. |
| `\центрирование` | Центрирует все, что следует за текущей группой, например. изображение фигуры. |
| `\samepage` | Предотвращает разрывы страниц внутри текущей группы. |
| `\enlargethispage{\baselineskip}` | Делает только текущую страницу немного выше, чтобы вместить еще одну строку. |
| `~` | Неразрывный пробел: `Figure~1` сохраняет число на одной строке. |

## Интервал

| Команда | Что он делает |
| --- | --- |
| `\quad` | Вставляет горизонтальное пространство шириной примерно с заглавную М. |
| `\qquad` | Вставляет двойной пробел `\quad`. |
| `\enspace` | Вставляет половину `\quad` горизонтального пространства. |
| `\hspace{1см}` | Вставляет горизонтальное пространство; исчезает при разрыве строки. |
| `\hspace*{1cm}` | Горизонтальное пространство, которое сохраняется даже при разрыве строки. |
| `\vspace{1см}` | Вставляет вертикальное пространство заданной длины. |
| `\vspace*{1cm}` | Вертикальное пространство, которое сохраняется даже при разрыве страницы. |
| `\smallskip` | Вставляет небольшой вертикальный разрыв между абзацами. |
| `\medskip` | Вставляет средний вертикальный разрыв между абзацами. |
| `\bigskip` | Вставляет большой вертикальный разрыв между абзацами. |
| `\hfill` | Растягивающееся горизонтальное пространство, которое раздвигает контент, заполняя строку. |
| `\vfill` | Растянутое вертикальное пространство, которое раздвигает контент, заполняя страницу. |
| `\dotfill` | Заполняет оставшуюся строку точками, как в строке меню или содержимого. |
| `\hrulefill` | Заполняет оставшуюся строку горизонтальной линейкой. |
| `\stretch{2}` | Эластичный клей с грузом для пропорционального расстояния: `\hspace{\stretch{2}}`. |
| `\заполнить` | Устройство эластичной длины; `\hspace{\fill}` — это то, во что расширяется `\hfill`. |
| `\фантом{текст}` | Занимает ровно столько места, сколько занимает аргумент, но ничего не печатает. |
| `\hphantom{текст}` | Занимает только ширину своего аргумента с нулевой высотой. |
| `\vphantom{текст}` | Занимает только высоту своего аргумента с нулевой шириной. |
| `\smash{...}` | Печатает свой аргумент, но делает вид, что он имеет нулевую высоту и глубину. |
| `\ стойка` | Невидимая поддержка высоты обычной строки для выравнивания высоты строк. |
| `\mathstrut` | Распорка в математическом режиме размером со скобку для выравнивания радикалов и дробей. |

## Коробки и правила

| Команда | Что он делает |
| --- | --- |
| `\mbox{...}` | Небьющийся горизонтальный ящик; также сохраняет свое содержимое в одной строке. |
| `\makebox[3cm][r]{...}` | Коробка заданной ширины с выбранным выравниванием (l, c, r, s). |
| `\fbox{...}` | Рисует рамку вокруг своего содержимого. |
| `\framebox[3cm][c]{...}` | Коробка в рамке заданной ширины с выбранным выравниванием. |
| `\parbox{5cm}{...}` | Поле абзаца: мини-столбец текста заданной ширины. |
| `\raisebox{2pt}{...}` | Смещает его содержимое вверх (или вниз при отрицательной длине). |
| `\rule{2cm}{0.4pt}` | Рисует заполненный прямоугольник; рабочая лошадка для нестандартных линий. |
| `\colorbox{yellow}{...}` | Помещает текст в поле с цветным фоном (xcolor). |
| `\fcolorbox{red}{yellow}{...}` | Цветная коробка с цветной рамкой (xcolor). |

## Страницы, нумерация и заголовки

| Команда | Что он делает |
| --- | --- |
| `\новая страница` | Завершает текущую страницу и начинает новую. |
| `\clearpage` | Начинает новую страницу после первой очистки всех ожидающих рисунков и таблиц. |
| `\cleardoublepage` | Подобно `\clearpage`, но также гарантирует, что следующая страница будет правой (нечетной) страницей. |
| `\pagebreak` | В этот момент запрашивается разрыв страницы, растягивая страницу на всю высоту. |
| `\nopagebreak` | Препятствует разрыву страницы на этом этапе. |
| `\pagenumbering{roman}` | Устанавливает стиль нумерации страниц (арабский, римский, римский, альфа, альфа), сбрасывая счетчик на 1. |
| `\pagestyle{фантазия}` | Устанавливает текущий стиль верхнего/нижнего колонтитула (обычный, пустой, заголовки, мои заголовки, необычный) для всех последующих страниц. |

## Окружающая среда в целом

Среда — это регион, открывающийся с помощью `\begin{name}` и закрывающийся с помощью `\end{name}`; все, что находится между ними, получает поведение этой среды. Полная история находится в [команды против сред](/learn/commands-environments/). Универсальные:

| Окружающая среда | Что он делает |
| --- | --- |
| `документ` | Тело каждого документа находится между `\begin{document}` и `\end{document}`. |
| `абстрактный` | Печатает аннотацию статьи со стандартным заголовком и макетом класса. |
| `титульный лист` | Обертывает созданную вручную полную титульную страницу; страница не пронумерована. |
| `центр` | Центрирует содержимое по горизонтали. |
| `flushleft` | Содержимое выравнивается по левому краю, по правому — неровное. |
| `флешрайт` | Содержимое выравнивается по правому краю, неровное по левому. |
| `перечислить` | Маркированный список; каждая запись начинается с `\item`. |
| `перечислить` | Нумерованный список; каждая запись начинается с `\item`. |
| `описание` | Маркированный список; записи начинаются с `\item[Label]`. |
| `\предмет` | Начинает одну запись внутри списков перечисления, перечисления или описаний. |
| `цитата` | Блок с отступом для коротких цитат, без отступа абзаца. |
| `цитата` | Блок с отступом для более длинных цитат с отступами абзацев. |
| `стих` | Блок с отступом для стихов, где `\\` завершает каждую строку стиха. |
| `небрежный` | Абзацы набираются с мягким переносом строк, форма окружения — `\sloppy`. |
| `список` | Общий конструктор списков, из которого определяются списки и друзья. |
| `тривлист` | Простой список без меток и полей, используемый внутри определений макросов. |
| `содержимое файла` | Записывает свое тело в файл во время компиляции, например. чтобы отправить .bib внутри .tex. |
| `приложения` | Обертывает главы приложения, включая `\appendixpage` и инструменты для каждого приложения (пакет приложения). |
