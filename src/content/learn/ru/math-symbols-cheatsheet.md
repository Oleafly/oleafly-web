# Настольная карточка с символами

Эта страница представляет собой справочную карту, а не урок. Ударения, большие операторы, наборы чисел и разделители, которые охватывают большую часть повседневной математики, — все в одном месте. Каждая команда здесь работает только в математическом режиме, и для наборов чисел требуется `\usepackage{amssymb}` в преамбуле. Информацию о греческом алфавите и его основных связях см. в разделе [Греческие и повседневные символы](/learn/greek-letters/). Чтобы узнать, как работает сам математический режим, начните с [основы математического режима](/learn/math-mode/).

## Акценты

```latex
\hat{x} \bar{x} \tilde{x} \vec{x} \dot{x} \ddot{x}
\widehat{xyz} \overline{xyz}
```

| Команда | Отображается как | Обычное значение |
| --- | --- | --- |
| `\hat{x}` | х с циркумфлексом | Оценщики, единичные векторы, операторы |
| `\bar{x}` | х с баром | Образцы средства, комплексные конъюгаты |
| `\tilde{x}` | х с тильдой | Аппроксимации, преобразованные переменные |
| `\vec{x}` | х со стрелкой | Векторы |
| `\dot{x}`, `\ddot{x}` | одна или две точки | Первая и вторая производные по времени |
| `\widehat{xyz}`, `\overline{xyz}` | растянутый акцент | Ударения в многобуквенных выражениях |

Простые акценты соответствуют одной букве; варианты «широкий» и «над» растягиваются, охватывая все, что находится в фигурных скобках.

## Крупные операторы

```latex
\sum_{i=1}^n \prod_{i=1}^n \int_a^b \oint
\lim_{x \to 0} \max_{x} \inf_{x}
```

| Команда | Значение |
| --- | --- |
| `\sum_{i=1}^n` | Сумма с нижней и верхней границей |
| `\prod_{i=1}^n` | Продукт |
| `\int_a^b` | Определенный интеграл |
| `\ мазь` | Контурный интеграл |
| `\lim_{x \to 0}` | Лимит |
| `\max_{x}`, `\inf_{x}` | Максимум, нижняя граница по переменной |

Границы прикрепляются с помощью обычного синтаксиса нижнего и верхнего индекса и заключаются в скобки, если длина превышает один символ. В математических вычислениях суммы, произведения и пределы размещают свои границы выше и ниже символа. Интегралы держат свои сбоку. Это стандартное соглашение.

## Наборы чисел

```latex
\mathbb{N} \mathbb{Z} \mathbb{Q} \mathbb{R} \mathbb{C}
```

Это натуральные, целые, рациональные, действительные и комплексные числа, выделенные на доске жирным шрифтом. Алфавит `\mathbb` и его родственники описаны в [Blackboard, script, Fraktur](/learn/mathbb-mathcal/).

## Разделители

```latex
\left( \frac{a}{b} \right)
\left\{ x : x > 0 \right\}
\langle v, w \rangle
```

`\left` и `\right` увеличивают свой разделитель до высоты вложенного материала, поэтому круглые скобки вокруг высокой дроби оборачивают ее, а не обрезают по высоте текста. Они должны приходить парами. Чтобы показать только одну сторону, закройте с помощью `\right.`, и невидимый партнер удовлетворит пару. Фигурные скобки — это специальные символы, поэтому фигурные скобки записываются `\{` и `\}`. Угловые скобки для внутренних продуктов — это `\langle` и `\rangle`, а не знаки "меньше" и "больше", которые являются символами отношений с неправильной формой и интервалом.
