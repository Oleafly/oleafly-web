# 項目符號、編號和定義列表

LaTeX 中的列表是環境：用 `\begin{...}` 打開一個列表，用 `\end{...}` 關閉它，並用 `\item` 標記每個條目。然後，LaTeX 會為您處理編號、項目符號、縮排和間距。最後一部分是重點。您永遠不會手動重新編號任何內容，如果您刪除編號列表的第三個條目，則條目四到十會默默地變成三到九。

## 三個列表環境

```latex
\begin{itemize}
 \item Bullet
\end{itemize}

\begin{enumerate}
 \item Numbered
\end{enumerate}

\begin{description}
 \item[Term] Definition style
\end{description}
```

「itemize」會產生無序的項目符號列表，當條目沒有順序（例如假設列表）時，它是正確的選擇。 「enumerate」會自動對每個條目進行編號，這正是您想要按順序發生的步驟或計劃返回引用的項目的情況。您甚至可以在枚舉中的“\item”後面放置“\label”，並稍後使用“\ref”引用其編號，就像使用節一樣。

「描述」是三者中最不為人所知的，但非常有用。每個“\item”都採用方括號中的可選參數，並且該參數以粗體形式列印為標籤，其後帶有定義文字。它是詞彙表、符號列表或任何「術語：解釋」結構的自然環境。

## 嵌套

多级列表的嵌套环境。將完整的 `\begin{itemize} ... \end{itemize}` 區塊放入外部清單的 `\item` 中，LaTeX 會縮排它並自動切換項目符號。這同樣適用於“enumerate”，其中嵌套會更改每個等級的編號樣式：首先是阿拉伯數字，然後是字母，然後是羅馬數字。 LaTeX 支持四级嵌套，这超出了任何可读文档的需要。如果你发现自己有三层深度，那么材料可能需要散文或表格。

## 自訂標籤

任何單一項目都可以使用可選參數覆寫其自己的標記：`\item[(a)]` 列印「(a)」而不是項目符號或數字。這對於一次性情況很方便，但如果您想要重新設計整個列表，則手動更改每個項目會破壞自動化。為此，請載入 `enumitem` 包，它允許您編寫諸如 `\begin{enumerate}[label=(\alph*)]` 之類的內容，以在一處重新標記整個列表，並且還為您提供收緊垂直間距的選項。

初學者常見的一個錯誤是在「\item」條目之間留一個空行，希望將它們分開。清單中的空行是無害的，但它在視覺上沒有任何作用。間距由清單環境本身或「enumitem」選項控制。另一種情況是：每個清單環境在任何文字之前都必須至少包含一個“\item”，否則您會收到令人困惑的錯誤“有些問題——也許缺少\item”。您可以在[live Playground](/live/) 中嘗試所有三個環境。
