# 演讲、海报和会议本身

接受电子邮件，相机准备就绪，航班已预订。现在是没人教的部分：会议。以下是实际发生的情况，以及如何很好地使用它。

## 谈话

如果您的论文有口头时段，您将进行一次演讲，通常为 10 到 20 分钟，并提出问题。数学是残酷而自由的：你无法展示论文。你可以提出一个想法、一个关键人物和一个阅读这篇论文的理由。

- [ ] 观众应该记住的一句话
- [ ] 大约每分钟一张幻灯片，越少越好
- [ ] 大字体、大数字、最小文本
- [ ] 大声排练至少三遍，一次仅用于计时
- [ ] 准备两个最有可能的问题

用 LaTeX 构建甲板，以便您的符号与论文相匹配：[Beamer basics](/learn/beamer-basics/) 帮助您实现目标。

## 海报展示环节

大多数被接受的论文都以海报的形式出现，而海报会议通常是会议中最好的部分：与那些选择停下来工作的人进行两个小时的直接对话。设计一个在两米外清晰可见的版本，并准备三个版本的宣传：为路过的人提供的 30 秒版本，为感兴趣的人提供的 2 分钟版本，以及为在飞机上阅读您论文的人提供的长版本。有关 LaTeX 方面，请参阅[会议海报](/learn/conference-poster/)。

## 闪电演讲和录音

两种让初次接触者感到惊讶的格式：

- **闪电演讲**：一些场馆为每张海报提供 1 到 2 分钟的预告时段。一张幻灯片，一张声明，“到 42 号海报来找我。”
- **录音**：许多会议需要预先录制演讲视频，在活动前几周上传，并有自己的截止日期。仔细检查演示者说明电子邮件；这个最后期限隐藏在第四段中。

## 网络才是真正的重点

谈话内容都有记录。这些论文都在网上。你以后无法下载的一件事是走廊：会议之间的对话、海报上的问题、与引用与你相同论文的人共进晚餐。其中一些对话变成了合作、博士后邀请和终身同事。

如果网络听起来很可怕，请使用内置的作弊代码：询问人们的工作情况。研究人员喜欢谈论他们的工作，“我看到了你的海报，你是如何处理 X 的？”是一个完整的社会策略。也可以参加稍微超出您所在区域的会谈；这就是新想法的来源。

## 工件和代码发布

期望发生了变化：审稿人和读者越来越期望论文背后的代码、数据或工件能够公开。许多场馆都运行带有徽章的工件评估轨道。实用版：

- [ ] 带有自述文件的公共存储库，说明如何重现主要结果
- [ ] 引脚依赖版本
- [ ] 链接论文和海报中的存储库
- [ ] 明确许可代码

如果您的项目已经存在于具有 GitHub 同步功能的 Git 中（请参阅[与 GitHub 同步](/learn/sync-with-github/)），则发布主要是清理过程，而不是迁移。

## 会后

将最终版本发布到人们可以找到的地方，更新您的网站，并分享一句话要点。然后休息。下一课，[你的第一篇论文，端到端](/learn/first-paper-roadmap/)，将整个管道放在一张地图上。
