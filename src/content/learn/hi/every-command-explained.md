# LaTeX ब्रह्माण्ड में प्रत्येक \कमांड को समझाया गया

यह पृष्ठ प्रत्येक LaTeX कमांड और वातावरण को परिभाषित करता है जो ओलेफ़ली लर्न पर किसी भी पाठ में दिखाई देता है, साथ ही व्यापक मानक शब्दावली जो आपको वास्तविक पेपरों में मिलेगी। कर्नेल, एम्समैथ, हाइपररेफ, ग्राफ़िक्स, बुकटैब्स, बाइबिलटेक्स, टिकज़, बीमर, और पैकेज शोधकर्ता वास्तव में लोड करते हैं। इसे श्रेणी के आधार पर स्किम करें, या आपको अभी मिले आदेश के लिए Ctrl/Cmd-F से पृष्ठ खोजें। प्रत्येक प्रविष्टि एक पंक्ति है: यह क्या करती है और यह कहां मायने रखती है, यह किस पैकेज से आती है।

## दस्तावेज़ कक्षाएं और सेटअप

| आदेश | यह क्या करता है |
| --- | --- |
| `\documentclass{article}` | प्रत्येक दस्तावेज़ की पहली पंक्ति: समग्र लेआउट चुनती है; आलेख कागजात के लिए डिफ़ॉल्ट विकल्प है। |
| `\डॉक्यूमेंटक्लास{रिपोर्ट}` | लंबी रिपोर्ट के लिए कक्षा: `\अध्याय` जोड़ती है और अपने पृष्ठ पर सार प्रारंभ करती है। |
| `\डॉक्यूमेंटक्लास{पुस्तक}` | पुस्तकों के लिए कक्षा: अध्याय, दो-तरफा लेआउट, आगे/मुख्य/पिछला मामला। |
| `\documentclass{letter}` | पत्राचार के लिए कक्षा, `\उद्घाटन`, `\समापन`, और पता आदेशों के साथ। |
| `\डॉक्यूमेंटक्लास{बीमर}` | स्लाइड प्रस्तुतियों के लिए क्लास `फ़्रेम` वातावरण से निर्मित। |
| `\documentclass[11pt,a4paper]{article}` | सामान्य वर्ग विकल्प: फ़ॉन्ट आकार (10pt, 11pt, 12pt), पेपर (a4paper, लेटरपेपर), `twocolumn`, `twoside`, `landscape`, `draft`, `titlepage`। |
| `\usepackage{amsmath}` | सुविधाएँ जोड़ने के लिए प्रस्तावना में एक पैकेज लोड करता है। |
| `\usepackage[margin=1in]{geometry}` | पेज मार्जिन और पेपर आकार (ज्यामिति) सेट करता है। |
| `\शीर्षक{...}` | दस्तावेज़ का शीर्षक संग्रहीत करता है, जिसे बाद में `\maketitle` द्वारा मुद्रित किया जाता है। |
| `\लेखक{...}` | `\maketitle` के लिए लेखक सूची संग्रहीत करता है; एकाधिक लेखकों को `\and` से अलग करें। |
| `\और` | `\author{...}` के अंदर लेखक के नाम के बीच विभाजक। |
| `\दिनांक{...}` | `\maketitle` द्वारा दिखाई गई तारीख को संग्रहीत करता है; `\date{}` इसे छुपाता है, `\date{\today}` आज दिखाता है। |
| `\आज` | संकलन समय पर वर्तमान दिनांक प्रिंट करता है। |
| `\मेकटाइटल` | शीर्षक ब्लॉक को `\title`, `\author`, और `\date` से प्रिंट करता है। |
| `\धन्यवाद{...}` | किसी शीर्षक या लेखक के नाम के साथ एक फ़ुटनोट संलग्न करता है, उदा. फंडिंग या संपर्क जानकारी के लिए। |
| `\संस्थान{...}` | बीमर और स्प्रिंगर एलएनसीएस वर्ग द्वारा उपयोग किया गया लेखक संबद्धता आदेश। |
| `\inst{1}` | एलएनसीएस और बीमर लेखक सूचियों में संबद्धता सुपरस्क्रिप्ट मार्कर: `एडा लवलेस\इंस्ट{1}`। |
| `\कीवर्ड्स{...}` | प्रकाशक में पेपर की कीवर्ड सूची प्रिंट करता हैएसीमार्ट और एलएलएनसीएस जैसी कक्षाएं। |
| `\पता{...}` | पत्र वर्ग: लेटरहेड के लिए प्रेषक का पता संग्रहीत करता है। |
| `\हस्ताक्षर{...}` | अक्षर वर्ग: समापन के अंतर्गत मुद्रित नाम को संग्रहीत करता है। |
| `\उद्घाटन{प्रिय...}` | पत्र वर्ग: अभिवादन प्रिंट करता है और पत्र का मुख्य भाग प्रारंभ करता है। |
| `\समापन{ईमानदारी से,}` | पत्र वर्ग: साइन-ऑफ और हस्ताक्षर ब्लॉक प्रिंट करता है। |
| `\LaTeX` | LaTeX लोगो को उसके उभरे हुए और निचले अक्षरों के साथ प्रिंट करता है। |
| `\TeX` | TeX लोगो को इसके निचले E. के साथ प्रिंट करता है
| `\इनपुट{फ़ाइल}` | उस स्थान पर दूसरी .tex फ़ाइल चिपकाता है, जैसे कि आपने इसे वहां टाइप किया हो। |
| `\शामिल करें{अध्याय1}` | एक नए पृष्ठ पर शुरू होने वाली अध्याय फ़ाइल को इनपुट करता है; `\includeonly` के माध्यम से आंशिक संकलन सक्षम करता है। |
| `\केवलशामिल करें{अध्याय1,अध्याय3}` | प्रस्तावना सूची यह प्रतिबंधित करती है कि कौन सी `\include` फ़ाइलें वास्तव में संकलित हैं। |
| `\हाइपरसेटअप{...}` | लिंक रंग और पीडीएफ मेटाडेटा जैसे हाइपररेफ विकल्प कॉन्फ़िगर करता है। |
| `\AtBeginDocument{...}` | `\begin{document}` के ठीक बाद कोड चलाता है, जो देर से सेटअप के लिए उपयोगी है। |
| `\AtEndDocument{...}` | दस्तावेज़ समाप्त होने से ठीक पहले कोड चलाता है। |
| `\मेकएटलेटर` | अस्थायी रूप से `@` अक्षर बनाता है ताकि आप आंतरिक आदेशों का उपयोग या पैच कर सकें। |
| `\मेकअदर` | `\makeatletter` के बाद `@` को सामान्य पर पुनर्स्थापित करता है। |
| `\टाइपआउट{...}` | डिबगिंग के लिए सुविधाजनक, संकलित लॉग और टर्मिनल पर एक संदेश प्रिंट करता है। |
| `\रक्षा` | `\कैप्शन` या `\सेक्शन` जैसे गतिशील तर्क के अंदर एक नाजुक कमांड को ढाल देता है। |
| `\लिस्टफ़ाइलें` | प्रस्तावना कमांड जो बग रिपोर्ट के लिए प्रत्येक लोड की गई फ़ाइल और उसके संस्करण को लॉग करता है। |

## संरचना और अनुभागीकरण

| आदेश | यह क्या करता है |
| --- | --- |
| `\भाग{...}` | पुस्तक और रिपोर्ट कक्षाओं में उच्चतम स्तर का विभाजन, अध्यायों से ऊपर। |
| `\अध्याय{...}` | पुस्तक और रिपोर्ट कक्षाओं में क्रमांकित अध्याय शीर्षक (लेख में नहीं)। |
| `\अनुभाग{...}` | किसी लेख में क्रमांकित शीर्ष-स्तरीय शीर्षक। |
| `\उपधारा{...}` | शीर्षक को `\अनुभाग` से एक स्तर नीचे क्रमांकित किया गया। |
| `\उपखंड{...}` | शीर्षक को `\उपखंड` से एक स्तर नीचे क्रमांकित किया गया। |
| `\पैराग्राफ{...}` | निम्नतम स्तर का शीर्षक: पैराग्राफ की शुरुआत में एक बोल्ड शीर्षक। |
| `\उपअनुच्छेद{...}` | `\पैराग्राफ` से एक स्तर नीचे, शायद ही कभी इसकी आवश्यकता हो। |
| `\अनुभाग*{...}` | तारांकित सेक्शनिंग बिना संख्या या टीओसी प्रविष्टि के शीर्षक को प्रिंट करता है। |
| `\परिशिष्ट` | क्रमांकन बदलता है जिससे निम्नलिखित अध्याय या अनुभाग परिशिष्ट ए, बी, सी बन जाते हैं
| `\अपेंडिक्सपेज` | एक अलग "परिशिष्ट" विभाजक पृष्ठ (परिशिष्ट पैकेज) प्रिंट करता है। |
| `\tableofcontents` | आपके सेक्शनिंग कमांड से निर्मित सामग्री की तालिका प्रिंट करता है। |
| `\लिस्टऑफिगुर्स` | पेज नंबरों के साथ सभी चित्र शीर्षकों की एक सूची प्रिंट करता है। |
| `\listoftables` | पेज नंबरों के साथ सभी तालिका कैप्शन की एक सूची प्रिंट करता है। |
| `\फ्रंटमैटर` | पूर्व-सामग्री पृष्ठों के लिए पुस्तक-वर्ग स्विच: रोमन पृष्ठ संख्याएँ, अनगिनत अध्याय। |
| `\मुख्य मामला` | पुस्तक-वर्ग मुख्य सामग्री पर वापस जाएँ: अरबी पृष्ठ संख्याएँ, क्रमांकित अध्याय। |
| `\बैकमैटर` | अंतिम पृष्ठों के लिए पुस्तक-श्रेणी स्विच: अध्यायों को क्रमांकित किया जाना बंद हो जाता है। |
| `\addcontentsline{toc}{chapter}{...}` | सामग्री तालिका (या आंकड़ों/तालिकाओं की सूची) में मैन्युअल रूप से एक प्रविष्टि जोड़ता है। |
| `\addtocontents{toc}{...}` | सामग्री फ़ाइल में मनमानी सामग्री (जैसे रिक्ति) लिखता है। |
| `\setcounter{secnumdepth}{3}` | नियंत्रित करता है कि सेक्शनिंग संख्याएँ कितनी गहराई तक जाती हैं। |
| `\setcounter{tocdepth}{2}` | यह नियंत्रित करता है कि विषय-सूची कितनी गहराई तक जाती है। |

## कमांड और वातावरण को परिभाषित करना

| आदेश | यह क्या करता है |
| --- | --- |
| `\newcommand{\R}{\mathbb{R}}` | आपके अपने आदेश को परिभाषित करता है; यदि नाम पहले से मौजूद है तो त्रुटियाँ। |
| `\renewcommand{...}{...}` | मौजूदा कमांड को फिर से परिभाषित करता है; यदि यह मौजूद नहीं है तो त्रुटियाँ। |
| `\providecommand{...}{...}` | किसी कमांड को केवल तभी परिभाषित करता है जब वह पहले से परिभाषित न हो; अन्यथा चुपचाप कुछ नहीं करता. |
| `\NewDocumentCommand` | लचीले वैकल्पिक तर्कों के साथ आधुनिक कमांड परिभाषा (LaTeX3/xparse)। |
| `\नयापर्यावरण{नाम}{आरंभ कोड}{अंत कोड}` | `\begin` और `\end` पर चलने वाले कोड के साथ अपने स्वयं के वातावरण को परिभाषित करता है। |
| `\नवीकरणीय वातावरण{नाम}{...}{...}` | मौजूदा वातावरण को फिर से परिभाषित करता है। |
| `\सुनिश्चित करें{...}` | मैक्रो की गणित सामग्री को गणित मोड के अंदर और बाहर दोनों जगह काम करने योग्य बनाता है। |
| `\DeclareMathOperator{\E}{E}` | एक ईमानदार ऑपरेटर नाम परिभाषित करता है; तारांकित प्रपत्र नीचे सीमाएँ रखता है (अम्समैथ)। |
| `\DeclareMathOperator*{\argmin}{arg\,min}` | तारांकित प्रपत्र: ऑपरेटर प्रदर्शन गणित (एम्समैथ) में नीचे की सीमा लेता है। |
| `\newtheorem{lemma}{Lemma}` | एक प्रमेय जैसा वातावरण (amsthm) घोषित करता है। |
| `\फू` | `\newcommand` पाठ में उपयोगकर्ता द्वारा परिभाषित मैक्रो के लिए उदाहरण नाम, वास्तविक LaTeX कमांड नहीं। |
| `\abs{x}` | कस्टम कमांड पाठ से उपयोगकर्ता-परिभाषित मैक्रो का उदाहरण जो पूर्ण-मूल्य बार टाइप करता है। |
| `\mat{A}` | बोल्ड मैट्रिक्स प्रतीक के लिए कस्टम कमांड पाठ से उपयोगकर्ता द्वारा परिभाषित मैक्रो का उदाहरण। |
| `\vect{v}` | बोल्ड वेक्टर प्रतीक के लिए कस्टम कमांड पाठ से उपयोगकर्ता द्वारा परिभाषित मैक्रो का उदाहरण। |
| `\सेट{...}` | कस्टम कमांड पाठ से उपयोगकर्ता-परिभाषित मैक्रो का उदाहरण जो टाइपसेट आकार सेट ब्रेसिज़। |
| `\साइटपेयर` | कस्टम कमांड पाठ से उदाहरण उपयोगकर्ता-परिभाषित उद्धरण सहायक मैक्रो, मानक कमांड नहीं। |
| `\ई` | अपेक्षा के लिए उदाहरण उपयोगकर्ता-परिभाषित ऑपरेटर, आमतौर पर इसके साथ परिभाषित किया गया है`\DeclareMathOperator` या `\newcommand`। |
| `\R` | वास्तविक के लिए उपयोगकर्ता-परिभाषित मैक्रो का उदाहरण: `\newcommand{\R}{\mathbb{R}}`। |
| `\argmax`, `\argmin` | arg max / arg min के लिए ऑपरेटर नाम, इस पाठ्यक्रम में `\DeclareMathOperator*` के साथ परिभाषित किए गए हैं, इसलिए सबस्क्रिप्ट नीचे हैं। |

## काउंटर और लंबाई

| आदेश | यह क्या करता है |
| --- | --- |
| `\newcounter{उदाहरण}` | एक नया काउंटर बनाता है, वैकल्पिक रूप से माता-पिता द्वारा रीसेट किया जाता है: `\newcounter{examples}[section]`। |
| `\सेटकाउंटर{पेज}{1}` | एक काउंटर का मान सेट करता है, यहां पेज नंबर पुनः प्रारंभ करता है। |
| `\addtocounter{examples}{2}` | कुछ भी प्रिंट किए बिना काउंटर पर एक मान जोड़ता है। |
| `\स्टेपकाउंटर{उदाहरण}` | एक-एक करके काउंटर बढ़ाता है। |
| `\refstepcounter{उदाहरण}` | एक काउंटर बढ़ाता है और इसे अगले `\लेबल` के लिए लक्ष्य बनाता है। |
| `\मूल्य{उदाहरण}` | अंकगणित या तुलना में उपयोग के लिए काउंटर का मान पढ़ता है। |
| `\अरबी{उदाहरण}` | एक काउंटर को अरबी अंकों के रूप में प्रिंट करता है: 1, 2, 3. |
| `\रोमन{उदाहरण}`, `\रोमन{उदाहरण}` | एक काउंटर को लोअरकेस या अपरकेस रोमन अंकों के रूप में प्रिंट करता है। |
| `\अल्फ़ा{उदाहरण}`, `\अल्फ़ा{उदाहरण}` | एक काउंटर को लोअरकेस या अपरकेस अक्षरों के रूप में प्रिंट करता है। |
| `\fnsymbol{फुटनोट}` | एक काउंटर को फ़ुटनोट प्रतीकों के रूप में प्रिंट करता है: तारांकन चिह्न, खंजर, इत्यादि। |
| `\newlength{\mygap}` | एक नया लंबाई रजिस्टर बनाता है। |
| `\setlength{\parskip}{6pt}` | लंबाई रजिस्टर को एक मान निर्दिष्ट करता है। |
| `\addtolength{\textheight}{1cm}` | मौजूदा लंबाई में जोड़ता है. |
| `\settowidth{\mygap}{text}` | कुछ पाठ की प्राकृतिक चौड़ाई पर लंबाई निर्धारित करता है। |
| `\parindent` | पहली पंक्ति के पैराग्राफ इंडेंट की लंबाई; `\setlength{\parindent}{0pt}` के साथ सेट करें। |
| `\पारस्किप` | अनुच्छेदों के बीच ऊर्ध्वाधर अंतराल की लंबाई; `\setlength` के साथ सेट करें। |
| `\लाइनविड्थ` | वर्तमान लाइन की लंबाई, आकार देने के लिए उपयोगी: `width=\linewidth`। |
| `\textwidth` | पृष्ठ पर संपूर्ण टेक्स्ट ब्लॉक की चौड़ाई की लंबाई. |
| `\टेक्सथाइट` | पृष्ठ पर पूर्ण पाठ ब्लॉक की ऊंचाई की लंबाई। |
| `\कॉलमविड्थ` | बहु-स्तंभ लेआउट में एक स्तंभ की चौड़ाई. |
| `\बेसलाइनस्किप` | क्रमागत रेखाओं की आधार रेखाओं के बीच लंबवत दूरी। |
|`\लाइनस्प्रेड{1.3}` | संपूर्ण दस्तावेज़ के लिए अग्रणी (लाइन रिक्ति) को स्केल करता है; प्रभावी होने के लिए `\selectfont` या आकार आदेश की आवश्यकता है। |

## पैराग्राफ, लाइन ब्रेक और हाइफ़नेशन

| आदेश | यह क्या करता है |
| --- | --- |
| `\\` | पैराग्राफ, तालिकाओं और सरणियों के अंदर वर्तमान पंक्ति को समाप्त करता है। |
| `\\[6pt]` | इसके बाद अतिरिक्त ऊर्ध्वाधर स्थान के साथ लाइन ब्रेक। |
| `\न्यूलाइन` | इसे उचित ठहराए बिना और किसी पृष्ठ को तोड़ने की अनुमति दिए बिना पंक्ति को तोड़ देता है। |
| `\लाइनब्रेक` | यहां उचित लाइन ब्रेक का अनुरोध किया गया है; वैकल्पिक `[0-4]` आग्रह सेट करता है। |
| `\नोलाइनब्रेक` | इस बिंदु पर लाइन ब्रेक को हतोत्साहित करता है। |
| `\par` | पैराग्राफ को समाप्त करता है, स्रोत में एक रिक्त पंक्ति के समान। |
| `\noindent` | इसके बाद आने वाले पैराग्राफ की पहली पंक्ति के इंडेंट को दबा देता है। |
| `\इंडेंट` | प्रथम-पंक्ति इंडेंट को बाध्य करता है जहां इसे अन्यथा दबा दिया जाएगा। |
| `\-` | किसी शब्द के अंदर एक अनुमत हाइफ़नेशन बिंदु को चिह्नित करता है। |
| `\हाइफ़नेशन{डेटा-सेट}` | प्रस्तावना सूची LaTeX को सिखाती है कि विशिष्ट शब्दों को कैसे हाइफ़न किया जाए। |
| `\मैला` | रिक्ति नियमों को ढीला करें ताकि लाइनें अधिक आसानी से टूटें, अधिक भरे बक्सों से बचें। |
| `\उधम मचाने वाला` | `\sloppy` के बाद सख्त रिक्ति नियमों को पुनर्स्थापित करता है। |
| `\रैग्डराइट` | निम्नलिखित पाठ को उचित ठहराने के बजाय उसे बाएँ-संरेखित करता है। |
| `\रैग्डलेफ्ट` | निम्नलिखित पाठ को दाएँ-संरेखित करें। |
| `\केन्द्रित` | वर्तमान समूह के अंदर आने वाली हर चीज़ को केन्द्रित करता है, उदाहरण के लिए एक आकृति की छवि. |
| `\समान पृष्ठ` | वर्तमान समूह के भीतर पेज ब्रेक को हतोत्साहित करता है। |
| `\enlargethispage{\baselineskip}` | एक और पंक्ति को निचोड़ने के लिए, केवल वर्तमान पृष्ठ को थोड़ा लंबा बनाता है। |
| `~` | नॉन-ब्रेकिंग स्पेस: `चित्र~1` संख्या को एक ही पंक्ति पर रखता है। |

## रिक्ति

| आदेश | यह क्या करता है |
| --- | --- |
| `\क्वाड` | कैपिटल एम की चौड़ाई के बारे में एक क्षैतिज स्थान सम्मिलित करता है। |
| `\qquad` | `\quad` के स्थान से दोगुना स्थान सम्मिलित करता है। |
| `\enspace` | क्षैतिज स्थान का आधा `\quad` सम्मिलित करता है। |
| `\hspace{1cm}` | क्षैतिज स्थान सम्मिलित करता है; एक लाइन ब्रेक पर गायब हो जाता है। |
| `\hspace*{1cm}` | क्षैतिज स्थान जो लाइन टूटने पर भी जीवित रहता है। |
| `\vspace{1cm}` | दी गई लंबाई का ऊर्ध्वाधर स्थान सम्मिलित करता है। |
| `\vspace*{1cm}` | लंबवत स्थान जो पेज ब्रेक पर भी बना रहता है। |
| `\स्मॉलस्किप` | अनुच्छेदों के बीच एक छोटा ऊर्ध्वाधर अंतर डालता है। |
| `\मेडस्किप` | अनुच्छेदों के बीच एक मध्यम ऊर्ध्वाधर अंतर डालता है। |
| `\बिगस्किप` | अनुच्छेदों के बीच एक बड़ा ऊर्ध्वाधर अंतर डालता है। |
| `\hभरें` | खिंचावयुक्त क्षैतिज स्थान जो लाइन को भरने के लिए सामग्री को अलग-अलग धकेलता है। |
| `\vभरें` | खिंचावदार ऊर्ध्वाधर स्थान जो पृष्ठ को भरने के लिए सामग्री को अलग-अलग धकेलता है। |
| `\dotfill` | शेष पंक्ति को बिंदुओं से भरता है, जैसे मेनू या सामग्री पंक्ति में। |
| `\hrulefill` | शेष पंक्ति को क्षैतिज नियम से भरता है। |
| `\खिंचाव{2}` | आनुपातिक अंतर के लिए वजन के साथ खिंचाव वाला गोंद: `\hspace{\stretch{2}}`। |
| `\भरें` | इकाई खिंचाव लंबाई; `\hspace{\fill}` वह है जिस पर `\hfill` का विस्तार होता है। |
| `\प्रेत{पाठ}` | अपने तर्क का सटीक स्थान लेता है लेकिन कुछ भी प्रिंट नहीं करता है। |
| `\hfantom{text}` | शून्य ऊंचाई के साथ, केवल अपने तर्क की चौड़ाई लेता है। |
| `\vफैंटम{टेक्स्ट}` | शून्य चौड़ाई के साथ, केवल अपने तर्क की ऊंचाई लेता है। |
| `\तोड़{...}` | अपना तर्क छापता है लेकिन दिखावा करता है कि उसकी ऊंचाई और गहराई शून्य है। |
| `\अकड़` | पंक्ति की ऊँचाई को बराबर करने के लिए, अदृश्य सामान्य रेखा की ऊँचाई का समर्थन करता है। |
| `\mathstrut` | रेडिकल और भिन्नों को संरेखित करने के लिए गणित-मोड एक कोष्ठक के आकार को स्ट्रट करता है। |

## बक्से और नियम

| आदेश | यह क्या करता है |
| --- | --- |
| `\एमबॉक्स{...}` | अटूट क्षैतिज बॉक्स; अपनी सामग्री को एक पंक्ति में भी रखता है। |
| `\मेकबॉक्स[3सेमी][आर]{...}` | चुने गए संरेखण (एल, सी, आर, एस) के साथ एक निर्धारित चौड़ाई का बॉक्स। |
| `\fbox{...}` | इसकी सामग्री के चारों ओर एक फ्रेम खींचता है। |
| `\framebox[3cm][c]{...}` | चयनित संरेखण के साथ निर्धारित चौड़ाई का फ़्रेमयुक्त बॉक्स। |
| `\parbox{5cm}{...}` | एक पैराग्राफ़ बॉक्स: दी गई चौड़ाई के पाठ का एक छोटा स्तंभ। |
| `\raisebox{2pt}{...}` | इसकी सामग्री को नकारात्मक लंबाई के साथ ऊपर (या नीचे) स्थानांतरित करता है। |
| `\rule{2cm}{0.4pt}` | एक भरा हुआ आयत बनाता है; कस्टम लाइनों के लिए वर्कहॉर्स। |
| `\रंगबॉक्स{पीला}{...}` | टेक्स्ट को रंगीन पृष्ठभूमि बॉक्स (xcolor) पर रखता है। |
| `\fcolorbox{red}{yellow}{...}` | रंगीन फ्रेम (xcolor) के साथ रंगीन बॉक्स। |

## पेज, नंबरिंग और हेडर

| आदेश | यह क्या करता है |
| --- | --- |
| `\न्यूपेज` | वर्तमान पृष्ठ को समाप्त करता है और एक नया प्रारंभ करता है। |
| `\क्लियरपेज` | पहले सभी लंबित आंकड़ों और तालिकाओं को फ्लश करने के बाद एक नया पेज शुरू होता है। |
| `\cleardoublepage` | `\clearpage` की तरह, लेकिन यह भी सुनिश्चित करता है कि अगला पृष्ठ दाहिनी ओर (विषम) पृष्ठ है। |
| `\पेजब्रेक` | इस बिंदु पर पेज ब्रेक का अनुरोध करता है, पेज को पूरी ऊंचाई तक खींचता है। |
| `\नोपेजब्रेक` | इस बिंदु पर पेज ब्रेक को हतोत्साहित करता है। |
| `\पेजनंबरिंग{रोमन}` | पृष्ठ संख्या शैली (अरबी, रोमन, रोमन, अल्फा, अल्फा) सेट करता है, काउंटर को 1 पर रीसेट करता है।
| `\पेजस्टाइल{फैंसी}` | निम्नलिखित सभी पेजों के लिए चालू हेडर/फुटर स्टाइल (सादा, खाली, हेडिंग, मायहेडिंग, फैंसी) सेट करता है। |
| `\यहपेजस्टाइल{खाली}` | केवल वर्तमान पृष्ठ के लिए शीर्ष लेख/पाद लेख शैली को ओवरराइड करता है। |
| `\thepage` | वर्तमान पृष्ठ संख्या प्रिंट करता है; हेडर और फ़ुटर के अंदर उपयोग किया जाता है। |
| `\मार्जिनपार{...}` | वर्तमान पंक्ति के बगल में पृष्ठ मार्जिन में एक नोट डालता है। |
| `\fancyhf{}` | अपना स्वयं का सेट करने से पहले सभी फैंसीएचडीआर हेडर और फुटर फ़ील्ड को साफ़ करता है। |
| `\फैंसीहेड[आर]{...}` | एक फैंसीएचडीआर हेडर फ़ील्ड सेट करता है, यहां दाहिनी ओर। |
| `\fancyfoot[C]{\thepage}` | एक फैंसीएचडीआर फ़ूटर फ़ील्ड सेट करता है, यहां एक केंद्रित पृष्ठ संख्या है। |
| `\हेडरूलविड्थ` | हेडर नियम मोटाई के लिए फैंसीएचडीआर मैक्रो; लाइन को हटाने के लिए 0pt पर नवीनीकृत करें। |
| `\फुटरूलेविड्थ` | फ़ुटर नियम मोटाई के लिए फैंसीएचडीआर मैक्रो, डिफ़ॉल्ट रूप से 0pt। |
| `\newgeometry{margin=2cm}` | पृष्ठ ज्यामिति को दस्तावेज़ के मध्य में बदलता है (ज्यामिति)। |
| `\रिस्टोरजियोमेट्री` | `\newgeometry` (ज्यामिति) के बाद प्रस्तावना ज्यामिति पर लौटता है। |

## विशेष पात्र

दस आरक्षित अक्षर और उन्हें कैसे मुद्रित करें, साथ ही सामान्य पाठ प्रतीक।

| आदेश | यह क्या करता है |
| --- | --- |
| `\%` | एक प्रतिशत चिह्न प्रिंट करता है (नंगे `%` से एक टिप्पणी शुरू होती है)। |
| `\&` | एक एम्परसेंड प्रिंट करता है (नंगे `&` तालिका स्तंभ विभाजक है)। |
| `\#` | एक हैश प्रिंट करता है (नंगे `#` मैक्रो तर्कों को चिह्नित करता है)। |
| `\_` | एक अंडरस्कोर प्रिंट करता है (नंगे `_` एक गणित सबस्क्रिप्ट है)। |
| `\{` और `\}` | घुंघराले ब्रेसिज़ (नंगे ब्रेसिज़ समूह) प्रिंट करें। |
| `\$` | एक डॉलर चिह्न प्रिंट करता है (नंगे `$` गणित मोड को टॉगल करता है)। |
| `\textbackslash` | टेक्स्ट में बैकस्लैश प्रिंट करता है। |
| `\textasciitilde` | टेक्स्ट में एक टिल्ड प्रिंट करता है (निष्पक्ष `~` एक नॉन-ब्रेकिंग स्पेस है)। |
| `\textasciicircum` | पाठ में एक कैरेट प्रिंट करता है (केवल `^` एक गणित सुपरस्क्रिप्ट है)। |
| `\टेक्स्टबार` | टेक्स्ट में एक वर्टिकल बार प्रिंट करता है। |

| `\ldots`, `\dots` | सही रिक्ति के साथ इलिप्सिस; `\dots` गणित मोड (amsmath) में अनुकूलित होता है। |
| `\टेक्स्टेलिप्सिस` | टेक्स्ट-मोड इलिप्सिस जो `\dots` गणित के बाहर उपयोग करता है। |

| `\dag`, `\ddag` | पाठ में डैगर और डबल डैगर, लेखक संबद्धता के लिए सामान्य। |

| `\P` | अनुच्छेद (पिलक्रो) चिह्न. |
| `\पाउंड` | ब्रिटिश पाउंड चिह्न. |
| `\यूरो` | यूरो चिह्न (यूरोसिम पैकेज; कर्नेल `\texteuro` भी प्रदान करता है)। |
| `\कॉपीराइट` | कॉपीराइट चिह्न. |
| `\textregistered` | पंजीकृत ट्रेडमार्क चिह्न. |
| `\texttrademark` | ट्रेडमार्क चिह्न. |
| `\टेक्स्टडिग्री` | डिग्री चिह्न: `25\textडिग्री C`। |
| `\textmu` | सीधा सूक्ष्ममाइक्रोन जैसे पाठ के लिए साइन इन करें। |

| `\textsf{...}` | सैन्स-सेरिफ़ पारिवारिक पाठ। |
| `\textmd{...}` | मध्यम (सामान्य) वजन, पूर्ववत बोल्ड। |

| `\फ़ुटनोटसाइज़` | फ़ुटनोट के लिए उपयोग किया जाने वाला आकार. |

| `\सामान्यआकार` | दस्तावेज़ का आधार आकार. |

सही रिक्ति के साथ सभी टाइपसेट सीधे; सीमा लेने वाले लोग प्रदर्शन गणित में नीचे सबस्क्रिप्ट डालते हैं।

| आदेश | यह क्या करता है |
| --- | --- |
| `\sin`, `\cos`, `\tan`, `\cot` | बुनियादी त्रिकोणमितीय कार्य. |
| `\sec`, `\csc` | सेकेंट और कोसेकेंट। |
| `\arcsin`, `\arccos`, `\arctan` | व्युत्क्रम त्रिकोणमितीय फलन. |

| `\exp`, `\ln`, `\log`, `\lg` | घातांक और लघुगणक (`\lg` परिपाटी के अनुसार लघुगणक आधार 2 या 10 है)। |
| `\det`, `\dim`, `\ker`, `\deg` | निर्धारक, आयाम, कर्नेल, डिग्री। |

| `\lim_{x \to 0}` | सीमा ऑपरेटर, प्रदर्शन गणित में नीचे दी गई सबस्क्रिप्ट के साथ सीधा। |
| `\limsup`, `\liminf` | श्रेष्ठ और निम्न को सीमित करें. |
| `\inf`, `\sup` | इन्फ़िमम और सुप्रीम ऑपरेटर, सीधे टाइपसेट। |
| `\मिनट`, `\अधिकतम` | न्यूनतम और अधिकतम ऑपरेटर, प्रदर्शन गणित में नीचे की सीमा के साथ सीधे टाइपसेट। |
| `\bmod` | ऑपरेटर रिक्ति के साथ बाइनरी मॉड ऑपरेटर: `a \bmod n`। |
| `\pmod{n}` | कोष्ठक में अनुगामी '(mod n)'। |
| `\mod{n}` | कोष्ठक के बिना 'मॉड एन' का अनुगमन (एम्समैथ)। |
| `\ऑपरेटरनाम{एलसीएम}` | प्रस्तावना घोषणा (एम्समैथ) के बिना एकबारगी ईमानदार ऑपरेटर का नाम। |
| `\ऑपरेटरनाम*{ess\,sup}` | एकबारगी ऑपरेटर जो सीमा से नीचे (एम्समैथ) लेता है। |

## गणित: भिन्न, द्विपद और स्टैकिंग

| आदेश | यह क्या करता है |
| --- | --- |
| `\frac{a}{b}` | स्टैक्ड भिन्न: हर के ऊपर अंश। |
| `\dfrac{a}{b}` | अंश को पूर्ण प्रदर्शन आकार के लिए मजबूर किया गया, यहां तक ​​कि इनलाइन (एम्समैथ) भी। |
| `\tfrac{a}{b}` | प्रदर्शन गणित (एम्समैथ) में भी, अंश को छोटे इनलाइन आकार के लिए मजबूर किया गया। |
| `\cfrac{a}{b}` | पूर्ण आकार के नेस्टेड स्तरों (एम्समैथ) के साथ निरंतर अंश। |
| `\sqrt{x}`, `\sqrt[3]{x}` | वर्गमूल; वैकल्पिक तर्क nवाँ मूल देता है। |
| `\binom{n}{k}` | कोष्ठकों में द्विपद गुणांक (अम्समैथ)। |
| `\dbinom{n}{k}`, `\tbinom{n}{k}` | प्रदर्शन-आकार और पाठ-आकार मजबूर द्विपद (एम्समैथ)। |
| `{n \choose k}` | सादा TeX द्विपद आदिम; LaTeX में हतोत्साहित, `\binom` का उपयोग करें। |
| `{a \over b}` | सादा TeX अंश आदिम; LaTeX में हतोत्साहित, `\frac` का प्रयोग करें। |
| `{a \atop b}` | बिना किसी पट्टी के सादा TeX स्टैकिंग आदिम; हतोत्साहित, `\substack` या `\genfrac` का उपयोग करें। |
| `\genfrac{(}{)}{0pt}{}{a}{b}` | `\frac`, `\binom`, और दोस्तों (amsmath) के पीछे सामान्य भिन्न निर्माता। |
| `\substack{i < n \\ j < m}` | एक बड़े ऑपरेटर (एम्समैथ) के तहत मल्टी-लाइन सबस्क्रिप्ट। |
| `\sideset{_a^b}{_c^d}{\prod}` | एक बड़े ऑपरेटर (एम्समैथ) के चारों कोनों पर सूचकांक जोड़ता है। |
| `\prescript{a}{b}{X}` | बाएं हाथ के सुपर/सबस्क्रिप्ट, जैसा कि आइसोटोप नोटेशन (मैथटूल्स) में होता है। |

## एम्समैथ और मैथटूल्स डिस्प्ले टूल्स

| आदेश | यह क्या करता है |
| --- | --- |
| `\टैग{...}` | स्वचालित समीकरण संख्या को आपके स्वयं के लेबल (एम्समैथ) से बदल देता है। |
| `\टैग*{...}` | जैसे `\tag` लेकिन आसपास के कोष्ठकों के बिना (एम्समैथ)। |
| `\नोटैग` | क्रमांकित वातावरण (एम्समैथ) की एक पंक्ति पर समीकरण संख्या को दबा देता है। |
| `\नॉनंबर` | `\notag` का पुराना पर्यायवाची. |
| `\numberwithin{eqation}{section}` | प्रति अनुभाग संख्या समीकरण: (2.1), (2.2) (अस्मथ)। |
| `\इंटरटेक्स्ट{...}` | संरेखण (एम्समैथ) रखते हुए, पाठ की पूर्ण-चौड़ाई वाली पंक्ति के साथ एक संरेखण ब्लॉक को बाधित करता है। |
| `\shortintertext{...}` | जैसे कम ऊर्ध्वाधर स्थान (गणित उपकरण) के साथ `\intertext`। |
| `\allowdisplaybreaks` | मल्टी-लाइन डिस्प्ले को पेजों में विभाजित होने दें (एम्समैथ)। |
| `\डिस्प्लेब्रेक` | डिस्प्ले के इस बिंदु पर पेज ब्रेक का अनुरोध करता है (एम्समैथ)। |
| `\smashoperator{\sum_{i=1}^{n}}` | विस्तृत ऑपरेटर सीमाओं को अधिक होने देता है ताकि वे सामग्री को अलग न करें (मैथटूल्स)। |
| `\मैथक्लैप{...}` | वाइड अंडर/ओवरस्क्रिप्ट (मैथटूल्स) के लिए शून्य-चौड़ाई वाली गणित सामग्री। |
| `\coloneqq` | कोलन-बराबर परिभाषा चिह्न := सही रिक्ति के साथ (मैथटूल)। |
| `\DeclarePairedDelimiter{\abs}{\lvert}{\rvert}` | एक तारांकित ऑटो-साइज़िंग फॉर्म (मैथटूल्स) के साथ एक सीमांकक मैक्रो को परिभाषित करता है। |
| `\eqref{eq:नुकसान}` | एक समीकरण संख्या को उसके कोष्ठकों (एम्समैथ) के साथ प्रिंट करता है। |
| `\qयहाँ` | एंड-ऑफ़-प्रूफ़ वर्ग को वर्तमान लाइन पर ले जाता है, उदा. प्रदर्शित समीकरण (amsthm) के बाद। |

| पर्यावरण | यह क्या करता है |

| `मल्टीलाइन` | पंक्तियों में टूटा हुआ एक लंबा समीकरण: पहली पंक्ति बाईं ओर, अंतिम पंक्ति दाईं ओर (अम्समैथ)। |
| `संरेखित`, `एकत्रित` | किसी अन्य डिस्प्ले (एम्समैथ) के अंदर प्रयोग करने योग्य एलाइन/गैदर के बिल्डिंग-ब्लॉक संस्करण। |
| `उपसमीकरण` | अंदर के समीकरणों को 1a, 1b, 1c (amsmath) के रूप में क्रमांकित करें। |
| 'मामले' | ब्रेस-समूहित केस भेद, जैसा कि टुकड़े-टुकड़े कार्यों (एम्समैथ) में होता है। |
| `डीकेस` | डिस्प्ले-स्टाइल प्रविष्टियों के साथ `केस` ताकि अंश पूर्ण आकार में रहें (मैथटूल)। |

| `बीमैट्रिक्स` | मैट्रिक्स को वर्गाकार कोष्ठकों (अम्समैथ) में लपेटा गया है। |
| 'बीमैट्रिक्स' | घुंघराले ब्रेसिज़ (एम्समैथ) में लिपटा हुआ मैट्रिक्स। |
| `वीमैट्रिक्स` | ऊर्ध्वाधर पट्टियों में लिपटा मैट्रिक्स, मानक निर्धारक संकेतन (एम्समैथ)। |
| 'वीमैट्रिक्स' | मैट्रिक्स को डबल बार (एम्समैथ) में लपेटा गया है। |

| `\पेजरेफ{अंजीर:सेटअप}` | वह पेज नंबर प्रिंट करता है जहां लेबल रहता है। |
| `\cref{अंजीर:सेटअप}` | संख्या और उसके प्रकार का नाम स्वचालित रूप से प्रिंट करता है: 'अंजीर। 1' (चतुराई)। |
| `\Cref{अंजीर:सेटअप}` | एक वाक्य की शुरुआत के लिए बड़े अक्षरों में `\cref` लिखा गया है: 'चित्रा 1' (चतुराई)। |
| `\crefrange{eq:a}{eq:d}` | एक श्रेणी प्रिंट करता है: 'eqs. 1 से 4' (चतुराई)। |
| `\labelcref{अंजीर:सेटअप}` | टाइप नाम (क्लेवरेफ) के बिना, केवल लेबल नंबर को क्लेवरफ शैली में प्रिंट करता है। |
| `\vref{अंजीर:सेटअप}` | आवश्यकता पड़ने पर संदर्भ प्लस एक स्वचालित 'अगले पृष्ठ पर' वाक्यांश (वैरियोरेफ)। |
| `\autoref{अंजीर:सेटअप}` | हाइपररेफ का टाइप किया गया संदर्भ: 'चित्र 1', जिसमें पूरा वाक्यांश जुड़ा हुआ है। |
| `\nameref{sec:intro}` | संदर्भित अनुभाग (हाइपररेफ़) का शीर्षक पाठ प्रिंट करता है। |
| `\href{https://example.com}{link text}` | कस्टम टेक्स्ट (हाइपररेफ) के साथ एक क्लिक करने योग्य लिंक बनाता है। |
| `\url{https://example.com}` | टाइपराइटर प्रकार में एक यूआरएल टाइप करता है और इसे क्लिक करने योग्य बनाता है। |
| `\hyperref[sec:intro]{वह अनुभाग}` | किसी लेबल (हाइपररेफ़) के लिए मनमाना टेक्स्ट लिंक बनाता है। |
| `\हाइपरटार्गेट{स्पॉट}{...}` | दस्तावेज़ में कहीं भी एक नामित लिंक लक्ष्य बनाता है (हाइपररेफ)। |
| `\हाइपरलिंक{स्पॉट}{टेक्स्ट}` | `\हाइपरटार्गेट` (हाइपररेफ) से लिंक। |
| `\फैंटमसेक्शन` | एक एंकर बनाता है ताकि अनगिनत शीर्षकों से लिंक सही जगह पर आ जाएं (हाइपररेफ)। |
| `\texorpdfstring{$\alpha$}{alpha}` | शीर्षकों में गणित के लिए एक सादा-पाठ विकल्प देता है ताकि पीडीएफ बुकमार्क वैध रहें (हाइपररेफ)। |
| `\pdfbookmark[1]{शीर्षक}{नाम}` | एक मैन्युअल पीडीएफ बुकमार्क प्रविष्टि (हाइपररेफ) जोड़ता है। |

## उद्धरण और ग्रंथ सूची

| आदेश | यह क्या करता है |
| --- | --- |
| `\उद्धरण{knuth1984}` | कुंजी द्वारा ग्रंथ सूची प्रविष्टि का हवाला देता है। |
| `\nocite{key}` | पाठ में उद्धृत किए बिना ग्रंथ सूची में एक प्रविष्टि जोड़ता है; `\nocite{*}` सब कुछ जोड़ता है। |
| `\citep{knuth1984}` | नटबिब लेखक-वर्ष शैली में कोष्ठक उद्धरण '(नुथ, 1984)'। |
| `\citet{knuth1984}` | नैटबिब लेखक-वर्ष शैली में पाठ्य उद्धरण 'नुथ (1984)'। |
| `\citeauthor{knuth1984}` | केवल लेखक के नाम (नैटबिब और बाइबिलटेक्स) प्रिंट करता है। |
| `\citeyear{knuth1984}` | केवल वर्ष प्रिंट करता है (नैटबिब और बाइबिलटेक्स)। |
| `\citealp{knuth1984}` | अपना खुद का निर्माण करने के लिए, कोष्ठक के बिना नटबिब कोष्ठक उद्धरण। |
| `\citealt{knuth1984}` | वर्ष भर कोष्ठक के बिना नटबीब पाठ्य उद्धरण। |
| `\parencite{knuth1984}` | बाइबिलटेक्स का मूल उद्धरण, `\citep` का एनालॉग। |
| `\textcite{knuth1984}` | बाइबिलटेक्स का पाठ्य उद्धरण, `\citet` का एनालॉग। |
| `\ऑटोसाइट{knuth1984}` | बाइबिलटेक्स उद्धरण जो शैली के पसंदीदा रूप (कोष्ठक, फ़ुटनोट, आदि) का अनुसरण करता है। |
| `\फ़ुटसाइट{knuth1984}` | बाइबिलटेक्स उद्धरण एक फुटनोट में रखा गया है। |
| `\fullcite{knuth1984}` | प्रविष्टि की पूर्ण ग्रंथसूची पाठ इनलाइन (biblatex) प्रिंट करता है। |
| `\citetitle{knuth1984}` | कार्य का शीर्षक (biblatex) प्रिंट करता है। |
| `\ग्रंथ सूची{रेफ्स}` | BibTeX: .bib फ़ाइल से संदर्भ सूची प्रिंट करता है। |
| `\ग्रंथ सूचीशैली{plainnat}` | BibTeX: संदर्भ प्रारूप चुनता है; क्लासिक शैलियों में सादा, अनसर्ट, अल्फा, एबीबीआरवी, आईईईईटीआर, एसीएम, एपलाइक शामिल हैं। |
| `\addbibresource{refs.bib}` | biblatex: प्रस्तावना में एक .bib फ़ाइल पंजीकृत करता है। |
| `\प्रिंटग्रंथ सूची` | biblatex: संदर्भ सूची को वहीं प्रिंट करता है जहां आप इसे रखते हैं। |
| `\bibitem{key}` | `ग्रंथसूची` परिवेश के अंदर एक हस्तलिखित प्रविष्टि। |
| `ग्रंथ सूची` (पर्यावरण) | हस्तलिखितजब आप BibTeX को पूरी तरह से छोड़ देते हैं तो संदर्भ सूची का उपयोग किया जाता है। |

## फ़्लोट्स, आंकड़े और टेबल

| आदेश या वातावरण | यह क्या करता है |
| --- | --- |
| 'आकृति' (पर्यावरण) | छवि प्लस कैप्शन के लिए फ़्लोटिंग कंटेनर; LaTeX अंतिम स्थान चुनता है। |
| `आकृति*` (पर्यावरण) | दो-स्तंभ दस्तावेज़ में दोनों स्तंभों को फैला हुआ चित्र। |
| `टेबल` (पर्यावरण) | सारणीबद्ध प्लस कैप्शन के लिए फ़्लोटिंग कंटेनर; LaTeX अंतिम स्थान चुनता है। |
| `टेबल*` (पर्यावरण) | दो-स्तंभ दस्तावेज़ में दोनों स्तंभों तक फैली तालिका। |
| `\begin{आंकड़ा}[htbp]` | प्लेसमेंट संकेत: यहां, ऊपर, नीचे, अपना पेज; `!` नियमों में ढील देता है, `[H]` (फ्लोट पैकेज) का मतलब बिल्कुल यहीं है। |
| `सारणीबद्ध` (पर्यावरण) | पंक्तियों और स्तंभों की वास्तविक ग्रिड: कोशिकाएँ `&` से विभाजित होती हैं, पंक्तियाँ `\\` से समाप्त होती हैं। |
| `सारणीबद्ध*` (पर्यावरण) | सारणीबद्ध एक निर्दिष्ट कुल चौड़ाई तक फैला हुआ। |
| `tabularx` (पर्यावरण) | निश्चित-चौड़ाई वाली तालिका जिसके `X` कॉलम बचे हुए स्थान (सारणी) को साझा करते हैं। |
| `सरणी` (पर्यावरण) | प्रति-कॉलम संरेखण के साथ गणित-मोड ग्रिड। |
| `लॉन्गटेबल` (पर्यावरण) | तालिका जो दोहराए जाने वाले शीर्षलेखों (लंबी तालिका) के साथ पृष्ठों में विभाजित हो सकती है। |
| `मिनीपेज` (पर्यावरण) | पेज के अंदर निश्चित-चौड़ाई वाला मिनी पेज, सामग्री को एक साथ रखने के लिए उपयोग किया जाता है। |
| `सबफिगर` (पर्यावरण) | एक उप-पैनल अपने स्वयं के कैप्शन के साथ, जैसे (ए) और (बी), एक आकृति (सबकैप्शन) के अंदर। |
| `रैपफिगर` (पर्यावरण) | चित्र जिसके चारों ओर मुख्य पाठ लपेटा हुआ है (रैपफिग)। |
| `साइडवेज़फिगर`, `साइडवेज़टेबल` (वातावरण) | फ़्लोट अपने पृष्ठ पर 90 डिग्री तक घूमते हैं (घूमते हुए)। |
| 'परिदृश्य' (पर्यावरण) | पीडीएफ पेज ऑटो-रोटेटेड (पीडीएफएलस्केप) के साथ, पूरे पेज को लैंडस्केप में घुमाता है। |
| `थ्रीपार्टटेबल` (पर्यावरण) | एक तालिका को लपेटता है ताकि फ़ुटनोट तालिका की चौड़ाई (थ्रीपार्टटेबल) के साथ संरेखित हो जाएं। |
| `टेबलनोट्स` (पर्यावरण) | तीन भागों वाली तालिका के अंतर्गत नोट्स की सूची, `\tnote{a}` से चिह्नित। |
| `एडजस्टबॉक्स` (पर्यावरणऔर `\एडजस्टबॉक्स`) | कुंजी-मूल्य विकल्प (एडजस्टबॉक्स) के साथ किसी भी सामग्री को मापें, आकार बदलें या क्रॉप करें। |
| `\कैप्शन{...}` | किसी आकृति या तालिका में क्रमांकित कैप्शन जोड़ता है; इसके बाद `\label` लगाएं। |
| `\कैप्शन*{...}` | किसी संख्या या सूची प्रविष्टि के बिना कैप्शन (कैप्शन पैकेज)। |
| `\कैप्शनसेटअप{...}` | कैप्शन फ़ॉन्ट, लेबल और रिक्ति (कैप्शन पैकेज) कॉन्फ़िगर करता है। |
| `\toprule` | बुकटैब टेबल के शीर्ष पर भारी नियम। |
| `\मध्यनियम` | बुकटैब टेबल के हेडर और बॉडी के बीच मध्यम नियम। |
| `\बॉटमरूल` | बुकटैब टेबल के नीचे भारी नियम। |
| `\cmidrule(lr){2-3}` | चयनित कॉलम (बुकटैब) तक फैला आंशिक नियम। |
| `\एडलाइनस्पेस` | नियम के बजाय, बुकटैब पंक्तियों के बीच छोटा अतिरिक्त लंबवत स्थान। |
| `\hline` | एक सादे सारणी में पूर्ण-चौड़ाई वाली क्षैतिज रेखा; बुकटैब नियम आमतौर पर बेहतर दिखते हैं। |
| `\क्लाइन{2-3}` | एक सादे सारणी में चयनित स्तंभों तक फैली क्षैतिज रेखा। |
| `\vline` | तालिका पंक्ति के इस बिंदु पर लंबवत रेखा; कॉलम `|` विनिर्देशक सामान्य तरीके हैं। |
| `\multicolumn{2}{c}{Header}` | सभी स्तंभों की कोशिकाओं को एक पंक्ति में मर्ज करता है। |
| `\मल्टीरो{2}{*}{लेबल}` | पंक्तियों (मल्टीरो) में कोशिकाओं को लंबवत रूप से मर्ज करता है। |
| `\अरेस्ट्रेच` | तालिका पंक्ति की ऊंचाई के लिए कारक; `\renewcommand{\arraystretch}{1.3}` के साथ सेट करें। |
| `\tabcolsep` | सारणीबद्ध स्तंभ के प्रत्येक तरफ पैडिंग की लंबाई। |
| `\newcolumntype{C}{>{\centering\arraybackslash}X}` | एक पुन: प्रयोज्य कॉलम विनिर्देशक (सरणी पैकेज) को परिभाषित करता है। |
| `\endfirsthead` | लॉन्गटेबल: केवल पहले पृष्ठ पर दिखाए गए हेडर के अंत को चिह्नित करता है। |
| `\एंडहेड` | लॉन्गटेबल: प्रत्येक अगले पृष्ठ पर दोहराए गए हेडर के अंत को चिह्नित करता है। |
| `\endfoot` | लॉन्गटेबल: प्रत्येक पृष्ठ विराम पर दिखाए गए पाद लेख के अंत को चिह्नित करता है। |
| `\endlastfoot` | लॉन्गटेबल: केवल अंत में दिखाए गए पाद लेख के अंत को चिह्नित करता है। |
|`\फ्लोटबैरियर` | इस बिंदु (प्लेसिन्स) से आगे बहती हुई तैरती नावों को रोकता है। |

## फ़ुटनोट

| आदेश | यह क्या करता है |
| --- | --- |
| `\फ़ुटनोट{...}` | पृष्ठ के नीचे एक नोट डालता है, जिस पर एक स्वचालित संख्या अंकित होती है। |
| `\फ़ुटनोटमार्क` | केवल फ़ुटनोट मार्कर प्रिंट करता है, उन स्थानों के लिए जहां `\फ़ुटनोट` की अनुमति नहीं है। |
| `\फुटनोटटेक्स्ट{...}` | पहले वाले `\फ़ुटनोटमार्क` के लिए पाठ प्रदान करता है। |

## प्रमेय और प्रमाण

| आदेश या वातावरण | यह क्या करता है |
| --- | --- |
| `\newtheorem{lemma}{Lemma}` | एक प्रमेय जैसा वातावरण (amsthm) घोषित करता है। |
| `\नयाप्रमेय*{टिप्पणी}{टिप्पणी}` | एक अनगिनत प्रमेय जैसा वातावरण (amsthm) घोषित करता है। |
| `\प्रमेयशैली{परिभाषा}` | निम्नलिखित `\newtheorem` घोषणाओं (amsthm) के लिए लुक (सादा, परिभाषा, टिप्पणी) सेट करता है। |
| `प्रमेय` (पर्यावरण) | क्रमांकित प्रमेय ब्लॉक, `\newtheorem{theorem}{Theorem}` द्वारा बनाया गया। |

| `शब्दशः` (पर्यावरण) | टाइपराइटर फ़ॉन्ट में बिल्कुल टाइप किए गए टेक्स्ट का ब्लॉक। |
| `\verbatiminput{file.txt}` | पूरी फ़ाइल शब्दशः (शब्दशः पैकेज) प्रिंट करता है। |
| `lstlisting` (पर्यावरण) | वैकल्पिक सिंटैक्स हाइलाइटिंग (लिस्टिंग) के साथ स्रोत कोड लिस्टिंग। |
| `\lstinline|code|` | लिस्टिंग शैली (लिस्टिंग) में इनलाइन कोड स्निपेट। |
| `\lstset{भाषा=पायथन}` | लिस्टिंग डिफ़ॉल्ट को कॉन्फ़िगर करता है: भाषा, क्रमांकन, रंग (लिस्टिंग)। |
| `\lstinputlisting{script.py}` | संपूर्ण स्रोत फ़ाइल को एक सूची (लिस्टिंग) के रूप में टाइप करता है। |
| `ढाला` (पर्यावरण) | पिगमेंट-संचालित हाइलाइट किए गए कोड ब्लॉक; संकलन समय पर `-शेल-एस्केप` की आवश्यकता है (ढाला)। |
| `\mintinline{पायथन}|कोड|` | इनलाइन हाइलाइट किया गया कोड (ढाला हुआ)। |

## बीमर (स्लाइड्स)

| आदेश या वातावरण | यह क्या करता है |
| --- | --- |
| `फ़्रेम` (पर्यावरण) | एक बीमर स्लाइड: `\begin{frame}{Slide title} ... \end{frame}`। |
| `\फ़्रेम{...}` | बीमर का एक-कमांड स्लाइड फॉर्म; `फ़्रेम' वातावरण सामान्य तरीका है। |
| `\frametitle{...}` | फ़्रेम के अंदर से स्लाइड शीर्षक सेट करता है। |
| `\framesubtitle{...}` | फ़्रेम शीर्षक के अंतर्गत एक छोटा उपशीर्षक सेट करता है। |
| `\शीर्षकपृष्ठ` | बीमर: एक फ्रेम के अंदर, आपके शीर्षक मेटाडेटा से शीर्षक स्लाइड को प्रिंट करता है। |
| `\tableofcontents[currentsection]` | जिस अनुभाग में आप हैं उसे उजागर करने वाली रूपरेखा स्लाइड |
| `\विराम` | बीमर: अगले स्लाइड चरण पर शेष फ़्रेम को प्रकट करता है। |
| `\ऑनस्लाइड<2->` | सामग्री किसी दिए गए ओवरले चरण से आगे दिखाई देती है। |
| `\only<2>{...}` | सामग्री केवल दिए गए चरणों पर मौजूद है और अन्यत्र कोई स्थान नहीं लेती है। |
| `\उजागर<2->{...}` | सामग्री अपने चरण से पहले अदृश्य होती है लेकिन हमेशा अपना स्थान सुरक्षित रखती है। |
| `\visible<2->{...}`, `\invisible<2>{...}` | लेआउट बदले बिना दिए गए चरणों पर सामग्री दिखाएं या छिपाएँ। |
| `\अलर्ट{...}` | थीम के अलर्ट रंग में टेक्स्ट को हाइलाइट करें, आमतौर पर लाल। |
| `ब्लॉक` (पर्यावरण) | थीम के मानक रंग में शीर्षक वाला बॉक्स। |
| `अलर्टब्लॉक` (पर्यावरण) | चेतावनियों या मुख्य बिंदुओं के लिए चेतावनी रंग में शीर्षक वाला बॉक्स। |
| `exampleblock` (पर्यावरण) | उदाहरण रंग में शीर्षक वाला बॉक्स, आमतौर पर हरा। |
| `कॉलम` (पर्यावरण) और `\कॉलम{0.5\textwidth}` | स्लाइड पर अगल-बगल लेआउट क्षेत्र। |
| `\usetheme{मैड्रिड}` | बीमर: प्रस्तावना में प्रस्तुति विषय चुनता है। |
| `\usecolortheme{सीहॉर्स}` | केवल थीम का रंग पैलेट स्वैप करता है। |
| `\usefonttheme{serif}` | केवल थीम के फ़ॉन्ट विकल्पों की अदला-बदली करता है। |
| `\setbeamertemplate{नेविगेशन प्रतीकों}{}` | यहां नेविगेशन आइकन हटाकर, एक थीम तत्व को ओवरराइड किया गया है। |
|`\setbeamercolor{title}{fg=black}` | एक थीम रंग को ओवरराइड करता है. |
| `\नोट{...}` | स्पीकर नोट्स एक फ्रेम से जुड़े होते हैं, जो केवल नोट्स आउटपुट में दिखाए जाते हैं। |

## टिकज़ और आरेख

| आदेश या वातावरण | यह क्या करता है |
| --- | --- |
| `tikzpicture` (पर्यावरण) | टिकज़ चित्र के लिए कैनवास; सभी `\draw` और `\node` कमांड इसके अंदर जाते हैं। |
| `\tikz` | एक-शॉट इनलाइन चित्र: `\tikz \draw (0,0) सर्कल (2pt);`। |
| `\ड्रा (0,0) -- (1,1);` | टिकज़ पथ कमांड जो रेखाएँ और आकार खींचता है; `[मोटा, लाल, ->]` जैसे विकल्प इसे स्टाइल करें। |
| `\भरें` | टिक्ज़ पथ कमांड जो किसी आकृति को स्ट्रोक करने के बजाय उसे भर देता है। |
| `\फिलड्रा` | टिक्ज़ पथ कमांड जो किसी आकृति को भरता है और रेखांकित करता है। |
| `\छाया` | टिक्ज़ पथ कमांड जो एक ग्रेडिएंट से भरता है। |
| `\क्लिप` | टिक्ज़ पथ जो बाद की सभी ड्राइंग को इसके आंतरिक भाग तक सीमित करता है। |
| `\पथ` | टिकज़ पथ जो ड्राइंग के बिना निर्देशांक की गणना करता है, उदाहरण के लिए नोड्स लगाने के लिए. |
| `\नोड at (0,0) {label};` | टिकज़ कमांड जो पाठ या आकृतियों को निर्देशांक पर रखता है। |
| `\निर्देशांक (ए) पर (1,2);` | बाद के पथों में पुन: उपयोग के लिए एक बिंदु का नाम बताता है। |
| `\foreach \i in {1,...,5}` | लूप जो किसी सूची पर ड्राइंग कोड को दोहराता है (TikZ/pgffor)। |
| `\tikzset{mystyle/.style={...}}` | पुन: प्रयोज्य टिक्ज़ शैलियों को आधुनिक तरीके से परिभाषित करता है। |
| `\tikzstyle` | पुरानी शैली-परिभाषा वाक्यविन्यास; बहिष्कृत, `\tikzset` का उपयोग करें। |
| `\usetikzlibrary{पोजीशनिंग}` | प्रस्तावना में अतिरिक्त टिक्ज़ सुविधाएँ लोड करता है। |
| `\मैट्रिक्स` (TikZ) | टिक्ज़पिक्चर के अंदर नोड्स की ग्रिड-संरेखित व्यवस्था। |
| `tikzcd` (पर्यावरण) | क्रमविनिमेय आरेखों के लिए ग्रिड; कोशिकाएँ `&` (tikz-cd) द्वारा विभाजित होती हैं। |
| `\तीर[आर, "एफ"]` | tikz-cd क्रमविनिमेय आरेख में कोशिकाओं के बीच एक तीर खींचता है। |

## इकाइयाँ (siunitx)

| आदेश | यह क्या करता है |
| --- | --- |
| `\संख्या{12345.678}` | उचित अंक समूहन और दशमलव मार्करों के साथ किसी संख्या को प्रारूपित करता है। |
| `\qty{9.8}{\मीटर\प्रति\सेकंड\वर्ग}` | इकाई सहित संख्या, सही दूरी पर (siunitx v3 नाम)। |
| `\यूनिट{\किलो\ग्राम}` | अकेले इकाई (siunitx v3 नाम)। |
| `\SI{9.8}{\मीटर\प्रति\सेकंड\वर्ग}` | v2 `\qty` का नाम; अभी भी कागजों में व्यापक रूप से देखा जाता है। |
| `\si{\kilo\gram}` | v2 `\यूनिट` का नाम। |
| `\sisetup{...}` | वैश्विक siunitx विन्यास. |
| `\DeclareSIUnit{\parsec}{pc}` | एक कस्टम इकाई (siunitx) को परिभाषित करता है। |

## एल्गोरिदम और छद्म कोड

कीवर्ड कमांड algpseudocode (algorithmicx) से हैं; `एल्गोरिदम` फ्लोट उन्हें लपेटता है।

| आदेश या वातावरण | यह क्या करता है |
| --- | --- |
| 'एल्गोरिदम' (पर्यावरण) | स्यूडोकोड के लिए फ्लोटिंग कंटेनर, कैप्शन और संख्या (एल्गोरिदम) के साथ। |
| 'एल्गोरिदमिक' (पर्यावरण) | स्यूडोकोड बॉडी स्वयं, कीवर्ड कमांड (एल्जीपीस्यूडोकोड) को धारण करती है। |
| `\राज्य` | स्यूडोकोड की एक कथन पंक्ति. |
| `\If{...}`, `\ElsIf{...}`, `\Else`, `\EndIf` | सशर्त ब्लॉक कीवर्ड. |
| `\For{...}`, `\ForAll{...}`, `\EndFor` | किसी श्रेणी या सेट पर कीवर्ड को लूप करें। |
| `\व्हाइल{...}`, `\एंडव्हाइल` | जबकि-लूप कीवर्ड. |
| `\Function{Name}{args}`, `\EndFunction` | फ़ंक्शन परिभाषा ब्लॉक. |
| `\Procedure{Name}{args}`, `\EndProcedure` | प्रक्रिया परिभाषा ब्लॉक. |
| `\वापसी` | वापसी कीवर्ड. |
| `\टिप्पणी{...}` | छद्मकोड रेखा पर दाएँ संरेखित टिप्पणी। |
| `\आवश्यकता`, `\सुनिश्चित` | किसी एल्गोरिथम के शीर्ष पर पूर्व शर्त और उत्तर शर्त पंक्तियाँ। |

## भाषा, उद्धरण और संपादकीय पैकेज

| `\उद्धरण{...}` | संदर्भ-जागरूक उद्धरण उस घोंसला और स्थानीयकरण को सही ढंग से चिह्नित करता है (csquotes)। |
| `\todo{इसे ठीक करें}` | मार्जिन नोट फ़्लैगिंग कार्य करने के लिए (टूडोनोट्स)। |

| `\xspace` | मैक्रो के अंत में, एक स्थान जोड़ता है जब तक कि विराम चिह्न (xspace) न आता हो। |
| `\patchcmd{\cmd}{find}{replace}{ok}{fail}` | मौजूदा मैक्रो की परिभाषा को जगह में पैच करता है (ईटूलबॉक्स)। |
| `\apptocmd`, `\pretocmd` | किसी मौजूदा मैक्रो (ईटूलबॉक्स) में कोड जोड़ें या प्रीपेन्ड करें। |
| `\newtoggle{draft}`, `\toggletrue{draft}`, `\iftoggle{draft}{...}{...}` | हल्के बूलियन झंडे (ईटूलबॉक्स)। |

| `\सेटलिस्ट[आइटमाइज़]{नोआइटमसेप}` | विश्व स्तर पर या प्रति स्तर (एनुमिटेम) सूची रिक्ति और लेबल को कॉन्फ़िगर करता है। |
| `पारस्किप` (पैकेज) | अनुच्छेदों को ब्लॉक करने के लिए दस्तावेज़ को स्विच करता है: बीच में जगह, कोई इंडेंट नहीं। |
| `माइक्रोटाइप` (पैकेज) | सूक्ष्म उभार और विस्तार जो औचित्य में सुधार करता है; बस इसे लोड करें. |
| `मल्टीकॉल्स` (पर्यावरण) | दो कॉलम वर्ग विकल्प (मल्टीकॉल) के बिना संतुलित बहु-स्तंभ पाठ। |

## रसायन विज्ञान, भौतिकी, और डोमेन नोटेशन

| आदेश | यह क्या करता है |
| --- | --- |
| `\ce{H2O}` | एक रासायनिक सूत्र या प्रतिक्रिया (एमएचसीएम) टाइपसेट करता है। |
| `\केमफिग{...}` | एक रासायनिक संरचना आरेख (केमफ़िग) बनाता है। |
| `\ब्रैकेट{\phi|\psi}` | ऑटो-साइज़ बार (ब्रेकेट) के साथ टाइपसेट डायराक ब्रा-केट नोटेशन। |

## प्रकाशक वर्ग आदेश

| आदेश या वातावरण | यह क्या करता है |
| --- | --- |
| `\IEEEauthorblockN{...}` | आईईईईट्रान: आईईईई सम्मेलन शीर्षक क्षेत्र में एक लेखक नाम ब्लॉक को प्रारूपित करता है। |
| `\IEEEauthorblockA{...}` | आईईईईट्रान: आईईईई सम्मेलन शीर्षक क्षेत्र में एक लेखक संबद्धता ब्लॉक को प्रारूपित करता है। |
| `\ccsdesc[500]{...}` | एसीमार्ट: पेपर के वर्गीकरण के लिए एक एसीएम सीसीएस अवधारणा की घोषणा करता है। |
| `CCSXML` (पर्यावरण) | एसीमार्ट: एसीएम वर्गीकरण उपकरण से मशीन-पठनीय एसीएम सीसीएस अवधारणाएं एक्सएमएल रखता है। |
| `\विश्वविद्यालय{...}` | क्लास-विशिष्ट मेटाडेटा कमांड थीसिस टेम्प्लेट में देखा जाता है, मानक LaTeX में नहीं। |

## सामान्यतः वातावरण

पर्यावरण एक ऐसा क्षेत्र है जो `\begin{name}` से खुलता है और `\end{name}` से बंद होता है; दोनों के बीच हर चीज़ को उस वातावरण का व्यवहार मिलता है। पूरी कहानी [कमांड बनाम वातावरण](/सीखें/कमांड-वातावरण/) में है। सामान्य प्रयोजन वाले:

| पर्यावरण | यह क्या करता है |
| --- | --- |
| `दस्तावेज़` | प्रत्येक दस्तावेज़ का मुख्य भाग `\begin{document}` और `\end{document}` के बीच रहता है। |
| 'सार' | कक्षा के मानक शीर्षक और लेआउट के साथ पेपर के सार को प्रिंट करता है। |
| `शीर्षक पृष्ठ` | हाथ से बना पूरा शीर्षक पृष्ठ लपेटता है; पृष्ठ क्रमांकित नहीं है. |
| `केंद्र` | इसकी सामग्री को क्षैतिज रूप से केन्द्रित करता है। |
| 'फ्लशलेफ्ट' | अपनी सामग्री को बाएँ-संरेखित करता है, दाएँ रैग्ड करता है। |
| 'फ्लशराइट' | इसकी सामग्री को दाएँ-संरेखित करता है, बाएँ रैग्ड करता है। |
| `आइटमाइज़` | बुलेटेड सूची; प्रत्येक प्रविष्टि `\आइटम` से शुरू होती है। |
| 'गिनो' | क्रमांकित सूची; प्रत्येक प्रविष्टि `\आइटम` से शुरू होती है। |
| 'विवरण' | लेबल की गई सूची; प्रविष्टियाँ `\आइटम[लेबल]` से शुरू होती हैं। |
| `\आइटम` | आइटमाइज़, गणना, या विवरण सूचियों के अंदर एक प्रविष्टि प्रारंभ करता है। |
| 'उद्धरण' | छोटे उद्धरणों के लिए इंडेंटेड ब्लॉक, कोई पैराग्राफ इंडेंट नहीं। |
| 'उद्धरण' | लंबे उद्धरणों के लिए इंडेंटेड ब्लॉक, पैराग्राफ इंडेंट के साथ। |
| 'पद्य' | कविता के लिए इंडेंटेड ब्लॉक, जहां `\\` प्रत्येक कविता पंक्ति को समाप्त करता है। |
| 'मैला' | आराम से लाइन-ब्रेकिंग के साथ पैराग्राफ टाइपसेट, `\sloppy` का पर्यावरण रूप। |
| `सूची` | सामान्य सूची निर्माता जिससे आइटमीकरण और मित्रों को परिभाषित किया जाता है। |
| `ट्रिवलिस्ट` | बिना किसी लेबल या मार्जिन वाली बेयर-बोन्स सूची, मैक्रो परिभाषाओं के अंदर उपयोग की जाती है। |
| `फ़ाइल सामग्री` | संकलन समय पर फ़ाइल के मुख्य भाग को लिखता है, उदा. .tex के अंदर .bib भेजने के लिए। |
| `परिशिष्ट` | परिशिष्ट अध्यायों को लपेटता है, `\appendixpage` और प्रति-परिशिष्ट उपकरण (परिशिष्ट पैकेज) को सक्षम करता है। |

## आगे कहाँ जाना है

यह पेज शब्दकोष है. पाठ व्याकरण हैं. पेस्ट-रेडी वन-पेजर के लिए, [चीटशीट](/लर्न/चीटशीट/) को खुला रखें। `\command{...}` और `\begin{...}` ब्लॉक के बीच अंतर के लिए, [कमांड बनाम वातावरण](/learn/commands-environments/) पढ़ें। किसी प्रतीक के लिए आप चित्र बना सकते हैं लेकिन नाम नहीं दे सकते, [गणित प्रतीकों](/सीखें/गणित-प्रतीकों-चीटशीट/) का उपयोग करें। यह देखने के लिए कि कोई गणित-मोड कमांड कैसा दिखता है, इसे [लाइव पूर्वावलोकन](/लाइव/) में पेस्ट करें और इसे प्रस्तुत करते हुए देखें।
