# pt、em、文本宽度

LaTeX 中几乎每个布局命令都需要一个长度：垂直空间、图像宽度、边距、标线厚度。长度是一个数字加一个单位，单位的选择决定了布局是否在字体大小或页面几何形状发生变化时适应，或者打破了它的变化。

|单位 |意义|
| --- | --- |
| `pt` |点（基点）|
| `em` |字体相对宽度 |
| `前` |字体相对高度 |
| `厘米` / `毫米` / `英寸` |绝对|
| `\textwidth` |文本块的宽度 |
| `\线宽` |当前列/小页的宽度 |

## 绝对和相对单位

`pt` 是打印机的点，TeX 的基本单位。字体大小和许多内部默认值均以磅为单位表示，在 TeX 的计算中，一英寸为 72.27 磅。 “cm”、“mm”和“in”是熟悉的绝对单位，适用于真正的物理要求，例如规定的一英寸边距。

`em` 和 `ex` 根据当前字体缩放：em 大致是表示为宽度的字体大小，ex 大约是小写 x 的高度。他们的优势在于比例。如果文档从 10pt 类型移动到 12pt 类型（其中硬编码的“\vspace{12pt}”变得太紧或太松），“\vspace{1em}”将保持视觉一致。

## 文件给你的长度

`\textwidth` 是页面文本块的宽度。 `\linewidth` 是当前容器的宽度，它等于普通文本中的 `\textwidth`，但在小型页面、列表或列中会变窄。前面的小数可以缩放其中之一，这是调整数字大小的标准方法：

```latex
\vspace{1em}
\includegraphics[width=0.5\textwidth]{f.pdf}
```

第一行插入一个 em 的垂直空间。第二个将图像设置为文本块宽度的一半，因此如果边距发生变化，图形会随之重新缩放，并且永远不会溢出到边距中。在小型页面或两列布局中，更喜欢 `0.5\linewidth`，因为 `\textwidth` 比您实际拥有的空间更宽。

长度也可设置。 `\setlength{\parindent}{0pt}` 删除段落缩进，并且相同的命令调整大多数命名的布局长度。

常见的错误是以厘米为单位计算尺寸。它一直有效，直到文档类别、纸张尺寸或边距发生变化，然后每个数字都需要手动重新调整。以“\textwidth”或“\linewidth”的分数表示的宽度在所有这些更改中保持不变，这就是模板几乎专门使用它们的原因。
