# 실제로 열 편집기를 선택하세요

초보자를 위한 최고의 LaTeX 편집기는 가장 강력한 편집기가 아닙니다. 이는 최소한의 마찰로 빈 파일에서 컴파일된 PDF로 이동하는 것입니다. 초기에 컴파일하는 것은 단일 기능보다 더 중요한 경우가 많습니다. 4가지 기능은 첫날에 필요한 것을 충족합니다.

첫째, 컴파일은 수 기가바이트 규모의 TeX 배포판을 직접 설치하지 않고도 작동해야 합니다. 둘째, SyncTeX를 사용하여 나란히 PDF 미리보기를 원하므로 PDF를 클릭하면 일치하는 소스 줄로 이동했다가 다시 돌아옵니다. 셋째, 파일은 디스크에 있는 일반 '.tex'여야 합니다. 따라서 내보내기 단계 없이 압축하거나 이메일로 보내거나 Git에 넣을 수 있습니다. 넷째, 오류는 원시 TeX 로그뿐만 아니라 읽을 수 있는 메시지로 도착해야 합니다.

## 현실적인 옵션

| 편집자 | 설정 | 오프라인으로 작동 | 메모 |
| --- | --- | --- | --- |
| 올리플리 | 앱 다운로드 | 항상 편집 중입니다. 컴파일은 캐시된 패키지를 사용합니다 | 번들 엔진, Git 기록, 선택적으로 나만의 키 AI |
| TeXShop / TeXworks | 먼저 TeX 배포판을 설치하세요 | 예 | 최소한의 신뢰성 |
| VS Code + LaTeX 워크숍 | 먼저 TeX 배포판을 설치하세요 | 예 | 이미 VS Code에서 작업하고 있는 경우 적합 |
| 뒷면 | 브라우저에서 계정 만들기 | 한정 | 제로 설치; 프로젝트는 서버에 존재합니다 |

가운데 두 행은 숨겨진 비용을 공유합니다. 편집기가 유용해지기 전에 TeX Live 또는 MiKTeX를 직접 설치하고 유지 관리해야 합니다. 많은 초보자들이 멈추는 곳이 바로 여기입니다. 브라우저 옵션은 설정을 제거하지만 파일을 계정으로 이동합니다. 장단점은 [브라우저 프로젝트와 디스크의 폴더](/learn/overleaf-vs-local/)에서 더 자세히 다룹니다.

## 합리적인 기본값

TeX 관리 없이 로컬 파일을 원하는 경우 [Oleafly](https://github.com/Oleafly/Oleafly/releases/latest)로 시작하세요. 컴파일러는 앱 내부에 포함되어 문서에 처음 필요할 때 패키지를 다운로드합니다. 어떤 편집기를 선택하든 [첫 번째 문서 튜토리얼](/learn/first-document/)과 연결하고 [치트시트](/learn/cheatsheet/)를 근처에 보관하세요. 편집자는 오늘 첫 페이지를 편집하는 것보다 중요하지 않습니다.
