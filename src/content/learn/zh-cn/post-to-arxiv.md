# 发布您的第一个 arXiv 预印本

发布到 arXiv 可以让您的作品公开、可引用并带有时间戳。这个过程有一些奇怪之处，让每个人第一次都感到惊讶。如果您还没有阅读过 [arXiv 是什么](/learn/what-is-arxiv/)，请从那里开始，然后再回来。

## 代言：门口的保镖

大多数类别中的全新提交者都需要来自知名 arXiv 作者的认可。如果您的帐户使用学术电子邮件并且您有具有 arXiv 历史记录的合著者，这通常是自动或快速的。否则，请询问您的顾问或合著者；系统会为您提供一个背书代码来发送它们。在你打算发帖之前几天而不是晚上就解决这个问题。

## 选择您的类别

arXiv 被组织成经过审核的类别，例如“cs.LG”（机器学习）、“cs.CL”（计算和语言）、“math.OC”（优化）、“stat.ML”。您可以选择一个主要类别，也可以选择一些次要类别。查找您引用的论文的实时位置，并关注它们。主要类别决定了哪个邮件列表公布您的论文，因此它决定了谁首先看到它。

## arXiv 想要你的源代码，而不是你的 PDF

这是最重要的。如果您的论文是使用 LaTeX 生成的，则 arXiv 需要 LaTeX 源代码，而不仅仅是 PDF。他们的 AutoTeX 系统在他们的服务器上编译它，读者可以下载该版本。结果：

- 您的论文需要的每个文件都必须上传：图形、“.bbl”文件（arXiv 不会为您运行 BibTeX，因此包括生成的“.bbl”）、非标准样式文件。
- 如果它不能在他们的系统上编译，你就修复它直到它可以编译。

## 首先清理你的源

您的评论与您的​​来源一起提供，任何人都可以下载它。这份草稿说明“% TODO：这个说法是真的吗？”将被公开。上传前：

- [ ] 删除注释。 “arxiv-latex-cleaner”工具可以自动执行此操作，并删除未使用的文件。
- [ ] 删除未使用的图形和旧部分
- [ ] 检查是否存在令人尴尬的文件名（`final_v7_ACTUALLY_final.tex`）
- [ ] 从头开始编译清理后的副本一次

使用 Git 支持的项目可以在这方面有所帮助：在 Oleafly 中，您可以分支检查点、清理源代码并与原始版本进行比较，以在导出 ZIP 之前确认没有发生任何实质性更改。

## 许可证

arXiv 要求您选择一个许可证。仅限 arXiv 的最低许可证是常见的默认许可证，并让您可以选择期刊。 CC BY 更为宽松。如果论文要发送给特定的出版商，请在选择任何不可撤销的内容之前检查他们的预印本政策。

## 公告周期及其民间传说

arXiv 按固定的工作日时间表分批公布新论文，并有提交截止时间。截止日期后立即提交的论文出现在下一个列表的顶部，而民间传说中的小型家庭手工业声称列表顶部的论文会受到更多关注。或许。不要因此而失眠；好的摘要比列表位置更重要。

## 版本：v1、v2 以及接受后

您的第一篇文章是 v1，并且是永久的：您可以添加版本但永远不能删除它们。当您有真正的改进时发布 v2，通常是[同行评审](/learn/peer-review-explained/) 之后接受的版本。接受后，使用可用于相机的内容更新 arXiv 副本（尊重出版商的政策），并在期刊参考字段中添加 DOI 或地点。读者会为此感谢你的。
