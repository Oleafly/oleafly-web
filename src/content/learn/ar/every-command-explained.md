# شرح كل أمر في عالم LaTeX

تحدد هذه الصفحة كل أمر وبيئة LaTeX تظهر في أي درس على Oleafly Learn، بالإضافة إلى المفردات القياسية الأوسع التي ستقابلها في الأوراق الحقيقية. Kernel، وamsmath، وhyperref، وgraphicx، وbooktabs، وbiblatex، وTikZ، وBeamer، والحزم التي يقوم الباحثون بالفعل بتحميلها. قم بتصفحها حسب الفئة، أو ابحث في الصفحة باستخدام Ctrl/Cmd-F عن الأمر الذي قابلته للتو. كل إدخال عبارة عن سطر واحد: ماذا يفعل، وأين يهم، ومن أي حزمة يأتي.

## فئات الوثيقة والإعداد

| الأمر | ماذا يفعل |
| --- | --- |
| `\documentclass{article}` | السطر الأول من كل مستند: يختار التخطيط العام؛ المقالة هي الاختيار الافتراضي للأوراق. |
| `\documentclass{report}` | فئة التقارير الأطول: تضيف `\chapter` وتبدأ الملخص على صفحتها الخاصة. |
| `\documentclass{book}` | فئة الكتب: الفصول، التخطيط على الوجهين، المادة الأمامية/الرئيسية/الخلفية. |
| `\documentclass{letter}` | فئة للمراسلات، باستخدام أوامر `\open` و`\closing` والعنوان. |
| `\documentclass{beamer}` | فئة العروض التقديمية للشرائح المبنية من بيئات "الإطار". |
| `\documentclass[11pt,a4paper]{article}` | خيارات الفئة الشائعة: حجم الخط (10pt، 11pt، 12pt)، الورق (a4paper، letterpaper)، `twocolumn`، `twoside`، `landscape`، ` Draft`، `titlepage`. |
| `\usepackage{amsmath}` | يقوم بتحميل حزمة في الديباجة لإضافة ميزات. |
| `\usepackage[margin=1in]{هندسة}` | يضبط هوامش الصفحة وحجم الورق (الهندسة). |
| `\العنوان{...}` | يخزن عنوان المستند، الذي سيتم طباعته لاحقًا بواسطة `\maketitle`. |
| `\المؤلف{...}` | يخزن قائمة المؤلفين لـ `\maketitle`؛ افصل بين عدة مؤلفين باستخدام `\و`. |
| `\ و` | فاصل بين أسماء المؤلفين داخل `\author{...}`. |
| `\تاريخ{...}` | يخزن التاريخ الموضح بواسطة `\maketitle`؛ `\date{}` يخفيه، `\date{\today}` يظهر اليوم. |
| `\اليوم` | طباعة التاريخ الحالي في وقت الترجمة. |
| `\maketitle` | يطبع قالب العنوان من `\title` و`\author` و`\date`. |
| `\شكرا{...}` | إرفاق حاشية سفلية بالعنوان أو اسم المؤلف، على سبيل المثال. للحصول على التمويل أو معلومات الاتصال. |
| `\المعهد{...}` | أمر انتماء المؤلف الذي يستخدمه Beamer وفئة Springer LNCS. |
| `\inst{1}` | علامة الخط العلوي للانتساب في قوائم مؤلفي LNCS وBeamer: `Ada Lovelace\inst{1}`. |
| `\الكلمات الرئيسية{...}` | طباعة قائمة الكلمات الرئيسية للورقة في الناشرفئات مثل acmart و llncs. |
| `\العنوان{...}` | فئة الرسالة: تخزن عنوان المرسل للورق ذي الرأسية. |
| `\التوقيع{...}` | فئة الحروف: تخزن الاسم المطبوع تحت الإغلاق. |
| `\opening{عزيزي ...}` | فئة الحروف: تطبع التحية وتبدأ بنص الرسالة. |
| `\إغلاق{مع خالص التقدير،}` | فئة الرسالة: تطبع كتلة تسجيل الخروج والتوقيع. |
| `\LaTeX` | يطبع شعار LaTeX بأحرفه المرتفعة والمنخفضة. |
| `\تكس` | يطبع شعار TeX بحرف E المنخفض
| `\الإدخال{ملف}` | قم بلصق ملف .tex آخر في مكانه، كما لو كنت قد كتبته هناك. |
| `\تشمل{الفصل1}` | يُدخل ملف الفصل بدءًا من صفحة جديدة؛ تمكين التجميعات الجزئية عبر `\includeonly`. |
| `\includeonly{chapter1,chapter3}` | قائمة الديباجة تقيد الملفات التي يتم تجميعها بالفعل `\include`. |
| `\hypersetup{...}` | يقوم بتكوين خيارات Hyperref مثل ألوان الارتباط وبيانات تعريف PDF. |
| `\AtBeginDocument{...}` | يقوم بتشغيل التعليمات البرمجية مباشرة بعد `\begin{document}`، وهو مفيد للإعداد المتأخر. |
| `\AtEndDocument{...}` | يقوم بتشغيل التعليمات البرمجية قبل انتهاء المستند مباشرةً. |
| `\makeatletter` | إنشاء حرف `@` مؤقتًا حتى تتمكن من استخدام الأوامر الداخلية أو تصحيحها. |
| `\اصنع آخر` | يعيد `@` إلى الوضع الطبيعي بعد `\makeatletter`. |
| `\typeout{...}` | يطبع رسالة إلى سجل الترجمة والمحطة الطرفية، وهو مفيد لتصحيح الأخطاء. |
| `\حماية` | يحمي أمرًا هشًا داخل وسيطة متحركة مثل `\caption` أو `\section`. |
| `\listfiles` | أمر الديباجة الذي يسجل كل ملف تم تحميله وإصداره، لتقارير الأخطاء. |

## الهيكل والتقسيم

| الأمر | ماذا يفعل |
| --- | --- |
| `\جزء{...}` | القسم الأعلى مستوى، فوق الفصول، في فصول الكتب والتقارير. |
| `\فصل{...}` | عنوان الفصل مرقم في فئات الكتاب والتقرير (وليس في المقالة). |
| `\ القسم {...}` | عنوان المستوى الأعلى مرقم في المقالة. |
| `\subsection{...}` | عنوان مرقم بمستوى واحد أسفل `\section`. |
| `\subsection{...}` | عنوان مرقم بمستوى واحد أسفل `\subsection`. |
| `\فقرة{...}` | عنوان المستوى الأدنى: عنوان عريض في بداية الفقرة. |
| `\فقرة فرعية{...}` | مستوى واحد أقل من `\paragraph`، نادرًا ما تكون هناك حاجة إليه. |
| `\section*{...}` | يؤدي التقسيم المميز بنجمة إلى طباعة العنوان بدون رقم أو إدخال جدول المحتويات. |
| `\الملحق` | يقوم بتبديل الترقيم بحيث تصبح الفصول أو الأقسام التالية هي الملحق أ، ب، ج. |
| `\صفحة الملحق` | طباعة صفحة مقسمة منفصلة "للملاحق" (حزمة الملحق). |
| `\جدول المحتويات` | يطبع جدول المحتويات، الذي تم إنشاؤه بناءً على أوامر التقسيم الخاصة بك. |
| `\قائمة الأشكال` | طباعة قائمة بجميع التسميات التوضيحية للأشكال مع أرقام الصفحات. |
| `\listoftables` | طباعة قائمة بجميع التسميات التوضيحية للجدول مع أرقام الصفحات. |
| `\فرونتماتر` | تبديل فئة الكتاب لصفحات المحتوى المسبق: أرقام الصفحات الرومانية، والفصول غير المرقمة. |
| `\الأمر الرئيسي` | قم بالتبديل إلى فئة الكتب مرة أخرى إلى المحتوى الرئيسي: أرقام الصفحات العربية، والفصول المرقمة. |
| `\ مادة خلفية` | تبديل فئة الكتاب لصفحات النهاية: يتوقف ترقيم الفصول. |
| `\addcontentsline{toc}{chapter}{...}` | يضيف إدخالاً يدويًا إلى جدول المحتويات (أو قائمة الأشكال/الجداول). |
| `\addtocontents{toc}{...}` | يكتب مادة عشوائية (مثل التباعد) في ملف المحتويات. |
| `\setcounter{secnumعمق}{3}` | يتحكم في مدى عمق أرقام التقسيم. |
| `\setcounter{tocعمق}{2}` | يتحكم في مدى عمق جدول المحتويات. |

## تحديد الأوامر والبيئات

| الأمر | ماذا يفعل |
| --- | --- |
| `\newcommand{\R}{\mathbb{R}}` | يحدد الأمر الخاص بك؛ أخطاء إذا كان الاسم موجودًا بالفعل. |
| `\renewcommand{...}{...}` | يعيد تعريف أمر موجود؛ الأخطاء إذا لم تكن موجودة. |
| `\providecommand{...}{...}` | يحدد الأمر فقط إذا لم يكن محددًا بالفعل؛ وإلا بصمت لا يفعل شيئا. |
| `\NewDocumentCommand` | تعريف الأمر الحديث مع الوسائط الاختيارية المرنة (LaTeX3/xparse). |
| `\newenvironment{name}{begin code}{end code}` | يحدد بيئتك الخاصة باستخدام التعليمات البرمجية التي يتم تشغيلها في `\begin` و`\end`. |
| `\renewenvironment{name}{...}{...}` | يعيد تعريف البيئة الحالية. |
| `\ensuremath{...}` | يجعل محتوى الرياضيات الخاص بالماكرو يعمل داخل وضع الرياضيات وخارجه. |
| `\DeclareMathOperator{\E}{E}` | يحدد اسم المشغل المستقيم؛ النموذج المميز بنجمة يضع الحدود أدناه (amsmath). |
| `\DeclareMathOperator*{\argmin}{arg\,min}` | النموذج المميز بنجمة: يأخذ عامل التشغيل الحدود أدناه في عرض الرياضيات (amsmath). |
| `\newtheorem{lemma}{Lemma}` | تعلن عن بيئة تشبه النظرية (امسثم). |
| `\فو` | اسم نموذج لماكرو محدد من قبل المستخدم في الدرس `\newcommand`، وليس أمر LaTeX حقيقي. |
| `\abs{x}` | مثال على الماكرو المعرف من قبل المستخدم من درس الأوامر المخصصة الذي يقوم بتنضيد أشرطة القيمة المطلقة. |
| `\مات {أ}` | مثال على الماكرو المحدد من قبل المستخدم من درس الأوامر المخصصة لرمز مصفوفة غامق. |
| `\vect{v}` | مثال على الماكرو المحدد من قبل المستخدم من درس الأوامر المخصصة لرمز متجه غامق. |
| `\مجموعة{...}` | مثال على الماكرو المحدد من قبل المستخدم من درس الأوامر المخصصة الذي يحدد حجم مجموعة الأقواس. |
| `\الزوج` | مثال على ماكرو مساعد الاقتباس المحدد بواسطة المستخدم من درس الأوامر المخصصة، وليس أمرًا قياسيًا. |
| `\ه` | مثال على عامل التشغيل المحدد من قبل المستخدم للتوقع، والذي يتم تعريفه عادةً بـ`\DeclareMathOperator` أو `\newcommand`. |
| `\ص` | مثال على الماكرو المعرف من قبل المستخدم للحقيقيات: `\newcommand{\R}{\mathbb{R}}`. |
| `\أرجماكس`، ``أرجمين` | أسماء عوامل التشغيل لـ arg max / arg min، تم تعريفها في هذه الدورة باستخدام `\DeclareMathOperator*` بحيث تكون المشتركات أدناه. |

## العدادات والأطوال

| الأمر | ماذا يفعل |
| --- | --- |
| `\newcounter{أمثلة}` | إنشاء عداد جديد، يمكن إعادة تعيينه اختياريًا بواسطة أحد الوالدين: `\newcounter{examples}[section]`. |
| `\setcounter{page}{1}` | يضبط قيمة العداد، هنا إعادة تشغيل أرقام الصفحات. |
| `\addtocounter{أمثلة}{2}` | إضافة قيمة إلى العداد دون طباعة أي شيء. |
| `\stepcounter{أمثلة}` | زيادة العداد بمقدار واحد. |
| `\refstepcounter{أمثلة}` | يزيد العداد ويجعله الهدف لـ `\label` التالي. |
| `\قيمة{أمثلة}` | يقرأ قيمة العداد لاستخدامها في العمليات الحسابية أو المقارنات. |
| `\عربي{أمثلة}` | طباعة عداد كأرقام عربية: 1، 2، 3. |
| `\roman{أمثلة}`، `\Roman{أمثلة}` | طباعة العداد كأرقام رومانية صغيرة أو كبيرة. |
| `\ألف{أمثلة}`، `\ألف{أمثلة}` | طباعة العداد بأحرف صغيرة أو كبيرة. |
| `\fnsymbol{حاشية سفلية}` | طباعة عداد كرموز الحواشي السفلية: العلامة النجمية، والخنجر، وما إلى ذلك. |
| `\newlength{\mygap}` | إنشاء سجل طول جديد. |
| `\setlength{\parskip}{6pt}` | يعين قيمة لسجل الطول. |
| `\addtolength{\textheight}{1cm}` | يضيف إلى طول موجود. |
| `\settowidth{\mygap}{text}` | يضبط الطول على العرض الطبيعي لبعض النص. |
| `\الوالد` | طول المسافة البادئة لفقرة السطر الأول؛ اضبط باستخدام `\setlength{\parindent}{0pt}`. |
| `\بارسكيب` | طول الفجوة العمودية بين الفقرات؛ تم ضبطه باستخدام `\setlength`. |
| `\عرض الخط` | طول السطر الحالي، مفيد للتحجيم: `width=\linewidth`. |
| `\عرض النص` | طول عرض كتلة النص الكامل على الصفحة. |
| `\ارتفاع النص` | طول ارتفاع كتلة النص الكامل على الصفحة. |
| `\عرض العمود` | عرض عمود واحد في تخطيط متعدد الأعمدة. |
| `\ خط الأساس` | المسافة العمودية بين خطوط الأساس للخطوط المتتالية. |
|`\linespread{1.3}` | يقيس المسافة البادئة (تباعد الأسطر) للمستند بأكمله؛ يحتاج إلى `\selectfont` أو أمر الحجم ليصبح ساري المفعول في مكانه. |

## الفقرات وفواصل الأسطر والواصلة

| الأمر | ماذا يفعل |
| --- | --- |
| `\\` | ينهي السطر الحالي داخل الفقرات والجداول والمصفوفات. |
| `\\[6 نقطة]` | فاصل سطر مع مسافة رأسية إضافية بعده. |
| `\السطر الجديد` | يكسر السطر دون تبريره ودون السماح بفاصل الصفحات. |
| `\فاصل السطر` | يطلب فاصل أسطر مبررًا هنا؛ اختياري `[0-4]` يضبط الإصرار. |
| `\nolinebreak` | لا يشجع على فاصل أسطر عند هذه النقطة. |
| `\ الاسمية` | ينهي الفقرة، مثل سطر فارغ في المصدر. |
| `\لا مسافة بادئة` | منع المسافة البادئة للسطر الأول من الفقرة التالية. |
| `\مسافة بادئة` | يفرض المسافة البادئة للسطر الأول حيث سيتم منعها. |
| `\-` | يضع علامة على نقطة الواصلة المسموح بها داخل الكلمة. |
| `\الواصلة{مجموعة البيانات}` | قائمة الديباجة لتعليم LaTeX كيفية وصل كلمات معينة. |
| `\قذرة` | يعمل على تخفيف قواعد التباعد بحيث تنكسر الخطوط بسهولة أكبر، مع تجنب الصناديق الممتلئة. |
| `\صعب` | يستعيد قواعد التباعد الصارمة بعد `\sloppy`. |
| `\ خشنة` | يقوم بمحاذاة النص التالي إلى اليسار بدلاً من ضبطه. |
| `\ خشنة اليسار` | محاذاة النص التالي إلى اليمين. |
| `\توسيط` | توسيط كل ما يلي داخل المجموعة الحالية، على سبيل المثال. صورة شخصية. |
| `\نفس الصفحة` | لا يشجع فواصل الصفحات داخل المجموعة الحالية. |
| `\تكبير هذه الصفحة{\baselineskip}` | يجعل الصفحة الحالية فقط أطول قليلاً، للضغط عليها في سطر واحد إضافي. |
| `~` | مسافة غير منقسمة: `الشكل~1` يبقي الرقم على نفس السطر. |

## التباعد

| الأمر | ماذا يفعل |
| --- | --- |
| `\رباعية` | إدراج مسافة أفقية حول عرض الحرف الكبير M. |

| `\vspace{1cm}` | إدراج مسافة رأسية بطول معين. |
| `\vspace*{1cm}` | مساحة عمودية تبقى حتى عند فاصل الصفحات. |

| `\ميدسكيب` | إدراج فجوة عمودية متوسطة بين الفقرات. |
| `\بيجسكيب` | إدراج فجوة رأسية كبيرة بين الفقرات. |
| `\hfill` | مساحة أفقية ممتدة تدفع المحتوى بعيدًا لملء الخط. |
| `\vfill` | مساحة رأسية ممتدة تدفع المحتوى بعيدًا لملء الصفحة. |
| `\حشوة` | يملأ السطر المتبقي بالنقاط، كما هو الحال في القائمة أو سطر المحتويات. |
| `\hrulefill` | يملأ السطر المتبقي بمسطرة أفقية. |
| `\تمدد{2}` | غراء قابل للتمدد بوزن، للتباعد المتناسب: `\hspace{\stretch{2}}`. |
| `\ملء` | طول الوحدة قابل للتمدد؛ `\hspace{\fill}` هو ما يتوسع إليه `\hfill`. |
| `\فانتوم{نص}` | يشغل مساحة حجته تمامًا ولكنه لا يطبع شيئًا. |
| `\hphantom{نص}` | يأخذ فقط عرض وسيطته، مع ارتفاع صفر. |
| `\vphantom{text}` | يأخذ فقط ارتفاع وسيطته، مع عرض صفر. |
| `\سحق{...}` | يطبع حجته ولكنه يتظاهر بأن ارتفاعه وعمقه صفر. |
| `\تبختر` | دعم غير مرئي لارتفاع الخط العادي، لتسوية ارتفاعات الصفوف. |
| `\mathstrut` | وضع الرياضيات يدعم حجم القوس لمحاذاة الجذور والكسور. |

## الصناديق والقواعد

| الأمر | ماذا يفعل |
| --- | --- |
| `\mbox{...}` | صندوق أفقي غير قابل للكسر كما يحتفظ بمحتوياته في سطر واحد. |
| `\makebox[3cm][r]{...}` | مربع بعرض محدد مع المحاذاة المختارة (l، c، r، s). |

| البيئة | ماذا يفعل |
| --- | --- |
| "وثيقة" | يقع نص كل مستند بين `\begin{document}` و`\end{document}`. |
| `ملخص` | يطبع ملخص الورقة بالعنوان والتخطيط القياسيين للفصل الدراسي. |
| `صفحة العنوان` | يغلف صفحة عنوان كاملة مصنوعة يدويًا؛ الصفحة غير مرقمة. |
| `المركز` | توسيط محتوياته أفقيا. |
| `يسار متساطح` | محاذاة اليسار محتوياته، خشنة اليمين. |
| `فلاشرايت` | محاذاة محتوياته لليمين، واليسار الممزق. |
| `` تفصيل '' | قائمة ذات تعداد نقطي؛ يبدأ كل إدخال بـ `\item`. |
| `تعداد` | قائمة مرقمة؛ يبدأ كل إدخال بـ `\item`. |
| `الوصف` | قائمة مصنفة؛ تبدأ الإدخالات بـ `\item[Label]`. |
| `\العنصر` | يبدأ إدخالًا واحدًا داخل قوائم التفصيل أو التعداد أو الوصف. |
