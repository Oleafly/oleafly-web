# 글꼴과 싸우지 않고 강조

LaTeX의 강조는 각각 영향을 받은 텍스트를 중괄호 인수로 사용하는 작은 명령 세트에서 비롯됩니다. LaTeX는 대부분의 워드 프로세서가 병합하는 두 가지 아이디어, 즉 특정 서체를 적용하고 강조된 범위를 표시하는 두 가지 아이디어를 분리합니다. 스타일이 변경될 때 문서의 일관성을 유지하는 명령을 파악합니다.

```latex
\textbf{bold}
\textit{italic}
\emph{emphasis} % preferred in running text
\underline{avoid} % rarely used in body text
\texttt{monospace}
\textsc{Small Caps}
```

## 명령

`\textbf`는 강한 강조와 정의의 표제어에 대한 표준 처리인 볼드체를 설정합니다. `\textit`은 이탤릭체 유형을 직접 설정합니다. `\texttt`는 실행 중인 텍스트의 파일 이름, 명령 및 코드 식별자에 대한 규칙인 고정폭 타자기 글꼴로 전환합니다. `\textsc`는 참고문헌의 저자 이름과 텍스트 줄을 지배하는 약어에 일반적으로 사용되는 작은 대문자를 설정합니다.

`\underline`이 존재하지만 예제에서는 해당 설명을 얻습니다. 밑줄은 타자기 시대의 이탤릭체 대체이며 LaTeX에서도 기계적인 문제가 있습니다. 밑줄이 그어진 텍스트는 상자에 배치되므로 줄을 넘어갈 수 없으며 밑줄이 그어진 긴 문구는 여백을 넘깁니다. 인쇄 타이포그래피에서 이탤릭체는 밑줄을 긋는 역할을 합니다.

명령이 중첩되므로 `\textbf{\textit{bold italic}}`는 글꼴이 글꼴을 제공할 때 두 명령을 결합합니다.

## 왜 \emph

``emph`는 겉모습보다는 의미를 표시합니다. "이것을 강조하세요"라고 말하고 상황에 따라 어떻게 할지 결정하게 됩니다. 수직 텍스트에서는 이탤릭체로 인쇄됩니다. 이미 기울임꼴로 표시된 텍스트 내에서는 다시 똑바로 세워져 강조 안의 강조가 계속 표시됩니다. 이탤릭체 텍스트 안에 하드 코딩된 `\textit`은 이탤릭체로 유지되고 내부 강조는 사라집니다. 마킹 의도도 나중에 성과를 거두게 됩니다. 클래스나 패키지는 문서 전체를 편집하지 않고도 한 곳에서 강조 모양을 재정의할 수 있습니다.

경험 법칙: 산문을 강조할 때는 `\emph`를 사용하고, 책 제목, 외국 문구, 종 이름과 같이 문맥에 관계없이 관례적으로 이탤릭체로 표시되는 항목에는 `\textit`을 사용하세요.

## 경계와 습관

이것들은 모두 텍스트 모드 명령이며 수식 내에서 잘못 작동합니다. 굵은 수학 기호에는 [굵은 수학](/learn/bold-math/)에서 다루는 `\mathbf` 또는 `\boldsymbol`이 필요합니다. 모든 것이 대담하면 아무것도 눈에 띄지 않으므로 겹쳐서 강조하는 것을 피하세요. 구조는 목차와 PDF 책갈피도 제공하므로 수동으로 굵게 표시하는 대신 `\section`과 같은 구조적 명령을 사용하여 제목을 작성합니다. [더 크고 작은 유형](/learn/font-size/)은 글꼴 크기에 대해 동일한 주장을 합니다.
