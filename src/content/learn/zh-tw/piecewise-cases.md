# 分段定義

分段函數在其領域的不同部分給出不同的公式：絕對值、ReLU 激活、稅級表。排版約定是高左大括號，每個案例一行，每行顯示公式及其應用條件。 「amsmath」套件提供了「cases」環境，它可以準確地產生此佈局，而無需任何手動調整括號大小。

## 案例環境

```latex
\[
f(x) =
\begin{cases}
 x^2 & x \ge 0 \\
 -x & x < 0
\end{cases}
\]
```

逐行閱讀此內容：整個內容位於 `\[ ... \]` 內，因此它在自己的行上顯示數學。 `f(x) =` 是普通數學，則 `\begin{cases}` 開啟分段區塊。在裡面，每行有兩列，用「&」分隔：左邊是公式，右邊是條件。行以“\\”結尾，但最後一行不需要。編譯時，LaTeX 會繪製一個足夠高的左大括號以跨越兩行，並對齊一列中的公式和另一列中的條件。

「&」在這裡發揮著真正的作用。如果沒有它，每一行都將是一個斑點，條件不會垂直排列。有了它，「x^2」和「-x」共享左邊緣，「x \ge 0」和「x < 0」共享它們自己的左邊緣，這使得定義可掃描。

必須具備兩件事才能編譯。首先，序言中的 `\usepackage{amsmath}`，因為 `cases` 不是核心 LaTeX 的一部分。其次，環境必須處於數學模式內。 `cases` 建立數學內容，但本身不會開啟數學模式。如果缺少其中一個，您將收到「環境案例未定義」或「缺少 $ 插入」錯誤。後者在[插入缺少的美元](/learn/missing-dollar/) 中進行了解釋。

## 新增單字

大多數已發表的分段定義都包含“如果”一詞，並且通常包含最後的“否則”。由於條件列是數學模式，因此普通單字需要“\text{...}”以適當的間距以文檔字體顯示：

```latex
\[
f(x) =
\begin{cases}
 x^2 & \text{if } x \ge 0 \\
 -x & \text{otherwise}
\end{cases}
\]
```

注意“\text{if }”內部的空格。數學模式會忽略您鍵入的空格，但在 `\text` 內部空格是真實的，因此在右大括號之前放置一個空格會將“if”與後面的條件分開。

## 變體和常見錯誤

如果公式是高分數並且看起來很擁擠，“mathtools”包提供了“dcases”，這是一個直接替代品，可以設定每個公式的顯示樣式。還有一種用於鏡像情況的“情況”，其中支架屬於右側。

最常見的錯誤是忘記行之間的“\\”，這會默默地將兩個案例合併為一長行。如果編譯的輸出顯示公式中存在條件，請先計算行中斷數。您可以在[遊樂場](/live/) 中嘗試現場環境。
