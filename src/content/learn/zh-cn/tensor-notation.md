# 堆叠索引

相对论和微分几何中的张量表示法区分了上索引和下索引，索引的水平顺序也有意义：一旦用度量升高和降低索引，首先具有较高索引的对象与首先具有较低索引的对象并不相同。 LaTeX 的默认脚本放置忽略了这种区别，因此张量较多的文档依赖于空组的小技巧。

```latex
T^{i}{}_{j}{}^{k}
R^{\mu}{}_{\nu\rho\sigma}
g_{\mu\nu}
```

## 空组技巧

写“T^i_j”会将上标和下标放在同一个水平槽中，一个叠放在另一个上面。要交错排列它们，请插入一个空组“{}”：“T^{i}{}_{j}”将“i”作为上标附加到 T，然后将“j”作为下标附加到后面的空组，因此下标位于上标之后而不是其下方。每个“{}”都会打开一个新的脚本槽，您可以根据张量需要链接任意数量的脚本槽，如“T^{i}{}_{j}{}^{k}”中所示。

第二行显示了真实物体的回报。在 `R^{\mu}{}_{\nu\rho\sigma}` 中，mu 占据第一个索引位置，三个较低的索引紧随其后。这是黎曼张量的标准布局。折叠交错，索引顺序变得不明确。当每个索引都位于一个级别时，如度量“g_{\mu\nu}”中所示，不需要任何技巧，单个下标组可以容纳所有索引。

同样的“{}”也解决了一个简单的错误。 `T^i^k` 使用“双上标”停止编译，因为一个原子不能有两个上标。 `T^{i}{}^{k}` 为第二个上标提供了自己的槽并干净地编译。

## 约定和一致性

索引是交错的还是堆叠的是字段约定。广义相对论几乎普遍地令人震惊。当没有指标移动索引时，其他区域可以使用堆叠索引。匹配您所在领域的习惯，如果您在某个地方提交，请先匹配期刊的模板，然后再匹配您自己的口味。 “tensor”包可以使用“\tensor”命令自动放置，但手动空组是可移植的，不需要包，并且可以在任何提交系统中保持不变。

一致性比选择本身更重要。决定一次每个张量的索引如何排列。对于您经常键入的内容，请在它们周围放置一个序言宏，这样后期对约定的更改就是一次编辑，而不是搜索整个文档。在[现场游乐场](/live/) 中并排比较交错和堆叠的表格。
