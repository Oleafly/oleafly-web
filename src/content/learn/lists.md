# Bullets, numbers, and definition lists

```latex
\begin{itemize}
 \item Bullet
\end{itemize}

\begin{enumerate}
 \item Numbered
\end{enumerate}

\begin{description}
 \item[Term] Definition style
\end{description}
```

Nest environments for multi-level lists. Custom labels: `\item[(a)]`.
