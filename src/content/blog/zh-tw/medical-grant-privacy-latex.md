臨床手稿和撥款敘述通常包括敏感細節，甚至
在去識別化最終完成之前。將每次按鍵交給第三方
編輯器既是一種政策決定，也是一種工具偏好。 IRB、資料使用
協議，醫院 IT 並不關心雲端編輯器是否方便
晚上 11 點。

這篇文章是關於起草和排版的，你可以向他們解釋
合規性。將其視為工作流程建議，而不是法律審查。

## 普通文件更容易推理

一個包含「.tex」和數字的資料夾可以位於加密磁碟、醫院中
筆記型電腦影像，或氣隙機器。您可以將合規性指向一條路徑。
瀏覽器專案需要信任供應商的存取模型、匯出路徑和
子處理者列表。

[Oleafly](https://github.com/Oleafly/Oleafly/releases/latest) 的建構是
故意方式：沒有帳戶，沒有產品遙測，項目作為普通資料夾
使用真正的 Git 儲存庫。 [隱私權頁面](/privacy/) 很短，因為
文件不需要 Oleafly 伺服器即可存在。網路是為了你的行動
take（包、可選的引文查找、託管人工智慧（如果啟用的話）、GitHub），
並非針對草稿的每次按鍵。

如果政策禁止雲端人工智慧，請關閉助理或將其指向本地
模型。編輯器、編譯循環和 Git 仍然可以工作。

## 無需使用 Word 即可追蹤更改

格蘭特 PI 仍然要求「追蹤變更」。在 LaTeX 領域，這通常意味著
Git 歷史記錄以及合著者的 PDF 註釋，或簡短的 Word 匯出
拒絕安裝任何東西的人。將“.tex”保留為事實來源；
請參閱[只講 Word 的合著者](/learn/collaborator-uses-word/)。

在 Oleafly 中，每個專案從第一天起就是一個 Git 儲存庫：自動檢查點
成功編譯和空閒編輯後，並排差異，一鍵式
恢復，當您需要私人遙控器時可選 GitHub。你可以分叉整個
將應用程式打包到第二個項目（完整歷史）中以嘗試冒險的削減
而不觸及提交副本。如果您使用可選的人工智慧助手，它
第一次編輯之前的檢查點，只有透過批准才能進行更改
差異。

名稱在目標或部分之後提交（`aim2-methods-cut`），以便 PI 可以略讀
無需像軟體工程師一樣閱讀差異即可了解歷史。

## 離線在醫院很有用

臨床網路會阻止隨機 SaaS 域。本地編譯器不斷寫入
可能在 EHR 會話之間。 Oleafly 在應用程式中提供了 Tectonic（和 Typst）；
包首次使用後會緩存，離線模式可以拒絕網絡
編譯器。拼字檢查和語法在散文上本地運行（它們跳過命令並
數學）。這些是醫院 IT 通常關心的限制，因此本地
研究編輯經常出現。

當您修復頁面限制時，原始程式碼旁邊的 SyncTeX 和 PDF 很重要
在 Wi-Fi 不可靠的護理站電腦上。

## 範本、頁數限制和印前檢查

NIH 風格和基礎模板涉及邊距、字體和頁碼。
幾何和字體包比巧妙的巨集更重要。編譯為 PDF 並
每次重大剪輯後檢查頁數，而不是門戶網站前一天晚上
關閉。當合適時，從圖庫中的已知模板開始；仍然匹配
目前字體、邊距和結構的 FOA（具體目標為一頁
表示一頁）。

當 PDF 必須經得起機器閱讀器的考驗（簡歷、某些機構
門戶），預檢顯示結構和解析器式擷取結果
在您提交之前。這些是您可以閱讀並採取行動的啟發式風險訊號。

## 多 PI 協作

按部分或目標擁有自己的文件。一個人擁有主“.bib”或共享
Zotero集團出口。就合著者是否編輯 TeX 或返回 PDF 註釋達成協議。
僅在政策需要時才在經批准的機構 Git 主機上使用私人遙控器
它；並非所有撥款草案都屬於公共 GitHub。

## 參考書目管理器

共享 Zotero 组导出多个 PI 可以刷新的“.bib”。導入到
项目，添加新引用时粘贴 DOI，并验证缺失的字段
在提交之前，年份不会在组装的 PDF 中显示为“[?]”：
[BibTeX 驗證器](/tools/bibtex-validator/)。 Oleafly 完成並檢查
当你写作时，根据项目参考书目的引用键，太糟糕了
`\cite` 鍵在日誌出現之前出現。

## 數位和 PHI

切勿將可識別的患者資料放入用於特定目的的圖表或標題中。
回購其他人可以克隆。使用去識別化的原理圖。仍然儲存任何東西
在與臨床資料集相同的控制下敏感，而不是緊鄰
公共方法圖。

## 這不是什麼

本地優先仍需接受 IRB 審查、資料使用協議和
去識別化。開啟託管 AI 或推送遙控器，有些位元組會離開
機器根據這些服務的政策。本地優先更改的是預設值
起草敏感敘述的路徑：您控制的資料夾、編輯器
離線運行，您可以恢復歷史記錄，而無需向供應商詢問
出口。

## 實用的啟動設定

1、建立本地專案；一旦包被快取就啟用離線編譯。
2. 除非政策和團隊就提供者達成一致，否則不要使用人工智慧。
3. 僅在經批准的主機上使用專用遙控器。
4. 章節所有權和單一書目所有者。
5. 在每次對目標和研究策略進行重大削減後進行頁數檢查。

寫得就像合規官員會詢問草稿在哪裡一樣。如果答案
是「加密筆記型電腦上的資料夾，Git 歷史記錄本地，可選私有
遠端”，你的狀況比“我們從未使用過的服務帳戶”更好
已審查。 」
