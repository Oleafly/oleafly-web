# 並ぶ複数行の方程式

複数のステップの導出は、等号を 1 列に積み重ねて表示すると最もよく見えます。これにより、行ごとに何が変更されたかを目で追跡できます。 `amsmath` パッケージは、そのための `align` 環境に加えて、整列が望ましくない場合に備えた小さな親戚ファミリーを提供します。

```latex
\usepackage{amsmath}
\begin{align}
 a &= b + c \\
 d &= e + f + g
\end{align}
```

## 読み取りを整列させる方法

各行は 1 つの方程式であり、「\\」で終わります。最後の行には何も必要ありません。 「&」は整列ポイントをマークし、すべての行の「&」は同じ列に配置されます。等号の直前に「&」を配置するのが標準的な習慣であるため、等号は重なり、左側が左側に垂れ下がります。各行には独自の方程式番号が与えられます。 [数値と方程式のポインタ](/learn/number-equations/) に示すように、番号なしに `align*` を書き込むか、個々の行に `\notag` を追加してその行だけをスキップします。

環境はそれ自体で数学を表示するため、`\[ ... \]` や `$ ... $` の中に置かないでください。これを別の数学環境にネストすると、混乱を招くエラーが発生します。

## 家族

|環境 |目的 |
| --- | --- |
| `整列` |数行、整列 |
| `整列*` |同じ、番号なし |
| 「集まる」 |複数行、中央揃え |
| `分割` |複数行の単一方程式番号 |
| `マルチライン` |長い方程式が整列せずに壊れています |

「gather」は、共有の整列点を持たないいくつかの方程式を処理します。各行を中央に配置し、各行に番号を付けます。 `split` は 1 つの数値の下に 1 つの複数行の方程式を構築し、`equation` 内に配置する必要があります。 `multline` は、整列なしで 1 つの長すぎる数式を分割し、最初の行は左に揃え、最後の行は右に揃えます。最後の 2 つは、[適合しない方程式](/learn/break-long-equations/) で詳しく説明します。

どちらを使用するかは 2 つの質問によって決まります。線は別々の方程式ですか、それとも 1 つの壊れた方程式ですか。もう 1 つは積み重ねる価値のある位置合わせポイントはありますか?分離して整列: `align`。分離して中心に置く:「集める」。単一および整列:「分割」。単一で整列されていない: `multline`。

## よくある間違い

「&」のない行もコンパイルされますが、独立して中央に配置され、何も整列しません。行上の 2 つの `&` は 2 番目の列のペアを開始し、これを `align` すると、並べて設定された方程式の 2 番目の列として読み取られます。出力に右に進む方程式がある場合は、アンパサンドを数えてください。最終行の末尾の `\\` は空の行を追加し、ブロックの下に奇数の垂直スペースとして表示されます。 [ライブ プレイグラウンド](/live/) に 3 ステップの導出を入力して、調整が行われるのを確認します。
