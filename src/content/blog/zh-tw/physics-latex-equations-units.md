物理手稿每頁包含的數學內容比大多數領域都多。那很好
直到半完成的章節因為一個標籤移動而破壞了整個編譯，
或直到每個合著者發明了不同的粗體向量約定。

這是理學碩士/博士章節、協作筆記和期刊的實用設置
仍需要兩列的提交內容。

## 從頭開始的多文件

即使是簡短的論文也可以從根文件中受益，章節包括：

```latex
\documentclass{report} % or the university class
\begin{document}
\include{chapters/intro}
\include{chapters/methods}
\include{chapters/results}
\end{document}
```

在起草時使用“\includeonly{chapters/methods}”，這樣就不會重建
三章解一個方程式。詳情：
[一個根文件，多章](/learn/split-chapter-files/)。

將數字保留在「figures/ch2/」下，並使用章節感知標籤命名方程
(`eq:ch2-hamiltonian`) 因此合併不會發生衝突。

## 單位不是文本

如果必須，請手寫 `$v = 3.0\,\mathrm{m\,s^{-1}}$`，或載入 `siunitx`
並使用 `\qty{3.0}{m.s^{-1}}`。期刊在間距和薄間距方面有所不同；挑選
一個包路徑並堅持下去。混合風格看起來就像兩位從未
遇見了。

對於值表，「siunitx」列類型對齊小數並保留單位
標題一致。不要在同一篇論文中混合使用“m/s”和“ms^{-1}”
方法中說明的原因。

## 狄拉克、向量與大膽約定

量子和凝聚態群通常需要狄拉克符號。類似的套餐
`physical` 或專用巨集用於 `\ket`、`\bra`、`\braket` 擊敗 ad-hoc
角度的組合。經典力學團體爭論粗體與箭頭
向量。在序言中記錄公約並拒絕暫時例外
章節中期。

請參閱[狄拉克符號](/learn/physical-braket/) 和[bold math](/learn/bold-math/)。

定義一次運算子 (`\DeclareMathOperator`)，因此微分運算子和
命名函數的字體不會漂移。

## 編號和交叉引用

您將引用的數字方程式；其餘的則不編號。一頁
「(1)(2)(3)...」比有兩個標記行的簡短敘述更難閱讀。
使用“\eqref”來表示方程式和穩定標籤。項目範圍的參考檢查
在顧問之前捕獲已刪除的標籤。

定理和引理（如果你使用它們）應該與以下共享一個清晰的編號方案：
部門範本的其餘部分。另請參閱
[定理與證明](/learn/theorems-proofs/)。

## 兩列日誌陷阱

APS、IOP 和類似的類別會改變浮動行為。看起來不錯的身材
「條款」中的「條款」可能會拒絕位於引用它的段落旁邊。編譯
提早對陣真正的班級，而不是提交前的周末。

有幫助的預設值：

- 兩列中的圖形寬度約為“0.45\textwidth”或“\columnwidth”
- 寬圖作為「圖*」（通常僅在頁面頂部）
- `multline` / `split` 中的長推導，或移至附錄

不要縮小方程式字體，直到無法閱讀為止。審稿人注意到。

## 圖表：圖表與原理圖

盡可能從 matplotlib/gnuplot/Root 將繪圖匯出為 PDF。光柵 PNG 是
對於照片和探測器影像，具有足夠的 dpi。原理圖可以是 TikZ 或
外部向量藝術；將原始碼保留在儲存庫中。裁剪之前的空白
`\includegraphics`。

## 當實驗室網路中斷時離線

光束線和無塵室並不以穩定的 Wi-Fi 聞名。
[Oleafly](https://github.com/Oleafly/Oleafly/releases/latest) 發布了
編譯器並將 SyncTeX、PDF 工作區和數學預覽保留在本機。每個
項目是真正的 Git，具有自動檢查點，因此錯誤的方程式編輯就是其中之一
恢復離開。當瀏覽器編輯器未載入時，仍會產生 PDF。

您可以使用 TeX Live、PDF 檢視器和 Git 組裝一個類似的離線堆疊：
手。不管怎樣，論文不應該依賴強制門戶來重新編譯
第三章。

＃＃ 合作

盡可能由作者擁有自己的章節。分享一張註釋表。運行完整文檔
每週編譯一次，因此跨章節引用會提前失敗。私有 Git 遠端
未發表的結果；僅當協作政策允許時才公開。

## 附錄與補充資料

長推導和額外的繪圖屬於附錄或單獨的補充
當期刊為兩欄且頁數有限時為 PDF。明確交叉引用
（“參見附錄B”）帶有真實標籤。不要假設裁判會打開拉鍊
沒有標題的鬆散圖形。

## 當顧問在紙上編輯時

如果可以的話，請在當天將標記套用到 TeX 原始碼。紙堆變得陳舊。
如果兩位顧問標記了衝突的符號，請更新序言表並傳送
單頁註釋 PDF，因此不必在每份草稿中都重新提出論點。

## 預提交

註釋表完整，向量和胸罩/套件一致，單位通過一個系統
（`siunitx` 或商定的手動樣式）。章節應清楚包括
`\ref`/`\eqref` 解析。編譯沒有字體的真實期刊或論文類
驚喜。圖形符合 dpi 和顏色規則；字幕是獨立的。存檔
原始碼和 PDF 以及提交版本的提交雜湊值。

物理寫作已經夠難的了。工具鏈應該保持無聊。
