長年にわたり、[Overleaf](https://www.overleaf.com/) が「LaTeX を始めるにはどうすればよいですか?」に対するデフォルトの答えでした。リンクを共有します。共著者のカーソルに注目してください。クラウドでコンパイルします。あの出入口は本物だ。マルチプレイヤーのペーパースプリントでは、それは依然として変わりません。

論文や求人市場のパッケージ、または長い単独のリライトのためにそこに住むと、無料の製品が小さく感じられ始めます。協力者は1人。時間単位で測定される履歴。 AIは1日ごとにカウントします。コンパイルタイムアウト。 Git と完全な歴史は、有料プランや退学時に失われるキャンパス ライセンスの背後にあります。このブラウザは、共有バッファを備えたブラウザとして優れています。それは完全な研究ワークスペースとして構築されたわけではありません。ATS チェック付きの再開、プロジェクトのフォーク、マルチフォーマットのエクスポート、LaTeX の隣にある Typst、オフラインの週、無制限のローカル履歴。

ここでは、Overleaf がまだオープン タブを獲得している場所、無料枠と製品範囲がなくなる場所、および一度ダウンロードした無料のデスクトップ アプリ ([Oleafly](https://github.com/Oleafly/Oleafly)) にそれらのプレーン ファイルが存在する場合に何が変わるかについて説明します。

## Overleaf で実際に購入した年数

**今でも有効な長所**

- リアルタイムのマルチユーザー編集、コメント、チャット – 「今夜は 3 人で 1 つの要約」には依然として最適なオプション
- リンクを開くだけの共著者はインストール不要
- 巨大なテンプレートギャラリーと出版社/組織のマッスルメモリー
- キャンパス内にいる間は有料機能を無料で利用できるキャンパス SSO とサイト ライセンス
- ビジュアル/コードの切り替えと、「オンライン LaTeX」の意味を現場に教える洗練された機能

**薄いままの場所 (特に無料)**

公開された個別のプラン ([Overleaf の価格設定](https://www.overleaf.com/user/subscription/plans) を再確認してください。数字は移動します):

|無料 |有料 / 組織 |
| --- | --- |
| **1 プロジェクトあたり 1 人の共同編集者** | 10 (学生/標準) または無制限 (プロ) |
| **AI は 1 日あたり 5 回使用** |より高いメーター。有料のフルアシスタント。プロ = 最大 AI |
| **基本的なコンパイル タイムアウト** | **24×** 基本タイムアウト |
| **履歴: 過去 24 時間** |全歴史 |
|統合 (Git/GitHub、Dropbox、Zotero/Mendeley など) |多くのプランでプレミアム |
| Student ~$8–10/月 · Standard ~$17–21/月 · Pro ~$33–42/月 · 大学: 営業担当者にお問い合わせください | |

したがって、無料利用枠は、主に単独でクラウドで作業する場合の本当のエディターとなります。 2 人目の共著者、先月のバージョン、より長いコンパイル、または 5 つを超える AI ナッジが必要になった瞬間に、デモに変わります。

ペイウォールに関するものではない 2 番目の薄さがあります。それは、製品が何のためにあるのかということです。 Overleaf は、ブラウザーでの共同作業用の LaTeX ドキュメントを最適化します。次のような場所としては弱いです。

- フォークと系統を含む論文、論文、ポスター、履歴書のポートフォリオを所有する
- 他のツールを使用せずに、同じプロジェクトを Word、HTML、Markdown、PowerPoint (Beamer)、EPUB にエクスポートします
- 求人アプリケーションが手元を離れる前に、ATS / アクセシビリティ プリフライトを実行します
- 1 つのライブラリと 1 つの Git モデルの下で、Typst と Markdown を LaTeX の隣に配置します
- 飛行機内やロックダウンされた病院のネットワーク上でオフラインで作業できます
- 独自のキーまたはローカル モデルで AI を使用し、すべての編集を承認差分として使用します
- 履歴をターミナルで永久に開くことができる実際の Git として扱います

これらは研究デスクの問題です。オーバーリーフはまずマルチプレイヤー向けに最適化されています。机の残りの部分は同じ重さになることはありません。

## 紙の書き込み: 両面

**裏面。** 紙の下書きを段落の途中で共有するのはスムーズです。コメントはドキュメント上にあります。 Git にまったく触れないグループにとっては、それが製品全体です。編集者は有能だ。プレビューはほとんどの記事で問題ありません。あなたは学部生のために TeX Live をインストールしなければならない人ではありません。

**論文執筆は依然として苦痛です。** プロジェクト全体のインテリジェンスは、完全なインデックスを中心に構築されたデスクトップ リサーチ エディタの隣に制限されています。章全体でのマクロの名前変更、`\cref` と複数キーの引用のライブチェック、200 ページのツリーにわたる構造ビュー、入力中の KaTeX プレビュー、`\commands` を無視する文法。無料のコンパイル タイムアウトは複雑な論文に影響を与えます。無料の履歴は 1 日後に消えます。リポジトリをフォークする方法のように、提出バージョンを実験ブランチに実際にフォークすることはできません。プロジェクトをクラウドに複製し、どれがどれであるかを覚えていればいいのです。

**Oleafly 側。** この論文はディスク上の複数ファイルのプロジェクトです。プロジェクト全体の定義への移行、参照、名前変更、ライブ ref/cite 診断 (乱雑な `\eqref` / `\cref` ファミリーを含む)、構造ビュー、実引数シェイプで定義したマクロの補完、TexLab/Tinymist (利用可能な場合)、ライブ数学プレビュー、散文のみのオフライン Harper + Hunspell。古いものを許容する SyncTeX、スプレッド、取り外し可能なウィンドウを備えた PDF ワークスペース。人間化されたエラーを使用して CPU 上で自動コンパイルします。本規模の CI (約 6,200 行) がエディターのテスト方法です。

**一般的な分割方法** ライブ共同編集は Overleaf に残ります。高度なマルチファイル オーサリング、数週間のオフライン、無制限のローカル コンパイルと履歴のローカル移動。多くの人が同じプレーン ファイルで両方を実行します。

## 機械が読み取る履歴書と書類

Overleaf は履歴書クラスをコンパイルします。うまくいかないのは、求人市場向けの PDF を製品として扱うことです。ATS を意識したテンプレート、決定論的な選択可能なテキスト、パーサー スタイルの抽出で実際に認識されるもの (名前、セクション、リスク) を表示するプリフライト パネルと、それに基づいて行動できるスコアが表示されます。 Web 履歴書ビルダーは、そのストーリーを月額料金で販売し、SaaS でレイアウトをトラップします。

Oleafly は履歴書指向のテンプレート、Preflight、および無料の Git を同梱しているため、「業界履歴書」、「学界履歴書」、および「フェローシップ」は完全な履歴を持つフォークされたプロジェクトであり、「cv_final_v4」という名前の 3 つのクラウド コピーではありません。

唯一の出力が共有用紙である場合は、このセクションをスキップしてください。同じデスクからアプリケーションを発送する場合も、ギャップにすぐに気づくでしょう。

## フォーク、クローン、リネージ

クラウド「コピープロジェクト」が存在します。研究デスクが望んでいるのは git フォークに近いものです。つまり、完全な履歴、目に見えるリネージュ、カメラ対応のツリーに触れることなく実験できることです。 Oleafly のライブラリでは、プロジェクトを本棚に置かれた本として扱います。 fork はプロジェクトとその Git 履歴をコピーします。血統がカードに表れます。 GitHub プッシュ/プルを介したクローン スタイルのワークフローは無料です。

オーバーリーフの無料履歴は 24 時間です。有料履歴の方が優れています。これは依然としてサービスのタイムラインであり、アカウントが停止した場合に保持するリポジトリではありません。

## エクスポートとハンドオフ

ジャーナルポータルは PDF を必要とし、多くの場合ソース zip を必要とします。 PI は Word を望んでいます。コース サイトでは PDF が必要です。会談にはスライドが必要だ。本にはEPUBが必要だ。 Overleaf の世界は主にクラウド LaTeX からの PDF とダウンロード ソースです。それは学術分野の多くをカバーしています。

Oleafly のエクスポート メニューはコンテキストを認識します。PDF とソースは常に zip です。 Word、HTML、Markdown、マネージド Pandoc 経由のプレーン テキスト。ビーマーからのパワーポイント。本のようなプロジェクトの場合は EPUB。画像プロジェクトの図 PNG パス。忠実度はさまざまですが (複雑な LaTeX → DOCX については正直に言ってください)、パスはアプリ内で無料です。

## AI、昼間のメーターで

オーバーリーフなし: 1 日あたり 5 回の AI 使用。有料プランでは上限が引き上げられ、アシスタントのロックが解除されます。組織は全員の AI を無効にすることができます。

Oleafly: AI はデフォルトでオフになっています。あなたの鍵かオラマ。ホストしたい場合は 9 つのプロバイダー。エージェントはログの編集、編集、読み取り、PDF テキストの確認、文献の検索を行うことができます。すべての書き込みは承認の差分です。削除には個別の確認が必要です。まずはGitチェックポイント。インラインAsk-AI。外部クライアント用の MCP。当社はトークンを販売しません。

1 日の上限とサブスクリプションのはしご、または持ち込みモデルと検査可能な編集を備えたホスト型の利便性。検査機関や治験審査委員会に説明できる信頼モデルを選択してください。

## マルチエンジンのリアリティ

Overleaf は LaTeX (およびその仲間) クラウドです。 Typst は別の場所に独自の Web ストーリーを持っています。 Markdown ノートはさらに別のツールに存在します。

Oleafly は、LaTeX (Tectonic)、Typst、Markdown を 1 つのライブラリで実行し、コンパイラーが管理され、1 つの Git モデル、1 つの PDF サーフェスが使用されます。テンプレートはエンジンごとにフィルターされます。これは製品の形状が異なります。つまり、別の LaTeX タブではなく、リサーチ デスクです。

## オフライン、プライバシー、所有権

ブラウザ: ネットワークもエディタもありません。ドラフトは規約に基づいてサーバー上に保存されます。エクスポートは、そうでない状態（アカウントへのアクセス、計画の変更、卒業）までの脱出手段です。

ローカル ワークスペース: プレーン フォルダー、実際の G​​it、オフライン編集とキャッシュされたコンパイル、オプションの厳密なオフライン モード。 Oleafly アカウントはありません。製品テレメトリはありません。パッケージ、引用、ホストされた AI、GitHub、アップデートのためのネットワーク - ご要望に応じて。

## Overleaf が依然として勝てる場所

- この時間はマルチユーザーによるタイピングとコメントをライブで配信します
- ゼロインストールの共著者
- 機関向け SSO と「誰もがすでに Overleaf を持っている」
- デフォルトでクラウド プロジェクトを開くパブリッシャーの習慣

Oleafly のライブ マルチプレイヤーはロードマップにあります。それまでは、Git をコラボレーション パスとして使用するか、ライブ スプリント用に Overleaf を使用し、ディープ ウィーク用にローカル アプリを保持します。すべてがプレーン ファイルであるため、切り替えを行ったり来たりするのは、移行プロジェクトというより退屈なインフラストラクチャになります。

## 無料のローカル ワークスペースが前進する場所

- 完全なエディターの機能 (プロジェクト インデックス、マクロ、構造、数式プレビュー、文章を意識した校正、言語サーバー)
- 古いものを許容する SyncTeX を備えた PDF ワークスペース
- 本物の Git + 無料の GitHub 同期 + 履歴付きのプロジェクト フォーク
- LaTeX の横に Typst + Markdown
- 引用の検索/貼り付け/インポート、図の作成、プリフライト、マルチフォーマットのエクスポート
- 承認の差分を備えた AI をキーの下に配置するか、完全にローカルに配置します
- 永久 $0、AGPL、一度ダウンロード

## ドラマなしで両方を試す

1. オーバーリーフ ソースを zip 圧縮します。
2. Oleafly を次からインストールします。
   [リリース ページ](https://github.com/Oleafly/Oleafly/releases/latest)。
3. インポート。一度コンパイルします。実際の紙や履歴書に 1 日分のことを書きます。
4. 今後も必要なライブ マルチプレイヤー用に Overleaf プロジェクトを保存します。

Tectonic は依然として重いパブリッシャー クラスでつまずく可能性があります。それらについては報告してください。彼らはロードマップを形作ります。ほとんどの ACM/IEEE/Elsevier スタイルの論文や論文は問題ありません。

## 終わりに

Overleaf は 10 周年を迎えました。今夜 3 人が同じ段落を必要とするとき、無料のマルチプレイヤーは依然として魔法のように感じられます。所有権、詳細な編集、フォーク、エクスポート、マルチエンジンでの作業、無制限の履歴、および制御できる AI に関しては、無料のローカル デスクがより適切です。 Oleafly を一度ダウンロードし、引き続き必要な場合はライブ スプリント用に Overleaf を保存し、機能マトリックスではなく実際の論文から決定します。
