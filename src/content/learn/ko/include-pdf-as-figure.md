# 그래픽으로서의 PDF 페이지

PDF는 LaTeX가 사용할 수 있는 최고의 그림 형식입니다. PNG 또는 JPG와 달리 PDF는 벡터 데이터를 저장하므로 어떤 확대/축소 수준에서도 선과 레이블이 선명하게 유지되고 PDF 안의 글꼴이 파일과 함께 이동합니다. Matplotlib, Inkscape 및 draw.io와 같은 도구는 모두 PDF를 내보내므로 다른 곳에서 그린 다이어그램을 문서에 바로 넣을 수 있습니다. 그러나 PDF에는 이미지에는 없는 한 가지 문제가 있습니다. PDF에는 많은 페이지가 포함될 수 있으며 LaTeX에 원하는 페이지를 알려주어야 합니다.

## 여러 페이지로 구성된 PDF에서 한 페이지 가져오기

`graphicx` 패키지의 `\includegraphics`는 일반적인 크기 조정 키와 함께 `page` 옵션을 허용합니다.

```latex
\includegraphics[page=1,width=\textwidth]{diagram.pdf}
```

여기서 `page=1`은 `diagram.pdf`의 첫 번째 페이지를 선택하고 `width=\textwidth`는 해당 페이지를 텍스트 블록의 전체 너비로 조정합니다. `page`를 생략하면 LaTeX는 자동으로 첫 번째 페이지를 사용합니다. 이는 일반적으로 원하는 것이지만 플로팅 스크립트가 여러 그림을 단일 파일에 쓸 때 놀랄 수 있습니다. 서로 다른 '페이지' 값을 사용하여 동일한 PDF를 여러 번 포함할 수 있습니다(그림 환경당 한 번씩, 각각 고유한 캡션과 레이블 포함).

일반 `그림` 환경에서 명령을 래핑하여 [다른 이미지](/learn/insert-images/)에서와 똑같이 캡션과 숫자를 얻습니다. 포함된 페이지는 자체 경계 상자로 잘립니다. 따라서 소스 PDF의 여백이 넉넉한 경우 그림이 패딩 처리된 것처럼 보입니다. 음수 간격으로 공백을 처리하는 대신 좁은 경계 상자로 다시 내보내거나 'pdfcrop'과 같은 도구를 사용하여 한 번 자릅니다.

## PDF 페이지로 전체 문서 삽입하기

때로는 수치를 전혀 원하지 않는 경우도 있습니다. 보충 PDF, 서명된 양식, 논문 부록에 게시된 설문지 등 전체 페이지를 문서에 그대로 포함시키길 원합니다. 이것이 `pdfpages` 패키지의 작업입니다:

```latex
\usepackage{pdfpages}
\includepdf[pages=-]{supplement.pdf}
```

`pages=-` 값은 모든 페이지를 의미합니다. 범위에 대해 `pages=2-5`를 작성하거나 특정 목록에 대해 `pages={1,3,7}`을 작성할 수도 있습니다. 삽입된 각 페이지는 자체 출력 페이지를 채우고 원래 레이아웃을 유지하며 문서의 페이지 번호 매기기에 참여하므로 부록을 계속해서 읽을 수 있습니다. 문서 클래스의 머리글이나 바닥글이 삽입된 페이지 위에 인쇄되고 이를 표시하지 않거나 사용자 지정하려는 경우 `pagecommand={}` 옵션을 추가하세요.

## 어떤 작업을 위한 어떤 도구

PDF 내용이 그림처럼 작동해야 하는 경우 `\includegraphics[page=...]`를 사용합니다. 즉, 내용이 떠 있고 캡션을 전달하며 텍스트에서 참조된다는 의미입니다. 페이지가 전체 크기로 독립되어 있어야 하는 경우 `\includepdf`를 사용하세요. 흔한 실수는 다이어그램에 `pdfpages`를 사용하는 것인데, 이는 `\ref`로 인용할 수 없는 캡션도 없고 참조도 없는 전체 페이지를 제공합니다. 독자가 "그림 3 참조"를 본다면 그것은 그림 환경에 속합니다.
