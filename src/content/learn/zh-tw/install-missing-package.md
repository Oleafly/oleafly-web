# 該套件沒有安裝

編譯遲早會因像「!」這樣的行而停止。 LaTeX 錯誤：找不到檔案「siunitx.sty」。該訊息的含義正如其所言：您的文件透過「\usepackage{siunitx}」請求一個包，而編譯器在您的電腦上找不到該包的「.sty」檔案。您的文件沒有任何問題。預設情況下，LaTeX 發行版並不提供每個包，修復取決於您運行的發行版。

## TeX 直播

TeX Live 是 Linux 和 macOS（如 MacTeX）上的標準發行版，包含一個名為「tlmgr」的套件管理器。從終端安裝缺少的套件：

```
tlmgr install siunitx
```

如果安裝了完整的 TeX Live（有很多 GB），則一切都已存在，並且不應出現此錯誤。它通常與較小的“基本”或“小型”安裝方案一起出現。請注意，「tlmgr」的參數是套件名稱，而不是檔案名，因此沒有「.sty」副檔名。

## MiKTeX

MiKTeX 在 Windows 上很常見，有兩種機制。它的即時安裝功能會在編譯過程中檢測到丟失的文件，並提供獲取它的功能，要么提示您，要么根據設定自動繼續。或者，打開 MiKTeX 控制台，前往「軟體包」選項卡，搜尋軟體包，然後將其安裝在那裡。如果即時安裝似乎掛起編譯，它通常正在等待隱藏在另一個視窗後面的確認對話框。

## 建構

Oleafly 捆綁的 Tectonic 引擎跳過了手動步驟：在編譯期間按需下載套件並存放在引擎的本機快取中。第一個使用「siunitx」的編譯會取得它；稍後編譯重用快取。下載依賴項時，首次運行可能需要更長的時間，並且需要網路連線。

## 安裝時沒有修復它

如果套件管理器報告不存在這樣的套件，請根據 CTAN（ctan.org 上的中央 LaTeX 套件存檔）上的套件頁面檢查拼字。最頑固的情況是由兩種不匹配造成的。首先，檔案和套件可以有不同的名稱，因為一個分發包可能包含多個「.sty」檔案。從錯誤訊息中搜尋 CTAN 尋找確切的「.sty」檔案名稱可以解決此問題。其次，該錯誤有時會命名您自己的專案中的文件，例如範本忘記包含的類別文件，並且沒有套件管理器可以提供該文件。該文件必須來自模板所在的位置。

關於舊建議的最後一點：從互聯網下載一個單獨的“.sty”檔案到您的專案資料夾中確實有效，因為 LaTeX 首先搜尋當前目錄，但它會將該套件凍結在隨機版本並將其隱藏以防止更新。更喜歡包管理器，並保留手動複製技巧，以應對截止日期前的緊急情況。
