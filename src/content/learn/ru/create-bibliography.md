# Создайте долговечный .bib

Файл `.bib` представляет собой небольшую текстовую базу данных всего, что вы можете процитировать. У каждой записи есть тип, ключ и набор полей, и один и тот же файл может годами служить каждой написанной вами статьей. Небольшая дисциплина сейчас, в том, как вы выбираете типы, заполняете поля и ключи имен, избавит вас от настоящей боли позже, когда стиль журнала внезапно потребует поля, которое вы никогда не записывали.

## Анатомия записи

```bibtex
@article{knuth84,
  author  = {Knuth, Donald E.},
  title   = {Literate Programming},
  journal = {The Computer Journal},
  year    = {1984},
  volume  = {27},
  number  = {2},
  pages   = {97--111}
}
```

Слово после `@` — это тип записи, который сообщает стилю, что это за работа и, следовательно, какие поля следует ожидать. `knuth84` — это ключ цитирования, дескриптор, который вы вводите внутри `\cite{...}`. Все остальное — поле. Поле «автор» использует форму «Последний, первый», поэтому стиль может надежно сокращать и сортировать имена, а поле «страницы» использует двойной дефис, который LaTeX печатает как тире диапазона страниц.

## Типы записей, которые вам действительно нужны

Шесть типов охватывают почти все академическое письмо. Используйте @article для журнальных статей, @inproceedings для статей на конференциях и семинарах, @book для книг, @phdthesis для диссертаций, @techreport для институциональных отчетов и многих препринтов и @misc для всего остального, включая программное обеспечение и веб-сайты. Выбор правильного типа имеет значение, поскольку стили форматируют каждый из них по-разному: для записи `@inproceedings` требуется `booktitle` (название конференции), а для `@article` — `journal`.

## Обязательные поля и почему валидаторы жалуются

У каждого типа есть обязательные поля, и отсутствие одного из них является наиболее распространенной причиной того, что запись в библиографии выглядит искаженной или вызывает предупреждение серверной части. Для @article необходимы следующие параметры: «автор», «название», «журнал» и «год»; для `@inproceedings`, `author`, `title`, `booktitle` и `year`. Отсутствие слов «год» или «автор» — классическая ошибка, поскольку стили года автора буквально не могут создать без них метку цитирования. Дополнительные поля, такие как «объем», «страницы», «doi» и «издатель», делают записи более полезными, поэтому записывайте их, пока источник находится перед вами. Вы можете проверить весь файл сразу с помощью [валидатора BibTeX](/tools/bibtex-validator/).

## Ключи, которые выдержат десятилетие

Ключи цитирования остаются навсегда. Каждый `\cite{knuth84}` в каждом черновике, заметке и слайде ссылается на эту конкретную строку, поэтому переименование ключа означает поиск каждого использования. Выберите соглашение, такое как «authorYEAR» или «authorYEARkeyword», применяйте его с первого дня и никогда не «очищайте» ключи в установленной базе данных. Если вы управляете ссылками в Zotero, плагин Better BibTeX может генерировать и закреплять для вас стабильные ключи; см. [Zotero в файл .bib](/learn/zotero-latex/). Чтобы связать файл с документом, начните с [От ключа .bib до внутритекстовой цитаты](/learn/add-citations/).
