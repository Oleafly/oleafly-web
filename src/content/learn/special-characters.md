# Characters that break the source

| Char | Code |
| --- | --- |
| % | `\%` |
| $ | `\$` |
| & | `\&` |
| # | `\#` |
| _ | `\_` |
| { } | `\{` `\}` |
| ~ | `\textasciitilde` |
| \ | `\textbackslash` |

A bare `%` comments out the rest of the line. That is the usual "my sentence disappeared" bug.
