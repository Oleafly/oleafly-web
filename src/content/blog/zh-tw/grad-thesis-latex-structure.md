這篇論文是一篇很長的論文，附有官僚主義。 LaTeX 處理長
紙好。官僚通常是2009年寫的大學班級檔案
最後在不同的 TeX Live 上進行了測試。

儘早開始建構結構，即使章節仍然是空的。在之間移動內容
最後一個月的檔案是交叉引用和圖形路徑中斷的原因。

## 接受類別文件，隔離其餘部分

將大學“.cls”（以及所需的“.bst”/標誌檔案）放入專案中。
不要重寫該類別。將您的巨集、套件和章節內容放入
您控制的文件：

```text
thesis/
  main.tex
  macros.tex
  chapters/
  figures/
  university.cls
```

如果課程在現代引擎上中斷，請分類
[無法編譯的大學類別檔案](/learn/fix-broken-template/)。
記錄論文辦公室接受的引擎（pdfLaTeX vs XeLaTeX vs
LuaLaTeX），然後再投資「fontspec」。

## 委員會期望的首要事項

摘要、奉献、致谢、目录、列表的罗马页码
数字/表格；主要章节为阿拉伯文。书籍/报告课程公开
`\frontmatter` / `\mainmatter`;基於文章的模板需要手動
`\頁碼`。指南：
[先罗马后阿拉伯](/learn/front-matter-page-numbers/)。

標題頁內容通常必須與研究所的 Word 範本相符。
準確地複製措辭。這裡的創造力讓 PDF 被拒絕
清單。

## 章節作為文件

一根多根包括：

```latex
\include{chapters/intro}
\include{chapters/background}
\include{chapters/methods}
\include{chapters/results}
\include{chapters/conclusion}
```

即使合著者為論文提供幫助，您也可以自己擁有章節。
將數字保留在「figures/chapter3/」下，以便重新排序時路徑保持穩定。
在起草完整論文時使用“\includeonly{chapters/methods}”
不是每個方程式編輯的成本：
[分割章節檔案](/learn/split-chapter-files/)。

标签在整个项目中应该是唯一的（`eq:ch3-main`，而不是`eq:main`
每個文件）。项目范围的结构视图和实时参考检查帮助
200 頁樹。

## 縮寫與符號

詞彙表包功能強大且複雜。對於許多論文來說，需要手動維護
前面的符號列表就足夠了。如果您需要自動擴展
首字母縮略詞，在本週之前預算一天學習“額外詞彙表”
提交，而不是在此期間。

在「macros.tex」中定義數學宏，並將該檔案視為共享法則。符號
介於第二章和第五章之間的內容對於迂腐的考官來說是一份禮物。

## 參考書目

整篇論文的一個“.bib”，或仔細合併的一小部分。穩定的按鍵。
軟綁定前驗證：
[BibTeX 驗證器](/tools/bibtex-validator/)。與部門風格相匹配
想要（數字、作者年份、註腳的人文風格）。請勿混合
biblatex 和經典 BibTeX 堆疊在一個序言中。

＃＃ 速度

完整的論文編譯速度很慢。圖形的草稿模式、`\includeonly` 和
TikZ 將購買時間外部化。注意事項：
[縮短等待 PDF 的時間](/learn/speed-up-compilation/)。

每周保持一次「完整編譯」儀式，這樣你仍然會看到跨章節的失敗
早。

## 備份與歷史記錄不同

Dropbox 副本是備份。 Git 是一個關於爭論如何改變的故事。
當章節編譯時提交。推送到私有 GitHub 或 GitLab 遠端。

[Oleafly](https://github.com/Oleafly/Oleafly/releases/latest) 初始化一個
每個專案的真實儲存庫，成功編譯和空閒編輯後的檢查點，
並在專案範圍的結構視圖和 SyncTeX 旁邊一鍵恢復
仍然可以跨章節文件工作。這使得這個習慣更難改掉。
你可以透過任何編輯器和細心的 Git 獲得同樣的紀律；論文
不應該依賴於記住在第十八個月執行「git init」。

## 委員會回饋循環

為不會開源的讀者匯出 PDF。追蹤問題中的評論或
共享文檔，但在 TeX 中套用編輯。當委員會成員返回
掃描標記 PDF，用日期和版本命名文件，以便您知道哪一個
引用的源代碼提交。

## 軟綁定與硬綁定清單

列印或存款之前：

- 類文件和引擎符合論文辦公室規則。
- 封面頁碼正確；如果需要，可以提供簽名頁。
- 所有`\ref`/`\cite` 解析；沒有`[?]`。
- 如有需要，列出圖表；字幕一致。
- 頁邊距和字體大小通過檢查表 PDF（列印測試頁）。
- 原始碼 + PDF + 提交哈希在存款後存檔。

## 圖表、表格和頁面“清單”

許多論文辦公室需要一份圖表清單。字幕必須是
保持一致，不要將整個方法部分轉儲到 20 行標題中。使用
清單的簡短標題和正文中較長的解釋性標題（如果
類別支援可選的短標題。

## 抄襲和先前的出版物

如果章節重新混合已發表的論文，請遵循大學的收錄規則
和合著者許可。保留每篇先前已接受的論文的 PDF 和論文
版本控制中的章節，並附有有關更改內容的註釋（符號、擴展
實驗，統一介紹）。

## 從本月開始，而不是你寫的月份

在提出大綱時建立骨架。編譯的空章節
算是進步。大多數後期恐慌是結構性債務加上頑固的債務
類文件，不是科學上的空白。儘早還清這筆債務。
