# Das Fachjargon-Glossar für die Forschung

Forscher sprechen einen Dialekt. Niemand gibt dir das Wörterbuch, also hier ist es: die Begriffe, die du in deinem ersten Jahr hören wirst, jeweils eine Zeile. Überfliegen Sie es jetzt und kehren Sie zurück, wenn Sie ein Meeting verwirrt.

## A bis Z

| Begriff | Bedeutung |
| --- | --- |
| Abstrakt | Die 150 bis 250 Wörter umfassende Zusammenfassung am Anfang einer Arbeit; oft der einzige Teil, den die Leute lesen |
| AoE | Überall auf der Erde: eine Deadline-Zeitzone, was bedeutet, dass Sie Zeit haben, bis der letzte Ort auf dem Planeten Mitternacht erreicht |
| APC | Artikelbearbeitungsgebühr, die Gebühr für Gold [Open Access](/learn/open-access-doi-explained/) Veröffentlichung |
| Artefakt | Der Code, die Daten oder Materialien hinter einem Papier, manchmal offiziell für ein Abzeichen bewertet |
| arXiv | Der große kostenlose [Preprint-Server](/learn/what-is-arxiv/), ausgesprochen „Archive“ |
| Kamerabereit | Die endgültige, vom Verlag formatierte Version einer akzeptierten Arbeit; Der Name stammt aus der Zeit, als Kameras beteiligt waren |
| Zitat | Ein formeller Hinweis auf frühere Arbeiten; auch die Einheit der akademischen Leistungspunkte |
| CFP | Call for Papers: Bekanntgabe des Themas, der Frist und der Regeln durch den Veranstaltungsort |
| Korrespondierender Autor | Der aufgeführte Autor, der alle E-Mails zum Artikel bearbeitet |
| Schreibtisch-Ablehnung | Ablehnung durch den Herausgeber oder die Vorsitzenden vor einer Überprüfung, in der Regel wegen Verstößen gegen den Geltungsbereich oder die Regeln |
| Doppelblind | Überprüfung, bei der Autoren und Gutachter voreinander verborgen sind, siehe [Peer-Review, entschlüsselt](/learn/peer-review-explained/) |
| DOI | Eine permanente ID für ein Papier, z. B. 10.1145/xxxxx; die zuverlässige Art zu zitieren |
| et al. | lateinisch „und andere“; „Smith et al.“ bedeutet Smith plus den Rest der Autorenliste |
| h-Index | Eine Forschermetrik: h Artikel mit jeweils mindestens h Zitaten; mit Skepsis behandeln |
| Impact-Faktor | Durchschnittliche aktuelle Zitierungen pro Artikel für eine Zeitschrift; ein Prestigevertreter, auch mit Skepsis behandeln |
| IRB | Institutional Review Board: die Ethikkommission, die Studien am Menschen genehmigen muss |
| Keynote | Der große eingeladene Vortrag, der einen Konferenztag eröffnet |
| Lit-Rezension | Lesen und Zusammenfassen der vorhandenen Arbeit zu einem Thema |
| LNCS |Die gelbe Tagungsreihe von Springer finden Sie unter [ACM, IEEE und Freunde](/learn/acm-ieee-and-friends/) |
| Große Überarbeitung | Urteil des Journals: Erhebliche Korrekturen erforderlich, dann erneute Überprüfung |
| Neuheit | Ob die Arbeit etwas wirklich Neues bewirkt; Lieblingsaxt der Rezensenten |
| PC | Programmkomitee: Der Gutachterpool für eine Konferenz |
| PI | Hauptforscher: der Professor, der das Labor leitet und das Stipendium innehat |
| Poster | Eine gedruckte Zusammenfassung, die Sie auf einer Konferenzsitzung daneben präsentieren |
| Vordruck | Ein vor dem Peer-Review öffentlich geteiltes Papier |
| Verfahren | Die veröffentlichte Sammlung der angenommenen Beiträge einer Konferenz |
| Widerlegung | Die kurze Antwort der Autoren auf Rezensionen vor der Entscheidung |
| Verwandte Arbeiten | Der Aufsatzbereich positioniert Ihre Arbeit im Vergleich zu früheren Aufsätzen |
| Reproduzierbarkeit | Ob andere Ihre Arbeit erneut ausführen und die gleichen Ergebnisse erzielen können |
| SIG | Spezielle Interessengruppe; ACMs Untergemeinschaften (SIGPLAN, SIGGRAPH) |
| Einzeljalousie | Rezension, bei der die Rezensenten die Autoren kennen, aber nicht umgekehrt |
| Einreichungsnummer | Die anonyme ID Ihrer Arbeit während der Überprüfung; du wirst es dir unwillkürlich merken |
| Ergänzendes Material | Zusätzliche Anhänge, Korrekturabzüge oder Videos, die zusammen mit der Arbeit eingereicht werden |
| Umfrage | Ein Aufsatz, der einen gesamten Forschungsbereich abbildet |
| Veranstaltungsort | Alle Ortsbeiträge werden veröffentlicht, siehe [Zeitschriften, Konferenzen und Workshops](/learn/journals-vs-conferences/) |
| Datensatzversion | Die offiziell veröffentlichte Kopie eines Artikels |

## So verwenden Sie dies

Merken Sie es sich nicht. Setzen Sie ein Lesezeichen und lesen Sie dann etwas Echtes: Die [Papieranatomie-Tour](/learn/paper-anatomy-tour/) zeigt diese Wörter in ihrem natürlichen Lebensraum und [was eine Forschungsarbeit eigentlich ist](/learn/what-is-a-research-paper/) verbindet die großen Wörter.
