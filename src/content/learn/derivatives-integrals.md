# Derivatives and integrals

```latex
\frac{dy}{dx}
\frac{\partial f}{\partial x}
\nabla f \nabla^2 f
f'(x) \dot{x}

\int_a^b f(x)\,dx
\iint_D f\,dA
```

Thin space `\,` before differentials is a common convention.
