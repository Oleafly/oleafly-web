# 白板照片來源

白板上的推導、課堂筆記的掃描頁、無法複製的 PDF 中的方程式：用手將數學重新輸入到 LaTeX 中既緩慢又容易出錯。現代工具可以透過照片完成大部分工作。現在轉換確實很好，但請將輸出視為草稿，而不是完成的轉錄。下面的工作流程是圍繞它而建構的。

## 從更好的照片開始

影像品質比工具選擇更能決定結果。直線拍攝而不是傾斜拍攝，因為傾斜的基線會使下標和上標變得模糊。獲得均勻的照明，而不會在板上產生眩光，並嚴格裁剪到您想要的單個方程式，因為周圍的圖表和雜散標記會變成幻覺符號。如果一張照片有三個方程，請將其裁剪為三張圖像，然後一次轉換它們；每個方程的結果始終優於一次頁面的結果。

## 使用您擁有的工具進行轉換

三種工具可以完成這項工作。專用方程式 OCR 服務在乾淨的輸入下是準確的。一般多模態模型接受聊天中的圖像並在詢問時返回 LaTeX，並且您可以回复“第二個下標應該是 j，而不是 i”以獲得正確的版本。 Oleafly 內建了映像到 LaTeX，透過您自己的 API 金鑰與您配置的任何提供者一起運行，因此片段可以從螢幕截圖轉到原始程式碼，而無需離開編輯器。請參閱[AI設定](/docs/ai-setup/)進行配置。在明確的輸入下，三種方法會收斂，這就是為什麼上面的照片建議比工具決策更重要的原因。

## 立即編譯

將輸出貼到「equation」環境中的文件中，並在執行其他操作之前進行編譯。轉換錯誤分為兩種，編譯器會為您捕獲第一種：不平衡的大括號、不匹配的“\left”和“\right”分隔符以及未知命令都會嚴重失敗，並且修復是機械的。 [缺少美元符號](/learn/missing-dollar/) 涵蓋了這些故障中最常見的情況。

## 然後校對數學

第二種錯誤編譯完美，錯誤。逐個符號地對照原始符號讀取渲染的方程，特別注意轉換可靠的地方：下標和上標，其中小字形模糊在一起，“x_i”變成“x_j”；素數和帽子，消失或遷移；相似對，例如“1”、“l”和“I”或“\rho”和“p”；以及總和和積分的界限。这些正是改变公式含义同时又使其在印刷上合理的细节。每个方程两分钟的比较就是全部成本，而且比审稿人在印刷品中发现错误的索引要便宜得多。
