多年来，[Overleaf](https://www.overleaf.com/) 一直是“我如何启动 LaTeX？”的默认答案。分享一个链接。观察合著者的光标。在云端编译。那个入口匝道是真实的。对于多人纸质冲刺来说，情况仍然如此。

一旦你住在那里是为了写论文、就业市场包或长时间的单独重写，免费产品就会开始让人感觉很小。合作者一名。历史以小时为单位。 AI按天计算。编译超时。 Git 和完整的历史记录位于付费计划或您离开时丢失的校园许可证的后面。该浏览器非常适合作为具有共享缓冲区的浏览器。它从未被构建为一个完整的研究工作区：带有 ATS 检查的简历、项目分叉、多格式导出、LaTeX 旁边的 Typst、离线几周、无限的本地历史记录。

这是 Overleaf 仍然获得开放选项卡的地方，免费套餐和产品范​​围耗尽的地方，以及当这些纯文件存在于您下载一次的免费桌面应用程序 ([Oleafly](https://github.com/Oleafly/Oleafly)) 中时发生的变化。

## Overleaf 上的几年真正买下了你

**仍然存在的优点**

- 实时多用户编辑、评论和聊天——仍然是“今晚三人一篇摘要”的最佳选择
- 合著者只需打开链接即可进行零安装
- 巨大的模板库和出版商/机构肌肉记忆
- 校园 SSO 和站点许可证，让您在校园内可以轻松使用付费功能
- 视觉/代码切换和润色，教导该领域“在线 LaTeX”的含义

**保持纤薄的地方（特别是免费的）**

已发布的个人计划（重新检查 [Overleaf 定价](https://www.overleaf.com/user/subscription/plans)；数字发生变化）：

|免费|付费/组织|
| --- | --- |
| **每个项目 1 名合作者** | 10（学生/标准）或无限制（专业）|
| **5 次人工智能使用/天** |更高米；付费完整助理； Pro = 最大 AI |
| **基本编译超时** | **24×** 基本超时 |
| **历史记录：过去 24 小时** |完整历史 |
|集成（Git/GitHub、Dropbox、Zotero/Mendeley 等）|许多计划的保费|
|学生 ~$8–10/月 · 标准 ~$17–21/月 · 专业版 ~$33–42/月 · 大学：联系销售 | |

因此，免费层是一个真正的编辑器，适用于大多数单独的云工作。当您需要第二位合著者、上个月的版本、更长的编译或超过五次人工智能推动时，它就会变成演示。

还有一个与付费专区无关的薄弱环节：产品的用途。 Overleaf 针对浏览器中的协作 LaTeX 文档进行了优化。作为一个地方，它的实力较弱：

- 拥有包含分叉和血统的论文、论文、海报和简历的组合
- 将同一项目导出到 Word、HTML、Markdown、PowerPoint (Beamer)、EPUB，无需使用其他工具
- 在工作申请交给您之前运行 ATS/辅助功能预检
- 将 Typst 和 Markdown 与 LaTeX 放在同一个库和一个 Git 模型下
- 在飞机上或锁定的医院网络上离线工作
- 将人工智能与您自己的密钥或本地模型一起使用，每次编辑都作为批准差异
- 将历史视为真正的 Git，您可以永远在终端中打开

这些都是研究台问题。背页首先针对多人游戏进行了优化；桌子的其余部分从来没有得到同样的重量。

## 论文写作：双面

**背页。** 在段落中间共享纸质草稿是毫无摩擦的。文档上有评论。对于永远不会接触 Git 的群体来说，这就是整个产品。编辑很有能力。预览对于大多数文章来说都很好。您永远不是必须为本科生安装 TeX Live 的人。

**论文写作仍然很痛苦。** 项目范围的智能受到围绕完整索引构建的桌面研究编辑器的限制：跨章节重命名宏、实时检查“\cref”和多键引用、200页树的结构视图、键入时进行 KaTeX 预览、忽略“\commands”的语法。免费编译超时会影响复杂的论文。免费历史记录一天后就会消失。您无法像分叉存储库那样真正将提交版本分叉到实验分支中 - 您在云中复制一个项目并希望您记住哪个是哪个。

**Oleafly side。** 本文是磁盘上的多文件项目。项目范围的转到定义、引用、重命名、实时引用/引用诊断（包​​括混乱的 `\eqref` / `\cref` 系列）、结构视图、使用实参形状定义的宏的完成、TexLab/Tinymist（如果可用）、实时数学预览、离线 Harper + Hunspell（仅限散文）。 PDF 工作区具有耐过时的 SyncTeX、跨页、可拆卸窗口。在您的 CPU 上自动编译，并出现人性化错误。书籍规模的 CI（约 6,200 行）是编辑器的测试方式。

**人们通常如何分割它。** 实时共同创作保留在 Overleaf 上。深度多文件创作、离线周、无限本地编译和历史记录移动本地。很多人都在同一个普通文件上执行这两种操作。

## 机器读取的简历和文档

Overleaf 将编译一个简历类。它将就业市场 PDF 视为一种产品，但效果不佳：考虑 ATS 的模板、确定性的可选文本，以及显示解析器式摘录实际看到的内容（名称、部分、风险）的预检面板，以及您可以采取行动的分数。网络简历制作者以按月付费的方式出售该故事，并在其 SaaS 中提供陷阱布局。

Oleafly 提供面向简历的模板、Preflight 和免费的 Git，因此“行业简历”、“学术简历”和“奖学金”是具有完整历史记录的分叉项目，而不是名为“cv_final_v4”的三个云副本。

如果您唯一的输出是共享论文，请跳过本节。如果您也从同一个办公桌发送申请，您很快就会注意到差距。

## 分叉、克隆、谱系

云“复制项目”存在。研究部门想要的是更接近 git 分支：完整的历史、可见的血统、无需接触相机就绪树即可进行实验。 Oleafly 的图书馆将项目视为书架上的书籍； fork 复制项目及其 Git 历史记录；血统显示在卡片上。通过 GitHub 推/拉的克隆式工作流程是免费的。

背面的免费历史记录是 24 小时。付费历史记录更好；它仍然是一个服务时间表，而不是帐户死亡时您保留的存储库。

## 导出和移交

期刊门户网站需要 PDF，通常还需要源 zip 文件。 PI 想要 Word。课程网站需要 PDF。会谈需要幻灯片。书籍需要 EPUB。 Overleaf 的世界主要是来自云 LaTeX 的 PDF 加上下载源。这涵盖了很多学术界。

Oleafly 的导出菜单具有上下文感知功能：始终为 PDF 和源 zip； Word、HTML、Markdown、通过托管 Pandoc 的纯文本；来自 Beamer 的 PowerPoint； EPUB 用于书籍类项目；图图像项目的 PNG 路径。保真度各不相同（老实说，复杂的 LaTeX → DOCX），但路径是在应用程序内且免费的。

## AI，在白天使用仪表

背面免费：每天使用 5 次 AI。付费计划提高了上限并解锁了助手。组织可以为所有人禁用人工智能。

Oleafly：AI 默认关闭。你的钥匙或奥拉马。当您需要托管时有九个提供商。 Agent可以编辑、编译、阅读日志、检查PDF文本、搜索文献。每次写入都是一个批准差异；删除需要明确确认；首先是 Git 检查点。内联询问-AI。适用于外部客户的 MCP。我们不向您出售代币。

通过每日上限和订阅阶梯提供便利的托管服务，或者自带模型和可检查的编辑。选择您可以向实验室或 IRB 解释的信任模型。

## 多引擎现实

Overleaf 是一个 LaTeX（和朋友）云。 Typst 在其他地方也有自己的网络故事。 Markdown 笔记存在于另一个工具中。

Oleafly 在一个库中运行 LaTeX (Tectonic)、Typst 和 Markdown，并管理编译器、一个 Git 模型、一个 PDF 界面。模板按引擎过滤。这是一种不同的产品形状——研究台，而不是另一个 LaTeX 选项卡。

## 离线、隐私、所有权

浏览器：没有网络，没有编辑器。草稿按照他们的条款保存在他们的服务器上。导出是您的逃生口，直到它不再（帐户访问、计划更改、毕业）。

本地工作区：普通文件夹、真正的 Git、离线编辑和缓存编译、可选的严格离线模式。没有 Oleafly 帐户。无产品遥测。包、引文、托管人工智能、GitHub、更新网络——只要您提出要求。
