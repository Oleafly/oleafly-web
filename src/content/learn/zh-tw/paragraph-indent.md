# 段落之間縮排或空格

版式有兩種標準方法來顯示一個段落的結束位置和下一個段落的開始位置：縮排每個新段落的第一行，或在段落之間留出垂直空間而不縮排。書籍和期刊幾乎總是使用第一個。網頁和商業文件使用第二種。 LaTeX 預設遵循書籍慣例，縮排除章節標題後的第一個段落之外的每個段落，段落之間沒有多餘的空格。如果您想要其他樣式，請變更兩個長度。

## 控制一切的兩個長度

```latex
\setlength{\parindent}{0pt}
\setlength{\parskip}{0.8em} % space between paragraphs instead
```

`\parindent` 是首行縮排的寬度。使用“\setlength”將其設為“0pt”可以刪除所有地方的縮排。 `\parskip` 是段落之間插入的垂直空間，通常為零（加上一點拉伸）；將其設定為「0.8em」會產生可見的間隙，比完整的空行略小。 「em」單位隨字體大小縮放，如果您稍後變更[字體大小](/learn/font-size/)，它會保持間距成比例。將這兩行放在序言中，整個文件遵循區塊樣式。

如果您走這條路，請注意，簡單的“\parskip”更改也會拉伸節標題、列表項目和目錄周圍的空間，因為它們也是從段落構建的。對於比簡短註釋更長的內容，請載入 `parskip` 套件 (`\usepackage{parskip}`) 套用相同的樣式，同時為您修補這些副作用。

## 抑制單一縮排

單一段落：將 `\noindent` 放在它的最開頭，第一個單字之前。這只會抑制該段落的縮進，並且當以下文字是同一想法的延續而不是新段落時，在顯示的方程式、程式碼清單或表格之後非常方便。相反的情況，即在 LaTeX 省略縮排的情況下強制縮排（例如標題後的第一段），由小型“indentfirst”包處理，而不是手動修復。

當我們在這裡時：LaTeX 中的新段落是由原始程式碼中的空白行創建的，而不是由「\\」創建的。 `\\` 指令是同一段落內的換行符，使用它來偽造段落間距會產生未滿的警告和不均勻的間隙。 [段落和換行符課程](/learn/paragraphs-newlines/) 完整地涵蓋了這一區別。

## 選擇一種風格並保留它

選擇縮排**或** parskip 樣式並保持一致。這兩種約定是替代方案，而不是層次：縮排的段落之間有很大的間隙，看起來像草稿，零縮排和零空間讓讀者根本無法看到段落從哪裡開始。如果您正在為期刊或會議撰寫文章，請不要更改長度；類文件已經實現了發布者的選擇，並且您的覆蓋將是佈局編輯器恢復的第一件事。
