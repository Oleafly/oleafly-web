# pt, em, 텍스트 너비

LaTeX의 거의 모든 레이아웃 명령은 길이(세로 공간, 이미지 너비, 여백, 규칙 두께)를 취합니다. 길이는 숫자에 단위를 더한 값이며, 단위 선택에 따라 글꼴 크기나 페이지 기하학이 변경될 때 레이아웃이 적용되는지, 아니면 적용되는 날짜가 바뀌는지가 결정됩니다.

| 단위 | 의미 |
| --- | --- |
| `pt` | 포인트(베이스) |
| '그들' | 글꼴 기준 너비 |
| `예` | 글꼴 기준 높이 |
| `cm` / `mm` / `in` | 절대 |
| `\textwidth` | 텍스트 블록의 너비 |
| `\선폭` | 현재 열/미니페이지의 너비 |

## 절대 및 상대 단위

`pt`는 TeX의 기본 단위인 프린터의 포인트입니다. 글꼴 크기와 많은 내부 기본값은 포인트로 표시되며 TeX 계산에서 1인치는 72.27포인트입니다. 'cm', 'mm' 및 'in'은 친숙한 절대 단위로, 요구사항이 1인치 마진과 같이 실제로 물리적인 경우에 적합합니다.

`em` 및 `ex`는 현재 글꼴에 따라 크기가 조정됩니다. em은 대략 너비로 표현된 글꼴 크기이고 ex는 소문자 x의 높이 정도입니다. 그들의 장점은 비례입니다. 하드 코딩된 `\vspace{12pt}`가 너무 빡빡하거나 너무 느슨해지는 문서가 10pt에서 12pt 유형으로 이동하는 경우 `\vspace{1em}`는 시각적 일관성을 유지합니다.

## 문서에서 제공하는 길이

`\textwidth`는 페이지 텍스트 블록의 너비입니다. `\linewidth`는 현재 컨테이너의 너비입니다. 이는 일반 텍스트의 `\textwidth`와 같지만 미니페이지, 목록 또는 열 내부에서는 좁아집니다. 앞에 있는 소수점은 둘 중 하나의 크기를 조정하며 이는 숫자 크기를 지정하는 표준 방법입니다.

```latex
\vspace{1em}
\includegraphics[width=0.5\textwidth]{f.pdf}
```

첫 번째 줄은 수직 공간의 한 em을 삽입합니다. 두 번째는 이미지를 텍스트 블록 너비의 절반으로 설정하므로 여백이 변경되면 그림의 크기가 조정되고 여백이 넘치지 않습니다. 미니페이지나 2열 레이아웃에서는 `0.5\linewidth`를 선호합니다. `\textwidth`가 실제 공간보다 넓기 때문입니다.

길이도 설정 가능합니다. `\setlength{\parindent}{0pt}`는 단락 들여쓰기를 제거하고 동일한 명령으로 대부분의 명명된 레이아웃 길이를 조정합니다.

일반적인 실수는 크기를 센티미터 단위로 표시하는 것입니다. 문서 클래스, 용지 크기 또는 여백이 변경될 때까지 작동하며 모든 수치를 수동으로 다시 조정해야 합니다. `\textwidth` 또는 `\linewidth`의 분수로 표현된 너비는 이러한 모든 변경 사항에 영향을 받지 않고 유지되므로 템플릿에서는 이를 거의 독점적으로 사용합니다.
