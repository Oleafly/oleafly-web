化學家通常出於以下兩個原因之一出現在 LaTeX 中：該雜誌堅持認為，
或者合作者已經這樣做了。不管怎樣，痛點看起來
熟悉：反應方案、同位素標示、條件表和
充滿期刊和專利的參考書目。

本指南涵蓋本科生報告到首次期刊提交。它將
不能取代複雜天然產品的 ChemDraw。它將保留手稿
以及與編譯器戰鬥的實驗部分。

## 與 mhchem 的反應

`mhchem` 是公式和反應的通常答案：

```latex
\usepackage[version=4]{mhchem}
\ce{CO2 + C -> 2CO}
\ce{^{14}C}
\ce{H2SO4}
\ce{Fe^2+ <=>[\ce{H2O}] Fe^3+}
```

固定版本 4，因此語法不會在合著者之間或 Overleaf 之間發生變化
和本地 TeX 安裝。較長的演練：
[化學式](/學習/化學符號/)。

箭頭上方和下方試劑的多步驟方案需要超過
內聯`\ce`。 mhchem 處理公式；佈局通常需要日誌方案
環境或外部人物。不要死記硬背二十步全合成
進入一系列線上化學生產線。

## 結構：chemfig 或外部圖紙

`chemfig` 在純 TeX 中繪製簡單的結構並保留所有內容
向量局部。複雜的天然產品幾乎總是比 ChemDraw 好，
Marvin 或類似的人，匯出為 PDF，然後匯出為“\includegraphics”。更喜歡向量 PDF
在 PNG 螢幕截圖上，使黏合線在列印和兩列中保持清晰
佈局。

按化合物 ID 命名檔案 (`cmpd-12.pdf`)。保留可編輯的 ChemDraw 原始碼
即使 git 只保存論文中的 PDF，也可以在實驗室檔案中保存。

## 實驗部分與長表

條件表（溫度、溶劑、產率、催化劑負載量）效果良好
對於數字列，使用 `booktabs` 和通常的 `siunitx` ：

```latex
\usepackage{booktabs,siunitx}
\begin{tabular}{l S S}
  \toprule
  {Entry} & {T / \degreeCelsius} & {Yield / \percent} \\
  \midrule
  1 & 25 & 72 \\
  \bottomrule
\end{tabular}
```

如果表格的運行時間比頁面長，請在截止日期之前切換到“longtable”
一周，不是在期刊抱怨 7pt 字體之後。標題應該說
「產量」意味著什麼（分離、NMR、GC），因此讀者不會猜測。

## 單位和光譜片段

選擇單位樣式並堅持使用：`siunitx`，或手動`\mathrm`（如果群組）
已經同意了。實驗部分的 NMR 和 HRMS 片段是
通常是帶有仔細間距的純文字。不要發明脆弱的宏語言
除非實驗室已經共享一篇論文，否則將處於論文中間。

按照筆記本的方式報告有效數字。 LaTeX 會愉快地列印
如果您輸入錯誤的精度。

## 方案與數字

許多化學期刊將方案（反應）與圖形（圖、
ORTEP，光譜）。使用日誌類別附帶的環境（`scheme`，
`figure`)，因此編號與生產相符。與 `\ref` 交叉引用且穩定
標籤（`sch:reduction`、`fig:ortep-1`）。

## 草稿的安全性

未發布的路線和行業合作夥伴將純雲端編輯器變成了
政策問題，而不僅僅是便利問題。保留`.tex`和数字
因為磁碟上的普通檔案用 Git 來說是無聊的。

[Oleafly](https://github.com/Oleafly/Oleafly/releases/latest) 是本地
研究編輯：捆綁編譯器、專案範圍的引用與引用檢查、離線
僅散文上的拼字和文法（因此 `\ce` 和引用鍵不會被標記為
「打字錯誤」）、真正的 Git 檢查點、僅透過批准進行編輯的可選 AI
差異。沒有帳戶。該草案不需要第三方編輯器即可存在。
網路用於套件、引文查找或人工智慧（如果您打開它們）。

## 引用正確的主要文獻

化學參考書目非常依賴期刊和專利。從 Zotero 匯出
或 EndNote 到具有穩定金鑰的「.bib」中，然後在先前驗證缺失的字段
提交：[BibTeX 驗證器](/tools/bibtex-validator/)。空參考書目
幾乎總是路徑或後端錯誤，而不是丟失引用。

期刊風格不同（ACS、RSC、Springer）。使用參考書目風格
模板附帶。不要將數字和作者年份黏在一起
序言。

＃＃ 合作

盡可能按人擁有部分。一個人擁有“.bib”。同意
mhchem 版本和結構匯出格式預先提供。當多次實驗
各個部分並行增長，每週編譯完整的 PDF，以便集成
驚喜很早就出現了。

## 預提交清單

值得最後通過：

- mhchem 版本已固定；公式編譯時不會發出任何警告
  忽略。
- 結構盡可能是向量；複合 ID 跨文本、方案、
  和SI。
- 表格採用三規則樣式；單位一致；標題中定義的產量
  或筆記。
- 方案/圖編號與期刊類別相符。
- `.bib` 已驗證；風格與範本相符。
- 敏感路由保留在本機資料夾中，並具有與實驗室相符的存取控制
  政策。

## SI 和期刊清單

許多化學期刊都會發布作者清單（圖形解析度、TOC
圖形尺寸、化合物表徵）。繪畫前先瀏覽 PDF
計劃。對於管理員來說，錯誤的 TOC 圖形縱橫比是一個愚蠢的原因
拒絕。

## 支援訊息

SI 通常有自己的模板或標題規則。保持 SI 來源相同
repo 作為主要論文，檔案名稱清晰。當期刊要求完整時
表徵，檢查正文中的每個化合物數字實際上
出現在 SI 中。

化學格式很繁瑣，因為物件很密集。獲取反應
右边的表格和实验部分读起来像是仔细的工作，而不是
從筆記本 PDF 貼上。
