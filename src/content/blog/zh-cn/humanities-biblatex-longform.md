人文学科手稿既关心引文形式，也关心论点。一个数字
IEEE 风格在这里是错误的；脚注、作者标题和档案来源是
规范。一旦你拥有的不仅仅是一篇研讨会论文和一篇论文，LaTeX 就值得学习。
参考书目中的几本书。

本指南适用于堆叠论文章节或起草长文章的学生
带有真实的脚注。如果您只需要三个 MLA 条目，您可以提前停止。

## 更喜欢 biblatex 的灵活性

`biblatex` 比经典的更好地处理脚注、详细样式和速记
适用于大多数人文学科工作流程的 BibTeX：

```latex
\usepackage[backend=biber,style=verbose-ibid]{biblatex}
\addbibresource{sources.bib}
```

常见的替代方案包括“authortitle”、“verbose”、特定于期刊的样式、
或您所在部门的任何规定。先匹配手册，再挑选
最接近的 biblatex 风格。背景：
[BibTeX 或 biblatex](/learn/bibtex-vs-biblatex/)。

运行 **biber** （或您的风格需要的后端），而不仅仅是 pdflatex。空
参考书目几乎总是后端或路径错误。验证条目
提交之前：[BibTeX 验证器](/tools/bibtex-validator/)。

## 档案和网络资源

信件、手稿和网站需要记录“@article”条目的字段
不关心：

- `@unpublished` 或 biblatex `@online` 用于带有 `urldate` 的网络资源
- 手稿的档案位置、馆藏、作品集
- 稳定的按键，两年后你仍能理解

不完整的条目会悄然失败，直到参考书目看起来稀疏为止。更喜欢一个
“.bib”（或项目的一小部分）在复制粘贴脚注文本上漂移
与引用的作品不同步。

## 脚注与尾注

许多人文学科风格都需要脚注。 `biblatex` 详细样式和
`\footcite` / 自动脚注引用涵盖了很多内容。如果
部门需要尾注，请尽早配置。转换三章
投稿那周的脚注引用情况很惨。

保持实质性旁白简短。如果脚注是一个完整的段落，询问是否
它属于正文。读者可以略读。

## 章节和重要版本

书籍长度的项目需要“书籍”、“回忆录”或大学论文课程
每章“\include”：

```latex
\include{chapters/ch1-intro}
\include{chapters/ch2-archive}
```

对其他章节的交叉引用应使用 `\ref` / `\cref`，而不是硬编码
当您重新排序时，“参见第 4 章”字符串会消失。列出的结构视图
跨文件的标题有助于撰写 200 页的草稿。编译也是如此
当你修改一章时`\includeonly`。

重要版本和平行文本有专门的包。不要发明一个
使用原始迷你页进行布局，直到您检查是否有维护类
对于您的语言来说已经存在。

## 引文和语言

使用适合论文语言的引号（`csquotes` 有助于
嵌套引号和语言感知标记）。块引用长于几行
应使用引用环境，而不是插入的手动缩进
两列布局或边距发生变化时。

对于多语言项目，XeLaTeX 或 LuaLaTeX 带有 `fontspec` 和一种语言
与堆叠 20 世纪 90 年代的“inputenc”黑客相比，安装 package 没有那么痛苦。选择字体
在你用无法使用的字体写第三章之前覆盖你需要的脚本
渲染它们。

## 图像、地图和合理使用说明

地图和手稿照片通常是外部 PDF/PNG，而不是 TikZ。
带有来源和权限状态的标题。将高分辨率母版保留在室外
git 历史（如果它们很大的话）；将压缩后的数据提交到论文中
实际使用，并在自述文件中注明大师居住的地方。

## 多年笔记的本地所有权

论文是一棵多年的文件树。仅将其保留在浏览器项目中
当学生转学或失去访问权限时，与一个帐户绑定是一种风险
毕业后。

普通文件夹加 Git，本地编译，老化效果更好。
[Oleafly](https://github.com/Oleafly/Oleafly/releases/latest) 的目标是
一种长文档。您可以获得跨章节、项目范围的结构视图
参考文献和引用，散文的离线拼写和语法（它跳过引用键），以及
无需帐户即可实现真正的 Git 检查点。您仍然可以在以下位置打开相同的文件
任何其他编辑器。所有权是重点。

## 委员会持续存在的工作流程

第一年根据手册冻结引文风格，并保留一个
具有稳定密钥的书目数据库。将章节文件置于版本控制之下
带有私人遥控器。前言（摘要、致谢、目录）应
遵循罗马/阿拉伯页面的大学课程规则。编译完整的 PDF
即使您使用“\includeonly”起草，也会每月一次，因此跨章节参考不会
最后给你一个惊喜。

## 预提交

- Biber/bibtex 运行干净；没有“[?]”引用。
- 脚注风格与部门相匹配。
- 章节交叉引用在重新排序后更新。
- 字体嵌入；页边距与论文办公室清单相符。
- 源文件和 PDF 均已存档，而不仅仅是上传门户收据。

## 索引和回溯内容

书籍类项目有时需要索引（`imakeidx` 和朋友）。预算
真正的索引传递时间；自动标记每个大写单词产生
垃圾。转录附录应使用清晰的编号，以确保主要内容
章节可以`\ref`。

## 委员会草稿与存款 PDF

编号行草稿或宽边距可以帮助标记，但存款 PDF 必须
与论文办公室样本相匹配。保留类别选项或单独的“草稿”标志
这样您就无需在存款早上手动编辑保证金。

尽早获得引文引擎。论证更值得关注
比上周的书目之争更重要。
