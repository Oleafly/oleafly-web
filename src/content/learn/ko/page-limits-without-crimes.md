# 인쇄상의 범죄가 없는 페이지 제한

귀하의 논문은 10.4 페이지입니다. 제한은 10개입니다. 다음 한 시간 안에 무슨 일이 일어나느냐에 따라 종이를 고칠지, 아니면 서류가 거부될 정도로 형식 위반을 범할지가 결정됩니다.

## 형식이 아닌 내용을 압축하세요

이 목록을 순서대로 작업하세요. 각 단계는 템플릿이 아닌 용지를 변경하므로 형식 검사기에 표시되지 않습니다.

1. **먼저 산문을 탄탄하게 하세요.** 오버플로의 절반 페이지는 일반적으로 장황한 관련 작업 섹션과 세 개의 중복되는 전환 문장입니다. 단어를 자르면 종이가 좋아집니다. 공백을 자르는 것은 그렇지 않습니다.
2. **과부 사냥.** 마지막 줄에 한두 단어가 포함된 단락은 한 줄 전체를 낭비합니다. 해당 단락의 한 문장을 다시 작성하면 다시 사용할 수 있습니다.
3. **그림의 크기를 정직하게 조정하세요.** 많은 그림의 내부 여백이 엄청납니다. 그림 자체의 공백을 자르거나, 읽을 수 있는 경우 2열 그림을 한 열에 놓습니다.
4. **슬림한 테이블.** 수직선이 없는 `booktabs` 테이블은 더 작고 보기에도 좋습니다. [아름다운 테이블](/learn/booktabs-beautiful/)을 참조하세요. 축약된 열 헤더는 실제 너비를 보장합니다.
5. **벡터 그림을 사용합니다.** PDF 플롯은 깔끔하게 축소되므로 가독성이 떨어지기 전에 픽셀화된 PNG보다 더 축소할 수 있습니다. 퍼지 래스터 그림에는 고유한 문제가 있습니다. [PDF의 퍼지 글꼴](/learn/fuzzy-font-pdf/)을 참조하세요.
6. **장소에서 허용하는 경우 자료를 부록이나 보충 자료로 옮깁니다**. 증명, 추가 절제, 하이퍼파라미터 테이블은 전형적인 오버플로 후보입니다. 부록이 한도에 포함되는지 확인하세요. 많은 장소에서는 이를 제외하고 일부는 그렇지 않습니다.

## 범죄

이는 용지 대신 템플릿을 변경합니다. 프로그램 위원회는 사람들이 시도하기 때문에 자동화된 형식 검사기를 실행합니다.

| 범죄 | 어떻게 잡히는가 |
|---|---|
| `\vspace{-8pt}`가 곳곳에 뿌려졌습니다 | 눈에 띄게 비좁은 간격, 클래스 기본값과 다름 |
| `\usepackage[margin=...]{기하학}` | 자동화된 마진 측정 |
| `\baselinestretch` 또는 글꼴 크기 축소 | 열당 줄 수, 글꼴 크기 조사 |
| 본문이나 캡션의 `\small` 또는 `\footnotesize` | 글꼴 크기 프로브, 리뷰어 눈알 |
| 부정 `\itemsep`, 분쇄된 목록 | 비좁은 모습, 체커 휴리스틱 |
| 내부 편집으로 클래스 파일 이름 바꾸기 | 공식 클래스에 대한 체크섬 |

## 공연장에서 실제로 확인하는 이유

페이지 제한은 공정성 계약입니다. 모든 저자는 동일한 공간을 가지며 모든 리뷰어는 제한된 양을 읽기로 약속합니다. 10페이지까지 속이는 논문은 실제로는 정직한 10페이지 논문과 경쟁하는 11페이지 논문입니다. 그렇기 때문에 위반은 스타일 문제가 아닌 무결성 문제로 처리됩니다. 리뷰 없이 거절당하는 곳이 많아, "하지만 내용은 좋았다"는 어필은 없습니다.

## 정직한 최후의 수단

산문을 강화하고, 플로트를 줄이고, 교정본을 부록으로 옮긴 후에도 여전히 끝났다면 결과를 잘라내세요. 고통스럽기는 하지만, 어쨌든 벼락치기보다 집중된 10페이지 분량의 논문 리뷰가 더 좋습니다. 리뷰어들은 밀도감을 느낄 수 있으며, 더 긴 형식의 [장소 선택](/learn/choose-your-venue/)은 항상 다음 제출을 위한 옵션입니다.
