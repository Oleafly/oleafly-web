物理手稿每页包含的数学内容比大多数领域都多。那很好
直到半完成的章节因为一个标签移动而破坏了整个编译，
或者直到每个合著者发明了不同的粗体矢量约定。

这是理学硕士/博士章节、协作笔记和期刊的实用设置
仍需要两列的提交内容。

## 从头开始​​的多文件

即使是简短的论文也可以从根文件中受益，章节包括：

```latex
\documentclass{report} % or the university class
\begin{document}
\include{chapters/intro}
\include{chapters/methods}
\include{chapters/results}
\end{document}
```

在起草时使用“\includeonly{chapters/methods}”，这样就不会重建
三章解一个方程。详情：
[一个根文件，多个章节](/learn/split-chapter-files/)。

将数字保留在“figures/ch2/”下，并使用章节感知标签命名方程
(`eq:ch2-hamiltonian`) 因此合并不会发生冲突。

## 单位不是文本

如果必须，请手写 `$v = 3.0\,\mathrm{m\,s^{-1}}$`，或者加载 `siunitx`
并使用 `\qty{3.0}{m.s^{-1}}`。期刊在间距和薄间距方面有所不同；挑选
一个包路径并坚持下去。混合风格看起来就像两位从未
遇见了。

对于值表，“siunitx”列类型对齐小数并保留单位
标题一致。不要在同一篇论文中混合使用“m/s”和“ms^{-1}”
方法中说明的原因。

## 狄拉克、向量和大胆约定

量子和凝聚态群通常需要狄拉克符号。类似的套餐
`physical` 或专用宏用于 `\ket`、`\bra`、`\braket` 击败 ad-hoc
角度的组合。经典力学团体争论粗体与箭头
向量。在序言中记录公约并拒绝临时例外
章节中期。

请参阅[狄拉克符号](/learn/physical-braket/) 和[bold math](/learn/bold-math/)。

定义一次运算符 (`\DeclareMathOperator`)，因此微分运算符和
命名函数的字体不会漂移。

## 编号和交叉引用

您将引用的数字方程；其余的则不编号。一页
“(1)(2)(3)...”比带有两个标记行的简短叙述更难阅读。
使用“\eqref”来表示方程和稳定标签。项目范围的参考检查
在顾问之前捕获已删除的标签。

定理和引理（如果你使用它们）应该与以下共享一个清晰的编号方案：
部门模板的其余部分。另请参阅
[定理和证明](/learn/theorems-proofs/)。

## 两列日志陷阱

APS、IOP 和类似的类会更改浮动行为。看起来不错的身材
“条款”中的“条款”可能会拒绝位于引用它的段落旁边。编译
提早对阵真正的班级，而不是提交前的周末。

有帮助的默认值：

- 两列中的图形宽度约为“0.45\textwidth”或“\columnwidth”
- 宽图作为“图*”（通常仅在页面顶部）
- `multline` / `split` 中的长推导，或移至附录

不要缩小方程式字体，直到无法阅读为止。审稿人注意到。

## 图表：图表和原理图

尽可能从 matplotlib/gnuplot/Root 将绘图导出为 PDF。光栅 PNG 是
对于照片和探测器图像，具有足够的 dpi。原理图可以是 TikZ 或
外部矢量艺术；将源代码保留在存储库中。裁剪之前的空白
`\includegraphics`。

## 当实验室网络中断时离线

光束线和洁净室并不以稳定的 Wi-Fi 闻名。
[Oleafly](https://github.com/Oleafly/Oleafly/releases/latest) 发布了
编译器并将 SyncTeX、PDF 工作区和数学预览保留在本地。每个
项目是真正的 Git，具有自动检查点，因此错误的方程式编辑就是其中之一
恢复离开。当浏览器编辑器未加载时，仍会生成 PDF。

您可以使用 TeX Live、PDF 查看器和 Git 组装一个类似的离线堆栈：
手。不管怎样，论文不应该依赖于强制门户来重新编译
第三章。

＃＃ 合作

尽可能由作者拥有自己的章节。分享一张注释表。运行完整文档
每周编译一次，因此跨章节引用会提前失败。私有 Git 远程
未发表的结果；仅当协作政策允许时才公开。

## 附录和补充材料

长推导和额外的绘图属于附录或单独的补充
当期刊为两栏且页数有限时为 PDF。明确交叉引用
（“参见附录B”）带有真实标签。不要假设裁判会打开拉链
没有标题的松散图形。

## 当顾问在纸上编辑时

如果可以的话，请在当天将标记应用到 TeX 源代码。纸堆变得陈旧。
如果两个顾问标记了冲突的符号，请更新序言表并发送
单页注释 PDF，因此不必在每份草稿中都重新提出论点。

## 预提交

注释表完整，矢量和胸罩/套件一致，单位通过一个系统
（`siunitx` 或商定的手动样式）。章节应清晰地包括
`\ref`/`\eqref` 解析。编译没有字体的真实期刊或论文类
惊喜。图形符合 dpi 和颜色规则；字幕是独立的。存档
源代码和 PDF 以及提交版本的提交哈希值。

物理写作已经够难的了。工具链应该保持无聊。
