# リサーチ執筆ツールボックスの昔と今

どの世代の研究者も、そのツールは永続的なものであると考えています。決してそうではありません。論文がどのように書かれたのか、そして現在のツールボックスがどのようになっているかを簡単に紹介します。これにより、意図的にツールボックスを選ぶことができます。

## 以前の時間

1980 年代に入ると、論文は **タイプライター**でタイプされ、方程式が手書きで入力され、ジャーナルに郵送されていました。その後、ワード プロセッサが登場しました。数十年にわたる **Word テンプレート**には、脆弱な番号付け、画像として貼り付けられた数式、段落が移動すると爆発する図のレイアウトが含まれていました。コラボレーションとは、**ファイルを電子メールでやり取りする**ことを意味します。「paper_final_v3_REALLY_FINAL_jw_edits.docx」は冗談ではなく、歴史です。 LaTeX はこれらすべてを通じて存在していました ([TeX の 45 年](/learn/history-of-tex-latex/) を参照) が、それをターミナルでコンパイルし、電子メールでも共有しました。

## 今日のツールボックス

|ツール |カテゴリー |何が得意なのか |
| --- | --- | --- |
|裏紙 |クラウド LaTeX エディタ |ブラウザーでのリアルタイム共同編集、セットアップ不要 |
| TeXstudio / TeXmaker |ローカル LaTeX IDE |クラシックなデスクトップ編集、無料 |
| VS コード + LaTeX ワークショップ |ローカルIDE |すでに VS Code を使用している場合は強力です |
|オレフライ |ローカルファーストのワークスペース | LaTeX、Typst、Markdown とコンパイラがバンドル |
|ゾテロ |リファレンスマネージャー |引用の収集、整理、エクスポート |
| Google スカラー |発見 |論文の検索と引用の追跡 |
| arXiv |ディスカバリー + プレプリント |最新作を無料で読むには、[プレプリントの世界](/learn/what-is-arxiv/) を参照してください。
|ティプスト |新しい写植システム | .tex を必要とする会場がない場合でも、高速で最新のドキュメントを作成できます。

**ディスカバリー** ツールが論文を検索し、**リファレンス マネージャー** が見つけたものを整理し、**編集者** がすべてを PDF に変換します。最終的にはそれぞれ 1 つずつになります。

## クラウドとローカル、正直に言って

**Overleaf** はインストールを完全に削除することで LaTeX を主流にしました。そのリアルタイムの共同編集はまさにそのキラー機能です。共著者が同じ瞬間に同じ文書を入力したい場合は、Overleaf のようなクラウド ツールの方が優れています。

**ローカル ファースト** ツールは取引を逆転します。ファイルはプレーン ファイルとしてマシン上に存在し、電車の中でも病院のファイアウォールの内側でも作業できます。サブスクリプションやサーバーの生存には何も依存しません。また、バージョン履歴は独自のタイムラインではなく本物の [Git](/learn/oleafly-workflow/) です。ローカル LaTeX の古典的な問題は、数ギガバイトの TeX ディストリビューションをインストールすることでした。それが変わった部分です。

## Oleafly が適している場所

Oleafly は、無料のオープンソースのローカルファーストのデスクトップ ワークスペースです。 LaTeX と Typst 用のコンパイラがバンドルされているため、ディストリビューションをインストールする必要はありません。引用は [DOI または arXiv ID](/learn/open-access-doi-explained/) によって取得でき、プロジェクトは正直な歴史を持つ Git リポジトリであり、会場テンプレートが組み込まれており、オプションの AI アシスタントが必要なときに役立ちます。目標は、ローカル パスをクラウド パスと同じくらい低摩擦にすることです。公平を期すために言うと、ライブでの同時共同編集には、依然として Overleaf が強力な選択肢となります。ファイルの所有権とオフライン作業については、ローカルファーストが優先されます。多くの人は、ローカルでドラフトを作成し、Git 経由で同期するという両方を使用しています。

## 悩まずに選択する

今月、あなたにとって最も摩擦を取り除くものから始めてください。 .tex ファイルは、テーブル上のすべてのツール間で移植可能です。この移植性はプレーンテキスト記述の本当の利点であり、[LaTeX vs Word](/learn/latex-vs-word/) で説明されています。次に、[最初のドキュメント](/learn/first-document/) を作成し、作業とともにツールボックスを拡張します。
