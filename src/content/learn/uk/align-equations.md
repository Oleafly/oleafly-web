# Багаторядкові рівняння, які вибудовуються

Виведення кількох кроків найкраще виглядає зі знаками рівності, складеними в один стовпець, щоб око могло відстежувати, що змінилося від рядка до рядка. Пакет `amsmath` забезпечує середовище `align` для цього, а також невелику родину родичів для випадків, коли вирівнювання не те, що вам потрібно.

```latex
\usepackage{amsmath}
\begin{align}
 a &= b + c \\
 d &= e + f + g
\end{align}
```

## Як читається align

Кожен рядок — це одне рівняння, яке закінчується `\\`; останній рядок не потребує. `&` позначає точку вирівнювання, а `&` кожного рядка потрапляє в той самий стовпець. Розміщення `&` безпосередньо перед знаком рівності є стандартною звичкою, тому знаки рівності складаються, а ліві сторони звисають ліворуч. Кожен рядок отримує власний номер рівняння; напишіть `align*` до числа none або додайте `\notag` до окремих рядків, щоб пропустити лише їх, як показано в [числах і покажчиках для рівнянь](/learn/number-equations/).

Середовище відкриває математику відображення самостійно, тому воно не повинно знаходитися всередині `\[ ... \]` або `$ ... $`; вкладення його в інше математичний середовище призводить до незрозумілих помилок.

## Сім'я

| Env | Призначення |
| --- | --- |
| `вирівняти` | Кілька рядків, вирівняних |
| `вирівняти*` | Те саме, без номера |
| `збирати` | Кілька рядків, по центру |
| `розділити` | Багаторядкове одне рівняння номер |
| `багаторядковий` | Довге рівняння, розбите без вирівнювання |

`gather` обробляє кілька рівнянь без спільної точки вирівнювання; він центрує кожен рядок і нумерує кожен. `split` створює одне багаторядкове рівняння під одним числом і має знаходитися всередині `equation`. `multline` розриває одну занадто довгу формулу без вирівнювання, перший рядок зміщує ліворуч, а останній — праворуч. Останні два детально розглядаються в [рівняннях, які не підходять](/learn/break-long-equations/).

Два питання вирішують, який використовувати: лінії є окремими рівняннями чи одним несправним рівнянням і чи є точка вирівнювання, яку варто об’єднати? Окремо та вирівняно: `align`. Окремо та по центру: `зібрати`. Одинарний і вирівняний: `split`. Одинарний і невирівняний: `multline`.

## Типові помилки

Рядок без `&` все ще компілюється, але центрується незалежно, і нічого не вирівнюється. Два `&` на рядку починають другу пару стовпців, яка `align` читається як другий стовпець рівнянь, розташованих поруч; якщо ваш вихід містить рівняння, що йдуть праворуч, порахуйте амперсанди. Кінцевий символ `\\` у останньому рядку додає порожній рядок, який відображається як непарний вертикальний пробіл під блоком. Введіть триетапну деривацію на [живому ігровому майданчику](/live/), щоб спостерігати за вирівнюванням.
