# 맞지 않는 방정식

조만간 파생은 텍스트 블록보다 더 넓은 방정식을 생성하며 LaTeX는 어디에서 중단할지 추측하기보다는 여백으로 실행되도록 합니다. 두 가지 `amsmath` 환경을 사용하면 구분선을 직접 배치할 수 있습니다. 하나의 긴 표현을 위한 `multiline`과 정렬 상태를 유지해야 하는 구분선을 위한 `split`입니다.

## 여러 줄

```latex
\begin{multline}
 a + b + c + d + e + f \\
 + g + h + i + j
\end{multline}
```

'multiline'은 자연스러운 정렬 지점이 없는 하나의 긴 수식에 적합합니다. `\\`로 나누기를 선택하면 환경이 레이아웃을 처리합니다. 첫 번째 줄은 왼쪽으로 설정되고 마지막 줄은 오른쪽으로 설정되며 중간 줄은 중앙에 배치됩니다. 전체 표현식은 마지막 줄에 배치된 하나의 방정식 번호를 갖습니다. 관례는 이항 연산자 앞에서 중단하는 것이므로 '+'는 연속 행을 열고 독자는 식이 계속되는 것을 한눈에 볼 수 있습니다.

## 나뉘다

```latex
\begin{equation}
\begin{split}
 a &= b + c \\
 &\quad + d + e
\end{split}
\end{equation}
```

`split`도 단일 숫자를 생성하지만 `align`과 같은 방식으로 선을 정렬하며 `&`는 정렬 지점을 표시합니다. 이는 독립형 환경이 아닙니다. 이는 '방정식'이나 숫자를 제공하는 다른 표시 환경 내에 있습니다. 여기서 '&'는 첫 번째 줄의 등호 앞에 위치하며 연속은 빈 정렬 지점인 '&\quad'로 시작하고 공백의 쿼드가 뒤따릅니다. 따라서 두 번째 줄은 등호 바로 뒤에 들여쓰기됩니다. 들여쓰기는 독자에게 이것이 새로운 방정식이 아니라 여전히 우변임을 알려줍니다.

## 둘 중 선택하기

방정식이 정렬할 가치가 있는 구조가 없는 하나의 긴 합계인 경우 '멀티라인'을 사용하세요. 연속 내용이 중단되어야 하는 등호가 있는 경우 `split`을 사용하세요. 완전히 분리된 방정식이 여러 개 있는 경우 둘 다 옳지 않습니다. 이는 [일렬로 정렬되는 여러 줄 방정식](/learn/align-equations/)에서 다루는 '정렬'을 위한 작업입니다.

둘 중 하나를 선택하기 전에 수학을 다시 작성하는 것을 고려해보세요. 이전 문장에서 하위 표현식의 이름을 지정하거나 인수분해하거나 두 개의 방정식으로 분할하면 폭이 제어되고 읽기도 더 좋아지는 경우가 많습니다. 유형을 지나치게 축소하는 것이 좋습니다. 꼭 맞게 꽉 조인 디스플레이는 거의 항상 깨끗하게 깨뜨린 것보다 읽기가 더 나쁩니다.

알아야 할 한 가지 오류: 둘러싸는 `equation` 없이 `split`을 단독으로 사용하면 "Package amsmath Error"와 함께 중지됩니다. 먼저 래핑한 다음 컴파일하세요. 두 환경 모두 [라이브 놀이터](/live/)에서 빠르게 실험해 볼 수 있습니다.
