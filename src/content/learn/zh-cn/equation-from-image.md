# 白板照片来源

白板上的推导、课堂笔记的扫描页、无法复制的 PDF 中的方程式：用手将数学重新输入到 LaTeX 中既缓慢又容易出错。现代工具可以通过照片完成大部分工作。现在转换确实很好，但请将输出视为草稿，而不是完成的转录。下面的工作流程是围绕它构建的。

## 从更好的照片开始

图像质量比工具选择更能决定结果。直线拍摄而不是倾斜拍摄，因为倾斜的基线会使下标和上标变得模糊。获得均匀的照明，而不会在板上产生眩光，并严格裁剪到您想要的单个方程式，因为周围的图表和杂散标记会变成幻觉符号。如果一张照片有三个方程，请将其裁剪为三张图像，然后一次转换它们；每个方程的结果始终优于一次页面的结果。

## 使用您拥有的工具进行转换

三种工具可以完成这项工作。专用方程式 OCR 服务在干净的输入下是准确的。一般多模态模型接受聊天中的图像并在询问时返回 LaTeX，并且您可以回复“第二个下标应该是 j，而不是 i”以获得正确的版本。 Oleafly 内置了图像到 LaTeX，通过您自己的 API 密钥与您配置的任何提供程序一起运行，因此片段可以从屏幕截图转到源代码，而无需离开编辑器。请参阅[AI设置](/docs/ai-setup/)进行配置。在明确的输入下，三种方法会收敛，这就是为什么上面的照片建议比工具决策更重要的原因。

## 立即编译

将输出粘贴到“equation”环境中的文档中，并在执行其他操作之前进行编译。转换错误分为两种，编译器会为您捕获第一种：不平衡的大括号、不匹配的“\left”和“\right”分隔符以及未知命令都会严重失败，并且修复是机械的。 [缺少美元符号](/learn/missing-dollar/) 涵盖了这些故障中最常见的情况。

## 然后校对数学

第二种错误编译完美，错误。逐个符号地对照原始符号读取渲染的方程，特别注意转换可靠的地方：下标和上标，其中小字形模糊在一起，“x_i”变成“x_j”；素数和帽子，消失或迁移；相似对，例如“1”、“l”和“I”或“\rho”和“p”；以及总和和积分的界限。这些正是改变公式含义同时又使其在印刷上合理的细节。每个方程两分钟的比较就是全部成本，而且比审稿人在印刷品中发现错误的索引要便宜得多。
