# Получите рабочий TeX на любой ОС

Для локальной записи LaTeX требуется система TeX: от нее зависит движок, который компилирует исходный код и тысячи документов пакетов. Есть два разумных способа получить его. Одно из них — приложение со встроенным движком, компиляция которого занимает минуты. Другой — полный дистрибутив TeX, который устанавливает полный набор инструментов командной строки, который может использовать любой редактор. Оба пути заканчиваются в одном месте: файл `.tex` превращается в PDF на вашем компьютере.

## Путь A: приложение с включенным движком

Загрузите [Oleafly](https://github.com/Oleafly/Oleafly/releases/latest) для Mac, Windows или Linux. Он включает в себя движок Tectonic, поэтому нет необходимости управлять отдельной установкой TeX: вы открываете приложение, создаете проект и компилируете. Когда в документе используется несуществующий пакет, Tectonic извлекает его по требованию, для чего требуется сетевое соединение при первом использовании данного пакета и ничего после этого. Этот путь подходит всем, кто хочет писать статьи, а не администрировать установку TeX, и он оставляет на диске обычные файлы `.tex` и `.bib`, которые может прочитать любой другой инструмент.

## Путь Б: полный дистрибутив TeX

При установке дистрибутива в качестве системных команд вы получаете `pdflatex`, `xelatex`, `lualatex` и менеджер пакетов. На Mac установите MacTeX, который представляет собой пакет TeX Live для macOS; если загрузка нескольких гигабайт нежелательна, BasicTeX — это небольшое ядро, которое вы расширяете с помощью TeX Live Utility по мере необходимости. В Windows MiKTeX является распространенным выбором и может устанавливать недостающие пакеты на лету во время компиляции, в то время как TeX Live работает одинаково хорошо. В Linux установите «texlive-full» из менеджера пакетов для всего сразу или меньшую схему, например «texlive-latex-extra», плюс инструмент «tlmgr» для добавления пакетов позже. Ожидайте, что полная установка займет некоторое время и несколько гигабайт диска.

## Проверьте установку

Откройте терминал и запросите у движка его версию:

```bash
pdflatex --version
# or
xelatex --version
```

Баннер версии означает, что набор инструментов находится на вашем пути и готов. Ошибка, сообщающая, что команда не найдена, обычно означает, что изменения установщика в вашем PATH еще не вступили в силу; перезапуск терминала или выход из системы и повторный вход в Windows решает эту проблему.

## Какой путь выбрать

Выберите приложение, если вы только начинаете или просто хотите найти кратчайший путь к скомпилированному PDF-файлу. Выберите полный дистрибутив, если вам нужны определенные движки, сборки для командной строки или интеграция с существующим редактором. Они сосуществуют без конфликта, поэтому начинать с пути А и добавлять позже путь Б ничего не стоит. В любом случае, следующий шаг один и тот же: скомпилируйте [ваш первый документ](/learn/first-document/).
