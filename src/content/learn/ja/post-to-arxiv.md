# 最初の arXiv プレプリントを投稿する

arXiv に投稿すると、あなたの作品が公開され、引用可能になり、タイムスタンプが付けられます。このプロセスには、初めて誰もが驚くようないくつかの癖があります。 [arXiv とは](/learn/what-is-arxiv/) をまだ読んでいない場合は、そこから始めてから戻ってきてください。

## 推薦: ドアの用心棒

ほとんどのカテゴリの新規投稿者は、実績のある arXiv 著者からの承認が必要です。アカウントで学術メールを使用しており、arXiv の履歴を持つ共著者がいる場合、これは多くの場合自動的または迅速に行われます。それ以外の場合は、アドバイザーまたは共著者に問い合わせてください。システムは、それらを送信するための承認コードを提供します。投稿予定の夜ではなく、数日前にこれを整理してください。

## カテゴリを選択してください

arXiv は、「cs.LG」 (機械学習)、「cs.CL」 (計算と言語)、「math.OC」 (最適化)、「stat.ML」などのモデレートされたカテゴリに編成されています。 1 つのプライマリ カテゴリと、必要に応じていくつかのセカンダリ カテゴリを選択します。引用した論文がどこに掲載されているかを調べて、フォローしてください。プライマリ カテゴリによって、どのメーリング リストが論文を発表するかが決まり、誰が最初に論文を閲覧するかが決まります。

## arXiv は PDF ではなくソースを必要としています

これが大きなものです。論文が LaTeX で作成された場合、arXiv には PDF だけでなく LaTeX ソースが必要です。彼らの AutoTeX システムはそれをサーバー上でコンパイルし、そのビルドを読者がダウンロードします。結果：

- 論文に必要なすべてのファイルがアップロードに含まれている必要があります: 図、`.bbl` ファイル (arXiv は BibTeX を実行しないので、生成された `.bbl` を含めてください)、標準ではないスタイル ファイル。
- 彼らのシステムでコンパイルできない場合は、コンパイルされるまで修正します。

## まずソースをクリーンアップします

コメントはソースと一緒に発送され、誰でもダウンロードできます。 「% TODO: この主張は真実ですか?」というメモの下書きは公開されます。アップロードする前に:

- [ ] コメントを削除します。 「arxiv-latex-cleaner」ツールはこれを自動化し、未使用のファイルも削除します。
- [ ] 未使用の図と古いセクションを削除します
- [ ] 恥ずかしいファイル名をチェックします (`final_v7_ACTUALLY_final.tex`)
- [ ] クリーンなコピーを一度最初からコンパイルします

Git ベースのプロジェクトで作業することは、ここで役に立ちます。Oleafly では、ZIP をエクスポートする前に、チェックポイントから分岐し、ソースをクリーンアップし、オリジナルとの差分を確認して、実質的な変更が何もないことを確認できます。

## ライセンス

arXiv はライセンスを選択するように求めます。最小限の arXiv のみのライセンスが一般的なデフォルトであり、ジャーナルに関するオプションが常に開かれています。 CC BY はより寛容です。論文が特定の出版社に宛てられている場合は、取り消し不可能なものを選択する前に、その出版社のプレプリント ポリシーを確認してください。

## アナウンスサイクルとその民間伝承

arXiv は、提出締め切りのある平日の固定スケジュールで、新しい論文をまとめて発表します。締め切り直後に提出された論文は次のリストの先頭に表示され、民間伝承の小規模な家内工業はリストのトップにある論文がより多くの注目を集めると主張している。多分。眠れなくなることはありません。優れた要約は、リストの位置よりもはるかに重要です。

## バージョン: v1、v2、および承認後

最初の投稿は v1 であり、それは永続的です。バージョンを追加することはできますが、削除することはできません。実際の改善が見られた場合は v2 を投稿します。通常は [ピアレビュー](/learn/peer-review-explained/) 後に承認されたバージョンです。受諾後、カメラ対応コンテンツで arXiv コピーを更新し (出版社のポリシーを尊重)、ジャーナル参照フィールドに DOI または会場を追加します。読者はきっと感謝してくれるでしょう。
