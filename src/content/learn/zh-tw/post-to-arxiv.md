# 發佈您的第一個 arXiv 預印本

發佈到 arXiv 可以讓您的作品公開、可引用並帶有時間戳。這個過程有一些奇怪之處，讓每個人第一次都感到驚訝。如果您還沒有閱讀過 [arXiv 是什麼](/learn/what-is-arxiv/)，請從那裡開始，然後再回來。

## 代言：門口的保鑣

大多數類別中的全新提交者都需要來自知名 arXiv 作者的認可。如果您的帳戶使用學術電子郵件並且您有具有 arXiv 歷史記錄的合著者，這通常是自動或快速的。否則，請詢問您的顧問或合著者；系統會為您提供一個背書代碼來發送它們。在你打算發文之前幾天而不是晚上就解決這個問題。

## 選擇您的類別

arXiv 被組織成經過審核的類別，例如「cs.LG」（機器學習）、「cs.CL」（計算和語言）、「math.OC」（最佳化）、「stat.ML」。您可以選擇一個主要類別，也可以選擇一些次要類別。尋找您引用的論文的即時位置，並關注它們。主要類別決定了哪個郵件清單公佈您的論文，因此它決定了誰首先看到它。

## arXiv 想要你的原始碼，而不是你的 PDF

這是最重要的。如果您的論文是使用 LaTeX 產生的，則 arXiv 需要 LaTeX 原始碼，而不僅僅是 PDF。他們的 AutoTeX 系統在他們的伺服器上編譯它，讀者可以下載該版本。結果：

- 您的論文所需的每個檔案都必須上傳：圖形、「.bbl」檔案（arXiv 不會為您執行 BibTeX，因此包括產生的「.bbl」）、非標準樣式檔案。
- 如果它不能在他們的系統上編譯，你就修復它直到它可以編譯。

## 首先清理你的來源

您的評論與您的來源一起提供，任何人都可以下載它。這份草稿說明「% TODO：這個說法是真的嗎？」將會被公開。上傳前：

- [ ] 刪除註釋。 “arxiv-latex-cleaner”工具可以自動執行此操作，並刪除未使用的檔案。
- [ ] 刪除未使用的圖形和舊部分
- [ ] 檢查是否有令人尷尬的檔案名稱（`final_v7_ACTUALLY_final.tex`）
- [ ] 從頭開始編譯清理後的副本一次

使用 Git 支援的專案可以在這方面有所幫助：在 Oleafly 中，您可以分支檢查點、清理原始程式碼並與原始版本進行比較，以在匯出 ZIP 之前確認沒有發生任何實質變更。

## 許可證

arXiv 要求您選擇一個許可證。僅限 arXiv 的最低許可證是常見的預設許可證，並讓您可以選擇期刊。 CC BY 較為寬鬆。如果論文要發送給特定的出版商，請在選擇任何不可撤銷的內容之前檢查他們的預印本政策。

## 公告週期及其民間傳說

arXiv 按固定的工作日時間表分批公佈新論文，並有提交截止時間。截止日期後立即提交的論文出現在下一個列表的頂部，而民間傳說中的小型家庭手工業聲稱列表頂部的論文會受到更多關注。或許。不要因此而失眠；好的摘要比列表位置更重要。

## 版本：v1、v2 以及接受後

您的第一篇文章是 v1，而且是永久的：您可以新增版本但永遠不能刪除它們。當您有真正的改進時發布 v2，通常是[同儕審查](/learn/peer-review-explained/) 之後接受的版本。接受後，使用可用於相機的內容更新 arXiv 副本（尊重出版商的政策），並在期刊參考欄位中添加 DOI 或地點。讀者會為此感謝你的。
