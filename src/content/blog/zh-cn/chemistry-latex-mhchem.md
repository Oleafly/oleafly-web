化学家通常出于以下两个原因之一出现在 LaTeX 中：该杂志坚持认为，
或者合作者已经这样做了。不管怎样，痛点看起来
熟悉：反应方案、同位素标签、条件表和
充满期刊和专利的参考书目。

本指南涵盖本科生报告到首次期刊提交。它将
不能取代复杂天然产品的 ChemDraw。它将保留手稿
以及与编译器战斗的实验部分。

## 与 mhchem 的反应

`mhchem` 是公式和反应的通常答案：

```latex
\usepackage[version=4]{mhchem}
\ce{CO2 + C -> 2CO}
\ce{^{14}C}
\ce{H2SO4}
\ce{Fe^2+ <=>[\ce{H2O}] Fe^3+}
```

固定版本 4，因此语法不会在合著者之间或 Overleaf 之间发生变化
和本地 TeX 安装。较长的演练：
[化学式](/学习/化学符号/)。

箭头上方和下方试剂的多步骤方案需要超过
内联`\ce`。 mhchem 处理公式；布局通常需要日志方案
环境或外部人物。不要死记硬背二十步全合成
进入一系列在线化学生产线。

## 结构：chemfig 或外部图纸

`chemfig` 在纯 TeX 中绘制简单的结构并保留所有内容
向量局部。复杂的天然产品几乎总是比 ChemDraw 更好，
Marvin 或类似的人，导出为 PDF，然后导出为“\includegraphics”。更喜欢矢量 PDF
在 PNG 屏幕截图上，使粘合线在打印和两列中保持清晰
布局。

按化合物 ID 命名文件 (`cmpd-12.pdf`)。保留可编辑的 ChemDraw 源代码
即使 git 只保存论文中的 PDF，也可以在实验室档案中保存。

## 实验部分和长表

条件表（温度、溶剂、产率、催化剂负载量）效果良好
对于数字列，使用 `booktabs` 和通常的 `siunitx` ：

```latex
\usepackage{booktabs,siunitx}
\begin{tabular}{l S S}
  \toprule
  {Entry} & {T / \degreeCelsius} & {Yield / \percent} \\
  \midrule
  1 & 25 & 72 \\
  \bottomrule
\end{tabular}
```

如果表的运行时间比页面长，请在截止日期之前切换到“longtable”
一周，不是在期刊抱怨 7pt 字体之后。标题应该说
“产量”意味着什么（分离、NMR、GC），因此读者不会猜测。

## 单位和光谱片段

选择一个单位样式并坚持使用：`siunitx`，或者手动`\mathrm`（如果组）
已经同意了。实验部分中的 NMR 和 HRMS 片段是
通常是带有仔细间距的纯文本。不要发明脆弱的宏语言
除非实验室已经共享一篇论文，否则将处于论文中间。

按照笔记本的方式报告有效数字。 LaTeX 会愉快地打印
如果您输入错误的精度。

## 方案与数字

许多化学期刊将方案（反应）与图形（图、
ORTEP，光谱）。使用日志类附带的环境（`scheme`，
`figure`)，因此编号与生产相匹配。与 `\ref` 交叉引用且稳定
标签（`sch:reduction`、`fig:ortep-1`）。

## 草稿的安全性

未发布的路线和行业合作伙伴将纯云编辑器变成了
政策问题，而不仅仅是便利问题。保留`.tex`和数字
因为磁盘上的普通文件用 Git 来说是无聊的。

[Oleafly](https://github.com/Oleafly/Oleafly/releases/latest) 是本地
研究编辑：捆绑编译器、项目范围的引用和引用检查、离线
仅散文上的拼写和语法（因此 `\ce` 和引用键不会被标记为
“打字错误”）、真正的 Git 检查点、仅通过批准进行编辑的可选 AI
差异。没有帐户。该草案不需要第三方编辑器即可存在。
网络用于包、引文查找或人工智能（如果您打开它们）。

## 引用正确的主要文献

化学参考书目非常依赖期刊和专利。从 Zotero 导出
或 EndNote 到具有稳定密钥的“.bib”中，然后在之前验证缺失的字段
提交：[BibTeX 验证器](/tools/bibtex-validator/)。空参考书目
几乎总是路径或后端错误，而不是丢失引用。

期刊风格不同（ACS、RSC、Springer）。使用参考书目风格
模板附带。不要将数字和作者年份粘在一起
序言。

＃＃ 合作

尽可能按人拥有部分。一个人拥有“.bib”。同意
mhchem 版本和结构导出格式预先提供。当多次实验
各个部分并行增长，每周编译完整的 PDF，以便集成
惊喜很早就出现了。

## 预提交清单

值得最后通过：

- mhchem 版本已固定；公式编译时不会发出任何警告
  忽略。
- 结构尽可能是矢量；复合 ID 跨文本、方案、
  和SI。
- 表格采用三规则样式；单位一致；标题中定义的产量
  或笔记。
- 方案/图编号与期刊类别相匹配。
- `.bib` 已验证；风格与模板相匹配。
- 敏感路由保留在本地文件夹中，并具有与实验室匹配的访问控制
  政策。

## SI 和期刊清单

许多化学期刊都会发布作者清单（图形分辨率、TOC
图形尺寸、化合物表征）。绘画前浏览一下 PDF
计划。对于管理员来说，错误的 TOC 图形纵横比是一个愚蠢的原因
拒绝。

## 支持信息

SI 通常有自己的模板或标题规则。保持 SI 源相同
repo 作为主要论文，文件名清晰。当期刊要求完整时
表征，检查正文中的每个化合物数字实际上
出现在 SI 中。

化学格式很繁琐，因为对象很密集。获取反应
右边的表格和实验部分读起来像是仔细的工作，而不是
从笔记本 PDF 粘贴。
