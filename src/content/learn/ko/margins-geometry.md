# 하나의 패키지에 마진이 있음

LaTeX의 기본 여백은 특히 A4 용지에서 엄청납니다. 이는 의도된 것입니다. 기본값은 약 66자의 편안한 줄 길이를 목표로 합니다. 이는 읽기에는 좋지만 대학 템플릿, 저널 또는 자신의 취향이 요구하는 경우는 거의 없습니다. 여섯 개의 하위 수준 길이를 수동으로 조정하는 대신 'geometry' 패키지로 페이지를 설정하고 원하는 레이아웃을 일반 용어로 설명합니다.

## 실제로 사용하게 될 두 가지 방법

```latex
\usepackage[margin=1in]{geometry}
% or
\usepackage[a4paper,top=2.5cm,bottom=2.5cm,left=2.5cm,right=2.5cm]{geometry}
```

첫 번째 형식은 빠른 형식입니다. `margin=1in`은 단일 옵션에서 네 개의 여백을 모두 1인치로 설정하고 기하학은 일치하도록 텍스트 너비와 높이를 다시 계산합니다. 이는 표준 "미국 논문" 모양이며 초안에 대한 합리적인 기본값입니다.

두 번째 형식은 모든 것을 설명합니다. 'a4paper'는 실제 용지 크기를 선언합니다(US Letter의 경우 'letterpaper' 사용). 이것이 없으면 기하학은 문서 클래스가 가정한 모든 것을 상속하므로 PDF 뷰어나 프린터가 기대하는 것과 일치하지 않을 수 있습니다. 'top', 'bottom', 'left', 'right' 옵션은 각 여백을 독립적으로 설정하므로 비대칭 레이아웃도 대칭 레이아웃만큼 쉽습니다. 단위를 자유롭게 혼합할 수 있습니다. `in`, `cm`, `mm`, `pt` 모두 작동합니다.

모든 것은 ``\begin{document}` 이전의 서문에서 발생합니다. 기하학은 옵션을 한 번 읽고 전체 페이지 레이아웃을 파생하므로 수동 조정보다 오류가 발생할 가능성이 적습니다.

## 인쇄된 사본의 제본 오프셋

문서를 인쇄하여 제본할 경우 텍스트가 책등까지 사라지지 않도록 내부 여백에 추가 공간이 필요합니다. 옵션에 '바인딩오프셋=0.5cm'을 추가하면 기하학이 각 페이지의 텍스트 블록을 바깥쪽으로 이동합니다. '양면' 문서에서는 왼쪽 페이지와 오른쪽 페이지 사이를 올바르게 교대하므로 손으로 오른쪽으로 이동하는 것은 지루합니다.

## 하지 말아야 할 것

이유를 알지 못하는 한 기하학을 수동 `\setlength{\textwidth}{...}`와 혼합하지 마십시오. LaTeX의 페이지 레이아웃은 상호의존적인 길이(`\textwidth`, `\oddsidemargin`, `\headheight` 및 친구들)의 웹이며 기하학은 이들 모두를 하나의 일관된 시스템으로 관리합니다. 지오메트리를 로드한 후 바로 하나의 길이를 변경하면 일반적으로 다른 길이가 일치하지 않게 되고 결국 페이지를 넘나드는 텍스트나 요청한 것과 다른 여백이 발생하게 됩니다. 문서 중간에 변경이 필요한 경우 기하학은 정확히 이를 위해 `\newgeometry{...}` 및 `\restoregeometry`를 제공합니다.

조정하기 전에 한 가지 주의 사항: 저널이나 컨퍼런스를 위해 글을 쓰는 경우 클래스 파일은 이미 필요한 여백을 인코딩하고 상단에 도형을 추가하면 제출 형식을 위반할 가능성이 높습니다. 논문, 메모, CV 등 레이아웃을 제어하는 ​​문서의 여백 조정을 저장하고 [문서 클래스](/learn/document-skeleton/)가 이미 제공하는 기능을 먼저 확인하세요.
