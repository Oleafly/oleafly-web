# 심볼 데스크 카드

이 페이지는 레슨이 아닌 참조 카드입니다. 대부분의 일상 수학을 다루는 악센트, 큰 연산자, 숫자 집합 및 구분 기호가 모두 한 곳에 있습니다. 여기의 모든 명령은 수학 모드에서만 작동하며 숫자 세트에는 프리앰블에 `\usepackage{amssymb}`가 필요합니다. 그리스 알파벳과 기본 관계에 대해서는 [그리스어 및 일상 기호](/learn/greek-letters/)를 참조하세요. 수학 모드 자체의 작동 방식을 알아보려면 [수학 모드 기본 사항](/learn/math-mode/)부터 시작하세요.

## 악센트

```latex
\hat{x} \bar{x} \tilde{x} \vec{x} \dot{x} \ddot{x}
\widehat{xyz} \overline{xyz}
```

| 명령 | 다음으로 렌더링 | 기존의 의미 |
| --- | --- | --- |
| ``모자{x}` | 곡절 부호가 있는 x | 추정량, 단위 벡터, 연산자 |
| ``\bar{x}` | 막대가 있는 x | 샘플 수단, 복합 접합체 |
| `\틸드{x}` | x에 물결표가 있음 | 근사치, 변환된 변수 |
| `\vec{x}` | x 화살표 | 벡터 |
| `\dot{x}`, `\ddot{x}` | 하나 또는 두 개의 점 | 1차 및 2차 파생상품 |
| ``\widehat{xyz}`, ``\overline{xyz}` | 뻗어 악센트 | 여러 글자로 된 표현에 대한 악센트 |

평범한 악센트는 한 글자에 맞습니다. 'wide' 및 'over' 변형은 중괄호 안에 있는 모든 내용을 확장합니다.

## 대형 사업자

```latex
\sum_{i=1}^n \prod_{i=1}^n \int_a^b \oint
\lim_{x \to 0} \max_{x} \inf_{x}
```

| 명령 | 의미 |
| --- | --- |
| `\sum_{i=1}^n` | 하한과 상한이 있는 합계 |
| `\prod_{i=1}^n` | 제품 |
| `\int_a^b` | 확실한 적분 |
| `\점` | 윤곽 적분 |
| `\lim_{x \to 0}` | 한도 |
| `\max_{x}`, `\inf_{x}` | 변수에 대한 최대, 최소 |

경계는 일반 아래 첨자 및 위 첨자 구문으로 첨부되며 한 문자보다 길면 중괄호로 묶입니다. 디스플레이 수학에서 합계, 곱 및 한계는 기호 위와 아래에 경계를 설정합니다. 적분은 측면에 유지됩니다. 이것이 표준 관례입니다.

## 숫자 세트

```latex
\mathbb{N} \mathbb{Z} \mathbb{Q} \mathbb{R} \mathbb{C}
```

칠판에 굵은 글씨로 표시된 자연수, 정수, 유리수, 실수, 복소수입니다. ``mathbb' 알파벳과 그 계열은 [Blackboard, script, Fraktur](/learn/mathbb-mathcal/)에서 다룹니다.

## 구분자

```latex
\left( \frac{a}{b} \right)
\left\{ x : x > 0 \right\}
\langle v, w \rangle
```

`\left` 및 `\right`는 구분 기호를 포함된 자료의 높이로 확장하므로 키가 큰 분수 주위의 괄호는 텍스트 높이에서 잘라내는 대신 이를 래핑합니다. 쌍으로 와야 합니다. 한 면만 표시하려면 '\right'로 닫으면 보이지 않는 파트너가 페어링을 만족합니다. 중괄호는 특수 문자이므로 집합 중괄호는 `\{` 및 `\}`로 작성됩니다. 내부 곱의 꺾쇠 괄호는 `\langle` 및 `\rangle`이며, 키보드의 보다 작음 및 보다 큼 기호는 절대로 잘못된 모양과 간격을 갖는 관계 기호입니다.
