# 導數和積分

微積分錶示法是 LaTeX 開始立足的地方。堆疊導數分數、帶極限的積分符號、變數上的點都是一兩個指令。本課程涵蓋了一些命令，這些命令幾乎可以產生您將編寫的所有導數和積分，以及將拋光紙與草稿分開的小間距習慣。

## 衍生品

```latex
\frac{dy}{dx}
\frac{\partial f}{\partial x}
\nabla f \quad \nabla^2 f
f'(x) \quad \dot{x}
```

普通的導數只是一個分數：「\frac{dy}{dx}」將「dy」堆疊在「dx」上。對於偏導數，將“d”替換為“\partial”，這將列印捲曲的偏分符號； `\frac{\partial f}{\partial x}` 是標準形式。高階偏音遵循相同的模式，例如 `\frac{\partial^2 f}{\partial x \partial y}`。

`\nabla` 給予梯度符號，由於它是一個普通符號，您可以像其他符號一樣提高它：`\nabla^2 f` 表示拉普拉斯算子。對於緊湊表示法，「f'(x)」直接使用撇號鍵，LaTeX 將一個或多個「'」標記轉換為適當升起的質數。牛頓時間導數的點表示法來自重音指令“\dot{x}”和“\ddot{x}”，它們在參數上放置一兩個點。

風格選擇：有些期刊希望微分「d」直立，寫「\mathrm{d}」。如果您這樣做，請在序言中定義一次 `\newcommand{\dd}{\mathrm{d}}` 並編寫 `\frac{\dd y}{\dd x}` 以便稍後可以翻轉選擇。

## 積分

```latex
\int_a^b f(x)\,dx
\iint_D f\,dA
```

`\int` 是積分符號，熟悉的下標和上標文法附加了限制：`_a` 表示下限，`^b` 表示上限。在內聯數學中，限制位於符號旁邊，以保持行緊湊；在顯示數學中，它們仍然位於積分符號旁邊（與總和不同），這是標準約定。二重和三重積分有自己的指令“\iint”和“\iiiint”，它們正確地間隔重複的符號，以及用於輪廓積分的“\oint”。

`dx` 之前的 `\,` 是一個薄空格。如果沒有它，「f(x)dx」會將被積函數直接運行到微分中，眼睛必須理清它們。薄空間是廣泛遵循的約定，因此請養成習慣：被積函數，然後是“\,”，然後是微分。

## 嘗試一下，常見錯誤

當您在 [live Playground](/live/) 中鍵入時，這些片段就會呈現，這是在派生堆疊進入文件之前檢查派生堆疊的快速方法；如果「$」和「\[」分隔符號仍然是新的，請參閱[數學模式基礎知識](/learn/math-mode/)。

這裡最常見的錯誤是在顯示數學中輸入帶有斜線的“d/dx”樣式導數，其中需要堆疊的“\frac”，或者忘記多字符限制上的大括號：“\int_a^b+1”僅在上標中放置“b”。寫入 `\int_a^{b+1}` 以便引發整個表達式。
