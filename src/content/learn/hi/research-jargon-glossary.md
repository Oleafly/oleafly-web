# शोध शब्दजाल शब्दावली

शोधकर्ता एक बोली बोलते हैं। कोई भी आपको शब्दकोश नहीं देता है, इसलिए यह यहाँ है: वे शब्द जो आप अपने पहले वर्ष में सुनेंगे, प्रत्येक पंक्ति में। अभी स्किम करें, जब भी कोई मीटिंग आपको भ्रमित कर दे तो वापस लौट आएं।

## A से Z

| अवधि | मतलब |
| --- | --- |
| सार | एक पेपर के शीर्ष पर 150 से 250 शब्दों का सारांश; अक्सर लोग केवल वही भाग पढ़ते हैं |
| एओई | पृथ्वी पर कहीं भी: एक समयसीमा समयक्षेत्र, जिसका अर्थ है कि ग्रह पर अंतिम स्थान आधी रात तक पहुंचने तक आपके पास समय है |
| एपीसी | आलेख प्रसंस्करण शुल्क, सोने के लिए शुल्क [ओपन एक्सेस](/learn/open-access-doi-explained/) प्रकाशन |
| कलाकृति | किसी पेपर के पीछे का कोड, डेटा या सामग्री, कभी-कभी बैज के लिए औपचारिक रूप से मूल्यांकन किया जाता है
| आर्क्सिव | बड़ा मुफ़्त [प्रीप्रिंट सर्वर](/learn/what-is-arxiv/), उच्चारित "संग्रह" |
| कैमरा-तैयार | स्वीकृत पेपर का अंतिम, प्रकाशक-स्वरूपित संस्करण; यह नाम कैमरों के शामिल होने से पहले का है |
| उद्धरण | पूर्व कार्य के लिए एक औपचारिक सूचक; शैक्षणिक ऋण की इकाई भी |
| सीएफपी | कागजात के लिए कॉल करें: स्थल की विषय, समय सीमा और नियमों की घोषणा |
| संबंधित लेखक | सूचीबद्ध लेखक जो पेपर के बारे में सभी ईमेल संभालता है |
| डेस्क अस्वीकार | किसी भी समीक्षा से पहले संपादक या अध्यक्षों द्वारा अस्वीकृति, आमतौर पर दायरे या नियम के उल्लंघन के लिए |
| डबल ब्लाइंड | समीक्षा करें जहां लेखक और समीक्षक एक-दूसरे से छिपे हुए हैं, देखें [सहकर्मी समीक्षा, डिकोडेड](/सीखें/सहकर्मी-समीक्षा-व्याख्या/) |
| डीओआई | किसी पेपर के लिए एक स्थायी आईडी, जैसे 10.1145/xxxx; उद्धृत करने का विश्वसनीय तरीका |
| और अन्य. | लैटिन "और अन्य"; "स्मिथ एट अल।" मतलब स्मिथ प्लस बाकी लेखक सूची |
| एच-सूचकांक | एक शोधकर्ता मीट्रिक: प्रत्येक में कम से कम एच उद्धरण वाले एच पेपर; संदेह के साथ व्यवहार करें |
| प्रभाव कारक | किसी पत्रिका के लिए प्रति पेपर औसत हालिया उद्धरण; एक प्रतिष्ठा प्रतिनिधि, संदेह के साथ भी व्यवहार करें |
| आईआरबी | संस्थागत समीक्षा बोर्ड: आचार समिति जिसे मनुष्यों से जुड़े अध्ययनों को मंजूरी देनी होगी |
| मुख्य वक्ता | सम्मेलन दिवस की शुरुआत करने वाली बड़ी आमंत्रित वार्ता |
| लिट समीक्षा | किसी विषय पर मौजूदा कार्य को पढ़ना और सारांशित करना |
| एलएनसीएस |स्प्रिंगर की पीली कार्यवाही श्रृंखला, देखें [ACM, IEEE, और मित्र](/learn/acm-ieee-and-friends/) |
| प्रमुख संशोधन | जर्नल का फैसला: पर्याप्त सुधारों की आवश्यकता, फिर पुनः समीक्षा |
| नवीनता | क्या कार्य वास्तव में कुछ नया करता है; समीक्षकों की पसंदीदा कुल्हाड़ी |
| पीसी | कार्यक्रम समिति: एक सम्मेलन के लिए समीक्षक पूल |
| पीआई | प्रधान अन्वेषक: प्रोफेसर जो प्रयोगशाला का नेतृत्व करता है और अनुदान रखता है |
| पोस्टर | एक मुद्रित सारांश जिसे आप सम्मेलन सत्र में उसके बगल में खड़े होकर प्रस्तुत करते हैं |
| प्रीप्रिंट | सहकर्मी समीक्षा से पहले सार्वजनिक रूप से साझा किया गया एक पेपर |
| कार्यवाही | किसी सम्मेलन के स्वीकृत पत्रों का प्रकाशित संग्रह |
| खंडन | निर्णय से पहले समीक्षाओं पर लेखकों की संक्षिप्त प्रतिक्रिया |
| सम्बंधित कार्य | पेपर अनुभाग आपके काम को पूर्व पेपरों के बीच स्थान देता है |
| प्रतिलिपि प्रस्तुत करने योग्यता | क्या अन्य लोग आपके काम को दोबारा शुरू कर सकते हैं और समान परिणाम प्राप्त कर सकते हैं |
| एसआईजी | विशेष रुचि समूह; ACM के उपसमुदाय (SIGPLAN, SIGGRAPH) |
| सिंगल ब्लाइंड | समीक्षा करें जहां समीक्षक लेखकों को जानते हैं लेकिन इसके विपरीत नहीं |
| सबमिशन संख्या | समीक्षा के दौरान आपके पेपर की अनाम आईडी; आप इसे अनायास ही याद कर लेंगे |
| अनुपूरक सामग्री | पेपर के साथ प्रस्तुत अतिरिक्त परिशिष्ट, साक्ष्य या वीडियो |
| सर्वेक्षण | संपूर्ण अनुसंधान क्षेत्र का मानचित्रण करने वाला एक पेपर |
| स्थान | जहां भी पेपर प्रकाशित होते हैं, वहां देखें [पत्रिकाएं, सम्मेलन और कार्यशालाएं](/सीखें/पत्रिकाएं-बनाम-सम्मेलन/) |
| रिकार्ड का संस्करण | एक पेपर की आधिकारिक प्रकाशित प्रति |

## इसका उपयोग कैसे करें

इसे याद मत करो. इसे बुकमार्क करें, फिर कुछ वास्तविक पढ़ें: [पेपर एनाटॉमी टूर] (/ सीखें / पेपर-एनाटॉमी-टूर /) इन शब्दों को उनके प्राकृतिक आवास में दिखाता है, और [वास्तव में एक शोध पत्र क्या है] (/ सीखें / एक शोध-पेपर क्या है /) बड़े शब्दों को एक साथ जोड़ता है।
